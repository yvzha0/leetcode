## [1695. 删除子数组的最大得分](https://leetcode.cn/problems/maximum-erasure-value/)

### 题目

给你一个正整数数组 `nums` ，请你从中删除一个含有 **若干不同元素** 的子数组**。**删除子数组的 **得分** 就是子数组各元素之 **和** 。

返回 **只删除一个** 子数组可获得的 **最大得分** *。*

如果数组 `b` 是数组 `a` 的一个连续子序列，即如果它等于 `a[l],a[l+1],...,a[r]` ，那么它就是 `a` 的一个子数组。

 

**示例 1：**

```
输入：nums = [4,2,4,5,6]
输出：17
解释：最优子数组是 [2,4,5,6]
```

**示例 2：**

```
输入：nums = [5,2,1,2,5,2,1,2,5]
输出：8
解释：最优子数组是 [5,2,1] 或 [1,2,5]
```

 

**提示：**

- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 104`

 

### 题解

#### 思路总结

利用**滑动窗口 + HashSet**寻找元素互不重复且元素和最大的连续子数组。

维护一个合法窗口，保证窗口中的所有元素都不重复：

- `set` 保存当前窗口中的元素。
- `l` 表示窗口左边界。
- `sum` 表示当前窗口元素和。
- 遍历到当前元素 `num` 时，如果它已经存在于窗口中，就不断移动左边界，并同步删除窗口左侧元素，直到 `num` 不再重复。
- 然后将当前元素加入窗口，并使用新的窗口和更新最大得分 `ans`。

由于数组元素全部为正数，合法窗口越长通常越有利，因此每次消除重复后都可以直接用当前窗口和更新答案。

整体时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **初始化窗口状态：** 创建 `set` 保存当前窗口元素，设置 `l = 0`、`sum = 0`、`ans = 0`。
2. **从左向右遍历数组：** 依次处理当前元素 `num`。
3. **判断是否出现重复：** 如果 `set` 中已经存在 `num`，说明当前窗口加入该元素后会出现重复。
4. **收缩窗口左边界：** 持续删除 `nums[l]`，同时从 `sum` 中减去对应值，并执行 `l++`。
5. **消除重复元素：** 当 `set` 中不再包含 `num` 时，当前窗口已经重新满足元素互不相同的条件。
6. **加入当前元素：** 将 `num` 加入 `set`，并累加到 `sum`。
7. **更新最大得分：** 使用当前合法窗口的 `sum` 更新 `ans`。
8. **返回最终答案：** 遍历结束后返回最大得分 `ans`。

```java
class Solution {
    public int maximumUniqueSubarray(int[] nums) {
        Set<Integer> set = new HashSet<>();
        int l = 0;
        int sum = 0;
        int ans = 0;
        for (int num : nums) {
            while(set.contains(num)){
                set.remove(nums[l]);
                sum -= nums[l];
                l++;
            }
            set.add(num);
            sum += num;
            ans = Math.max(ans, sum);
        }
        return ans;
    }
}
```

## [1658. 将 x 减到 0 的最小操作数](https://leetcode.cn/problems/minimum-operations-to-reduce-x-to-zero/)

### 题目

给你一个整数数组 `nums` 和一个整数 `x` 。每一次操作时，你应当移除数组 `nums` 最左边或最右边的元素，然后从 `x` 中减去该元素的值。请注意，需要 **修改** 数组以供接下来的操作使用。

如果可以将 `x` **恰好** 减到 `0` ，返回 **最小操作数** ；否则，返回 `-1` 。

 

**示例 1：**

```
输入：nums = [1,1,4,2,3], x = 5
输出：2
解释：最佳解决方案是移除后两个元素，将 x 减到 0 。
```

**示例 2：**

```
输入：nums = [5,6,7,8,9], x = 4
输出：-1
```

**示例 3：**

```
输入：nums = [3,2,20,1,1,3], x = 10
输出：5
解释：最佳解决方案是移除后三个元素和前两个元素（总共 5 次操作），将 x 减到 0 。
```

 

**提示：**

- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 104`
- `1 <= x <= 109`

### 题解

#### 思路总结

当前实现把问题转换为**寻找和为 `sum - x` 的最长连续子数组**。因为最终只能从数组左右两端删除元素，所以删除结束后留下来的部分一定是一段连续子数组。

设数组总和为 `sum`，删除元素总和必须等于 `x`，因此保留下来的连续子数组之和必须等于：

```
sum - x
```

而删除次数最少，就等价于**保留下来的连续子数组长度最长**。由于题目保证所有 `nums[i] > 0`，可以使用滑动窗口在线性时间内找到这个最长子数组。

------

#### 解题步骤

1. **计算数组总和：** 得到所有元素之和 `sum`。
2. **计算目标和：** 设置 `target = sum - x`，表示需要保留下来的连续子数组之和。
3. **判断无解情况：** 如果 `target < 0`，说明整个数组的和都小于 `x`，返回 `-1`。
4. **处理全部删除情况：** 如果 `target == 0`，说明必须删除整个数组，返回 `n`。
5. **初始化滑动窗口：** 使用 `left` 表示左边界，`right` 表示右边界，`windowSum` 表示当前窗口和。
6. **扩展右边界：** 每次把 `nums[right]` 加入窗口。
7. **缩小窗口：** 当 `windowSum > target` 时不断移动 `left`，直到窗口和不大于目标值。
8. **更新最长长度：** 当 `windowSum == target` 时，更新 `maxLen`。
9. **计算最终答案：** 如果存在合法窗口，返回 `n - maxLen`，否则返回 `-1`。

```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int sum = 0;
        int n = nums.length;
        for(int num : nums){
            sum += num;
        }
        int target = sum - x;
        if(target < 0){
            return -1;
        }
        if(target == 0){
            return n;
        }
        int ans = n;
        sum = 0;
        int l = 0;
        for(int r = 0; r < n; r++){
            sum += nums[r];
            while(sum > target){
                sum -= nums[l];
                l++;
            }
            if(sum == target){
                ans = Math.min(ans, n - (r - l + 1));
            }
        }

        return ans == n ? -1 : ans;
    }
}
```

## [1234. 替换子串得到平衡字符串](https://leetcode.cn/problems/replace-the-substring-for-balanced-string/)

### 题目

有一个只含有 `'Q', 'W', 'E', 'R'` 四种字符，且长度为 `n` 的字符串。

假如在该字符串中，这四个字符都恰好出现 `n/4` 次，那么它就是一个「平衡字符串」。

 

给你一个这样的字符串 `s`，请通过「替换一个子串」的方式，使原字符串 `s` 变成一个「平衡字符串」。

你可以用和「待替换子串」长度相同的 **任何** 其他字符串来完成替换。

请返回待替换子串的最小可能长度。

如果原字符串自身就是一个平衡字符串，则返回 `0`。

 

**示例 1：**

```
输入：s = "QWER"
输出：0
解释：s 已经是平衡的了。
```

**示例 2：**

```
输入：s = "QQWE"
输出：1
解释：我们需要把一个 'Q' 替换成 'R'，这样得到的 "RQWE" (或 "QRWE") 是平衡的。
```

**示例 3：**

```
输入：s = "QQQW"
输出：2
解释：我们可以把前面的 "QQ" 替换成 "ER"。 
```

**示例 4：**

```
输入：s = "QQQQ"
输出：3
解释：我们可以替换后 3 个 'Q'，使 s = "QWER"。
```

 

**提示：**

- `1 <= s.length <= 10^5`
- `s.length` 是 `4` 的倍数
- `s` 中只含有 `'Q'`, `'W'`, `'E'`, `'R'` 四种字符

### 题解

#### 思路总结

当前实现采用**滑动窗口**， `count` 的含义为：**当前待替换窗口之外，四种字符分别还剩多少个**。

当右指针 `r` 扩展时，将 `s[r]` 从窗口外计数中减去；当四种字符在窗口外的数量都不超过 `target = n / 4` 时，说明窗口外已经满足平衡字符串的上限要求，因此当前窗口内部一定可以通过替换补齐缺少的字符。此时不断右移 `l`，寻找更短的合法窗口。

------

#### 解题步骤

1. **统计字符数量：** 统计 `'Q'`、`'W'`、`'E'`、`'R'` 在整个字符串中的出现次数。
2. **计算目标数量：** 每种字符最终都应该出现 `n / 4` 次。
3. **判断初始状态：** 如果四种字符都已经等于目标数量，直接返回 `0`。
4. **扩展滑动窗口：** 将 `s[r]` 放入待替换区域，因此从窗口外计数中减去一次。
5. **判断窗口是否合法：** 如果窗口外四种字符数量都不超过 `target`，说明当前窗口可以通过替换解决所有不平衡。
6. **更新最短长度：** 使用 `r - l + 1` 更新答案。
7. **收缩左边界：** 将 `s[l]` 重新放回窗口外，对应计数加一，然后右移 `l`。
8. **返回最小窗口：** 遍历结束后返回 `ans`。

```java
class Solution {
    public int balancedString(String s) {
        int[] count = new int[4];
        int n = s.length();
        int target = n / 4;
        for(char c : s.toCharArray()){
            count[index(c)]++;
        }
        if(count[0] == target && count[1] == target && count[2] == target && count[3] == target){
            return 0;
        }
        int l = 0;
        int ans = n;
        for(int r = 0; r < n; r++){
            count[index(s.charAt(r))]--;
            while(count[0] <= target && count[1] <= target && count[2] <= target && count[3] <= target){
                ans = Math.min(ans, r - l + 1);
                count[index(s.charAt(l))]++;
                l++;
            }
        }
        return ans;
    }

    private int index(Character c){
        return switch (c) {
            case 'Q' -> 0;
            case 'W' -> 1;
            case 'E' -> 2;
            default -> 3;
        };
    }
}
```

## [1093. 大样本统计](https://leetcode.cn/problems/statistics-from-a-large-sample/)

### 题解

#### 思路总结

当前实现是基于**计数数组统计五个统计量**。由于 `count[i]` 已经表示数值 `i` 出现了多少次，因此不需要真正还原并排序原始样本，只需要扫描 `0 ~ 255` 即可计算最小值、最大值、平均值、众数和中位数。

当前代码整体逻辑正确。最小值和最大值通过两端扫描得到；众数通过最大频次得到；平均值按照 `i * count[i]` 的贡献计算；中位数则通过累计频次找到排序后的中间位置。

------

#### 解题步骤

1. **寻找最小值：** 从 `0` 开始找到第一个 `count[i] > 0` 的位置。
2. **寻找最大值：** 从 `255` 开始向左找到第一个 `count[i] > 0` 的位置。
3. **统计样本数量：** 累加所有 `count[i]` 得到样本总数。
4. **寻找众数：** 找到出现次数最大的 `count[i]`，对应的 `i` 就是众数。
5. **计算平均值：** 累加每个值的贡献 `i * count[i]`，再除以总样本数。
6. **判断中位数位置：** 根据样本数量的奇偶性确定排序后的中间位置。
7. **累计频次：** 从小到大累计 `count[i]`，直到覆盖中位数位置。
8. **计算中位数：** 奇数取中间元素，偶数取中间两个元素的平均值。
9. **返回统计结果：** 按 `[minimum, maximum, mean, median, mode]` 返回。

```java
class Solution {
    public double[] sampleStats(int[] count) {
        double[] ans = new double[5];
        int i = 0;
        int j = 255;
        double num = 0;
        int max = 0;
        while(count[i] == 0){
            i++;
        }
        while(count[j] == 0){
            j--;
        }
        ans[0] = i;
        ans[1] = j;
        while(i <= j){
            num += count[i];
            if(count[i] > max){
                max = count[i];
                ans[4] = i;
            }
            i++;
        }
        i = (int) ans[0];
        j = (int) ans[1];
        while(i <= j){
            ans[2] += i / num * count[i];
            i++;
        }
        if(num % 2 == 0){
            int mid = (int) (num / 2);
            i = (int) ans[0];
            j = (int) ans[1];
            int cnt = 0;
            while(i <= j){
                cnt += count[i];
                if(cnt > mid){
                    ans[3] = i;
                    break;
                }else if(cnt == mid){
                    int a = i;
                    i++;
                    while(count[i] == 0){
                        i++;
                    }
                    ans[3] = (double) (a + i) / 2;
                    break;
                }
                i++;
            }
        }else {
            int mid = (int) (num / 2) + 1;
            i = (int) ans[0];
            j = (int) ans[1];
            int cnt = 0;
            while(i <= j){
                cnt += count[i];
                if(cnt >= mid){
                    ans[3] = i;
                    break;
                }
                i++;
            }
        }
        return ans;
    }
}
```
