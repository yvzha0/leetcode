## [1695. 删除子数组的最大得分](https://leetcode.cn/problems/maximum-erasure-value/)

### 题目

给你一个正整数数组 `nums` ，请你从中删除一个含有 **若干不同元素** 的子数组**。**删除子数组的 **得分** 就是子数组各元素之 **和** 。

返回 **只删除一个** 子数组可获得的 **最大得分** *。*

如果数组 `b` 是数组 `a` 的一个连续子序列，即如果它等于 `a[l],a[l+1],...,a[r]` ，那么它就是 `a` 的一个子数组。

 

**示例 1：**

```
输入：nums = [4,2,4,5,6]
输出：17
解释：最优子数组是 [2,4,5,6]
```

**示例 2：**

```
输入：nums = [5,2,1,2,5,2,1,2,5]
输出：8
解释：最优子数组是 [5,2,1] 或 [1,2,5]
```

 

**提示：**

- `1 <= nums.length <= 105`
- `1 <= nums[i] <= 104`

 

### 题解

#### 思路总结

利用**滑动窗口 + HashSet**寻找元素互不重复且元素和最大的连续子数组。

维护一个合法窗口，保证窗口中的所有元素都不重复：

- `set` 保存当前窗口中的元素。
- `l` 表示窗口左边界。
- `sum` 表示当前窗口元素和。
- 遍历到当前元素 `num` 时，如果它已经存在于窗口中，就不断移动左边界，并同步删除窗口左侧元素，直到 `num` 不再重复。
- 然后将当前元素加入窗口，并使用新的窗口和更新最大得分 `ans`。

由于数组元素全部为正数，合法窗口越长通常越有利，因此每次消除重复后都可以直接用当前窗口和更新答案。

整体时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **初始化窗口状态：** 创建 `set` 保存当前窗口元素，设置 `l = 0`、`sum = 0`、`ans = 0`。
2. **从左向右遍历数组：** 依次处理当前元素 `num`。
3. **判断是否出现重复：** 如果 `set` 中已经存在 `num`，说明当前窗口加入该元素后会出现重复。
4. **收缩窗口左边界：** 持续删除 `nums[l]`，同时从 `sum` 中减去对应值，并执行 `l++`。
5. **消除重复元素：** 当 `set` 中不再包含 `num` 时，当前窗口已经重新满足元素互不相同的条件。
6. **加入当前元素：** 将 `num` 加入 `set`，并累加到 `sum`。
7. **更新最大得分：** 使用当前合法窗口的 `sum` 更新 `ans`。
8. **返回最终答案：** 遍历结束后返回最大得分 `ans`。

```java
class Solution {
    public int maximumUniqueSubarray(int[] nums) {
        Set<Integer> set = new HashSet<>();
        int l = 0;
        int sum = 0;
        int ans = 0;
        for (int num : nums) {
            while(set.contains(num)){
                set.remove(nums[l]);
                sum -= nums[l];
                l++;
            }
            set.add(num);
            sum += num;
            ans = Math.max(ans, sum);
        }
        return ans;
    }
}
```
