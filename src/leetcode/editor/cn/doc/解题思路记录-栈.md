## [1673. 找出最具竞争力的子序列](https://leetcode.cn/problems/find-the-most-competitive-subsequence/)

### 题目

给你一个整数数组 `nums` 和一个正整数 `k` ，返回长度为 `k` 且最具 **竞争力** 的 `nums` 子序列。

数组的子序列是从数组中删除一些元素（可能不删除元素）得到的序列。

在子序列 `a` 和子序列 `b` 第一个不相同的位置上，如果 `a` 中的数字小于 `b` 中对应的数字，那么我们称子序列 `a` 比子序列 `b`（相同长度下）更具 **竞争力** 。 例如，`[1,3,4]` 比 `[1,3,5]` 更具竞争力，在第一个不相同的位置，也就是最后一个位置上， `4` 小于 `5` 。

 

**示例 1：**

```
输入：nums = [3,5,2,6], k = 2
输出：[2,6]
解释：在所有可能的子序列集合 {[3,5], [3,2], [3,6], [5,2], [5,6], [2,6]} 中，[2,6] 最具竞争力。
```

**示例 2：**

```
输入：nums = [2,4,3,3,5,4,9,6], k = 4
输出：[2,3,3,4]
```

 

**提示：**

- `1 <= nums.length <= 105`
- `0 <= nums[i] <= 109`
- `1 <= k <= nums.length`

### 题解

#### 思路总结

当前实现采用**单调栈 + 下一个更小元素 + 贪心选择**。

题目要求从 `nums` 中选出长度恰好为 `k` 的子序列，使其字典序最小。

由于子序列必须保持原数组中的相对顺序，因此每次选择元素时，需要满足两个条件：

- **当前选择尽可能小：** 优先选择后面更小的元素。
- **保证剩余元素数量足够：** 不能为了选择更小的元素而导致最终无法选满 `k` 个。

当前代码首先使用单调栈预处理 `nextSmall[i]`，表示下标 `i` 右侧第一个严格小于 `nums[i]` 的元素位置。

随后通过 `nextSmall` 不断向右跳转，在保证剩余元素数量足够的前提下，寻找当前能够选择的最小元素。

#### 解题步骤

1. **初始化下一个更小元素数组：** 创建 `nextSmall[n]`，记录每个元素右侧第一个严格更小元素的下标。
2. **建立单调栈：** 使用 `stack` 保存尚未找到下一个更小元素的下标，保持对应元素单调不减。
3. **预处理 nextSmall：** 遍历数组，当当前元素小于栈顶元素时，弹出栈顶，并将当前下标记录为被弹出元素的下一个更小位置。
4. **初始化答案：** 创建长度为 `k` 的 `ans`，使用 `j` 表示当前可以选择的起始位置。
5. **寻找更优候选：** 获取 `nextSmall[j]`，判断能否跳转到后面更小的元素。
6. **检查剩余元素数量：** 如果 `n - next >= k - i`，说明选择该位置后仍有足够元素完成剩余选择，可以继续跳转。
7. **确定当前元素：** 当无法继续跳转时，将 `nums[j]` 加入答案。
8. **更新起始位置：** 执行 `j++`，确保下一次选择发生在当前元素之后。
9. **返回结果：** 选满 `k` 个元素后返回 `ans`。

```java
class Solution {
    public int[] mostCompetitive(int[] nums, int k) {
        int n = nums.length;
        int[] nextSmall = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(0);
        for(int i = 1; i < n; i++){
            while(!stack.isEmpty() && nums[i] < nums[stack.peek()]){
                nextSmall[stack.pop()] = i;
            }
            stack.push(i);
        }
        int[] ans = new int[k];
        int i = 0;
        int j = 0;
        while(i < k){
            int next = nextSmall[j];
            while(next != 0 && n - next >= k - i){
                j = next;
                next = nextSmall[j];
            }
            ans[i++] = nums[j];
            j++;
        }
        return ans;
    }
}
```

## [1249. 移除无效的括号](https://leetcode.cn/problems/minimum-remove-to-make-valid-parentheses/)

### 题目

给你一个由 `'('`、`')'` 和小写字母组成的字符串 `s`。

你需要从字符串中删除最少数目的 `'('` 或者 `')'` （可以删除任意位置的括号)，使得剩下的「括号字符串」有效。

请返回任意一个合法字符串。

有效「括号字符串」应当符合以下 **任意一条** 要求：

- 空字符串或只包含小写字母的字符串
- 可以被写作 `AB`（`A` 连接 `B`）的字符串，其中 `A` 和 `B` 都是有效「括号字符串」
- 可以被写作 `(A)` 的字符串，其中 `A` 是一个有效的「括号字符串」

 

**示例 1：**

```
输入：s = "lee(t(c)o)de)"
输出："lee(t(c)o)de"
解释："lee(t(co)de)" , "lee(t(c)ode)" 也是一个可行答案。
```

**示例 2：**

```
输入：s = "a)b(c)d"
输出："ab(c)d"
```

**示例 3：**

```
输入：s = "))(("
输出：""
解释：空字符串也是有效的
```

 

**提示：**

- `1 <= s.length <= 105`
- `s[i]` 可能是 `'('`、`')'` 或英文小写字母

### 题解

#### 思路总结

当前实现采用**栈 + 哈希集合 + 括号匹配**。

首先使用栈保存尚未匹配的左括号 `'('` 的下标。遍历字符串时：

- 遇到 `'('`，将其下标入栈。
- 遇到 `')'`，如果栈不为空，则弹出一个左括号，完成匹配。
- 如果遇到 `')'` 时栈为空，说明当前右括号无法匹配，需要删除。
- 遍历结束后，栈中剩余的左括号也都需要删除。

使用 `HashSet` 保存需要删除的括号下标，最后重新遍历字符串，跳过这些位置即可。

#### 解题步骤

1. **初始化数据结构：** 使用 `stack` 保存未匹配左括号的下标，使用 `set` 保存需要删除的字符下标。
2. **遍历字符串：** 依次读取每个字符。
3. **处理左括号：** 遇到 `'('` 时，将当前位置加入栈。
4. **处理右括号：** 遇到 `')'` 时，如果栈不为空，则弹出一个左括号完成匹配。
5. **记录无效右括号：** 如果栈为空，说明当前右括号无法匹配，将其下标加入 `set`。
6. **记录无效左括号：** 第一次遍历结束后，将栈中剩余的左括号下标全部加入 `set`。
7. **构造结果字符串：** 再次遍历原字符串，跳过 `set` 中记录的位置。
8. **返回结果：** 将 `StringBuilder` 转换成字符串返回。

```java
class Solution {
    public String minRemoveToMakeValid(String s) {
        Set<Integer> set = new HashSet<>();
        Deque<Integer> stack = new ArrayDeque<>();
        int n = s.length();
        for(int i = 0; i < n; i++){
            char c = s.charAt(i);
            if(c == '('){
                stack.push(i);
            }else if(c == ')'){
                if(stack.isEmpty()){
                    set.add(i);
                }else {
                    stack.pop();
                }
            }
        }
        while(!stack.isEmpty()){
            set.add(stack.pop());
        }
        StringBuilder ans = new StringBuilder();
        for(int i = 0; i < n; i++){
            if(!set.contains(i)){
                ans.append(s.charAt(i));
            }
        }
        return ans.toString();
    }
}
```

## [1209. 删除字符串中的所有相邻重复项 II](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string-ii/)

### 题目

给你一个字符串 `s`，「`k` 倍重复项删除操作」将会从 `s` 中选择 `k` 个相邻且相等的字母，并删除它们，使被删去的字符串的左侧和右侧连在一起。

你需要对 `s` 重复进行无限次这样的删除操作，直到无法继续为止。

在执行完所有删除操作后，返回最终得到的字符串。

本题答案保证唯一。

 

**示例 1：**

```
输入：s = "abcd", k = 2
输出："abcd"
解释：没有要删除的内容。
```

**示例 2：**

```
输入：s = "deeedbbcccbdaa", k = 3
输出："aa"
解释： 
先删除 "eee" 和 "ccc"，得到 "ddbbbdaa"
再删除 "bbb"，得到 "dddaa"
最后删除 "ddd"，得到 "aa"
```

**示例 3：**

```
输入：s = "pbbcggttciiippooaais", k = 2
输出："ps"
```

 

**提示：**

- `1 <= s.length <= 10^5`
- `2 <= k <= 10^4`
- `s` 中只含有小写英文字母。

### 题解

#### 思路总结

当前实现采用**栈 + 连续字符计数 + 贪心删除**。

题目要求不断删除连续 `k` 个相同字符，并且删除后左右两侧的字符可能重新相邻，形成新的可删除片段。

因此，可以使用栈记录当前尚未删除的连续字符段。

当前代码定义 `Pair`，其中：

- `key`：当前连续字符段的字符。
- `val`：该字符连续出现的次数。

遍历字符串时：

- 如果当前字符与栈顶字符不同，则创建新的字符段入栈。
- 如果当前字符与栈顶字符相同，则增加栈顶计数。
- 如果加入当前字符后恰好达到 `k` 次，则直接弹出栈顶，完成删除。

这种方式能够自然处理**删除后产生的连锁反应**。

#### 解题步骤

1. **定义栈节点：** 使用 `Pair` 保存字符 `key` 和连续出现次数 `val`。
2. **初始化栈：** 创建 `Deque<Pair>`，记录当前尚未删除的连续字符段。
3. **遍历字符串：** 依次读取 `s` 中的每个字符。
4. **判断是否需要新建字符段：** 如果栈为空，或者当前字符与栈顶字符不同，则将 `(c, 1)` 入栈。
5. **处理相同字符：** 如果当前字符与栈顶字符相同，则判断加入该字符后是否达到 `k` 次。
6. **删除重复字符段：** 如果栈顶计数已经为 `k - 1`，说明加入当前字符后达到 `k` 次，直接弹出栈顶。
7. **更新连续次数：** 如果尚未达到 `k` 次，则将栈顶计数加一。
8. **构造结果字符串：** 依次弹出栈中的字符段，根据出现次数恢复字符。
9. **反转最终结果：** 由于栈的弹出顺序与原字符串相反，因此使用 `reverse()` 恢复正确顺序。

```java
class Solution {
    class Pair{
        private char key;
        private int val;

        public Pair(char key, int val) {
            this.key = key;
            this.val = val;
        }
    }
    public String removeDuplicates(String s, int k) {
        Deque<Pair> stack = new ArrayDeque<>();
        for(char c : s.toCharArray()){
            if(stack.isEmpty() || stack.peek().key != c){
                stack.push(new Pair(c, 1));
            }else {
                if(stack.peek().val == k - 1){
                    stack.pop();
                }else {
                    stack.peek().val++;
                }
            }
        }
        StringBuilder sb = new StringBuilder();
        while(!stack.isEmpty()){
            Pair pair = stack.pop();
            sb.append(String.valueOf(pair.key).repeat(Math.max(0, pair.val)));
        }
        return sb.reverse().toString();
    }
}
```

## [1190. 反转每对括号间的子串](https://leetcode.cn/problems/reverse-substrings-between-each-pair-of-parentheses/)

### 题目

给出一个字符串 `s`（仅含有小写英文字母和括号）。

请你按照从括号内到外的顺序，逐层反转每对匹配括号中的字符串，并返回最终的结果。

注意，您的结果中 **不应** 包含任何括号。

 

**示例 1：**

```
输入：s = "(abcd)"
输出："dcba"
```

**示例 2：**

```
输入：s = "(u(love)i)"
输出："iloveu"
解释：先反转子字符串 "love" ，然后反转整个字符串。
```

**示例 3：**

```
输入：s = "(ed(et(oc))el)"
输出："leetcode"
解释：先反转子字符串 "oc" ，接着反转 "etco" ，然后反转整个字符串。
```

 

**提示：**

- `1 <= s.length <= 2000`
- `s` 中只有小写英文字母和括号
- 题目测试用例确保所有括号都是成对出现的

### 题解

#### 思路总结

当前实现采用**栈 + StringBuilder + 括号内字符串反转**。

使用 `Deque<StringBuilder>` 保存每一层括号外部已经处理的字符串，并使用 `sb` 构造当前括号层级中的字符串。

遍历字符串时：

- **遇到 `'('`：** 将当前 `sb` 入栈，然后创建新的 `StringBuilder`，处理括号内部。
- **遇到 `')'`：** 将当前 `sb` 反转，再与栈顶保存的外层字符串拼接。
- **遇到普通字母：** 直接追加到当前 `sb`。

由于内层括号会先遇到对应的右括号，因此会先完成反转，正好满足题目要求的**从内到外逐层反转**。

#### 解题步骤

1. **初始化栈和字符串构造器：** 使用 `stack` 保存外层字符串，使用 `sb` 保存当前层级的字符串。
2. **遍历输入字符串：** 依次处理每个字符。
3. **遇到左括号：** 将当前 `sb` 入栈，创建新的 `StringBuilder`，开始处理内层字符串。
4. **遇到普通字符：** 将字符追加到当前 `sb`。
5. **遇到右括号：** 调用 `sb.reverse()` 反转当前括号中的内容。
6. **合并内外层字符串：** 弹出栈顶保存的外层字符串，并追加反转后的内层字符串。
7. **继续处理剩余内容：** 如果存在更外层括号，后续遇到右括号时会继续进行反转。
8. **返回最终结果：** 遍历结束后返回 `sb.toString()`。

```java
class Solution {
    public String reverseParentheses(String s) {
        Deque<StringBuilder> stack = new ArrayDeque<>();
        StringBuilder sb = new StringBuilder();
        for(char c : s.toCharArray()){
            if(c == '('){
                stack.push(sb);
                sb = new StringBuilder();
            }else if(c == ')'){
                sb = stack.pop().append(sb.reverse());
            }else {
                sb.append(c);
            }
        }
        return sb.toString();
    }
}
```

## [1047. 删除字符串中的所有相邻重复项](https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/)

### 题目

给出由小写字母组成的字符串 `s`，**重复项删除操作** 会选择两个相邻且相同的字母，并删除它们。

在 `s` 上反复执行重复项删除操作，直到无法继续删除。

在完成所有重复项删除操作后返回最终的字符串。答案保证唯一。

 

**示例 1：**

```
输入："abbaca"
输出："ca"
解释：
例如，在 "abbaca" 中，我们可以删除 "bb" 由于两字母相邻且相同，这是此时唯一可以执行删除操作的重复项。之后我们得到字符串 "aaca"，其中又只有 "aa" 可以执行重复项删除操作，所以最后的字符串为 "ca"。
```

**示例 2：**

```
输入：s = "azxxzy"
输出："ay"
```

 

**提示：**

- `1 <= s.length <= 105`
- `s` 仅由小写英文字母组成。

### 题解

#### 思路总结

当前实现采用**栈 + 相邻字符匹配 + 贪心删除**。

使用 `Deque<Character>` 作为栈，保存经过重复项删除后仍然保留的字符。

遍历字符串时：

- **栈为空：** 当前字符直接入栈。
- **当前字符与栈顶相同：** 说明形成了两个相邻且相同的字符，弹出栈顶，相当于删除这一对字符。
- **当前字符与栈顶不同：** 将当前字符入栈，等待后续字符匹配。

由于删除后栈顶会重新暴露出来，因此能够自动处理**删除后形成的新相邻重复字符**。

最后将栈中剩余字符依次弹出，并通过 `reverse()` 恢复原来的字符顺序。

#### 解题步骤

1. **初始化栈：** 创建 `Deque<Character>`，用于保存当前尚未被删除的字符。
2. **加入首字符：** 将 `s.charAt(0)` 入栈，作为初始有效字符。
3. **遍历后续字符：** 从下标 `1` 开始，依次处理字符串中的每个字符。
4. **判断栈是否为空：** 如果栈为空，直接将当前字符入栈。
5. **判断是否形成重复项：** 如果当前字符与栈顶字符相同，弹出栈顶，相当于删除一对相邻重复字符。
6. **保留不重复字符：** 如果当前字符与栈顶不同，将当前字符入栈。
7. **构造结果字符串：** 遍历结束后，依次弹出栈中的字符，追加到 `StringBuilder`。
8. **恢复字符顺序：** 由于栈是后进先出结构，使用 `reverse()` 将结果反转。
9. **返回最终结果：** 返回删除所有相邻重复项后的字符串。

```java
class Solution {
    public String removeDuplicates(String s) {
        StringBuilder sb = new StringBuilder();
        Deque<Character> stack = new ArrayDeque<>();
        stack.push(s.charAt(0));
        for(int i = 1; i < s.length(); i++){
            if(stack.isEmpty()){
                stack.push(s.charAt(i));
            }else {
                if(s.charAt(i) == stack.peek()){
                    stack.pop();
                }else {
                    stack.push(s.charAt(i));
                }
            }
        }
        while(!stack.isEmpty()){
            sb.append(stack.pop());
        }
        return sb.reverse().toString();
    }
}
```

## [1021. 删除最外层的括号](https://leetcode.cn/problems/remove-outermost-parentheses/)

### 题目

有效括号字符串为空 `""`、`"(" + A + ")"` 或 `A + B` ，其中 `A` 和 `B` 都是有效的括号字符串，`+` 代表字符串的连接。

- `s` 是一个有效括号字符串

### 题解

#### 思路总结

当前实现采用**括号计数 + 原语分解 + StringBuilder**。

使用 `l` 和 `r` 分别统计已经遍历的左括号和右括号数量，同时使用 `sb` 保存当前原语字符串。

由于题目保证 `s` 是有效括号字符串，因此：

- 当 `l > r` 时，说明当前仍然处于某个原语内部。
- 当 `l == r` 时，说明当前原语已经完整结束。

此时，`sb` 保存的就是一个完整原语，删除其首尾括号后，将剩余部分加入答案，再清空 `sb`，继续处理下一个原语。

#### 解题步骤

1. **初始化括号计数：** 使用 `l` 和 `r` 分别记录已经遍历的左括号和右括号数量。
2. **初始化字符串构造器：** `sb` 保存当前原语，`ans` 保存删除最外层括号后的结果。
3. **遍历字符串：** 依次读取每个括号，并追加到 `sb`。
4. **更新括号数量：** 遇到 `'('` 时增加 `l`，遇到 `')'` 时增加 `r`。
5. **判断原语是否结束：** 当 `l == r` 时，说明当前原语的括号已经全部匹配。
6. **删除最外层括号：** 使用 `ans.append(sb, 1, sb.length() - 1)`，只保留当前原语中间的内容。
7. **清空当前原语：** 执行 `sb.setLength(0)`，准备处理下一段。
8. **返回结果：** 遍历结束后返回 `ans.toString()`。

```java
class Solution {
    public String removeOuterParentheses(String s) {
        int l = 0;
        int r = 0;
        StringBuilder ans = new StringBuilder();
        StringBuilder sb = new StringBuilder();
        for(char c : s.toCharArray()){
            sb.append(c);
            if(c == '('){
                l++;
            }else {
                r++;
            }
            if(l == r){
                ans.append(sb, 1, sb.length() - 1);
                sb.setLength(0);
            }
        }
        return ans.toString();
    }
}
```

### 题目

给定一个长度为 `n` 的链表 `head`

返回一个整数数组 `answer` ，其中 `answer[i]` 是第 `i` 个节点( **从1开始** )的下一个更大的节点的值。如果第 `i` 个节点没有下一个更大的节点，设置 `answer[i] = 0` 。

 

**示例 1：**

![img](https://assets.leetcode.com/uploads/2021/08/05/linkedlistnext1.jpg)

```
输入：head = [2,1,5]
输出：[5,5,0]
```

**示例 2：**

![img](https://assets.leetcode.com/uploads/2021/08/05/linkedlistnext2.jpg)

```
输入：head = [2,7,4,3,5]
输出：[7,0,5,5,0]
```

 

**提示：**

- 链表中节点数为 `n`
- `1 <= n <= 104`
- `1 <= Node.val <= 109`

### 题解

#### 思路总结

当前实现采用**单调栈 + 链表遍历 + 下一个更大元素**。

由于链表只能从前向后遍历，而题目要求寻找每个节点右侧第一个严格大于它的节点，因此可以使用单调栈保存尚未找到下一个更大元素的节点信息。

当前代码使用 `Pair` 保存：

- `idx`：节点在链表中的下标。
- `val`：节点的数值。

遍历链表时，如果当前节点的值大于栈顶节点的值，说明**当前节点就是栈顶节点右侧第一个严格更大的节点**，因此可以弹出栈顶，并更新对应的答案。

不断执行上述操作，直到栈为空，或者栈顶节点的值大于等于当前节点的值。

遍历结束后，栈中剩余的节点都没有找到更大值，答案保持默认的 `0`。

#### 解题步骤

1. **定义栈节点：** 使用 `Pair` 保存链表节点的下标 `idx` 和数值 `val`。
2. **初始化单调栈：** 创建 `Deque<Pair>`，保存尚未找到下一个更大元素的节点。
3. **计算链表长度：** 通过 `len(head)` 获取节点总数，用于初始化答案数组。
4. **遍历链表：** 使用 `head` 从前向后访问节点，同时通过 `i` 记录当前下标。
5. **比较当前值与栈顶值：** 如果 `head.val > stack.peek().val`，说明当前节点可以作为栈顶节点的下一个更大节点。
6. **更新答案并弹栈：** 将当前节点值写入 `ans[pair.idx]`，然后继续比较新的栈顶。
7. **当前节点入栈：** 将当前节点的下标和值加入栈，等待后续更大的节点。
8. **处理未匹配节点：** 遍历结束后，栈中剩余节点没有下一个更大值，对应答案保持 `0`。
9. **返回结果：** 返回 `ans`。

```java
class Solution {
    class Pair{
        int idx;
        int val;

        public Pair(int idx, int val) {
            this.idx = idx;
            this.val = val;
        }
    }

    public int[] nextLargerNodes(ListNode head) {
        Deque<Pair> stack = new ArrayDeque<>();
        int i = 0;
        int n = len(head);
        int[] ans = new int[n];
        while(head != null){
            int val = head.val;
            while(!stack.isEmpty() && val > stack.peek().val){
                Pair pair = stack.pop();
                ans[pair.idx] = val;
            }
            stack.push(new Pair(i++, val));
            head = head.next;
        }
        return ans;
    }

    private int len(ListNode head){
        int res = 0;
        while(head != null){
            res++;
            head = head.next;
        }
        return res;
    }
}
```

## [1003. 检查替换后的词是否有效](https://leetcode.cn/problems/check-if-word-is-valid-after-substitutions/)

### 题目

如果字符串 `s` 有效，则返回 `true`；否则，返回 `false`。

 

**示例 1：**

```
输入：s = "aabcbc"
输出：true
解释：
"" -> "abc" -> "aabcbc"
因此，"aabcbc" 有效。
```

**示例 2：**

```
输入：s = "abcabcababcc"
输出：true
解释：
"" -> "abc" -> "abcabc" -> "abcabcabc" -> "abcabcababcc"
因此，"abcabcababcc" 有效。
```

**示例 3：**

```
输入：s = "abccba"
输出：false
解释：执行操作无法得到 "abccba" 。
```

 

**提示：**

- `1 <= s.length <= 2 * 104`
- `s` 由字母 `'a'`、`'b'` 和 `'c'` 组成

### 题解

#### 思路总结

当前实现采用**栈 + 字符匹配 + 贪心消除**。

题目要求判断字符串 `s` 能否通过不断插入 `"abc"` 得到。

可以逆向思考：

**如果字符串能够通过插入 `"abc"` 构造出来，那么也应该能够通过不断删除连续的 `"abc"`，最终得到空字符串。**

因此，可以使用栈模拟删除过程。

当前代码根据字符的不同进行处理：

- 遇到 `'a'`：直接入栈。
- 遇到 `'b'`：要求栈顶必须是 `'a'`，然后将 `'b'` 入栈。
- 遇到 `'c'`：要求栈顶必须是 `'b'`，然后连续弹出 `'b'` 和它前面的 `'a'`，相当于删除 `"abc"`。

如果遇到无法匹配的字符，直接返回 `false`。

遍历结束后，如果栈为空，说明整个字符串可以被完全消除。

#### 解题步骤

1. **初始化栈：** 使用 `Deque<Character>` 保存当前尚未消除的字符。
2. **遍历字符串：** 依次处理 `s` 中的每一个字符。
3. **处理字符 a：** 遇到 `'a'` 时直接入栈，表示可能开始一个新的 `"abc"`。
4. **处理字符 b：** 如果栈为空，或者栈顶不是 `'a'`，则无法形成合法的 `"abc"`，返回 `false`。
5. **保存字符 b：** 如果栈顶是 `'a'`，将 `'b'` 入栈，等待后续的 `'c'`。
6. **处理字符 c：** 如果栈为空，或者栈顶不是 `'b'`，则返回 `false`。
7. **消除 abc：** 当遇到合法的 `'c'` 时，连续弹出两个字符，相当于将 `"abc"` 从当前字符串中删除。
8. **判断最终状态：** 遍历结束后，如果栈为空则返回 `true`，否则返回 `false`。

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for(char c : s.toCharArray()){
            if(c == 'a'){
                stack.push(c);
            }else {
                if(stack.isEmpty()){
                    return false;
                }
                if(c == 'b'){
                    if(stack.peek() != 'a'){
                        return false;
                    }
                    stack.push(c);
                }else {
                    if(stack.peek() != 'b'){
                        return false;
                    }
                    stack.pop();
                    stack.pop();
                }
            }
        }
        return stack.isEmpty();
    }
}
```

## [946. 验证栈序列](https://leetcode.cn/problems/validate-stack-sequences/)

### 题目

给定 `pushed` 和 `popped` 两个序列，每个序列中的 **值都不重复**，只有当它们可能是在最初空栈上进行的推入 push 和弹出 pop 操作序列的结果时，返回 `true`；否则，返回 `false` 。

 

**示例 1：**

```
输入：pushed = [1,2,3,4,5], popped = [4,5,3,2,1]
输出：true
解释：我们可以按以下顺序执行：
push(1), push(2), push(3), push(4), pop() -> 4,
push(5), pop() -> 5, pop() -> 3, pop() -> 2, pop() -> 1
```

**示例 2：**

```
输入：pushed = [1,2,3,4,5], popped = [4,3,5,1,2]
输出：false
解释：1 不能在 2 之前弹出。
```

 

**提示：**

- `1 <= pushed.length <= 1000`
- `0 <= pushed[i] <= 1000`
- `pushed` 的所有元素 **互不相同**
- `popped.length == pushed.length`
- `popped` 是 `pushed` 的一个排列

### 题解

#### 思路总结

当前实现采用**栈模拟 + 贪心匹配**。

题目给出入栈顺序 `pushed` 和出栈顺序 `popped`，要求判断是否存在一种合法的栈操作序列，使两者同时成立。

由于入栈顺序已经固定，因此只需要按照 `pushed` 依次入栈，并不断尝试按照 `popped` 的顺序出栈。

核心贪心策略是：

**每次入栈后，只要栈顶元素等于当前需要弹出的元素，就立即弹出，直到无法继续匹配。**

当前代码使用 `j` 指向 `popped` 中下一个需要弹出的元素。

如果最终 `j == n`，说明所有元素都可以按照指定顺序弹出，返回 `true`；否则返回 `false`。

#### 解题步骤

1. **初始化栈：** 使用 `Deque<Integer>` 模拟实际的入栈和出栈操作。
2. **初始化出栈指针：** 设置 `j = 0`，指向 `popped` 中当前需要弹出的元素。
3. **按照指定顺序入栈：** 依次遍历 `pushed`，将当前元素加入栈。
4. **判断栈顶是否匹配：** 如果栈顶等于 `popped[j]`，说明当前元素可以按照目标顺序弹出。
5. **连续执行出栈：** 只要栈顶仍然与下一个待弹出元素相等，就不断执行 `pop()`，并右移 `j`。
6. **继续处理后续元素：** 如果栈顶与当前目标不相等，则暂时保留栈中元素，继续入栈。
7. **判断最终结果：** 如果 `j == n`，说明所有元素均已按目标顺序弹出，返回 `true`。

```java
class Solution {
    public boolean validateStackSequences(int[] pushed, int[] popped) {
        int n = popped.length;
        int j = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        for(int i = 0; i < n; i++){
            // 先入栈
            stack.push(pushed[i]);

            // 栈顶等于当前需要弹出的元素，就一直弹
            while (!stack.isEmpty() && j < n && stack.peek() == popped[j]) {
                stack.pop();
                j++;
            }
        }
        return j == n;
    }
}
```

- 例如，如果 `s = "()))"` ，你可以插入一个开始括号为 `"(()))"` 或结束括号为 `"())))"` 。

**示例 1：**

```

输出：1
```

**示例 2：**

```
输入：s = "((("
输出：3
```

 

**提示：**

- `1 <= s.length <= 1000`
- `s` 只包含 `'('` 和 `')'` 字符。

### 题解

#### 思路总结

当前实现采用**栈 + 括号匹配 + 贪心统计**。

使用 `Deque<Character>` 保存尚未匹配的左括号，并使用 `ans` 记录需要补充的括号数量。

遍历字符串时：

- **遇到 `'('`：** 将左括号入栈，等待后续右括号匹配。
- **遇到 `')'` 且栈不为空：** 弹出一个左括号，完成匹配。
- **遇到 `')'` 且栈为空：** 当前右括号无法匹配，必须补充一个左括号，因此 `ans++`。
- **遍历结束后：** 栈中剩余的左括号都没有对应的右括号，需要补充相同数量的右括号。

因此，最终答案为：
$$
\ \text{ans}+\text{stack.size()} \
$$

#### 解题步骤

1. **初始化栈：** 使用 `Deque<Character>` 保存尚未匹配的左括号。
2. **初始化答案：** 设置 `ans = 0`，记录需要补充的括号数量。
3. **遍历字符串：** 依次读取每个括号。
4. **处理左括号：** 遇到 `'('` 时直接入栈。
5. **处理可以匹配的右括号：** 遇到 `')'` 且栈不为空时，弹出一个左括号。
6. **处理无法匹配的右括号：** 如果栈为空，则需要补充一个左括号，将 `ans` 加一。
7. **处理剩余左括号：** 遍历完成后，栈中每个左括号都需要补充一个右括号。
8. **返回最终答案：** 返回 `ans + stack.size()`。

```java
class Solution {
    public int minAddToMakeValid(String s) {
        int ans = 0;
        Deque<Character> stack = new ArrayDeque<>();
        for(char c : s.toCharArray()){
            if(c == '('){
                stack.push(c);
            }else {
                if(stack.isEmpty()){
                    ans++;
                }else {
                    stack.pop();
                }
            }
        }
        ans += stack.size();
        return ans;
    }
}
```

## [907. 子数组的最小值之和](https://leetcode.cn/problems/sum-of-subarray-minimums/)

### 题目

给定一个整数数组 `arr`，找到 `min(b)` 的总和，其中 `b` 的范围为 `arr` 的每个（连续）子数组。

由于答案可能很大，因此 **返回答案模 `10^9 + 7`** 。

 

**示例 1：**

```
输入：arr = [3,1,2,4]
输出：17
解释：
子数组为 [3]，[1]，[2]，[4]，[3,1]，[1,2]，[2,4]，[3,1,2]，[1,2,4]，[3,1,2,4]。 
最小值为 3，1，2，4，1，1，2，1，1，1，和为 17。
```

**示例 2：**

```
输入：arr = [11,81,94,43,3]
输出：444
```

 

**提示：**

- `1 <= arr.length <= 3 * 104`
- `1 <= arr[i] <= 3 * 104`

### 题解

#### 思路总结

当前实现采用**单调栈 + 贡献法 + 左右边界**。

题目要求计算所有连续子数组的最小值之和。如果直接枚举所有子数组，即使维护区间最小值，也至少需要 O(n²) 时间。

当前算法换了一个角度：

**不再枚举每个子数组，而是计算每个元素作为子数组最小值时，对最终答案产生的贡献。**

对于 `arr[i]`，只需要知道它作为最小值时，能够向左、向右扩展多远。

当前代码通过单调栈一次遍历得到：

- `preMin[i]`：左侧最近的**小于等于** `arr[i]` 的元素下标，不存在则为 `-1`。
- `nextMin[i]`：右侧最近的**严格小于** `arr[i]` 的元素下标，不存在则为 `n`。

因此，以 `arr[i]` 为指定最小值的子数组数量为：
$$
\ (i-preMin[i])\times(nextMin[i]-i) \
$$
对应贡献为：
$$
\ arr[i]\times(i-preMin[i])\times(nextMin[i]-i) \
$$

#### 解题步骤

1. **初始化边界数组：** 创建 `preMin` 和 `nextMin`，并将 `nextMin` 的默认值设为 `n`，表示右侧不存在更小元素。
2. **初始化单调栈：** 使用 `Deque<Integer>` 保存数组下标，维护从栈底到栈顶对应元素单调不减。
3. **查找右侧更小元素：** 遍历 `arr`，如果当前元素严格小于栈顶元素，则弹出栈顶，并将当前下标记录为它的 `nextMin`。
4. **查找左侧小于等于元素：** 弹栈完成后，栈顶就是当前元素左侧最近的小于等于它的元素。
5. **当前下标入栈：** 将 `i` 加入单调栈，等待后续更小的元素。
6. **计算贡献：** 遍历所有下标，根据左右边界计算 `arr[i]` 对答案的贡献。
7. **处理取模：** 将各元素贡献累加后，对 `10^9 + 7` 取模。
8. **返回结果：** 将最终结果转换为 `int` 返回。

```java
class Solution {
    public int sumSubarrayMins(int[] arr) {
        int n = arr.length;
        int[] nextMin = new int[n];
        int[] preMin = new int[n];
        Arrays.fill(nextMin, n);
        Deque<Integer> stack = new ArrayDeque<>();
        for(int i = 0; i < n; i++){
            while(!stack.isEmpty() && arr[stack.peek()] > arr[i]){
                nextMin[stack.pop()] = i;
            }
            preMin[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }
        int mod = 1000000007;
        long ans = 0;
        for(int i = 0; i < n; i++){
            ans = (ans + (long) arr[i] * (nextMin[i] - i) * (i - preMin[i])) % mod;
        }
        return Math.toIntExact(ans);
    }
}
```

### 题目

设计一种算法，收集某支股票的每日价格报价，并返回该股票当前日期的 **价格跨度**。

股票在某一天的 **价格跨度** 是指：从当天开始向前，连续的股票价格小于或等于当天价格的最大天数。

- 例如，如果股票过去四天的价格为 `[7,2,1,2]`，今天的价格为 `2`，那么今天的价格跨度为 `4`，因为从今天开始向前，有连续 4 天的股票价格小于或等于 2。
- 同样，如果股票过去四天的价格为 `[7,34,1,2]`，今天的价格为 `8`，那么今天的价格跨度为 `3`，因为从今天开始向前，有连续 3 天的股票价格小于或等于 8。

实现 `StockSpanner` 类：

- `StockSpanner()` 初始化该类的对象。
- `int next(int price)` 给定今天的股票价格 `price`，返回今天股票价格的 **价格跨度**。

 

**示例 1：**

```
输入
["StockSpanner", "next", "next", "next", "next", "next", "next", "next"]
[[], [100], [80], [60], [70], [60], [75], [85]]
输出
[null, 1, 1, 1, 2, 1, 4, 6]

解释
StockSpanner stockSpanner = new StockSpanner();
stockSpanner.next(100); // 返回 1
stockSpanner.next(80);  // 返回 1
stockSpanner.next(60);  // 返回 1
stockSpanner.next(70);  // 返回 2
stockSpanner.next(60);  // 返回 1
stockSpanner.next(75);  // 返回 4，因为包含今天在内的最后 4 天的价格都小于或等于今天的价格 75。
stockSpanner.next(85);  // 返回 6
```

 

**约束条件：**

- `1 <= price <= 105`
- 最多会调用 `104` 次 `next`。

### 题解

#### 思路总结

当前实现采用**单调栈 + 数组记录历史价格 + 哨兵节点**。

题目要求计算当前股票价格的跨度，即：

**从今天开始向前，连续多少天的股票价格小于或等于今天的价格。**

当前代码使用三个核心变量：

- `list`：保存每天的股票价格。
- `stack`：保存尚未被后续更高或相等价格淘汰的日期下标。
- `i`：表示当前是第几天，从 `0` 开始。

每次调用 `next(price)` 时：

1. 将今天的价格加入 `list`。
2. 不断弹出栈顶价格小于或等于今天价格的日期。
3. 弹栈结束后，栈顶就是今天之前最近一个价格**严格大于**今天价格的日期。
4. 使用当前日期与该日期的下标差计算跨度。

#### 解题步骤

1. **初始化单调栈：** 创建 `Deque<Integer>`，保存股票价格对应的日期下标。
2. **添加哨兵节点：** 将 `-1` 入栈，表示左侧不存在价格更高的日期。
3. **初始化价格列表：** 创建 `ArrayList<Integer>`，保存每天的股票价格。
4. **记录当天价格：** 每次调用 `next(price)`，先将 `price` 加入 `list`。
5. **维护单调栈：** 如果栈顶对应的历史价格小于或等于今天价格，则将该下标弹出。
6. **确定跨度边界：** 弹栈结束后，栈顶就是最近一个严格大于今天价格的日期下标。
7. **计算价格跨度：** 使用 `i - stack.peek()` 得到今天的跨度。
8. **当前日期入栈：** 将日期下标 `i` 入栈，并执行 `i++`。
9. **返回跨度：** 返回计算结果。

```java
class StockSpanner {
    Deque<Integer> stack;
    List<Integer> list;
    int i = 0;
    public StockSpanner() {
        stack = new ArrayDeque<>();
        stack.push(-1);
        list = new ArrayList<>();
    }
    
    public int next(int price) {
        list.add(price);
        while(stack.size() > 1 && list.get(stack.peek()) <= price){
            stack.pop();
        }
        int res = i - stack.peek();
        stack.push(i++);
        return res;
    }
}
```

### 题目

实现 `FreqStack` 类:

freqStack.push (7);//堆栈是 [5,7,5,7]
freqStack.push (4);//堆栈是 [5,7,5,7,4]
freqStack.push (5);//堆栈是 [5,7,5,7,4,5]
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,5,7,4]。
freqStack.pop ();//返回 7 ，因为 5 和 7 出现频率最高，但7最接近顶部。堆栈变成 [5,7,5,4]。
freqStack.pop ();//返回 5 ，因为 5 出现频率最高。堆栈变成 [5,7,4]。
freqStack.pop ();//返回 4 ，因为 4, 5 和 7 出现频率最高，但 4 是最接近顶部的。堆栈变成 [5,7]。
```

 

**提示：**

- `0 <= val <= 109`
- `push` 和 `pop` 的操作数不大于 `2 * 104`。
- 输入保证在调用 `pop` 之前堆栈中至少有一个元素。

### 题解

#### 思路总结

当前实现采用**哈希表 + 按频率分组的栈 + 最大频率维护**。

这道题有两个要求：

- **优先弹出出现频率最高的元素。**
- **如果多个元素频率相同，则优先弹出其中最近入栈的元素。**

如果只使用普通栈，无法快速找到频率最高的元素；如果只使用频率哈希表，又无法确定相同频率下的入栈顺序。

因此，当前实现将二者结合起来：

- `freq`：记录每个元素当前出现的频率。
- `group`：按照频率分组，每个频率对应一个栈。
- `maxFreq`：记录当前所有元素中的最高频率。

每次 `push(val)`，先更新元素的频率，再将该元素压入对应频率的栈。

每次 `pop()`，直接从 `group[maxFreq]` 中弹出栈顶元素。

#### 解题步骤

#### 1. push 操作

当前代码：

```
public void push(int val) {
    int curFreq = freq.getOrDefault(val, 0) + 1;
    freq.put(val, curFreq);

    maxFreq = Math.max(maxFreq, curFreq);

    Stack<Integer> stack =
        group.getOrDefault(curFreq, new Stack<>());

    stack.push(val);
    group.put(curFreq, stack);
}
```

执行过程：

1. 查询 `val` 当前出现的次数。
2. 将其频率加一。
3. 更新全局最大频率 `maxFreq`。
4. 获取新频率对应的栈，如果不存在则创建。
5. 将 `val` 压入该频率对应的栈。

注意：**同一个元素可能同时存在于多个频率栈中。**

例如连续执行：

```
push(5);
push(5);
push(5);
```

会得到：

```
freq[5] = 3

group[1] = [5]
group[2] = [5]
group[3] = [5]

maxFreq = 3
```

这些记录分别代表 `5` 的频率达到 `1`、`2`、`3` 时的入栈事件。

#### 2. pop 操作

当前代码：

```
public int pop() {
    int val = group.get(maxFreq).pop();

    freq.put(val, freq.get(val) - 1);

    if (group.get(maxFreq).isEmpty()) {
        maxFreq--;
    }

    return val;
}
```

执行过程：

1. 找到最高频率对应的栈。
2. 弹出该栈的栈顶元素。
3. 将弹出元素的频率减一。
4. 如果最高频率对应的栈已经为空，则减少 `maxFreq`。
5. 返回弹出的元素。

这样既能保证频率最高优先，也能保证同频率下最近入栈的元素优先。

```java
class FreqStack {
    Map<Integer, Stack<Integer>> group;
    Map<Integer, Integer> freq;
    int maxFreq;

    public FreqStack() {
        group = new HashMap<>();
        freq = new HashMap<>();
        maxFreq = 0;
    }
    
    public void push(int val) {
        int curFreq = freq.getOrDefault(val, 0) + 1;
        freq.put(val, curFreq);
        maxFreq = Math.max(maxFreq, curFreq);
        Stack<Integer> stack = group.getOrDefault(curFreq, new Stack<>());
        stack.push(val);
        group.put(curFreq, stack);
    }
    
    public int pop() {
        int val = group.get(maxFreq).pop();
        freq.put(val, freq.get(val) - 1);
        if(group.get(maxFreq).isEmpty()){
            maxFreq--;
        }
        return val;
    }
}
```

## [880. 索引处的解码字符串](https://leetcode.cn/problems/decoded-string-at-index/)

### 题目

给定一个编码字符串 `s` 。请你找出 **解码字符串** 并将其写入磁带。解码时，从编码字符串中 **每次读取一个字符** ，并采取以下步骤：

- 如果所读的字符是字母，则将该字母写在磁带上。
- 如果所读的字符是数字（例如 `d`），则整个当前磁带总共会被重复写 `d-1` 次。

现在，对于给定的编码字符串 `s` 和索引 `k`，查找并返回解码字符串中的第 `k` 个字母。

 

**示例 1：**

```
输入：s = "leet2code3", k = 10
输出："o"
解释：
解码后的字符串为 "leetleetcodeleetleetcodeleetleetcode"。
字符串中的第 10 个字母是 "o"。
```

**示例 2：**

```
输入：s = "ha22", k = 5
输出："h"
解释：
解码后的字符串为 "hahahaha"。第 5 个字母是 "h"。
```

**示例 3：**

```
输入：s = "a2345678999999999999999", k = 1
输出："a"
解释：
解码后的字符串为 "a" 重复 8301530446056247680 次。第 1 个字母是 "a"。
```

 

**提示：**

- `2 <= s.length <= 100`
- `s` 只包含小写字母与数字 `2` 到 `9` 。
- `s` 以字母开头。
- `1 <= k <= 109`
- 题目保证 `k` 小于或等于解码字符串的长度。
- 解码后的字符串保证少于 `263` 个字母。

### 题解

#### 思路总结

当前实现采用**正序统计解码长度 + 逆序遍历 + 模运算**。

题目要求返回解码字符串中的第 `k` 个字符，但解码后的字符串可能非常长，无法直接构造完整字符串。

因此，可以从两个方向处理：

1. **正序遍历：** 只计算解码字符串的长度，不实际生成字符串。
2. **逆序遍历：** 撤销编码操作，通过模运算不断缩小目标字符所在的范围。
3. **确定目标字符：** 当逆序遇到某个字母，并且目标位置恰好对应当前解码字符串的最后一个字符时，直接返回该字母。

当前代码的核心操作是：

```
k %= size;
```

它能够将重复字符串中的目标位置映射回重复前的字符串。

#### 解题步骤

1. **初始化解码长度：** 定义 `long size = 0`，用于记录当前已经扫描的编码前缀所对应的解码字符串长度。
2. **正序遍历字符串：** 依次读取编码字符串 `s` 中的每个字符。
3. **处理普通字母：** 如果当前字符是小写字母，说明解码时会将该字符追加到字符串末尾，因此执行 `size++`。
4. **处理数字字符：** 如果当前字符是数字 `d`，说明当前整个字符串需要重复 `d` 次，因此执行 `size *= d`。
5. **完成长度统计：** 正序遍历结束后，`size` 就是完整解码字符串的长度。
6. **逆序遍历字符串：** 从编码字符串的最后一个字符开始，向前逐个还原编码操作。
7. **映射目标位置：** 每次处理字符前，先执行 `k %= size`，将目标位置映射到当前解码字符串对应的循环位置。
8. **撤销数字操作：** 如果当前字符是数字 `d`，说明正序时执行了重复操作，因此逆序时通过 `size /= d` 恢复重复前的长度。
9. **处理普通字母：** 如果当前字符是字母，说明正序时它被追加到了字符串末尾。如果此时 `k == 0`，则当前字母就是目标字符，直接返回。
10. **继续缩小字符串范围：** 如果当前字母不是目标字符，则执行 `size--`，撤销这个字母的追加操作，继续向前寻找。

```java
class Solution {
    public String decodeAtIndex(String s, int k) {
        long size = 0;
        int n = s.length();
        for(int i = 0; i < n; i++){
            char c = s.charAt(i);
            if(Character.isDigit(c)){
                size *= c - '0';
            }else {
                size++;
            }
        }

        for(int i = n - 1; i >= 0; i--){
            char c = s.charAt(i);
            k %= size;
            if(Character.isDigit(c)){
                size /= c - '0';
            }else {
                if(k == 0){
                    return String.valueOf(c);
                }
                size--;
            }
        }
        return "";
    }
}
```

## [856. 括号的分数](https://leetcode.cn/problems/score-of-parentheses/)

### 题目

给定一个平衡括号字符串 `S`，按下述规则计算该字符串的分数：

- `()` 得 1 分。
- `AB` 得 `A + B` 分，其中 A 和 B 是平衡括号字符串。
- `(A)` 得 `2 * A` 分，其中 A 是平衡括号字符串。

 

**示例 1：**

```
输入： "()"
输出： 1
```

**示例 2：**

```
输入： "(())"
输出： 2
```

**示例 3：**

```
输入： "()()"
输出： 2
```

**示例 4：**

```
输入： "(()(()))"
输出： 6
```

 

**提示：**

1. `S` 是平衡括号字符串，且只含有 `(` 和 `)` 。
2. `2 <= S.length <= 50`

### 题解

#### 思路总结

当前实现采用**递归 + 括号平衡计数 + 分治**。

题目给出了三条计算规则：

1. **基本情况：** `()` 的分数为 `1`。
2. **拼接情况：** `AB` 的分数为 `score(A) + score(B)`。
3. **嵌套情况：** `(A)` 的分数为 `2 * score(A)`。

当前代码直接按照这三条规则递归计算。

首先判断当前字符串是否为 `"()"`，如果是则返回 `1`。

否则，使用 `balance` 记录括号的嵌套深度。当 `balance` 第一次变为 `0` 时，说明找到了一个完整的平衡括号字符串。

- 如果该位置不是字符串末尾，说明字符串可以分解成 `A + B`，分别计算后相加。
- 如果直到字符串末尾才恢复平衡，说明整个字符串形如 `(A)`，去掉最外层括号后递归计算，并将结果乘以 `2`。

#### 解题步骤

1. **判断基本情况：** 如果当前字符串为 `"()"`，直接返回 `1`，作为递归终止条件。
2. **初始化括号计数：** 设置 `balance = 0`，记录尚未匹配的左括号数量。
3. **遍历当前字符串：** 遇到 `'('` 时将 `balance` 加一，遇到 `')'` 时将其减一。
4. **寻找平衡位置：** 当 `balance == 0` 时，说明从当前字符串起点到位置 `i` 构成了一个完整的平衡括号字符串。
5. **判断是否存在拼接：** 如果 `i != s.length() - 1`，说明后面还有字符，整个字符串可以拆分为 `A + B`。
6. **递归计算拼接分数：** 将字符串分成 `A = s.substring(0, i + 1)` 和 `B = s.substring(i + 1)`，返回 `score(A) + score(B)`。
7. **处理嵌套结构：** 如果遍历过程中不存在提前恢复平衡的位置，说明整个字符串形如 `(A)`。
8. **递归计算嵌套分数：** 去掉首尾括号，得到内部字符串 `A`，返回 `2 * score(A)`。
9. **返回最终答案：** 通过递归不断分解括号字符串，最终得到完整分数。

```java
class Solution {
    public int scoreOfParentheses(String s) {
        if(s.equals("()")){
            return 1;
        }
        int balance = 0;
        for(int i = 0; i < s.length(); i++){
            if(s.charAt(i) == '('){
                balance++;
            }else {
                balance--;
            }
            if(balance == 0){
                if(i != s.length() - 1){
                    String A = s.substring(0, i + 1);
                    String B = s.substring(i + 1);
                    return scoreOfParentheses(A) + scoreOfParentheses(B);
                }
            }
        }
        String in = s.substring(1, s.length() - 1);
        return 2 * scoreOfParentheses(in);
    }
}
```

## [844. 比较含退格的字符串](https://leetcode.cn/problems/backspace-string-compare/)

### 题目

给定 `s` 和 `t` 两个字符串，当它们分别被输入到空白的文本编辑器后，如果两者相等，返回 `true` 。`#` 代表退格字符。

**注意：**如果对空文本输入退格字符，文本继续为空。

 

**示例 1：**

```
输入：s = "ab#c", t = "ad#c"
输出：true
解释：s 和 t 都会变成 "ac"。
```

**示例 2：**

```
输入：s = "ab##", t = "c#d#"
输出：true
解释：s 和 t 都会变成 ""。
```

**示例 3：**

```
输入：s = "a#c", t = "b"
输出：false
解释：s 会变成 "c"，但 t 仍然是 "b"。
```

 

**提示：**

- `1 <= s.length, t.length <= 200`
- `s` 和 `t` 只含有小写字母以及字符 `'#'`

 

**进阶：**

- 你可以用 `O(n)` 的时间复杂度和 `O(1)` 的空间复杂度解决该问题吗？

### 题解

#### 思路总结

当前实现采用**StringBuilder 模拟栈 + 字符串比较**。

题目要求判断两个字符串经过退格操作后是否相等，其中 `'#'` 表示删除前面的一个字符。

当前代码通过 `build()` 方法分别处理 `s` 和 `t`：

- 遇到普通字母时，将字符追加到 `StringBuilder` 中。
- 遇到 `'#'` 时，如果 `StringBuilder` 不为空，就删除最后一个字符。
- 如果 `StringBuilder` 为空，则忽略当前退格操作。

最后比较两个处理后的字符串是否相等。

#### 解题步骤

1. **定义字符串处理方法：** 使用 `build(String s)` 模拟字符串输入和退格操作。
2. **初始化字符串构造器：** 创建 `StringBuilder sb`，保存当前文本编辑器中的有效字符。
3. **遍历输入字符串：** 依次读取字符串中的每个字符。
4. **处理普通字符：** 如果当前字符不是 `'#'`，则使用 `sb.append(c)` 将其添加到末尾。
5. **处理退格字符：** 如果当前字符是 `'#'`，并且 `sb` 不为空，则删除最后一个字符。
6. **忽略无效退格：** 如果当前字符是 `'#'`，但 `sb` 已经为空，则不执行任何操作。
7. **生成处理结果：** 遍历结束后，返回 `sb.toString()`。
8. **比较两个字符串：** 分别调用 `build(s)` 和 `build(t)`，通过 `equals()` 判断最终字符串是否相等。
9. **返回结果：** 如果两个字符串相等则返回 `true`，否则返回 `false`。

```java
class Solution {
    public boolean backspaceCompare(String s, String t) {
        return build(s).equals(build(t));
    }

    private String build(String s){
        StringBuilder sb = new StringBuilder();
        for(char c : s.toCharArray()){
            if(c != '#'){
                sb.append(c);
            }else {
                if(!sb.isEmpty()){
                    sb.deleteCharAt(sb.length() - 1);
                }
            }
        }
        return sb.toString();
    }
}

## [739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)

### 题目

给定一个整数数组 `temperatures` ，表示每天的温度，返回一个数组 `answer` ，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

 

**示例 1:**

```
输入: temperatures = [73,74,75,71,69,72,76,73]
输出: [1,1,4,2,1,1,0,0]
```

**示例 2:**

```
输入: temperatures = [30,40,50,60]
输出: [1,1,1,0]
```

**示例 3:**

```
输入: temperatures = [30,60,90]
输出: [1,1,0]
```

 

**提示：**

- `1 <= temperatures.length <= 105`
- `30 <= temperatures[i] <= 100`

 

### 题解

#### 思路总结

当前实现采用**单调栈 + 下一个更大元素**。

题目要求找到每一天之后，第一个温度严格高于当天温度的日期，并计算相隔的天数。

当前代码使用 `Deque<Integer>` 作为单调栈，保存**尚未找到更高温度的日期下标**。

遍历温度数组时：

- 如果当前温度小于或等于栈顶日期的温度，则将当前下标入栈。
- 如果当前温度严格大于栈顶日期的温度，说明当前日期就是栈顶日期之后第一个温度更高的日期。
- 不断弹出所有温度低于当前温度的栈顶下标，并通过下标差计算等待天数。
- 遍历结束后，栈中剩余的日期都没有更高温度，答案保持默认的 `0`。

#### 解题步骤

1. **初始化单调栈：** 创建 `Deque<Integer> stack`，用于保存尚未找到更高温度的日期下标。
2. **初始化结果数组：** 创建长度为 `n` 的 `ans`，默认所有元素为 `0`，表示暂时没有找到更高温度。
3. **从左向右遍历：** 使用下标 `i` 依次访问 `temperatures[i]`，将其作为当前日期的温度。
4. **检查栈顶温度：** 如果栈不为空，并且当前温度严格大于栈顶下标对应的温度，说明栈顶日期已经找到下一个更高温度。
5. **弹出栈顶下标：** 使用 `stack.pop()` 获取之前尚未找到更高温度的日期 `j`。
6. **计算等待天数：** 因为当前日期 `i` 是日期 `j` 之后第一个温度更高的日期，所以设置 `ans[j] = i - j`。
7. **连续处理满足条件的日期：** 继续检查新的栈顶，直到栈为空，或者栈顶温度大于等于当前温度。
8. **当前日期入栈：** 将下标 `i` 压入栈中，等待未来某一天出现更高温度。
9. **返回结果数组：** 遍历完成后，未被弹出的日期没有找到更高温度，对应答案保持为 `0`，直接返回 `ans`。

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        Deque<Integer> stack = new ArrayDeque<>();
        int n = temperatures.length;
        int[] ans = new int[n];
        for(int i = 0; i < n; i++){
            while(!stack.isEmpty() && temperatures[stack.peek()] < temperatures[i]){
                int j = stack.pop();
                ans[j] = i - j;
            }
            stack.push(i);
        }
        return ans;
    }
}
```

## [735. 小行星碰撞](https://leetcode.cn/problems/asteroid-collision/)

### 题目

给定一个整数数组 `asteroids`，表示在同一行的小行星。数组中小行星的索引表示它们在空间中的相对位置。

对于数组中的每一个元素，其绝对值表示小行星的大小，正负表示小行星的移动方向（正表示向右移动，负表示向左移动）。每一颗小行星以相同的速度移动。

找出碰撞后剩下的所有小行星。碰撞规则：两个小行星相互碰撞，较小的小行星会爆炸。如果两颗小行星大小相同，则两颗小行星都会爆炸。两颗移动方向相同的小行星，永远不会发生碰撞。

 

**示例 1：**

```
输入：asteroids = [5,10,-5]
输出：[5,10]
解释：10 和 -5 碰撞后只剩下 10 。 5 和 10 永远不会发生碰撞。
```

**示例 2：**

```
输入：asteroids = [8,-8]
输出：[]
解释：8 和 -8 碰撞后，两者都发生爆炸。
```

**示例 3：**

```
输入：asteroids = [10,2,-5]
输出：[10]
解释：2 和 -5 发生碰撞后剩下 -5 。10 和 -5 发生碰撞后剩下 10 。
```

**示例 4：**

```
输入：asteroids = [3,5,-6,2,-1,4]
输出：[-6,2,4]
解释：小行星 -6 使小行星 3 和 5 爆炸，然后继续向左移动。在另一边，小行星 2 摧毁了小行星 -1。由于 2 和 4 都向右移动，它们永远不会相撞。
```

 

**提示：**

- `2 <= asteroids.length <= 104`
- `-1000 <= asteroids[i] <= 1000`
- `asteroids[i] != 0`

### 题解

#### 思路总结

当前实现采用**栈 + 碰撞模拟**。

题目要求模拟小行星之间的碰撞，并返回最终存活的小行星。

由于所有小行星的移动速度相同，因此只有一种情况可能发生碰撞：

**左侧小行星向右移动，右侧小行星向左移动。**

对应条件为：

```
stack.peek() > 0 && asteroid < 0
```

当前代码使用栈保存尚未被摧毁的小行星，并从左向右遍历数组。

当遇到向右移动的小行星时，直接入栈；当遇到向左移动的小行星时，判断它是否会与栈顶发生碰撞。

根据双方大小，有三种结果：

- **当前小行星更大：** 栈顶小行星爆炸，继续检查新的栈顶。
- **双方大小相等：** 两颗小行星同时爆炸。
- **栈顶小行星更大：** 当前小行星爆炸，栈顶保持不变。

#### 解题步骤

1. **初始化栈：** 创建 `Deque<Integer> stack`，保存当前尚未被摧毁的小行星。
2. **遍历小行星数组：** 依次读取当前小行星 `asteroid`，按照其移动方向进行处理。
3. **处理向右移动的小行星：** 如果 `asteroid > 0`，直接入栈。由于当前小行星位于此前所有小行星的右侧，不会立即发生碰撞。
4. **处理向左移动的小行星：** 如果 `asteroid < 0`，检查栈顶是否存在向右移动的小行星。
5. **判断当前小行星是否更大：** 如果栈顶为正数，且 `stack.peek() + asteroid < 0`，说明当前负数小行星更大，弹出栈顶。
6. **处理连续碰撞：** 重复弹栈过程，直到栈为空、栈顶为负数，或者当前小行星无法继续摧毁栈顶。
7. **判断是否能够存活：** 如果栈为空，或者栈顶为负数，说明当前小行星不会再发生碰撞，将其入栈。
8. **处理大小相等的碰撞：** 如果栈顶为正数，并且 `stack.peek() + asteroid == 0`，说明双方大小相等，弹出栈顶，当前小行星也不入栈。
9. **处理当前小行星被摧毁的情况：** 如果栈顶为正数，并且其大小大于当前小行星，则保持栈不变，直接处理下一颗小行星。
10. **构造结果数组：** 遍历结束后，将栈中的元素依次弹出，并从结果数组的末尾向前填充，恢复原始的相对位置顺序。
11. **返回最终结果：** 返回所有碰撞结束后存活的小行星数组。

```java
class Solution {
    public int[] asteroidCollision(int[] asteroids) {
        Deque<Integer> stack = new ArrayDeque<>();
        for(int asteroid : asteroids){
            if(asteroid > 0){
                stack.push(asteroid);
                continue;
            }
            while(!stack.isEmpty() && asteroid < 0 && stack.peek() > 0 && stack.peek() + asteroid < 0){
                stack.pop();
            }
            if(stack.isEmpty() || stack.peek() < 0){
                stack.push(asteroid);
            }else {
                if(stack.peek() + asteroid == 0){
                    stack.pop();
                }
            }
        }
        int n = stack.size();
        int[] ans = new int[n];
        for(int i = n - 1; i >= 0; i--){
            ans[i] = stack.pop();
        }
        return ans;
    }
}
```

## [726. 原子的数量](https://leetcode.cn/problems/number-of-atoms/)

给你一个字符串化学式 `formula` ，返回 **每种原子的数量** 。

- `formula` 由英文字母、数字、`'('` 和 `')'` 组成
- `formula` 总是有效的化学式

### 题解

#### 思路总结

当前实现采用**栈 + 哈希表 + 括号解析 + 字典序排序**。

题目要求统计化学式中每种原子的总数量，其中需要特别处理两种情况：

- **普通原子：** 例如 `H2O`，表示两个 `H` 和一个 `O`。
- **括号嵌套：** 例如 `Mg(OH)2`，括号内所有原子的数量都需要乘以 `2`。

当前代码使用：

```
Deque<Map<String, Integer>> stack = new ArrayDeque<>();
```

栈中的每个 `Map` 表示当前括号层级内的原子数量。

遍历化学式时：

- 遇到 `'('`：创建新的哈希表入栈，开始统计括号内部的原子。
- 遇到 `')'`：弹出当前括号对应的哈希表，读取括号后的倍数，再将原子数量合并到外层哈希表。
- 遇到大写字母：解析完整的原子名称及其数量，并累加到当前哈希表中。

最后通过 `TreeMap` 将原子名称按照字典序排序，并构造结果字符串。

#### 解题步骤

1. **初始化栈：** 创建 `Deque<Map<String, Integer>>`，用于保存不同括号层级对应的原子统计结果。
2. **创建最外层哈希表：** 首先向栈中压入一个空的 `HashMap`，用于保存整个化学式的统计结果。
3. **初始化遍历指针：** 设置 `i = 0`，从左向右遍历化学式。
4. **处理左括号：** 如果当前字符为 `'('`，创建一个新的 `HashMap` 并入栈，表示进入新的括号层级。
5. **处理右括号：** 如果当前字符为 `')'`，弹出栈顶哈希表，得到当前括号内部的原子统计结果。
6. **解析括号倍数：** 从右括号后面读取连续数字，得到当前括号对应的倍数 `sum`；如果没有数字，则默认倍数为 `1`。
7. **合并括号内原子数量：** 遍历弹出的哈希表，将每种原子的数量乘以 `sum`，然后累加到外层哈希表中。
8. **解析普通原子名称：** 如果当前字符为大写字母，则继续读取后续小写字母，得到完整原子名称，例如 `H`、`Mg`、`He`。
9. **解析原子数量：** 继续读取原子名称后的数字。如果不存在数字，则当前原子的数量默认为 `1`。
10. **更新当前层级统计结果：** 将解析出的原子名称及数量累加到栈顶哈希表中。
11. **按字典序排序：** 遍历完成后，将最外层哈希表转换为 `TreeMap`，使原子名称按字典序排列。
12. **构造结果字符串：** 依次追加原子名称及数量。如果数量为 `1`，则只追加原子名称。
13. **返回最终结果：** 将 `StringBuilder` 转换为字符串并返回。

```java
class Solution {
    public String countOfAtoms(String formula) {
        int n = formula.length();
        Deque<Map<String, Integer>> stack = new ArrayDeque<>();
        stack.push(new HashMap<>());
        int i = 0;
        while(i < n){
            char c = formula.charAt(i);
            if(c == '('){
                stack.push(new HashMap<>());
                i++;
            }else if(c == ')'){
                Map<String, Integer> top = stack.pop();
                Map<String, Integer> parent = stack.peek();
                int sum = 0;
                i++;
                while(i < n && Character.isDigit(formula.charAt(i))){
                    sum = sum * 10 + formula.charAt(i) - '0';
                    i++;
                }
                if(sum == 0){
                    sum = 1;
                }
                for(String s : top.keySet()){
                    parent.put(s, parent.getOrDefault(s, 0) + top.get(s) * sum);
                }
            }else {
                int start = i++;
                while(i < n && Character.isLowerCase(formula.charAt(i))){
                    i++;
                }
                String atom = formula.substring(start, i);
                int sum = 0;
                while(i < n && Character.isDigit(formula.charAt(i))){
                    sum = sum * 10 + formula.charAt(i) - '0';
                    i++;
                }
                if(sum == 0){
                    sum = 1;
                }
                stack.peek().put(atom, stack.peek().getOrDefault(atom, 0) + sum);
            }
        }

        Map<String, Integer> result = new TreeMap<>(stack.pop());
        StringBuilder sb = new StringBuilder();
        for(String s : result.keySet()){
            sb.append(s);
            int num = result.get(s);
            if(num > 1){
                sb.append(num);
            }
        }
        return sb.toString();
    }
}
```

- 对于 `"C"` 和 `"D"` 操作，题目数据保证记录此操作时前面总是存在一个有效的分数

### 题解

#### 思路总结

当前实现采用 **栈 + 模拟**，按照操作顺序维护比赛中所有仍然有效的得分，最终计算这些得分的总和。

**1. 栈的作用**

当前代码使用：

```java
Deque<Integer> stack = new ArrayDeque<>();
```

其中，栈保存当前所有有效的得分，并且：

- **栈顶**表示最近一次有效得分。
- **栈顶下方的元素**表示倒数第二次有效得分。
- 新增得分时，使用 `push()`。
- 取消得分时，使用 `pop()`。
- 查看最近一次得分时，使用 `peek()`。

由于栈具有 **后进先出（LIFO）** 的特点，因此能够直接处理 `"C"` 和 `"D"` 操作。

**2. 四种操作的处理方式**

**情况一：普通整数**

当操作为一个整数时，将字符串转换成整数，然后压入栈中。

```java
stack.push(Integer.valueOf(op));
```

**情况二：操作 "D"**

当前得分等于最近一次有效得分的两倍。

```java
stack.push(stack.peek() * 2);
```

**情况三：操作 "C"**

取消最近一次有效得分，因此直接弹出栈顶元素。

```java
stack.pop();
```

**情况四：操作 "+"**

当前得分等于最近两次有效得分之和。

当前实现：

```java
int sum = stack.pop() + stack.peek();
stack.push(sum - stack.peek());
stack.push(sum);
```

**3. 计算最终得分**

所有操作处理完成后，栈中保存的就是全部有效得分。

当前代码：

```java
int ans = 0;

while (!stack.isEmpty()) {
    ans += stack.pop();
}

return ans;
```

依次弹出所有有效得分并累加，最终得到答案。

---

#### 解题步骤

1. **初始化栈：** 使用 `Deque<Integer> stack = new ArrayDeque<>()`，保存所有尚未取消的有效得分。

2. **遍历操作数组：** 依次读取 `operations` 中的每个字符串 `op`，按照操作类型更新得分记录。

3. **处理普通整数：** 如果 `op` 不是 `"+"`、`"D"` 或 `"C"`，则使用 `Integer.valueOf(op)` 将其转换为整数，并通过 `stack.push()` 压入栈顶。

4. **处理 `"D"` 操作：** 使用 `stack.peek()` 获取最近一次有效得分，将其乘以 `2` 后压入栈中，作为本回合的新得分。

5. **处理 `"C"` 操作：** 使用 `stack.pop()` 删除最近一次有效得分，使该得分不再参与后续计算。

6. **处理 `"+"` 操作：** 先使用 `stack.pop()` 取出最近一次得分，再使用 `stack.peek()` 获取倒数第二次得分，计算两者之和。

7. **恢复原来的最近一次得分：** 由于 `"+"` 只需要增加一条记录，不能删除原有得分，因此使用 `sum - stack.peek()` 恢复之前弹出的元素。

8. **记录 `"+"` 操作的新得分：** 将计算得到的 `sum` 压入栈中，使其成为最新的一次有效得分。

9. **遍历完成后初始化总分：** 设置 `ans = 0`，用于保存所有有效得分的总和。

10. **依次累加有效得分：** 当栈不为空时，不断使用 `stack.pop()` 取出得分，并累加到 `ans` 中。

11. **返回最终结果：** 当所有有效得分都已累加后，返回 `ans`，即比赛记录中的总分。

```java
class Solution {
    public int calPoints(String[] operations) {
        Deque<Integer> stack = new ArrayDeque<>();
        for(String op : operations){
            if(op.equals("+")){
                int sum = stack.pop() + stack.peek();
                stack.push(sum - stack.peek());
                stack.push(sum);
            }else if(op.equals("D")){
                stack.push(stack.peek() * 2);
            }else if(op.equals("C")){
                stack.pop();
            }else {
                stack.push(Integer.valueOf(op));
            }
        }
        int ans = 0;
        while(!stack.isEmpty()){
            ans += stack.pop();
        }
        return ans;
    }
}
```

## [636. 函数的独占时间](https://leetcode.cn/problems/exclusive-time-of-functions/)

### 题目

有一个 **单线程** CPU 正在运行一个含有 `n` 道函数的程序。每道函数都有一个位于 0 和 `n-1` 之间的唯一标识符。

- `0 <= timestamp <= 109`
- 两个开始事件不会在同一时间戳发生
- 两个结束事件不会在同一时间戳发生
- 每道函数都有一个对应 `"start"` 日志的 `"end"` 日志

### 题解

#### 思路总结

当前实现采用 **栈 + 时间区间模拟 + 时间差累计**，计算单线程 CPU 中每个函数的独占执行时间。

本题的核心是：**利用调用栈确定当前正在执行的函数，再根据相邻日志的时间戳计算实际执行时间。**

**1. 栈的作用**

当前代码使用：

```java
Deque<Integer> stack = new ArrayDeque<>();
```

栈中保存尚未结束的函数调用，其特点是：

- 栈顶元素表示当前正在执行的函数。
- 当新函数开始时，将其编号压入栈中。
- 当当前函数结束时，将其编号弹出栈。
- 如果函数调用其他函数，原函数会留在栈中，等待子函数结束后恢复执行。

**2. 定义时间边界 pre**

当前代码使用：

```java
int pre = 0;
```

其中：**`pre` 表示当前尚未结算的执行时间段的起始时间戳。**

每遇到一条日志，就根据日志类型，结算自 `pre` 开始、到当前事件为止的执行时间。

这个变量可以避免单独记录每次函数开始和暂停的时间。

**3. 处理 start 日志**

假设当前日志为：

```text
1:start:2
```

表示函数 `1` 从时间戳 `2` 的起始时刻开始执行。

如果调用栈不为空，说明此前有一个函数正在执行，现在它将被新函数暂停。

因此，需要先结算原函数在时间区间 `[pre, time)` 内的独占时间。

对应时间长度为：

$$
time-pre
$$

随后，将新函数编号压入栈：

```java
stack.push(id);
```

更新待结算时间段的起点：

```java
pre = time;
```

**4. 处理 end 日志**

假设当前日志为：

```text
1:end:5
```

表示函数 `1` 在时间戳 `5` 的末尾结束执行。

因此，这个函数实际占用了从 `pre` 到 `time` 的所有整数时间单位。

对应时间长度为：

$$
time-pre+1
$$

最后更新：

```java
pre = time + 1;
```

因为结束时间戳 `time` 已经被结算，下一段尚未结算的执行时间应当从 `time+1` 开始。

---

#### 解题步骤

1. **初始化答案数组：** 创建 `ans[n]`，其中 `ans[id]` 表示函数 `id` 的累计独占时间，初始值全部为 `0`。

2. **初始化时间边界：** 设置 `pre = 0`，表示当前尚未结算的执行时间段的起始时间。

3. **初始化调用栈：** 创建 `Deque<Integer> stack = new ArrayDeque<>()`，保存所有已经开始但尚未结束的函数调用。

4. **遍历日志列表：** 按照给定顺序依次处理 `logs` 中的每一条日志。

5. **解析日志字符串：** 使用 `split(":")` 将日志分为函数编号、事件类型和时间戳三个部分。

6. **提取函数编号和时间戳：** 使用 `Integer.parseInt()` 将字符串转换为整数，得到 `id` 和 `time`。

7. **判断是否为 start 日志：** 如果事件类型为 `"start"`，说明新的函数调用即将占用 CPU。

8. **结算此前正在执行的函数：** 如果调用栈不为空，说明栈顶函数从 `pre` 执行到了 `time` 的起始时刻，因此将 `time - pre` 累加到 `ans[stack.peek()]`。

9. **记录新函数调用：** 将新函数编号 `id` 压入调用栈，表示该函数开始执行。

10. **更新时间边界：** 对于 `start` 日志，设置 `pre = time`，表示新函数从当前时间戳开始占用 CPU。

11. **处理 end 日志：** 如果当前日志类型为 `"end"`，说明栈顶函数在时间戳 `time` 的末尾结束执行。

12. **结算结束函数的独占时间：** 弹出栈顶函数，并将 `time - pre + 1` 累加到其答案中。这里加 `1` 是因为结束时间戳本身也属于函数的执行时间。

13. **更新下一段执行时间的起点：** 设置 `pre = time + 1`，避免已经结算的时间单位被重复统计。

14. **继续处理后续日志：** 重复上述操作，调用栈会自动维护函数之间的调用、暂停、恢复和结束关系。

15. **返回最终答案：** 所有日志处理完成后，返回 `ans`，得到每个函数的独占执行时间。

```java
class Solution {
    public int[] exclusiveTime(int n, List<String> logs) {
        int[] ans = new int[n];
        int pre = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        for(String log : logs){
            String[] a = log.split(":");
            int id = Integer.parseInt(a[0]);
            int time = Integer.parseInt(a[2]);
            if(a[1].equals("start")){
                if(!stack.isEmpty()){
                    ans[stack.peek()] += time - pre;
                }
                stack.push(id);
                pre = time;
            }else {
                ans[stack.pop()] += time - pre + 1;
                pre = time + 1;
            }
        }
        return ans;
    }
}
```

## [503. 下一个更大元素 II](https://leetcode.cn/problems/next-greater-element-ii/)

### 题目

给定一个循环数组 `nums` （ `nums[nums.length - 1]` 的下一个元素是 `nums[0]` ），返回 *`nums` 中每个元素的 **下一个更大元素*** 。

数字 `x` 的 **下一个更大的元素** 是按数组遍历顺序，这个数字之后的第一个比它更大的数，这意味着你应该循环地搜索它的下一个更大的数。如果不存在，则输出 `-1` 。

 

**示例 1:**

```
输入: nums = [1,2,1]
输出: [2,-1,2]
解释: 第一个 1 的下一个更大的数是 2；
数字 2 找不到下一个更大的数； 
第二个 1 的下一个最大的数需要循环搜索，结果也是 2。
```

**示例 2:**

```
输入: nums = [1,2,3,4,3]
输出: [2,3,4,-1,4]
```

 

**提示:**

- `1 <= nums.length <= 104`
- `-109 <= nums[i] <= 109`

### 题解

#### 思路总结

本题采用 **单调栈 + 循环遍历** 的思想，解决循环数组中的下一个更大元素问题。

与普通的下一个更大元素不同，循环数组允许从数组末尾继续回到数组开头，因此需要考虑两种情况：

1. 当前元素右侧存在更大的元素。
2. 当前元素右侧不存在更大的元素，但数组开头到当前元素之前存在更大的元素。

**1. 单调栈的定义**

使用栈保存尚未找到下一个更大元素的数组下标：

```java
Deque<Integer> stack = new ArrayDeque<>();
```

栈中存储的是下标，而不是元素值，方便通过下标访问原数组以及更新答案数组。

**2. 单调栈的维护**

遍历数组时，如果当前元素大于栈顶下标对应的元素，说明当前元素就是栈顶元素的下一个更大元素。

因此：

- 不断弹出栈顶下标。
- 将当前元素赋值给对应的答案位置。
- 直到栈为空，或者栈顶元素大于等于当前元素。

**3. 循环数组的处理**

当前代码采用两次遍历：

- 第一次从左向右遍历，寻找每个元素右侧的第一个更大元素。
- 第二次再次从左向右遍历，利用数组开头部分的元素，寻找第一次遍历尚未解决的答案。

第一次遍历结束后，栈中剩余的下标表示：在当前位置右侧没有找到更大元素的元素。

第二次遍历相当于补充检查循环数组中的前半部分。

#### 解题步骤

1. **初始化变量：** 获取数组长度 `n`，创建答案数组 `ans`，并将所有元素初始化为 `-1`。

2. **初始化单调栈：** 创建 `Deque<Integer>`，用于保存尚未找到下一个更大元素的下标。

3. **初始化最大值：** 设置 `max = Integer.MIN_VALUE`，用于记录数组中的全局最大值，优化第二次遍历。

4. **第一次遍历数组：** 从下标 `0` 开始遍历到 `n-1`，逐个处理数组元素。

5. **更新最大值：** 使用 `Math.max()` 更新当前遍历范围内的最大值。

6. **维护单调栈：** 当栈不为空，并且当前元素严格大于栈顶下标对应的元素时，持续执行弹栈操作。

7. **更新答案：** 每次弹出一个下标 `idx`，将当前元素 `nums[i]` 设置为 `ans[idx]`，表示找到了该元素的下一个更大元素。

8. **当前下标入栈：** 完成弹栈操作后，将当前下标 `i` 压入栈中，等待后续更大元素的出现。

9. **第二次遍历数组：** 从数组开头重新遍历，利用循环数组的特性，为第一次遍历中尚未找到答案的元素寻找更大的元素。

10. **判断是否可以提前结束：** 如果栈顶元素等于全局最大值，说明栈中剩余元素均为全局最大值，不可能再找到更大的元素，直接结束遍历。

11. **继续维护单调栈：** 如果当前元素大于栈顶元素，则持续弹栈，并更新对应位置的答案。

12. **返回结果：** 遍历结束后，返回答案数组 `ans`。仍为 `-1` 的位置表示不存在下一个更大元素。

```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        Deque<Integer> stack = new ArrayDeque<>();
        int max = Integer.MIN_VALUE;
        int n = nums.length;
        int[] ans = new int[n];
        Arrays.fill(ans, -1);
        for(int i = 0; i < n; i++){
            max = Math.max(max, nums[i]);
            while(!stack.isEmpty() && nums[stack.peek()] < nums[i]){
                ans[stack.pop()] = nums[i];
            }
            stack.push(i);
        }
        for(int i = 0; i < n && !stack.isEmpty(); i++){
            if(nums[stack.peek()] == max){
                break;
            }
            while(!stack.isEmpty() && nums[stack.peek()] < nums[i]){
                ans[stack.pop()] = nums[i];
            }
        }
        return ans;
    }
}
```

## [496. 下一个更大元素 I](https://leetcode.cn/problems/next-greater-element-i/)

### 题目

`nums1` 中数字 `x` 的 **下一个更大元素** 是指 `x` 在 `nums2` 中对应位置 **右侧** 的 **第一个** 比 `x` 大的元素。

```

**进阶：**你可以设计一个时间复杂度为 `O(nums1.length + nums2.length)` 的解决方案吗？

### 题解

#### 思路总结

本题采用 **单调栈 + 哈希表** 的方式，解决下一个更大元素问题。

核心思想是：先遍历 `nums2`，利用单调栈找出每个元素的下一个更大元素，并通过哈希表建立元素与答案之间的映射关系。最后遍历 `nums1`，直接从哈希表中获取对应答案。

**1. 哈希表初始化**

```java
Map<Integer, Integer> map = new HashMap<>();
for(int num : nums2){
    map.put(num, -1);
}
```

将 `nums2` 中所有元素的默认答案初始化为 `-1`。

这样，如果某个元素始终没有找到更大的元素，就保留 `-1`。

**2. 单调栈维护**

使用单调递减栈，保存尚未找到下一个更大元素的数字。

遍历 `nums2` 时：

- 如果栈为空，直接将当前元素入栈。
- 如果当前元素小于等于栈顶元素，直接入栈。
- 如果当前元素大于栈顶元素，说明当前元素就是栈顶元素的下一个更大元素。
- 不断弹出小于当前元素的栈顶元素，并更新哈希表。

**3. 查询答案**

由于 `nums1` 是 `nums2` 的子集，因此可以直接通过哈希表查询：

```java
ans[i] = map.get(nums1[i]);
```

不需要再次遍历 `nums2`，每次查询的平均时间复杂度为 O(1)。

#### 解题步骤

1. **初始化哈希表：** 创建 `HashMap<Integer, Integer>`，遍历 `nums2`，将每个元素作为 key，默认答案 `-1` 作为 value。

2. **初始化单调栈：** 创建 `Deque<Integer>`，用于保存尚未找到下一个更大元素的数字。

3. **遍历 nums2：** 从左向右遍历数组，将当前元素记为 `j`。

4. **维护单调栈：** 当栈不为空，并且当前元素 `j` 大于栈顶元素时，说明找到了栈顶元素的下一个更大元素。

5. **更新哈希表：** 弹出栈顶元素，并将当前元素 `j` 设置为该元素对应的下一个更大元素。

6. **重复弹栈：** 持续执行上述操作，直到栈为空或者栈顶元素大于等于当前元素。

7. **当前元素入栈：** 将当前元素 `j` 压入栈中，等待后续更大元素的出现。

8. **初始化答案数组：** 创建长度为 `nums1.length` 的数组 `ans`。

9. **查询结果：** 遍历 `nums1`，通过哈希表查询每个元素对应的下一个更大元素，并赋值给 `ans`。

10. **返回结果：** 返回答案数组 `ans`。

```java
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        Map<Integer, Integer> map = new HashMap<>();
        for(int num : nums2){
            map.put(num, -1);
        }
        Deque<Integer> stack = new ArrayDeque<>();
        for (int j : nums2) {
            while (!stack.isEmpty() && stack.peek() < j) {
                map.put(stack.pop(), j);
            }
            stack.push(j);
        }

        int n = nums1.length;
        int[] ans = new int[n];
        for(int i = 0; i < n; i++){
            ans[i] = map.get(nums1[i]);
        }
        return ans;
    }
}
```

## [456. 132 模式](https://leetcode.cn/problems/132-pattern/)

### 题目

给你一个整数数组 `nums` ，数组中共有 `n` 个整数。**132 模式的子序列** 由三个整数 `nums[i]`、`nums[j]` 和 `nums[k]` 组成，并同时满足：`i < j < k` 和 `nums[i] < nums[k] < nums[j]` 。

如果 `nums` 中存在 **132 模式的子序列** ，返回 `true` ；否则，返回 `false` 。

 

**示例 1：**

```
输入：nums = [1,2,3,4]
输出：false
解释：序列中不存在 132 模式的子序列。
```

**示例 2：**

```
输入：nums = [3,1,4,2]
输出：true
解释：序列中有 1 个 132 模式的子序列： [1, 4, 2] 。
```

**示例 3：**

```
输入：nums = [-1,3,2,0]
输出：true
解释：序列中有 3 个 132 模式的的子序列：[-1, 3, 2]、[-1, 3, 0] 和 [-1, 2, 0] 。
```

 

**提示：**

- `n == nums.length`
- `1 <= n <= 2 * 105`
- `-109 <= nums[i] <= 109`

### 题解

#### 思路总结

当前实现采用 **单调栈 + 逆序遍历 + 维护候选值**，判断整数数组中是否存在满足条件的 `132` 模式子序列。

题目要求找到三个下标：

$$
i<j<k
$$

同时满足：

$$
nums[i]<nums[k]<nums[j]
$$

其中：

- `nums[i]`：三个数字中最小的值，对应模式中的 **1**。
- `nums[j]`：三个数字中最大的值，对应模式中的 **3**。
- `nums[k]`：大小介于两者之间的值，对应模式中的 **2**。

**本题的关键是：从右向左遍历数组，利用单调栈寻找可以组成 `3、2` 的元素组合，再判断左侧是否存在更小的 `1`。**

**1. 为什么从右向左遍历？**

对于 `132` 模式：

$$
nums[i]<nums[k]<nums[j]
$$

需要保证三个元素的下标顺序为：

$$
i<j<k
$$

如果从右向左遍历，就可以先处理右侧的元素，寻找符合：

$$
nums[j]>nums[k]
$$

的组合。

当这样的组合存在时，只需要继续向左寻找一个满足：

$$
nums[i]<nums[k]
$$

的元素，就找到了完整的 `132` 模式。

因此，逆序遍历能够将三个元素之间的关系转化为逐步确定候选值的问题。

**2. 单调栈的作用**

当前代码使用单调栈保存右侧已经遍历过、尚未被弹出的元素值。

栈中元素从栈底到栈顶保持 **单调不增**：

$$
stack[0]\ge stack[1]\ge\cdots\ge stack[top]
$$

当当前元素大于栈顶元素时：说明当前元素可以作为模式中的 **3**，被弹出的栈顶元素可以作为模式中的 **2**。

由于当前元素的下标更小，因此能够保证：

$$
j<k
$$

同时，弹栈条件保证：

$$
nums[k]<nums[j]
$$

这样就找到了满足顺序关系的 `3、2` 组合。

---

#### 解题步骤

1. **获取数组长度：** 使用 `n = nums.length`，记录数组中的元素数量。

2. **初始化单调栈：** 创建 `Deque<Integer> stack`，保存从右向左遍历时尚未被弹出的元素值。

3. **初始化数字 2 的候选值：** 设置 `second = Integer.MIN_VALUE`，表示当前尚未找到合法的 `3、2` 组合。

4. **从右向左遍历数组：** 使用 `i` 从 `n-1` 递减到 `0`，保证已经处理的所有元素都位于当前位置右侧。

5. **检查是否能够组成 132 模式：** 如果 `nums[i] < second`，说明当前元素能够作为模式中的 `1`，并且右侧已经存在合法的 `3、2` 组合，直接返回 `true`。

6. **尝试使用当前元素作为数字 3：** 如果尚未找到完整模式，则比较当前元素与栈顶元素。

7. **维护单调栈：** 当栈不为空，并且 `nums[i] > stack.peek()` 时，说明当前元素比栈顶元素大，可以形成合法的 `3、2` 组合。

8. **更新数字 2 的候选值：** 弹出栈顶元素，并赋值给 `second`，将其作为当前已找到的数字 `2` 候选值。

9. **持续弹出较小元素：** 重复弹栈操作，直到栈为空，或者栈顶元素大于等于当前元素。

10. **将当前元素入栈：** 执行 `stack.push(nums[i])`，使栈继续保持从栈底到栈顶单调不增的性质。

11. **继续向左寻找更小元素：** 通过后续遍历，判断是否存在比 `second` 更小的元素，从而组成完整的 `132` 模式。

12. **返回最终结果：** 如果整个数组遍历完成后，仍然没有找到满足 `nums[i] < nums[k] < nums[j]` 且 `i < j < k` 的三个元素，则返回 `false`。

```java
class Solution {
    public boolean find132pattern(int[] nums) {
        int n = nums.length;
        Deque<Integer> stack = new ArrayDeque<>();
        int second = Integer.MIN_VALUE;
        for(int i = n - 1; i >= 0; i--){
            if(nums[i] < second){
                return true;
            }
            while(!stack.isEmpty() && nums[i] > stack.peek()){
                second = stack.pop();
            }
            stack.push(nums[i]);
        }
        return false;
    }
}
```

## [402. 移掉 K 位数字](https://leetcode.cn/problems/remove-k-digits/)

### 题目

给你一个以字符串表示的非负整数 `num` 和一个整数 `k` ，移除这个数中的 `k` 位数字，使得剩下的数字最小。请你以字符串形式返回这个最小的数字。

 

**示例 1 ：**

```
输入：num = "1432219", k = 3
输出："1219"
解释：移除掉三个数字 4, 3, 和 2 形成一个新的最小的数字 1219 。
```

**示例 2 ：**

```
输入：num = "10200", k = 1
输出："200"
解释：移掉首位的 1 剩下的数字为 200. 注意输出不能有任何前导零。
```

**示例 3 ：**

```
输入：num = "10", k = 2
输出："0"
解释：从原数字移除所有的数字，剩余为空就是 0 。
```

 

**提示：**

- `1 <= k <= num.length <= 105`
- `num` 仅由若干位数字（0 - 9）组成
- 除了 **0** 本身之外，`num` 不含任何前导零

### 题解

#### 思路总结

当前实现采用 **单调栈 + 贪心算法**，在删除恰好 `k` 位数字的前提下，使剩余数字组成的非负整数尽可能小。

**本题的核心是：对于位数相同的两个非负整数，越靠左的数字越小，整个整数通常就越小。因此，应优先删除靠左且比后面数字更大的数字。**

这种局部贪心选择可以通过单调栈高效实现。

**1. 单调栈的定义**

当前代码：

```java
Deque<Character> stack = new ArrayDeque<>();
```

使用栈保存尚未被删除的数字字符。

其中：

- 栈底对应保留数字的左侧。
- 栈顶对应保留数字的右侧。
- 新数字从栈顶加入。
- 当新数字小于栈顶数字时，可以考虑删除栈顶数字。

**在仍有删除次数且已完成必要弹栈的情况下，栈中保留的数字从栈底到栈顶单调不减。**

需要注意，如果删除次数已经用完，后续数字只能直接入栈，此时整个栈不一定继续满足单调性。

**2. 贪心删除策略**

当前代码：

```java
while (!stack.isEmpty() && k > 0 && stack.peek() > c) {
    stack.pop();
    k--;
}
```

当满足以下三个条件时：

- 栈不为空。
- 还有剩余删除次数。
- 栈顶数字大于当前数字。

就删除栈顶数字。

原因是：**在必须保留相同数量数字的前提下，让更小的数字尽可能靠前，能够使最终结果更小。**

**3. 遍历结束后还要继续删除**

当前代码：

```java
while (k > 0) {
    stack.pop();
    k--;
}
```

如果整个数字基本呈单调不减趋势，例如：

```text
num = "12345"
k = 2
```

遍历过程中不会出现前面的数字大于后面数字的情况，因此没有数字被弹出。

但题目要求必须删除恰好 `2` 位。

此时应删除最后两位：

```text
12345 → 123
```

因为在无法通过删除逆序数字改善前面数位时，保留更靠左的数字能够得到更小的结果。

因此，**当遍历结束后仍有剩余删除次数，应当从保留序列的末尾继续删除。**

---

#### 解题步骤

1. **初始化单调栈：** 创建 `Deque<Character> stack`，保存当前决定保留的数字字符。

2. **从左向右遍历字符串：** 使用 `num.toCharArray()` 获取所有数字字符，并依次处理当前字符 `c`。

3. **判断是否可以删除较大的数字：** 如果栈不为空、剩余删除次数 `k > 0`，并且栈顶数字大于当前数字，则可以通过删除栈顶数字改善最终结果。

4. **删除栈顶数字：** 执行 `stack.pop()`，移除当前保留序列末尾较大的数字。

5. **减少删除次数：** 每删除一个数字，就执行 `k--`，保证总删除次数不会超过题目要求。

6. **持续执行贪心删除：** 使用 `while` 循环重复检查栈顶，直到栈为空、删除次数用完，或者栈顶数字小于等于当前数字。

7. **将当前数字入栈：** 执行 `stack.push(c)`，将当前数字加入保留序列。

8. **处理遍历结束后剩余的删除次数：** 如果 `k > 0`，说明还需要删除部分数字，则不断弹出栈顶，直到删除次数全部用完。

9. **初始化结果字符串：** 创建 `StringBuilder sb`，用于存储最终保留的数字。

10. **将栈中数字依次取出：** 不断执行 `stack.pop()`，将所有保留数字添加到 `sb` 中。此时字符顺序与原来的保留顺序相反。

11. **清理前导零：** 当 `sb` 非空且最后一个字符为 `'0'` 时，持续删除末尾字符。由于 `sb` 当前为反序，这相当于清理正序结果中的前导零。

12. **判断结果是否为空：** 如果清理后 `sb` 为空，说明剩余数字全部为零或者所有数字都已经删除，返回 `"0"`。

13. **恢复数字顺序：** 如果 `sb` 非空，则执行 `sb.reverse()`，恢复原始数字的相对顺序。

14. **返回最终结果：** 将反转后的 `StringBuilder` 转换为字符串，得到删除恰好 `k` 位数字后的最小非负整数。

```java
class Solution {
    public String removeKdigits(String num, int k) {
        Deque<Character> stack = new ArrayDeque<>();
        for(char c : num.toCharArray()){
            while(!stack.isEmpty() && k > 0 && stack.peek() > c){
                stack.pop();
                k--;
            }
            stack.push(c);
        }
        while(k > 0){
            stack.pop();
            k--;
        }
        StringBuilder sb = new StringBuilder();
        while(!stack.isEmpty()){
            sb.append(stack.pop());
        }
        while(!sb.isEmpty() && sb.charAt(sb.length() - 1) == '0'){
            sb.deleteCharAt(sb.length() - 1);
        }
        return sb.isEmpty() ? "0" : sb.reverse().toString();
    }
}
```

## [394. 字符串解码](https://leetcode.cn/problems/decode-string/)

### 题目

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

测试用例保证输出的长度不会超过 `105`。

 

**示例 1：**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2：**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3：**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

**示例 4：**

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

 

**提示：**

- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是一个 **有效** 的输入。
- `s` 中所有整数的取值范围为 `[1, 300]` 

### 题解

#### 思路总结

当前实现采用 **递归 + 括号匹配 + 字符串重复展开**，按照编码规则逐层解析字符串，最终得到完整的解码结果。

**本题的关键在于：遇到重复编码时，需要先找到对应的右括号，再递归解码括号内部的字符串，最后将解码结果重复指定次数。**

---

#### 解题步骤

1. **初始化结果字符串：** 创建 `StringBuilder sb`，保存当前递归层已经完成解码的字符。

2. **初始化遍历变量：** 获取字符串长度 `n`，设置下标 `i = 0`，从左向右解析编码字符串。

3. **读取当前字符：** 使用 `s.charAt(i)` 获取当前字符，并判断其类型。

4. **处理普通字母：** 如果当前字符是字母，则直接追加到 `sb` 中，并将下标 `i` 向后移动一位。

5. **处理重复编码片段：** 如果当前字符是数字，则进入重复次数的解析过程。

6. **解析完整的重复次数：** 初始化 `num = 0`，连续读取数字字符，通过 `num = num * 10 + 当前数字` 得到重复次数。

7. **跳过左括号：** 解析数字结束后，使用 `int start = ++i` 跳过 `'['`，同时记录内部编码字符串的起始位置。

8. **初始化括号计数器：** 设置 `l = 1` 和 `r = 0`，表示已经处理了当前编码片段的最外层左括号。

9. **扫描括号内部的字符：** 从 `start` 开始向右遍历，遇到 `'['` 就增加左括号计数，遇到 `']'` 就增加右括号计数。

10. **寻找匹配的右括号：** 当 `l == r` 时，说明当前编码片段的所有嵌套括号都已闭合，结束括号扫描。

11. **截取内部编码字符串：** 使用 `s.substring(start, i - 1)` 获取当前最外层方括号内部的完整编码内容。

12. **递归解码内部字符串：** 调用 `decodeString()`，将内部编码内容转换为真正的解码字符串。

13. **重复解码结果：** 使用 `repeat(num)` 将内部解码结果重复指定次数。

14. **追加当前编码片段的结果：** 将重复后的字符串追加到当前层的 `StringBuilder` 中。

15. **继续处理后续字符：** 重复普通字符和编码片段的处理过程，直到当前字符串全部解析完成。

16. **返回当前层结果：** 使用 `sb.toString()` 返回当前递归层的完整解码字符串，最外层返回值即为最终答案。

```java
class Solution {
    public String decodeString(String s) {
        StringBuilder sb = new StringBuilder();
        int n = s.length();
        int i = 0;
        while(i < n){
            char c = s.charAt(i);
            if(Character.isLetter(c)){
                sb.append(c);
                i++;
            }else {
                int num = 0;
                while(Character.isDigit(s.charAt(i))){
                    num = num * 10 + s.charAt(i) - '0';
                    i++;
                }
                int start = ++i;
                int l = 1;
                int r = 0;
                while(l != r){
                    if(s.charAt(i) == '['){
                        l++;
                    }else if(s.charAt(i) == ']'){
                        r++;
                    }
                    i++;
                }
                sb.append(decodeString(s.substring(start, i - 1)).repeat(num));
            }
        }
        return sb.toString();
    }
}
```

- `s` 由数字、方括号 `"[]"`、负号 `'-'` 、逗号 `','`组成
- 用例保证 `s` 是可解析的 `NestedInteger`
- 输入中的所有值的范围是 `[-106, 106]`

### 题解

#### 思路总结

当前实现采用 **栈 + 字符串解析 + 嵌套结构构建**，将包含整数和嵌套列表的字符串转换为对应的 `NestedInteger` 对象。

**本题的关键是：利用栈记录当前尚未完成解析的嵌套列表，在遇到左括号时创建新列表，在遇到右括号时完成当前列表，并将其添加到外层列表中。**

**1. 特殊处理独立整数**

当前代码：

```java
if (s.charAt(0) != '[') {
    return new NestedInteger(Integer.parseInt(s));
}
```

如果字符串不是以 `'['` 开头，说明整个输入就是一个独立整数。

**2. 栈的定义**

**栈保存已经创建、但尚未遇到对应右括号的嵌套列表对象。**

具体来说：

- 栈底对应较外层的列表。
- 栈顶对应当前正在解析的最内层列表。
- 遇到 `'['` 时，新建列表并压入栈。
- 遇到 `']'` 时，弹出已经解析完成的列表。
- 遇到整数时，将其添加到栈顶列表中。

**3. 处理左括号 '['**

当前代码：

```java
if (c == '[') {
    stack.push(new NestedInteger());
}
```

表示开始解析一个新的嵌套列表。

**4. 处理右括号 ']'**

当前代码：

```java
NestedInteger cur = stack.pop();

if (!stack.isEmpty()) {
    stack.peek().add(cur);
} else {
    return cur;
}
```

遇到 `']'`，说明当前列表已经解析完成。

首先取出当前完整的内层列表。

接下来分为两种情况。

**情况一：栈中还有外层列表**

说明当前列表是某个外层列表的子元素。

因此将当前列表添加到外层列表中。

**情况二：栈已经为空**

如果弹栈后栈为空，说明当前关闭的是整个输入的最外层列表。

此时直接返回完整的解析结果。

**5. 处理逗号 ','**

逗号仅用于分隔列表元素，不需要创建对应对象。

因此可以直接跳过。

---

#### 解题步骤

1. **判断是否为独立整数：** 如果输入字符串的第一个字符不是 `'['`，则使用 `Integer.parseInt(s)` 解析整个整数，并直接返回对应的 `NestedInteger` 对象。

2. **初始化嵌套列表栈：** 创建 `Deque<NestedInteger> stack`，保存尚未完成解析的各层列表。

3. **从左向右遍历字符串：** 使用 `i` 从 `0` 遍历到 `s.length()-1`，依次读取每个字符。

4. **处理左括号：** 如果当前字符是 `'['`，说明开始一个新的列表，创建 `new NestedInteger()` 并压入栈中。

5. **处理右括号：** 如果当前字符是 `']'`，说明当前列表已经解析完成，弹出栈顶的 `NestedInteger` 对象。

6. **判断当前列表是否存在父列表：** 如果弹栈后栈不为空，说明当前列表属于某个外层列表，将其通过 `stack.peek().add(cur)` 添加到父列表中。

7. **判断最外层列表是否完成：** 如果弹栈后栈为空，说明最外层列表已经解析完成，直接返回当前对象。

8. **处理逗号：** 如果当前字符是 `','`，则跳过该字符，继续处理下一个列表元素。

9. **处理整数起始位置：** 如果当前字符不是方括号或逗号，则说明开始解析一个整数，初始化 `sign = 1` 和 `num = 0`。

10. **判断整数是否为负数：** 如果当前字符为 `'-'`，则设置 `sign = -1`，并将下标移动到数字部分。

11. **解析完整整数：** 连续读取数字字符，执行 `num = num * 10 + 当前数字`，直到遇到非数字字符。

12. **修正遍历下标：** 数字解析结束后执行 `i--`，避免外层 `for` 循环跳过后面的逗号或右括号。

13. **创建整数节点：** 使用 `new NestedInteger(sign * num)` 创建当前整数对应的对象。

14. **添加整数节点：** 使用 `stack.peek().add()` 将整数节点添加到当前最内层列表中。

15. **继续解析嵌套结构：** 重复上述步骤，直到整个输入字符串对应的最外层列表完成解析。

16. **返回最终结果：** 最外层右括号被处理时，栈清空并返回完整的 `NestedInteger` 对象。

```java
// This is the interface that allows for creating nested lists.
// You should not implement it, or speculate about its implementation
public interface NestedInteger {
    // @return true if this NestedInteger holds a single integer, rather than a nested list.
    public boolean isInteger();

    // @return the single integer that this NestedInteger holds, if it holds a single integer
    // Return null if this NestedInteger holds a nested list
    public Integer getInteger();

    // Set this NestedInteger to hold a single integer.
    public void setInteger(int value);

    // Set this NestedInteger to hold a nested list and adds a nested integer to it.
    public void add(NestedInteger ni);

    // @return the nested list that this NestedInteger holds, if it holds a nested list
    // Return empty list if this NestedInteger holds a single integer
    public List<NestedInteger> getList();
}

class Solution {
    public NestedInteger deserialize(String s) {
        if(s.charAt(0) != '['){
            return new NestedInteger(Integer.parseInt(s));
        }
        Deque<NestedInteger> stack = new ArrayDeque<>();
        for(int i = 0; i < s.length(); i++){
            char c = s.charAt(i);
            if(c == '['){
                stack.push(new NestedInteger());
            }else if(c == ']'){
                NestedInteger cur = stack.pop();
                if(!stack.isEmpty()){
                    stack.peek().add(cur);
                }else {
                    return cur;
                }
            }else if(c == ','){
                continue;
            }else {
                int sign = 1;
                if(c == '-'){
                    sign = -1;
                    i++;
                }
                int num = 0;
                while(i < s.length() && s.charAt(i) >= '0' && s.charAt(i) <= '9'){
                    num = num * 10 + s.charAt(i) - '0';
                    i++;
                }
                i--;

                stack.peek().add(new NestedInteger(sign * num));
            }
        }
        return null;
    }
}
```

## [341. 扁平化嵌套列表迭代器](https://leetcode.cn/problems/flatten-nested-list-iterator/)

### 题目

给你一个嵌套的整数列表 `nestedList` 。每个元素要么是一个整数，要么是一个列表；该列表的元素也可能是整数或者是其他列表。请你实现一个迭代器将其扁平化，使之能够遍历这个列表中的所有整数。

实现扁平迭代器类 `NestedIterator` ：

- `NestedIterator(List<NestedInteger> nestedList)` 用嵌套列表 `nestedList` 初始化迭代器。
- `int next()` 返回嵌套列表的下一个整数。
- `boolean hasNext()` 如果仍然存在待迭代的整数，返回 `true` ；否则，返回 `false` 。

你的代码将会用下述伪代码检测：

```
initialize iterator with nestedList
res = []
while iterator.hasNext()
    append iterator.next() to the end of res
return res
```

如果 `res` 与预期的扁平化列表匹配，那么你的代码将会被判为正确。

 

**示例 1：**

```
输入：nestedList = [[1,1],2,[1,1]]
输出：[1,1,2,1,1]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,1,2,1,1]。
```

**示例 2：**

```
输入：nestedList = [1,[4,[6]]]
输出：[1,4,6]
解释：通过重复调用 next 直到 hasNext 返回 false，next 返回的元素的顺序应该是: [1,4,6]。
```

 

**提示：**

- `1 <= nestedList.length <= 500`
- 嵌套列表中的整数值在范围 `[-106, 106]` 内

### 题解

#### 思路总结

当前实现采用 **递归深度优先搜索（DFS）+ 队列 + 预先扁平化**，在迭代器初始化时将嵌套列表中的所有整数按照原始顺序提取出来，并保存到队列中。

之后通过队列的先进先出特性，实现 `next()` 和 `hasNext()`。

**本题的核心是：将嵌套列表中的所有整数按照深度优先、从左到右的顺序进行遍历，并通过迭代器接口逐个返回。**

当前实现选择在构造函数中完成全部扁平化处理。

**1. 构造函数初始化**

构造函数执行两项操作：

1. 创建空队列。
2. 递归遍历整个嵌套列表，将所有整数加入队列。

这意味着：**迭代器创建完成时，所有整数都已经按照正确顺序存入队列。**

因此，后续调用 `next()` 时不需要再解析嵌套结构。

**3. DFS 递归遍历**

对于当前列表中的每个 `NestedInteger`，存在两种情况。

**情况一：当前元素是整数**

直接将整数加入队列。

**情况二：当前元素是嵌套列表**

此时：递归处理该列表中的全部元素。

由于递归会先完成当前子列表，再继续处理外层列表的下一个元素，所以能够保证整数的原始遍历顺序。

**4. next() 的实现**

从队列头部取出一个整数，并将其移除。

**5. hasNext() 的实现**

由于所有整数已经在构造函数中加入队列，因此只需要判断队列是否为空。

如果队列非空，说明仍然存在未返回的整数，返回 `true`。

如果队列为空，说明所有整数都已返回，返回 `false`。

这种实现的优点是：**`next()` 和 `hasNext()` 都只需要常数时间。**

---

#### 解题步骤

1. **定义队列成员变量：** 使用 `Deque<Integer> queue` 保存嵌套列表中按照原始顺序提取出来的所有整数。

2. **初始化迭代器：** 在 `NestedIterator` 构造函数中创建 `ArrayDeque`，作为存储整数的先进先出队列。

3. **开始递归扁平化：** 调用辅助方法 `f(nestedList)`，遍历传入的整个嵌套列表。

4. **按照原始顺序遍历当前列表：** 使用增强 `for` 循环，从左到右依次处理每个 `NestedInteger` 元素。

5. **判断当前元素是否为整数：** 调用 `nes.isInteger()`，确定当前节点保存的是整数还是嵌套列表。

6. **处理整数节点：** 如果当前节点为整数，则通过 `nes.getInteger()` 取得数值，并使用 `queue.offer()` 将其加入队列末尾。

7. **处理嵌套列表节点：** 如果当前节点不是整数，则调用 `nes.getList()` 获取内部列表。

8. **递归展开内部列表：** 对内部列表再次调用 `f()`，优先完成当前子列表的整数提取。

9. **恢复外层遍历：** 当内部列表遍历完成后，返回上一层递归，继续处理外层列表中的后续元素。

10. **完成全部扁平化：** 当所有递归调用结束后，队列中已经按照从左到右的顺序保存了全部整数。

11. **实现 next()：** 调用 `queue.poll()`，取出并移除队列头部的整数，将其作为下一个迭代结果返回。

12. **实现 hasNext()：** 调用 `queue.isEmpty()`，如果队列非空则返回 `true`，否则返回 `false`。

13. **完成迭代：** 外部调用方通过重复执行 `hasNext()` 和 `next()`，依次取得所有整数，直到队列为空。

```java
public class NestedIterator implements Iterator<Integer> {
    Deque<Integer> queue;
    public NestedIterator(List<NestedInteger> nestedList) {
        queue = new ArrayDeque<>();
        f(nestedList);
    }

    private void f(List<NestedInteger> nestedList){
        for(NestedInteger nes : nestedList){
            if(nes.isInteger()){
                queue.offer(nes.getInteger());
            }else {
                f(nes.getList());
            }
        }
    }

    @Override
    public Integer next() {
        return queue.poll();
    }

    @Override
    public boolean hasNext() {
        return !queue.isEmpty();
    }
}
```

## [331. 验证二叉树的前序序列化](https://leetcode.cn/problems/verify-preorder-serialization-of-a-binary-tree/)

### 题目

序列化二叉树的一种方法是使用 **前序遍历** 。当我们遇到一个非空节点时，我们可以记录下这个节点的值。如果它是一个空节点，我们可以使用一个标记值记录，例如 `#`。

![img](https://assets.leetcode.com/uploads/2021/03/12/pre-tree.jpg)

例如，上面的二叉树可以被序列化为字符串 `"9,3,4,#,#,1,#,#,2,#,6,#,#"`，其中 `#` 代表一个空节点。

给定一串以逗号分隔的序列，验证它是否是正确的二叉树的前序序列化。编写一个在不重构树的条件下的可行算法。

**保证** 每个以逗号分隔的字符或为一个整数或为一个表示 `null` 指针的 `'#'` 。

你可以认为输入格式总是有效的

- 例如它永远不会包含两个连续的逗号，比如 `"1,,3"` 。

**注意：**不允许重建树。

 

**示例 1:**

```
输入: preorder = "9,3,4,#,#,1,#,#,2,#,6,#,#"
输出: true
```

**示例 2:**

```
输入: preorder = "1,#"
输出: false
```

**示例 3:**

```
输入: preorder = "9,#,#,1"
输出: false
```

 

**提示:**

- `1 <= preorder.length <= 104`
- `preorder` 由以逗号 `“，”` 分隔的 `[0,100]` 范围内的整数和 `“#”` 组成

### 题解

#### 思路总结

当前实现采用 **槽位计数法（Slot Counting）+ 贪心遍历**，在不重建二叉树的情况下，判断给定字符串是否为合法的二叉树前序序列化。

**本题的核心是：每个节点都需要占用一个槽位，非空节点会产生两个新的子节点槽位，而空节点不会产生新槽位。**

因此，只需要维护当前还剩余多少个可供后续节点填充的槽位，就能在线性时间内验证序列化是否有效。

**1. 槽位的定义**

**`positionNum` 表示当前序列化过程中，尚未被节点填充的槽位数量。**

最开始：positionNum = 1

因为整棵二叉树必须有一个根节点，所以初始时存在一个根节点槽位。

之后，每读取一个节点，都需要占用一个已有槽位。

**2. 非空节点的槽位变化**

对于非空节点，它需要：

- 占用一个已有槽位。
- 产生一个左子节点槽位。
- 产生一个右子节点槽位。

因此，槽位变化为：

$$
positionNum'=positionNum-1+2
$$

化简：

$$
positionNum'=positionNum+1
$$

**每处理一个非空节点，槽位数量净增加 1。**

**3. 空节点的槽位变化**

对于空节点，它同样需要占用一个已有槽位。但是空节点没有子节点，因此不会产生新的槽位。

所以：

$$
positionNum'=positionNum-1
$$

**每处理一个空节点，槽位数量减少 1。**

**4. 为什么槽位为 0 时不能继续读取节点？**

槽位数量为 `0`，意味着此前的节点已经构成了一棵完整的二叉树。

如果此时序列化字符串中还有新的节点，那么这个节点已经没有合法位置可以放置。

**合法的前序序列化不能在槽位全部用完后继续出现节点。**

**5. 完整的合法性条件**

对于前序序列化，合法性需要同时满足：

**条件一：处理每个节点之前，必须至少存在一个可用槽位。**

$$
positionNum>0
$$

**条件二：处理全部节点之后，槽位必须恰好用完。**

$$
positionNum=0
$$

这两个条件缺一不可。

第一个条件避免出现多余节点。

第二个条件避免出现缺失节点。

---

#### 解题步骤

1. **拆分序列化字符串：** 使用 `preorder.split(",")`，将输入字符串按照逗号分隔，得到所有节点标记。

2. **初始化槽位数量：** 设置 `positionNum = 1`，表示最开始存在一个可以放置根节点的槽位。

3. **从左向右遍历节点：** 使用增强 `for` 循环，按照前序遍历的顺序依次处理每个节点标记。

4. **检查当前是否存在可用槽位：** 如果 `positionNum == 0`，说明此前已经构成完整二叉树，但仍然存在后续节点，直接返回 `false`。

5. **占用一个槽位：** 每读取一个节点，无论是整数还是空节点，都执行 `positionNum--`，表示该节点占用了一个位置。

6. **判断当前节点是否为空：** 使用 `node.equals("#")` 判断当前节点是否为空节点。

7. **处理空节点：** 如果当前节点为 `#`，则不增加槽位，因为空节点不存在左右子节点。

8. **处理非空节点：** 如果当前节点不是 `#`，则执行 `positionNum += 2`，表示该节点产生两个新的子节点槽位。

9. **继续处理下一个节点：** 重复槽位检查、槽位占用和新槽位生成的过程。

10. **检查所有节点是否处理完成：** 当整个节点数组遍历结束后，检查是否还有尚未填充的槽位。

11. **判断序列化是否完整：** 如果 `positionNum == 0`，说明所有槽位恰好被填满，序列化合法。

12. **返回最终结果：** 返回 `positionNum == 0`，如果仍有剩余槽位则返回 `false`，否则返回 `true`。

```java
class Solution {
    public boolean isValidSerialization(String preorder) {
        String[] nodes = preorder.split(",");
        int positionNum = 1;
        for(String node : nodes){
            if(positionNum == 0){
                return false;
            }
            positionNum--;
            if(!node.equals("#")){
                positionNum += 2;
            }
        }
        return positionNum == 0;
    }
}
```
