## [1600. 王位继承顺序](https://leetcode.cn/problems/throne-inheritance/)

### 题目

一个王国里住着国王、他的孩子们、他的孙子们等等。每一个时间点，这个家庭里有人出生也有人死亡。

这个王国有一个明确规定的王位继承顺序，第一继承人总是国王自己。我们定义递归函数 `Successor(x, curOrder)` ，给定一个人 `x` 和当前的继承顺序，该函数返回 `x` 的下一继承人。

```
Successor(x, curOrder):
    如果 x 没有孩子或者所有 x 的孩子都在 curOrder 中：
        如果 x 是国王，那么返回 null
        否则，返回 Successor(x 的父亲, curOrder)
    否则，返回 x 不在 curOrder 中最年长的孩子
```

比方说，假设王国由国王，他的孩子 Alice 和 Bob （Alice 比 Bob 年长）和 Alice 的孩子 Jack 组成。

1. 一开始， `curOrder` 为 `["king"]`.
2. 调用 `Successor(king, curOrder)` ，返回 Alice ，所以我们将 Alice 放入 `curOrder` 中，得到 `["king", "Alice"]` 。
3. 调用 `Successor(Alice, curOrder)` ，返回 Jack ，所以我们将 Jack 放入 `curOrder` 中，得到 `["king", "Alice", "Jack"]` 。
4. 调用 `Successor(Jack, curOrder)` ，返回 Bob ，所以我们将 Bob 放入 `curOrder` 中，得到 `["king", "Alice", "Jack", "Bob"]` 。
5. 调用 `Successor(Bob, curOrder)` ，返回 `null` 。最终得到继承顺序为 `["king", "Alice", "Jack", "Bob"]` 。

通过以上的函数，我们总是能得到一个唯一的继承顺序。

请你实现 `ThroneInheritance` 类：

- `ThroneInheritance(string kingName)` 初始化一个 `ThroneInheritance` 类的对象。国王的名字作为构造函数的参数传入。
- `void birth(string parentName, string childName)` 表示 `parentName` 新拥有了一个名为 `childName` 的孩子。
- `void death(string name)` 表示名为 `name` 的人死亡。一个人的死亡不会影响 `Successor` 函数，也不会影响当前的继承顺序。你可以只将这个人标记为死亡状态。
- `string[] getInheritanceOrder()` 返回 **除去** 死亡人员的当前继承顺序列表。

 

**示例：**

```
输入：
["ThroneInheritance", "birth", "birth", "birth", "birth", "birth", "birth", "getInheritanceOrder", "death", "getInheritanceOrder"]
[["king"], ["king", "andy"], ["king", "bob"], ["king", "catherine"], ["andy", "matthew"], ["bob", "alex"], ["bob", "asha"], [null], ["bob"], [null]]
输出：
[null, null, null, null, null, null, null, ["king", "andy", "matthew", "bob", "alex", "asha", "catherine"], null, ["king", "andy", "matthew", "alex", "asha", "catherine"]]

解释：
ThroneInheritance t= new ThroneInheritance("king"); // 继承顺序：king
t.birth("king", "andy"); // 继承顺序：king > andy
t.birth("king", "bob"); // 继承顺序：king > andy > bob
t.birth("king", "catherine"); // 继承顺序：king > andy > bob > catherine
t.birth("andy", "matthew"); // 继承顺序：king > andy > matthew > bob > catherine
t.birth("bob", "alex"); // 继承顺序：king > andy > matthew > bob > alex > catherine
t.birth("bob", "asha"); // 继承顺序：king > andy > matthew > bob > alex > asha > catherine
t.getInheritanceOrder(); // 返回 ["king", "andy", "matthew", "bob", "alex", "asha", "catherine"]
t.death("bob"); // 继承顺序：king > andy > matthew > bob（已经去世）> alex > asha > catherine
t.getInheritanceOrder(); // 返回 ["king", "andy", "matthew", "alex", "asha", "catherine"]
```

 

**提示：**

- `1 <= kingName.length, parentName.length, childName.length, name.length <= 15`
- `kingName`，`parentName`， `childName` 和 `name` 仅包含小写英文字母。
- 所有的参数 `childName` 和 `kingName` **互不相同**。
- 所有 `death` 函数中的死亡名字 `name` 要么是国王，要么是已经出生了的人员名字。
- 每次调用 `birth(parentName, childName)` 时，测试用例都保证 `parentName` 对应的人员是活着的。
- 最多调用 `105` 次`birth` 和 `death` 。
- 最多调用 `10` 次 `getInheritanceOrder` 。

### 题解

#### 思路总结

当前实现使用递归方式：使用 `home` 保存“父节点 → 按出生顺序排列的孩子列表”，使用 `dead` 记录死亡成员，而 `dfs()` 直接对整棵家族树做**前序遍历**。

------

#### 解题步骤

1. **建立家族关系：** `home` 保存每个人按照出生顺序排列的所有孩子。
2. **初始化国王：** 构造函数中保存 `kingName`，并为国王建立空的孩子列表。
3. **处理出生事件：** 将新孩子加入父亲的孩子列表尾部，并为新孩子创建空的孩子列表。
4. **处理死亡事件：** 将死亡成员加入 `dead` 集合，不修改家族树结构。
5. **从国王开始 DFS：** `getInheritanceOrder()` 创建结果列表，并从 `kingName` 开始前序遍历。
6. **处理当前成员：** 如果当前成员没有死亡，则将其加入继承顺序。
7. **递归处理孩子：** 按孩子出生顺序依次调用 `dfs()`，自然保证继承顺序正确。
8. **保留死亡成员后代：** 即使当前成员已经死亡，也仍然继续遍历他的孩子。
9. **返回继承顺序：** DFS 完成后返回结果列表。

```java
class ThroneInheritance {
    Map<String, List<String>> home = new HashMap<>();
    Set<String> dead = new HashSet<>();
    private String kingName;
    public ThroneInheritance(String kingName) {
        home.put(kingName, new ArrayList<>());
        this.kingName = kingName;
    }
    
    public void birth(String parentName, String childName) {
        home.get(parentName).add(childName);
        home.put(childName, new ArrayList<>());
    }
    
    public void death(String name) {
        dead.add(name);
    }
    
    public List<String> getInheritanceOrder() {
        List<String> ans = new ArrayList<>();
        dfs(kingName, ans);
        return ans;
    }

    private void dfs(String name, List<String> ans){
        if(!dead.contains(name)){
            ans.add(name);
        }
        List<String> children = home.get(name);
        for(String child : children){
            dfs(child, ans);
        }
    }
}
```

## [1305. 两棵二叉搜索树中的所有元素](https://leetcode.cn/problems/all-elements-in-two-binary-search-trees/)

### 题目

给你 `root1` 和 `root2` 这两棵二叉搜索树。请你返回一个列表，其中包含 **两棵树** 中的所有整数并按 **升序** 排序。.

 

**示例 1：**

![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/12/29/q2-e1.png)

```
输入：root1 = [2,1,4], root2 = [1,0,3]
输出：[0,1,1,2,3,4]
```

**示例 2：**

![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/12/29/q2-e5-.png)

```
输入：root1 = [1,null,8], root2 = [8,1]
输出：[1,1,8,8]
```

 

**提示：**

- 每棵树的节点数在 `[0, 5000]` 范围内
- `-105 <= Node.val <= 105`

### 题解

#### 思路总结

当前实现分成两个阶段：先分别对两棵二叉搜索树做**中序遍历**，由于 BST 的中序遍历结果天然有序，因此得到两个升序数组；然后使用双指针执行类似归并排序中的 merge，将两个有序数组合并为最终升序结果。

#### 解题步骤

1. **创建两个有序列表：** `list1` 和 `list2` 分别保存两棵 BST 的中序遍历结果。
2. **中序遍历第一棵树：** 按照左子树、根节点、右子树的顺序将节点值加入 `list1`。
3. **中序遍历第二棵树：** 使用相同方式得到升序的 `list2`。
4. **初始化双指针：** `i` 和 `j` 分别指向两个有序列表的起始位置。
5. **比较当前元素：** 当两个列表都还有元素时，将较小值加入答案并移动对应指针。
6. **处理相等元素：** 当前实现先加入 `list2[j]`，后续仍会处理 `list1[i]`，因此重复元素可以完整保留。
7. **处理剩余元素：** 当一个列表遍历完成后，将另一个列表剩余元素依次加入答案。
8. **返回最终结果：** 得到两棵树所有节点值组成的升序列表。

```java
class Solution {
    public List<Integer> getAllElements(TreeNode root1, TreeNode root2) {
        List<Integer> ans = new ArrayList<>();
        List<Integer> list1 = new ArrayList<>();
        List<Integer> list2 = new ArrayList<>();
        inorder(root1, list1);
        inorder(root2, list2);
        int i = 0;
        int j = 0;
        while(i < list1.size() || j < list2.size()){
            if(i < list1.size() && j < list2.size()){
                if(list1.get(i) < list2.get(j)){
                    ans.add(list1.get(i));
                    i++;
                }else {
                    ans.add(list2.get(j));
                    j++;
                }
            }else if(i < list1.size()){
                ans.add(list1.get(i));
                i++;
            }else {
                ans.add(list2.get(j));
                j++;
            }
        }
        return ans;
    }

    private void inorder(TreeNode root, List<Integer> ans){
        if(root == null){
            return;
        }
        inorder(root.left, ans);
        ans.add(root.val);
        inorder(root.right, ans);
    }
}
```

## [1302. 层数最深叶子节点的和](https://leetcode.cn/problems/deepest-leaves-sum/)

### 题目

给你一棵二叉树的根节点 `root` ，请你返回 **层数最深的叶子节点的和** 。

 

**示例 1：**

**![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/12/28/1483_ex1.png)**

```
输入：root = [1,2,3,4,5,null,6,7,null,null,null,null,8]
输出：15
```

**示例 2：**

```
输入：root = [6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]
输出：19
```

 

**提示：**

- 树中节点数目在范围 `[1, 104]` 之间。
- `1 <= Node.val <= 100`

 

### 题解

#### 思路总结

当前实现采用**层序遍历 BFS**。使用队列按照从上到下的顺序逐层访问二叉树，每进入一层时先通过 `queue.size()` 记录当前层的节点数量，再将 `ans` 清零，然后依次处理这一层的所有节点并累加它们的值。同时，将当前节点的左右孩子加入队列，为下一层遍历做准备。

由于 `ans` 在每一层开始时都会重新置为 `0`，因此它始终保存**当前正在处理这一层的节点值之和**。BFS 最后处理的一定是整棵树的最深层，当最后一层处理完成后队列为空，循环结束，此时 `ans` 保存的正好就是最深层所有节点的值之和。二叉树最深层的节点一定都是叶子节点，因此最终结果就是题目要求的最深叶子节点之和。

#### 解题步骤

1. **初始化 BFS 队列：** 将根节点加入队列，准备从第一层开始遍历。
2. **逐层进行遍历：** 只要队列非空，就说明还有一层节点需要处理。
3. **重置当前层节点和：** 每进入新的一层，将 `ans` 清零，只统计当前这一层。
4. **记录当前层节点数量：** 使用 `size = queue.size()` 固定本轮需要处理的节点个数。
5. **依次弹出当前层节点：** 连续处理 `size` 个节点，避免把刚加入的下一层节点提前处理。
6. **加入下一层节点：** 当前节点存在左孩子或右孩子时，将其加入队列。
7. **累加当前节点值：** 将当前层每个节点的 `val` 加入 `ans`。
8. **继续处理下一层：** 当前层结束后队列中只剩下一层节点，进入下一轮。
9. **返回最终结果：** 最后一轮结束后的 `ans` 就是最深叶子节点之和。

```java
class Solution {
    public int deepestLeavesSum(TreeNode root) {
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        queue.offer(new TreeNode(-1));
        int ans = 0;
        while (!queue.isEmpty()){
            TreeNode node = queue.poll();
            if(node.val != -1){
                if(node.left != null){
                    queue.offer(node.left);
                }
                if(node.right != null){
                    queue.offer(node.right);
                }
                ans += node.val;
            }else {
                if(!queue.isEmpty()){
                    ans = 0;
                    queue.offer(new TreeNode(-1));
                }
            }
        }
        return ans;
    }
}
```
