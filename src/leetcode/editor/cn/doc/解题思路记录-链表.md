## [1721. 交换链表中的节点](https://leetcode.cn/problems/swapping-nodes-in-a-linked-list/)

### 题目

给你链表的头节点 `head` 和一个整数 `k` 。

**交换** 链表正数第 `k` 个节点和倒数第 `k` 个节点的值后，返回链表的头节点（链表 **从 1 开始索引**）。

 

**示例 1：**

![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2021/01/10/linked1.jpg)

```
输入：head = [1,2,3,4,5], k = 2
输出：[1,4,3,2,5]
```

**示例 2：**

```
输入：head = [7,9,6,6,7,8,3,0,9,5], k = 5
输出：[7,9,6,6,8,7,3,0,9,5]
```

**示例 3：**

```
输入：head = [1], k = 1
输出：[1]
```

**示例 4：**

```
输入：head = [1,2], k = 1
输出：[2,1]
```

**示例 5：**

```
输入：head = [1,2,3], k = 2
输出：[1,2,3]
```

 

**提示：**

- 链表中节点的数目是 `n`
- `1 <= k <= n <= 105`
- `0 <= Node.val <= 100`

### 题解

#### 思路总结

当前实现采用**快慢指针**一次定位正数第 `k` 个节点和倒数第 `k` 个节点。先让 `fast` 从头节点向后移动 `k - 1` 步，此时 `fast` 正好位于正数第 `k` 个节点，因此用 `first` 保存该节点。

随后令 `slow` 从头节点开始，与 `fast` 同步向后移动。当 `fast` 到达链表尾节点时，`slow` 恰好位于倒数第 `k` 个节点。最后交换 `first.val` 和 `slow.val` 即可。

------

#### 解题步骤

1. **初始化快指针：** 令 `fast` 指向链表头节点。
2. **找到正数第 k 个节点：** 将 `fast` 向后移动 `k - 1` 步。
3. **保存第一个目标节点：** 此时 `fast` 就是正数第 `k` 个节点，用 `first` 保存。
4. **初始化慢指针：** 令 `slow` 从链表头节点开始。
5. **同步移动双指针：** 当 `fast.next != null` 时，让 `fast` 和 `slow` 同时向后移动。
6. **找到倒数第 k 个节点：** 当 `fast` 到达尾节点时，`slow` 恰好位于倒数第 `k` 个节点。
7. **交换节点值：** 使用临时变量交换 `first.val` 和 `slow.val`。
8. **返回链表：** 链表节点结构没有改变，直接返回 `head`。

```java
class Solution {
    public ListNode swapNodes(ListNode head, int k) {
        ListNode fast = head;
        for(int i = 1; i < k; i++){
            fast = fast.next;
        }
        ListNode first = fast;
        ListNode slow = head;
        while(fast.next != null){
            fast = fast.next;
            slow = slow.next;
        }
        int temp = first.val;
        first.val = slow.val;
        slow.val = temp;
        return head;
    }
}
```

## [1670. 设计前中后队列](https://leetcode.cn/problems/design-front-middle-back-queue/)

### 题目

### 题解

#### 思路总结

当前实现采用**双向链表 + 中间指针 `mid` + 长度 `size`**，并通过两个哨兵节点 `head`、`tail` 简化头尾插入和删除操作。核心不变量是：`mid` 始终指向队列的“偏前中间节点”，即长度为 4 时指向第 2 个节点，长度为 5 时指向第 3 个节点。

每次在前、中、后进行插入或删除后，根据操作前 `size` 的奇偶性调整 `mid`。由于双向链表已知节点的插入、删除，以及 `mid` 向前或向后移动都只需要 O(1)，所以六种操作都能够达到 **O(1)** 时间复杂度。

------

#### 解题步骤

1. **建立双向链表：** 使用 `head` 和 `tail` 两个哨兵节点表示链表边界，避免单独处理头尾指针连接。
2. **维护中间节点：** `mid` 始终指向队列偏前的中间位置，即第 `(size + 1) / 2` 个节点。
3. **处理 pushFront：** 在头部插入节点，原长度为奇数时需要将 `mid` 向前移动一位。
4. **处理 pushMiddle：** 原长度为偶数时插在 `mid` 后面，原长度为奇数时插在 `mid` 前面，新节点直接成为新的 `mid`。
5. **处理 pushBack：** 在尾部插入节点，原长度为偶数时需要将 `mid` 向后移动一位。
6. **处理 popFront：** 删除第一个节点，原长度为偶数时将 `mid` 向后移动一位。
7. **处理 popMiddle：** 直接删除 `mid`，原长度为偶数时新 `mid` 是原 `mid.next`，原长度为奇数时新 `mid` 是原 `mid.pre`。
8. **处理 popBack：** 删除最后一个节点，原长度为奇数时将 `mid` 向前移动一位。
9. **处理单节点情况：** 删除唯一节点后将 `mid` 设置为 `null`。
10. **统一插入删除：** 使用 `insertAfter()` 和 `remove()` 完成链表指针调整，使各个公开操作保持简洁。

```java
class FrontMiddleBackQueue {
    private ListNode head;
    private ListNode tail;
    // mid 始终指向“偏前的中间节点”
    // 例如长度 4: [1, 2, 3, 4]，mid 指向 2
    // 长度 5: [1, 2, 3, 4, 5]，mid 指向 3
    private ListNode mid;
    private int size;

    public FrontMiddleBackQueue() {
        head = new ListNode();
        tail = new ListNode();
        head.next = tail;
        tail.pre = head;
        mid = null;
        size = 0;
    }
    
    public void pushFront(int val) {
        ListNode node = new ListNode(val);
        insertAfter(head, node);
        if(size == 0){
            mid = node;
        }else if (size % 2 == 1){
            mid = mid.pre;
        }
        size++;
    }
    
    public void pushMiddle(int val) {
        ListNode node = new ListNode(val);
        if(size == 0){
            insertAfter(head, node);
        }else {
            if(size % 2 == 0){
                insertAfter(mid, node);
            }else {
                insertAfter(mid.pre, node);
            }
        }
        mid = node;
        size++;
    }
    
    public void pushBack(int val) {
        ListNode node = new ListNode(val);
        insertAfter(tail.pre, node);
        if(size == 0){
            mid = node;
        }else if (size % 2 == 0){
            mid = mid.next;
        }
        size++;
    }
    
    public int popFront() {
        if(size == 0){
            return -1;
        }
        int val = head.next.val;
        if(size == 1){
            mid = null;
        }else if(size % 2 == 0){
            mid = mid.next;
        }
        remove(head.next);
        size--;
        return val;
    }

    public int popMiddle() {
        if(size == 0){
            return -1;
        }
        ListNode temp = mid;
        if(size == 1){
            mid = null;
        }else if(size % 2 == 0){
            mid = mid.next;
        }else {
            mid = mid.pre;
        }
        remove(temp);
        size--;
        return temp.val;
    }

    public int popBack() {
        if(size == 0){
            return -1;
        }
        int val = tail.pre.val;
        if(size == 1){
            mid = null;
        }else if(size % 2 == 1){
            mid = mid.pre;
        }
        remove(tail.pre);
        size--;
        return val;
    }

    private void insertAfter(ListNode cur, ListNode node) {
        node.pre = cur;
        node.next = cur.next;

        cur.next.pre = node;
        cur.next = node;
    }

    private void remove(ListNode node) {
        node.pre.next = node.next;
        node.next.pre = node.pre;

        node.pre = null;
        node.next = null;
    }

    class ListNode {
        private int val;
        private ListNode next;
        private ListNode pre;
        ListNode() {}
        ListNode(int val) { this.val = val; }
    }
}
```

## [1669. 合并两个链表](https://leetcode.cn/problems/merge-in-between-linked-lists/)

### 题目

给你两个链表 `list1` 和 `list2` ，它们包含的元素分别为 `n` 个和 `m` 个。

请你将 `list1` 中下标从 `a` 到 `b` 的全部节点都删除，并将`list2` 接在被删除节点的位置。

下图中蓝色边和节点展示了操作后的结果：

![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/11/28/fig1.png)

请你返回结果链表的头指针。

 

**示例 1：**

![img](https://pic.leetcode.cn/1709608717-NVGojm-image.png)

```
输入：list1 = [10,1,13,6,9,5], a = 3, b = 4, list2 = [1000000,1000001,1000002]
输出：[10,1,13,1000000,1000001,1000002,5]
解释：我们删除 list1 中下标为 3 和 4 的两个节点，并将 list2 接在该位置。上图中蓝色的边和节点为答案链表。
```

**示例 2：**

![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/11/28/merge_linked_list_ex2.png)

```
输入：list1 = [0,1,2,3,4,5,6], a = 2, b = 5, list2 = [1000000,1000001,1000002,1000003,1000004]
输出：[0,1,1000000,1000001,1000002,1000003,1000004,6]
解释：上图中蓝色的边和节点为答案链表。
```

 

**提示：**

- `3 <= list1.length <= 104`
- `1 <= a <= b < list1.length - 1`
- `1 <= list2.length <= 104`

### 题解

#### 思路总结

当前实现采用**定位删除区间前驱节点 + 找到 `list2` 尾节点 + 重新连接链表**的方式。首先在 `list1` 中找到下标 `a - 1` 的节点 `cur`，它是待删除区间 `[a, b]` 的前一个节点；然后保存下标 `a` 的节点到 `mid`，并让 `cur.next` 指向 `list2`，完成前半部分连接。

随后找到 `list2` 的尾节点，同时让 `mid` 向后移动到原 `list1` 中下标 `b + 1` 的节点。最后令 `list2` 的尾节点指向 `mid`，就完成了整个拼接。原 `[a, b]` 区间不需要逐个真正“删除”，只要断开它与结果链表的连接即可。

------

#### 解题步骤

1. **定位删除区间前驱：** 从 `list1` 头节点开始移动到下标 `a - 1` 的节点。
2. **保存删除区间起点：** 使用 `mid` 指向原链表下标为 `a` 的节点。
3. **连接 list2 头部：** 将下标 `a - 1` 节点的 `next` 指向 `list2`。
4. **寻找 list2 尾节点：** 沿着 `list2` 不断向后移动，直到最后一个节点。
5. **越过删除区间：** 从原下标 `a` 的节点开始移动，直到下标 `b + 1` 的节点。
6. **连接剩余链表：** 将 `list2` 的尾节点指向原 `list1` 的下标 `b + 1` 节点。
7. **返回原头节点：** 由于题目保证 `a >= 1`，原头节点不会被替换，直接返回 `list1`。

```java
class Solution {
    public ListNode mergeInBetween(ListNode list1, int a, int b, ListNode list2) {
        int i = 0;
        ListNode cur = list1;
        while(i < a - 1){
            cur = cur.next;
            i++;
        }
        ListNode mid = cur.next;
        cur.next = list2;
        i++;
        while(list2.next != null){
            list2 = list2.next;
        }
        while(i <= b){
            mid = mid.next;
            i++;
        }
        list2.next = mid;
        return list1;
    }
}
```

## [1290. 二进制链表转整数](https://leetcode.cn/problems/convert-binary-number-in-a-linked-list-to-integer/)

### 题目

给你一个单链表的引用结点 `head`。链表中每个结点的值不是 0 就是 1。已知此链表是一个整数数字的二进制表示形式。

请你返回该链表所表示数字的 **十进制值** 。

**最高位** 在链表的头部。

 

**示例 1：**

![img](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/12/15/graph-1.png)

```
输入：head = [1,0,1]
输出：5
解释：二进制数 (101) 转化为十进制数 (5)
```

**示例 2：**

```
输入：head = [0]
输出：0
```

 

**提示：**

- 链表不为空。
- 链表的结点总数不超过 `30`。
- 每个结点的值不是 `0` 就是 `1`。

### 题解

#### 思路总结

当前实现采用**从高位到低位逐位计算二进制数值**。链表头部是最高位，因此遍历到一个新的二进制位时，之前已经得到的数值需要先左移一位，也就是乘以 `2`，再加上当前节点的 `0` 或 `1`。

因此每处理一个节点都执行 `ans = ans * 2 + head.val`。例如链表 `[1,0,1]` 的计算过程是 `0 → 1 → 2 → 5`，最终得到十进制值 `5`。当前实现只需要遍历链表一次，时间复杂度 O(n)、空间复杂度 O(1)，已经是最优解法。

------

#### 解题步骤

1. **初始化结果：** 设置 `ans = 0`，表示当前已经处理的二进制前缀对应的十进制值。
2. **从头遍历链表：** 按照二进制从高位到低位的顺序读取每个节点。
3. **左移已有数值：** 将已有结果乘以 `2`，相当于二进制整体左移一位。
4. **加入当前二进制位：** 将当前节点值 `head.val` 加入最低位。
5. **移动链表指针：** 继续处理下一个节点。
6. **返回最终结果：** 遍历结束后 `ans` 就是整个二进制链表对应的十进制值。

```java
class Solution {
    public int getDecimalValue(ListNode head) {
        int ans = 0;
        while(head != null){
            ans = ans * 2 + head.val;
            head = head.next;
        }
        return ans;
    }
}
```

## [1171. 从链表中删去总和值为零的连续节点](https://leetcode.cn/problems/remove-zero-sum-consecutive-nodes-from-linked-list/)

### 题目

给你一个链表的头节点 `head`，请你编写代码，反复删去链表中由 **总和** 值为 `0` 的连续节点组成的序列，直到不存在这样的序列为止。

删除完毕后，请你返回最终结果链表的头节点。

 

你可以返回任何满足题目要求的答案。

（注意，下面示例中的所有序列，都是对 `ListNode` 对象序列化的表示。）

**示例 1：**

```
输入：head = [1,2,-3,3,1]
输出：[3,1]
提示：答案 [1,2,1] 也是正确的。
```

**示例 2：**

```
输入：head = [1,2,3,-3,4]
输出：[1,2,4]
```

**示例 3：**

```
输入：head = [1,2,3,-3,-2]
输出：[1]
```

 

**提示：**

- 给你的链表中可能有 `1` 到 `1000` 个节点。
- 对于链表中的每个节点，节点的值：`-1000 <= node.val <= 1000`.

### 题解

#### 思路总结

当前实现采用**前缀和 + HashMap + 两次遍历**。在链表前添加一个值为 `0` 的虚拟头节点 `preHead`，然后计算从虚拟头节点到当前位置的前缀和 `sum`。如果两个节点位置的前缀和相同，那么它们之间所有节点的值之和一定为 `0`。

第一遍遍历时，`map` 保存每个前缀和**最后一次出现的节点**。第二遍再次计算前缀和，对于当前节点 `cur`，直接执行 `cur.next = map.get(sum).next`，相当于跳过当前节点与该前缀和最后一次出现位置之间的所有节点。由于这部分节点的总和为 `0`，因此可以一次删除尽可能长的零和区间。两遍处理后，不需要真的反复扫描删除，最终链表已经不存在需要继续删除的零和连续子链表。

------

#### 解题步骤

1. **创建虚拟头节点：** 在原链表前加入值为 `0` 的 `preHead`，方便处理从头节点开始的零和区间。
2. **初始化前缀和映射：** 使用 `HashMap<Integer, ListNode>` 保存“前缀和 → 最后一次出现该前缀和的节点”。
3. **第一次遍历链表：** 从 `preHead` 开始累计前缀和 `sum`。
4. **记录最后出现位置：** 每次执行 `map.put(sum, cur)`，相同前缀和会覆盖之前节点，只保留最靠后的节点。
5. **重新计算前缀和：** 第二遍再次从 `preHead` 开始令 `sum = 0` 并逐节点累加。
6. **寻找相同前缀和末端：** `map.get(sum)` 表示当前前缀和最后一次出现的位置。
7. **跳过零和区间：** 将 `cur.next` 直接连接到该节点的下一个节点，从链表中删除中间所有零和节点。
8. **继续处理剩余链表：** 顺着修改后的 `next` 指针继续遍历。
9. **返回最终头节点：** 返回 `preHead.next`。

```java
class Solution {
    public ListNode removeZeroSumSublists(ListNode head) {
        ListNode preHead = new ListNode(0);
        preHead.next = head;
        Map<Integer, ListNode> map = new HashMap<>();
        int sum = 0;
        for(ListNode cur = preHead; cur != null; cur = cur.next){
            sum += cur.val;
            map.put(sum, cur);
        }
        sum = 0;
        for(ListNode cur = preHead; cur != null; cur = cur.next){
            sum += cur.val;
            cur.next = map.get(sum).next;
        }
        return preHead.next;
    }
}
```

## [1019. 链表中的下一个更大节点](https://leetcode.cn/problems/next-greater-node-in-linked-list/)

### 题目

给定一个长度为 `n` 的链表 `head`

对于列表中的每个节点，查找下一个 **更大节点** 的值。也就是说，对于每个节点，找到它旁边的第一个节点的值，这个节点的值 **严格大于** 它的值。

返回一个整数数组 `answer` ，其中 `answer[i]` 是第 `i` 个节点( **从1开始** )的下一个更大的节点的值。如果第 `i` 个节点没有下一个更大的节点，设置 `answer[i] = 0` 。

 

**示例 1：**

![img](https://assets.leetcode.com/uploads/2021/08/05/linkedlistnext1.jpg)

```
输入：head = [2,1,5]
输出：[5,5,0]
```

**示例 2：**

![img](https://assets.leetcode.com/uploads/2021/08/05/linkedlistnext2.jpg)

```
输入：head = [2,7,4,3,5]
输出：[7,0,5,5,0]
```

 

**提示：**

- 链表中节点数为 `n`
- `1 <= n <= 104`
- `1 <= Node.val <= 109`

### 题解

#### 思路总结

当前实现采用**单调栈**寻找每个节点右侧第一个严格更大的节点。由于链表无法通过下标随机访问，先遍历一次得到长度 `n`，创建答案数组；第二次从左到右遍历链表，同时使用栈保存“还没有找到下一个更大节点”的节点信息，每个栈元素记录节点下标和节点值。

当访问当前节点时，如果 `head.val > stack.peek()[1]`，说明当前节点就是栈顶节点遇到的第一个更大节点，因此不断弹栈并填写对应答案。直到栈为空或者栈顶节点值大于等于当前值，再将当前节点加入栈。遍历结束后仍留在栈中的节点不存在下一个更大节点，而 `int[]` 默认值正好为 `0`，无需额外处理。

------

#### 解题步骤

1. **计算链表长度：** 遍历链表得到节点数量 `n`，用于创建长度固定的答案数组。
2. **初始化单调栈：** 栈中保存尚未找到下一个更大节点的 `{下标, 节点值}`。
3. **从左到右遍历：** 依次处理链表中的每个节点。
4. **判断当前节点是否更大：** 如果当前值严格大于栈顶节点值，则当前节点就是栈顶节点的下一个更大节点。
5. **连续弹出较小节点：** 不断弹栈，并将这些节点对应的答案设置为当前节点值。
6. **保存当前节点：** 将当前节点的下标和值压入栈中，等待后面的更大节点。
7. **保留未匹配节点：** 遍历完成后栈中剩余节点不存在更大节点，对应答案保持默认值 `0`。
8. **返回结果数组：** 返回 `ans`。

```java
class Solution {
    public int[] nextLargerNodes(ListNode head) {
        int n = len(head);
        int[] ans = new int[n];
        Deque<int[]> stack = new ArrayDeque<>();
        for(int i = 0; i < n; i++){
            while(!stack.isEmpty() && head.val > stack.peek()[1]){
                ans[stack.pop()[0]] = head.val;
            }
            stack.push(new int[] {i, head.val});
            head = head.next;
        }
        return ans;
    }

    private int len(ListNode head){
        int res = 0;
        while(head != null){
            res++;
            head = head.next;
        }
        return res;
    }
}
```
