## [1758. 生成交替二进制字符串的最少操作数](https://leetcode.cn/problems/minimum-changes-to-make-alternating-binary-string/)

### 题目

给你一个仅由字符 `'0'` 和 `'1'` 组成的字符串 `s` 。一步操作中，你可以将任一 `'0'` 变成 `'1'` ，或者将 `'1'` 变成 `'0'` 。

**交替字符串** 定义为：如果字符串中不存在相邻两个字符相等的情况，那么该字符串就是交替字符串。例如，字符串 `"010"` 是交替字符串，而字符串 `"0100"` 不是。

返回使 `s` 变成 **交替字符串** 所需的 **最少** 操作数。

 

**示例 1：**

```
输入：s = "0100"
输出：1
解释：如果将最后一个字符变为 '1' ，s 就变成 "0101" ，即符合交替字符串定义。
```

**示例 2：**

```
输入：s = "10"
输出：0
解释：s 已经是交替字符串。
```

**示例 3：**

```
输入：s = "1111"
输出：2
解释：需要 2 步操作得到 "0101" 或 "1010" 。
```

 

**提示：**

- `1 <= s.length <= 104`
- `s[i]` 是 `'0'` 或 `'1'`

### 题解

1. **明确目标形态** 长度固定的交替字符串只有两种可能：
   - 形态一：`"010101..."`（索引为偶数是 `'0'`，奇数是 `'1'`）
   - 形态二：`"101010..."`（与形态一完全相反）
2. **统计形态一的修改步数** 遍历字符串 `s`，利用 `i % 2` 模拟形态一的交替规律。若当前字符 `s.charAt(i) - '0'` 不等于 `i % 2`，则说明该位置需要修改，计数器 `ans` 加 1。
3. **利用互补原理计算形态二** 由于形态一和形态二完全相反，修改成形态二所需的步数不需要重新遍历，它直接等于总长度减去形态一的步数，即 `s.length() - ans`。
4. **返回最小值** 比较两种形态所需的步数，返回较小值：`Math.min(ans, s.length() - ans)`。

```java
class Solution {
    public int minOperations(String s) {
        int ans = 0;
        int n = s.length();
        for(int i = 0;i < n;i++){
            // 变成010101...形式
            if(s.charAt(i) - '0' != i % 2){
                ans++;
            }
        }
        ans = Integer.min(ans, s.length() - ans);
        return ans;
    }
}
```

## [1736. 替换隐藏数字得到的最晚时间](https://leetcode.cn/problems/latest-time-by-replacing-hidden-digits/)

### 题目

给你一个字符串 `time` ，格式为 ` hh:mm`（小时：分钟），其中某几位数字被隐藏（用 `?` 表示）。

有效的时间为 `00:00` 到 `23:59` 之间的所有时间，包括 `00:00` 和 `23:59` 。

替换 `time` 中隐藏的数字，返回你可以得到的最晚有效时间。

 

**示例 1：**

```
输入：time = "2?:?0"
输出："23:50"
解释：以数字 '2' 开头的最晚一小时是 23 ，以 '0' 结尾的最晚一分钟是 50 。
```

**示例 2：**

```
输入：time = "0?:3?"
输出："09:39"
```

**示例 3：**

```
输入：time = "1?:22"
输出："19:22"
```

 

**提示：**

- `time` 的格式为 `hh:mm`
- 题目数据保证你可以由输入的字符串生成有效的时间

### 题解

#### 思路总结

利用**贪心算法（Greedy Algorithm）**从高位到低位依次替换字符串中的 `?`。由于目标是得到最晚时间，应优先让小时十位、小时个位、分钟十位和分钟个位尽可能大，同时保证最终时间仍处于 `00:00` 到 `23:59` 的有效范围内。

算法核心逻辑在于：

1. **优先处理小时部分**，因为小时对时间大小的影响高于分钟。
2. **根据相邻位确定最大合法数字**，保证小时不超过 `23`。
3. **分钟部分直接取最大合法值**，分钟十位最大为 `5`，分钟个位最大为 `9`。
4. **按照从高位到低位的顺序填充**，每一步都选择当前能取到的最大合法数字。

整体过程只需依次检查固定的四个数字位置，实现 **O(1)** 时间复杂度和 **O(1)** 空间复杂度。

------

#### 解题步骤

1. **转换字符串结构**：将字符串 `time` 转换为字符数组 `chars`，便于直接修改各个数字位置。
2. **处理小时十位**：若 `chars[0]` 为 `?`，则根据小时个位 `chars[1]` 判断可填入的最大数字；当小时个位未知时直接组成最大小时 `23`，当小时个位大于等于 `4` 时只能填 `1`，否则填 `2`。
3. **处理小时个位**：若 `chars[1]` 为 `?`，当小时十位小于 `2` 时可填最大数字 `9`，否则小时十位为 `2`，只能填最大数字 `3`。
4. **处理分钟十位**：若 `chars[3]` 为 `?`，填入分钟十位允许的最大数字 `5`。
5. **处理分钟个位**：若 `chars[4]` 为 `?`，填入分钟个位允许的最大数字 `9`。
6. **构造最终结果**：将修改后的字符数组重新转换为字符串并返回，得到能够生成的最晚有效时间。

```java
class Solution {
    public String maximumTime(String time) {
        char[] chars = time.toCharArray();
        if(chars[0] == '?'){
            if(chars[1] == '?'){
                chars[0] = '2';
                chars[1] = '3';
            }else if(chars[1] >= '4'){
                chars[0] = '1';
            }else {
                chars[0] = '2';
            }
        }

        if(chars[1] == '?'){
            if(chars[0] < '2'){
                chars[1] = '9';
            }else {
                chars[1] = '3';
            }
        }

        if(chars[3] == '?'){
            chars[3] = '5';
        }

        if(chars[4] == '?'){
            chars[4] = '9';
        }

        return new String(chars);
    }
}
```

## [1704. 判断字符串的两半是否相似](https://leetcode.cn/problems/determine-if-string-halves-are-alike/)

### 题目

给你一个偶数长度的字符串 `s` 。将其拆分成长度相同的两半，前一半为 `a` ，后一半为 `b` 。

两个字符串 **相似** 的前提是它们都含有相同数目的元音（`'a'`，`'e'`，`'i'`，`'o'`，`'u'`，`'A'`，`'E'`，`'I'`，`'O'`，`'U'`）。注意，`s` 可能同时含有大写和小写字母。

如果 `a` 和 `b` 相似，返回 `true` ；否则，返回 `false` 。

 

**示例 1：**

```
输入：s = "book"
输出：true
解释：a = "bo" 且 b = "ok" 。a 中有 1 个元音，b 也有 1 个元音。所以，a 和 b 相似。
```

**示例 2：**

```
输入：s = "textbook"
输出：false
解释：a = "text" 且 b = "book" 。a 中有 1 个元音，b 中有 2 个元音。因此，a 和 b 不相似。
注意，元音 o 在 b 中出现两次，记为 2 个。
```

 

**提示：**

- `2 <= s.length <= 1000`
- `s.length` 是偶数
- `s` 由 **大写和小写** 字母组成

### 题解

#### 思路总结

利用**双指针 + 计数（Two Pointers + Counting）**判断字符串两半是否相似。分别从字符串的前半部分和后半部分同时遍历，统计两部分元音字母数量的差值，最终若差值为 `0`，则说明两部分包含相同数量的元音字母。

算法核心逻辑在于：

1. **确定字符串中点**，将字符串划分为长度相同的两部分。
2. **同时遍历前后两部分**，分别判断当前字符是否为元音字母。
3. **维护元音数量差值**，前半部分遇到元音则加一，后半部分遇到元音则减一。
4. **根据最终差值判断结果**，若差值为 `0`，则两部分元音数量相同。

整体过程仅遍历字符串一次，实现 **O(n)** 时间复杂度和 **O(1)** 空间复杂度。

------

#### 解题步骤

1. **初始化变量**：定义元音字符集合 `ss`，计算字符串中点 `n`，并初始化计数器 `count`。
2. **同时遍历两部分字符串**：从前半部分起始位置和后半部分末尾位置同时遍历，每次分别获取两个字符。
3. **统计元音数量差值**：若前半部分当前字符为元音，则将 `count` 加一；若后半部分当前字符为元音，则将 `count` 减一。
4. **判断最终结果**：遍历结束后，若 `count` 等于 `0`，说明两部分元音数量相同，返回 `true`；否则返回 `false`。

```java
class Solution {
    public boolean halvesAreAlike(String s) {
        String ss = "aeiouAEIOU";
        int n = s.length() / 2;
        int count = 0;
        for(int i = 0; i < n; i++){
            char c1 = s.charAt(i);
            char c2 = s.charAt(n * 2 - 1 - i);
            if(ss.indexOf(c1) != -1){
                count++;
            }
            if(ss.indexOf(c2) != -1){
                count--;
            }
        }
        return count == 0;
    }
}
```

## [1694. 重新格式化电话号码](https://leetcode.cn/problems/reformat-phone-number/)

### 题目

给你一个字符串形式的电话号码 `number` 。`number` 由数字、空格 `' '`、和破折号 `'-'` 组成。

请你按下述方式重新格式化电话号码。

- 首先，**删除** 所有的空格和破折号。

- 其次，将数组从左到右

   

  每 3 个一组

   

  分块，

  直到 

  剩下 4 个或更少数字。剩下的数字将按下述规定再分块：

  - 2 个数字：单个含 2 个数字的块。
  - 3 个数字：单个含 3 个数字的块。
  - 4 个数字：两个分别含 2 个数字的块。

最后用破折号将这些块连接起来。注意，重新格式化过程中 **不应该** 生成仅含 1 个数字的块，并且 **最多** 生成两个含 2 个数字的块。

返回格式化后的电话号码。

 

**示例 1：**

```
输入：number = "1-23-45 6"
输出："123-456"
解释：数字是 "123456"
步骤 1：共有超过 4 个数字，所以先取 3 个数字分为一组。第 1 个块是 "123" 。
步骤 2：剩下 3 个数字，将它们放入单个含 3 个数字的块。第 2 个块是 "456" 。
连接这些块后得到 "123-456" 。
```

**示例 2：**

```
输入：number = "123 4-567"
输出："123-45-67"
解释：数字是 "1234567".
步骤 1：共有超过 4 个数字，所以先取 3 个数字分为一组。第 1 个块是 "123" 。
步骤 2：剩下 4 个数字，所以将它们分成两个含 2 个数字的块。这 2 块分别是 "45" 和 "67" 。
连接这些块后得到 "123-45-67" 。
```

**示例 3：**

```
输入：number = "123 4-5678"
输出："123-456-78"
解释：数字是 "12345678" 。
步骤 1：第 1 个块 "123" 。
步骤 2：第 2 个块 "456" 。
步骤 3：剩下 2 个数字，将它们放入单个含 2 个数字的块。第 3 个块是 "78" 。
连接这些块后得到 "123-456-78" 。
```

**示例 4：**

```
输入：number = "12"
输出："12"
```

**示例 5：**

```
输入：number = "--17-5 229 35-39475 "
输出："175-229-353-94-75"
```

 

**提示：**

- `2 <= number.length <= 100`
- `number` 由数字和字符 `'-'` 及 `' '` 组成。
- `number` 中至少含 **2** 个数字。

### 题解

#### 思路总结

利用**字符串处理 + 贪心分组**实现电话号码重新格式化。首先删除原字符串中的空格和破折号，得到只包含数字的新字符串，然后按照题目要求从左到右优先每三个数字划分为一组，同时特殊处理剩余 `2`、`3`、`4` 个数字的情况，避免产生长度为 `1` 的分组。

算法核心逻辑在于：

1. **预处理字符串**，去除所有非数字字符，获得纯数字字符串。
2. **从左到右遍历数字字符串**，优先每三个数字划分为一组。
3. **处理剩余数字情况：**
   - 剩余 `2` 或 `3` 个数字时，直接作为最后一组。
   - 剩余 `4` 个数字时，拆分为两个长度为 `2` 的分组。
4. **使用分隔符连接各个分组**，得到最终格式化后的电话号码。

整体过程只需遍历数字字符串一次，实现 **O(n)** 时间复杂度和 **O(n)** 空间复杂度。

------

#### 解题步骤

1. **清理电话号码格式**：删除字符串中的空格和破折号，只保留数字字符，得到待处理的电话号码。
2. **初始化遍历过程**：根据数字字符串长度 `n`，从起始位置开始，每次处理最多三个数字。
3. **划分三位分组**：当剩余数字数量大于 `4` 时，将当前三个数字作为一个分组，并添加连接符。
4. **处理剩余数字**：当剩余数字数量为 `2` 或 `3` 时，将剩余数字作为最后一个分组；当剩余数字数量为 `4` 时，将其拆分为两个长度为 `2` 的分组。
5. **返回格式化结果**：将所有分组连接成字符串，得到重新格式化后的电话号码。

```java
class Solution {
    public String reformatNumber(String number) {
        number = number.replace(" ", "").replace("-", "");
        int n = number.length();
        StringBuilder sb = new StringBuilder();
        for(int i = 0; i < n; i += 3){
            if(n - i == 2 || n - i == 3){
                sb.append(number, i, n);
            }else if(n - i == 4){
                sb.append(number, i, i + 2).append("-").append(number, i + 2, n);
                break;
            }else {
                sb.append(number, i, i + 3).append("-");
            }
        }
        return sb.toString();
    }
}
```

## [1684. 统计一致字符串的数目](https://leetcode.cn/problems/count-the-number-of-consistent-strings/)

### 题目

给你一个由不同字符组成的字符串 `allowed` 和一个字符串数组 `words` 。如果一个字符串的每一个字符都在 `allowed` 中，就称这个字符串是 **一致字符串** 。

请你返回 `words` 数组中 **一致字符串** 的数目。

 

**示例 1：**

```
输入：allowed = "ab", words = ["ad","bd","aaab","baa","badab"]
输出：2
解释：字符串 "aaab" 和 "baa" 都是一致字符串，因为它们只包含字符 'a' 和 'b' 。
```

**示例 2：**

```
输入：allowed = "abc", words = ["a","b","c","ab","ac","bc","abc"]
输出：7
解释：所有字符串都是一致的。
```

**示例 3：**

```
输入：allowed = "cad", words = ["cc","acd","b","ba","bac","bad","ac","d"]
输出：4
解释：字符串 "cc"，"acd"，"ac" 和 "d" 是一致字符串。
```

 

**提示：**

- `1 <= words.length <= 104`
- `1 <= allowed.length <= 26`
- `1 <= words[i].length <= 10`
- `allowed` 中的字符 **互不相同** 。
- `words[i]` 和 `allowed` 只包含小写英文字母。

### 题解

#### 思路总结

利用**哈希集合（HashSet）**实现一致字符串统计。由于 `allowed` 中的字符互不重复，可以将其中所有字符存入集合，通过集合的快速查找能力判断 `words` 中每个字符串的字符是否都存在于 `allowed` 中。

算法核心逻辑在于：

1. **建立字符集合**，存储 `allowed` 中允许出现的所有字符。
2. **遍历字符串数组**，逐个检查每个字符串中的字符。
3. **判断字符串是否一致**，若存在任意字符不属于允许集合，则该字符串不是一致字符串。
4. **统计满足条件的字符串数量**，最终返回一致字符串的个数。

整体过程利用哈希集合实现字符快速判断，遍历所有字符串一次，实现 **O(n)** 时间复杂度和 **O(1)** 空间复杂度（字符集大小固定）。

------

#### 解题步骤

1. **初始化字符集合**：遍历字符串 `allowed`，将其中所有字符加入集合 `set`，用于快速判断字符是否合法。
2. **遍历字符串数组**：依次访问 `words` 中的每个字符串，并假设当前字符串是一致字符串。
3. **检查字符串字符**：遍历当前字符串中的每个字符，判断该字符是否存在于集合 `set` 中；若不存在，则说明该字符串不是一致字符串。
4. **统计结果数量**：若当前字符串中的所有字符均存在于 `allowed` 中，则增加一致字符串计数；否则跳过该字符串。
5. **返回统计结果**：遍历结束后，返回所有一致字符串的数量。

```java
class Solution {
    public int countConsistentStrings(String allowed, String[] words) {
        Set<Character> set = new HashSet<>();
        for(char c : allowed.toCharArray()){
            set.add(c);
        }
        int ans = 0;
        for(String word : words){
            ans++;
            for(char c : word.toCharArray()){
                if(!set.contains(c)){
                    ans--;
                    break;
                }
            }
        }
        return ans;
    }
}
```

## [1678. 设计 Goal 解析器](https://leetcode.cn/problems/goal-parser-interpretation/)

### 题目

请你设计一个可以解释字符串 `command` 的 **Goal 解析器** 。`command` 由 `"G"`、`"()"` 和/或 `"(al)"` 按某种顺序组成。Goal 解析器会将 `"G"` 解释为字符串 `"G"`、`"()"` 解释为字符串 `"o"` ，`"(al)"` 解释为字符串 `"al"` 。然后，按原顺序将经解释得到的字符串连接成一个字符串。

给你字符串 `command` ，返回 **Goal 解析器** 对 `command` 的解释结果。

 

**示例 1：**

```
输入：command = "G()(al)"
输出："Goal"
解释：Goal 解析器解释命令的步骤如下所示：
G -> G
() -> o
(al) -> al
最后连接得到的结果是 "Goal"
```

**示例 2：**

```
输入：command = "G()()()()(al)"
输出："Gooooal"
```

**示例 3：**

```
输入：command = "(al)G(al)()()G"
输出："alGalooG"
```

 

**提示：**

- `1 <= command.length <= 100`
- `command` 由 `"G"`、`"()"` 和/或 `"(al)"` 按某种顺序组成

### 题解

#### 思路总结

利用**字符串遍历 + 模式匹配**实现 Goal 解析器。由于 `command` 只包含三种固定形式：`G`、`()` 和 `(al)`，因此可以通过遍历字符串，根据当前字符判断对应的命令类型，并将其转换为目标字符串。

算法核心逻辑在于：

1. **逐字符扫描字符串**，判断当前位置对应的命令类型。
2. **根据不同模式进行转换：**
   - 遇到 `G`，直接解析为 `G`。
   - 遇到 `()`，解析为 `o`。
   - 遇到 `(al)`，解析为 `al`。
3. **跳过已经解析的字符**，避免重复处理同一个命令。
4. **拼接所有解析结果**，得到最终字符串。

整体过程只需遍历字符串一次，实现 **O(n)** 时间复杂度和 **O(n)** 空间复杂度。

------

#### 解题步骤

1. **初始化结果字符串**：创建 `StringBuilder` 用于保存 Goal 解析器转换后的结果。
2. **遍历命令字符串**：从左到右依次访问 `command` 中的每个字符，根据当前位置字符判断命令类型。
3. **解析单字符命令**：若当前字符为 `G`，直接将 `G` 加入结果字符串。
4. **解析括号命令**：若当前字符为 `(`，根据下一个字符判断是 `()` 还是 `(al)`；若下一个字符为 `)`，则解析为 `o`，否则解析为 `al`。
5. **调整遍历位置**：解析括号命令后跳过已经处理的字符，避免重复解析。
6. **返回解析结果**：遍历结束后，将拼接完成的字符串作为最终答案返回。

```java
class Solution {
    public String interpret(String command) {
        StringBuilder sb = new StringBuilder();
        int n = command.length();
        for(int i = 0; i < n; i++){
            if(command.charAt(i) == 'G'){
                sb.append('G');
            }else {
                if(command.charAt(i + 1) == ')'){
                    sb.append('o');
                    i++;
                }else {
                    sb.append("al");
                    i += 3;
                }
            }
        }
        return sb.toString();
    }
}
```

## [1668. 最大重复子字符串](https://leetcode.cn/problems/maximum-repeating-substring/)

### 题目

给你一个字符串 `sequence` ，如果字符串 `word` 连续重复 `k` 次形成的字符串是 `sequence` 的一个子字符串，那么单词 `word` 的 **重复值为 `k`** 。单词 `word` 的 **最大重复值** 是单词 `word` 在 `sequence` 中最大的重复值。如果 `word` 不是 `sequence` 的子串，那么重复值 `k` 为 `0` 。

给你一个字符串 `sequence` 和 `word` ，请你返回 **最大重复值 `k`** 。

 

**示例 1：**

```
输入：sequence = "ababc", word = "ab"
输出：2
解释："abab" 是 "ababc" 的子字符串。
```

**示例 2：**

```
输入：sequence = "ababc", word = "ba"
输出：1
解释："ba" 是 "ababc" 的子字符串，但 "baba" 不是 "ababc" 的子字符串。
```

**示例 3：**

```
输入：sequence = "ababc", word = "ac"
输出：0
解释："ac" 不是 "ababc" 的子字符串。
```

 

**提示：**

- `1 <= sequence.length <= 100`
- `1 <= word.length <= 100`
- `sequence` 和 `word` 都只包含小写英文字母。

### 题解一

#### 思路总结

利用**枚举重复次数 + 字符串匹配**解决最大重复子字符串问题。

字符串 `word` 最多只能重复：

```
sequence.length() / word.length()
```

次，因为重复后的字符串长度不能超过 `sequence`。

当前实现从这个理论最大值开始向下枚举 `k`，每次构造 `word` 连续重复 `k` 次得到的字符串，然后判断它是否为 `sequence` 的子串。由于按照 `k` 从大到小搜索，因此第一次匹配成功时，对应的 `k` 就是最大重复值。

------

#### 解题步骤

1. **计算最大重复次数：** 使用 `sequence.length() / word.length()` 得到 `word` 理论上最多能够重复的次数 `k`。
2. **从最大次数向下枚举：** 从当前 `k` 开始逐渐减小重复次数，优先检查更大的重复值。
3. **构造重复字符串：** 使用 `word.repeat(k)` 得到 `word` 连续重复 `k` 次后的字符串。
4. **判断是否为子串：** 使用 `sequence.contains()` 判断构造出的重复字符串是否出现在 `sequence` 中。
5. **找到后立即返回：** 由于 `k` 按照从大到小枚举，因此第一次匹配成功的 `k` 就是最大重复值。
6. **处理不存在情况：** 如果所有正整数重复次数都无法匹配，则最终返回 `0`。

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int k = sequence.length() / word.length();
        for(; k >= 0; k--){
            if(sequence.contains(word.repeat(k))){
                return k;
            }
        }
        return 0;
    }
}
```

## 题解二

#### 思路总结

利用**动态规划**统计 `word` 在 `sequence` 中连续重复出现的最大次数。

定义：

`dp[i]` 表示以 `sequence[i]` 作为最后一个字符时，连续出现了多少个 `word`。

对于当前位置 `i`，对应单词的起始位置为：

```
start = i - m + 1
```

如果区间 `[start, start + m)` 与 `word` 相同，那么当前至少出现了一个 `word`。由于连续重复的前一个 `word` 必须恰好结束在 `start - 1`，也就是 `i - m`，因此状态转移为：

```
dp[i] = dp[i - m] + 1
```

如果当前位置是第一个完整的 `word`，前面不存在对应状态，则 `dp[i] = 1`。

遍历过程中维护最大的 `dp[i]`，即可得到最大重复值。

------

#### 解题步骤

1. **获取字符串长度：** 使用 `m` 表示 `word` 的长度，使用 `n` 表示 `sequence` 的长度。
2. **初始化动态规划数组：** 创建 `dp`，其中 `dp[i]` 表示以位置 `i` 结尾时连续出现的 `word` 数量。
3. **枚举单词结束位置：** 从 `i = m - 1` 开始遍历，因为此前的位置无法组成一个完整的 `word`。
4. **计算当前起始位置：** 使用 `start = i - m + 1` 得到当前长度为 `m` 的子串起点。
5. **判断是否匹配单词：** 如果当前长度为 `m` 的子串与 `word` 相同，则当前位置能够形成一个完整的 `word`。
6. **连接前一个重复单词：** 如果前面还存在长度为 `m` 的区域，则通过 `dp[start - 1] + 1` 得到当前连续重复次数。
7. **处理第一次匹配：** 如果当前匹配从下标 `0` 开始，则当前连续重复次数为 `1`。
8. **更新最大重复次数：** 使用当前 `dp[i]` 更新全局最大值 `ans`。
9. **返回最终结果：** 遍历完成后返回 `ans`。

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int m = word.length();
        int n = sequence.length();
        int[] dp = new int[n];
        int ans = 0;
        for(int i = m - 1; i < n; i++){
            int start = i - m + 1;
            if(word.equals(sequence.substring(start, start + m))){
                if(i > m - 1){
                    dp[i] = dp[start - 1] + 1;
                }else {
                    dp[i] = 1;
                }
                ans = Math.max(ans, dp[i]);
            }
        }
        return ans;
    }
}
```

## [1653. 使字符串平衡的最少删除次数](https://leetcode.cn/problems/minimum-deletions-to-make-string-balanced/)

### 题目

给你一个字符串 `s` ，它仅包含字符 `'a'` 和 `'b'` 。

你可以删除 `s` 中任意数目的字符，使得 `s` **平衡** 。当不存在下标对 `(i,j)` 满足 `i < j` ，且 `s[i] = 'b'` 的同时 `s[j]= 'a'` ，此时认为 `s` 是 **平衡** 的。

请你返回使 `s` **平衡** 的 **最少** 删除次数。

 

**示例 1：**

```
输入：s = "aababbab"
输出：2
解释：你可以选择以下任意一种方案：
下标从 0 开始，删除第 2 和第 6 个字符（"aababbab" -> "aaabbb"），
下标从 0 开始，删除第 3 和第 6 个字符（"aababbab" -> "aabbbb"）。
```

**示例 2：**

```
输入：s = "bbaaaaabb"
输出：2
解释：唯一的最优解是删除最前面两个字符。
```

 

**提示：**

- `1 <= s.length <= 105`
- `s[i]` 要么是 `'a'` 要么是 `'b'` 。

### 题解一

#### 思路总结

利用**枚举分割点 + 前后缀计数**解决最少删除次数问题。

平衡字符串的最终形式一定满足：

```
aaaa...bbbb
```

也就是说，可以在字符串中选择一个分割位置，使得：

- 分割点左侧只能保留 `'a'`，因此左侧所有 `'b'` 都必须删除。
- 分割点右侧只能保留 `'b'`，因此右侧所有 `'a'` 都必须删除。

因此，对于任意一个分割位置，需要删除的字符数量就是：

```
左侧 b 的数量 + 右侧 a 的数量
```

当前实现使用：

- `leftb` 维护分割点左侧 `'b'` 的数量。
- `righta` 维护分割点右侧 `'a'` 的数量。

随着分割点从左向右移动，不断计算 `leftb + righta` 的最小值，即可得到答案。

整体时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **统计所有字符 a：** 第一次遍历字符串，统计全部 `'a'` 的数量并保存到 `righta`，表示分割点位于字符串最左侧时右边需要删除的 `'a'` 数量。
2. **初始化删除次数：** 使用 `righta` 作为初始答案，表示删除全部 `'a'`，最终只保留 `'b'` 的情况。
3. **从左向右移动分割点：** 第二次遍历字符串，每处理一个字符，就相当于将该字符从分割点右侧移动到左侧。
4. **更新左侧 b 数量：** 如果当前字符是 `'b'`，说明左侧多了一个需要删除的 `'b'`，执行 `leftb++`。
5. **更新右侧 a 数量：** 如果当前字符是 `'a'`，说明该字符已经从右侧移到左侧，因此执行 `righta--`。
6. **计算当前删除次数：** 当前分割位置需要删除的字符数量为 `leftb + righta`。
7. **维护最小删除次数：** 每次移动分割点后使用 `leftb + righta` 更新 `ans`。
8. **返回最终结果：** 所有分割位置检查完成后，返回最小删除次数 `ans`。

```java
class Solution {
    public int minimumDeletions(String s) {
        int righta = 0;
        int leftb = 0;
        int ans = 100000;
        for(char c : s.toCharArray()){
            if(c == 'a'){
                righta++;
            }
        }
        ans = Math.min(ans, righta);
        for(char c : s.toCharArray()){
            if(c == 'b'){
                leftb++;
            }else {
                righta--;
            }
            ans = Math.min(ans, leftb + righta);
        }
        return ans;
    }
}
```

### 题解二

#### 思路总结

利用**动态规划 + 状态压缩**解决字符串平衡所需的最少删除次数。

遍历字符串时维护两个状态：

- `bCount`：当前已经遇到的 `'b'` 数量。
- `dp`：使当前已经遍历的前缀字符串达到平衡状态所需的最少删除次数。

当遇到 `'b'` 时，字符 `'b'` 可以合法地出现在平衡字符串的后半部分，因此不需要立即删除，只需要执行 `bCount++`。

当遇到 `'a'` 时，如果前面已经存在 `'b'`，就产生了 `"ba"` 的不平衡关系，此时有两种选择：

`删除当前 a`：删除次数为 `dp + 1`。

`保留当前 a`：需要删除前面所有 `'b'`，删除次数为 `bCount`。

因此状态转移为：

```
dp = Math.min(dp + 1, bCount)
```

最终 `dp` 就是使整个字符串平衡所需的最少删除次数。

------

#### 解题步骤

1. **初始化状态：** 设置 `bCount = 0` 记录已经遍历到的 `'b'` 数量，设置 `dp = 0` 表示当前前缀变平衡所需的最少删除次数。
2. **从左向右遍历字符串：** 依次处理字符串中的每一个字符。
3. **处理字符 b：** 如果当前字符是 `'b'`，不会立即破坏平衡结构，只需要执行 `bCount++`。
4. **处理字符 a：** 如果当前字符是 `'a'`，需要在删除当前 `'a'` 和删除前面所有 `'b'` 两种方案之间选择。
5. **计算删除当前 a 的代价：** 当前前缀原本最少需要删除 `dp` 个字符，再删除当前 `'a'`，总代价为 `dp + 1`。
6. **计算保留当前 a 的代价：** 如果保留当前 `'a'`，则前面所有 `'b'` 都不能存在，因此需要删除 `bCount` 个 `'b'`。
7. **更新最少删除次数：** 使用 `dp = Math.min(dp + 1, bCount)` 保存处理当前前缀后的最优结果。
8. **返回最终答案：** 遍历完整个字符串后返回 `dp`。

```java
class Solution {
    public int minimumDeletions(String s) {
        int bCount = 0;
        int dp = 0;
        for(char c : s.toCharArray()){
            if(c == 'b'){
                bCount++;
            }else {
                dp = Math.min(dp + 1, bCount);
            }
        }
        return dp;
    }
}
```

## [1624. 两个相同字符之间的最长子字符串](https://leetcode.cn/problems/largest-substring-between-two-equal-characters/)

### 题目

给你一个字符串 `s`，请你返回 **两个相同字符之间的最长子字符串的长度** *，*计算长度时不含这两个字符。如果不存在这样的子字符串，返回 `-1` 。

**子字符串** 是字符串中的一个连续字符序列。

 

**示例 1：**

```
输入：s = "aa"
输出：0
解释：最优的子字符串是两个 'a' 之间的空子字符串。
```

**示例 2：**

```
输入：s = "abca"
输出：2
解释：最优的子字符串是 "bc" 。
```

**示例 3：**

```
输入：s = "cbzxy"
输出：-1
解释：s 中不存在出现出现两次的字符，所以返回 -1 。
```

**示例 4：**

```
输入：s = "cabbac"
输出：4
解释：最优的子字符串是 "abba" ，其他的非最优解包括 "bb" 和 "" 。
```

 

**提示：**

- `1 <= s.length <= 300`
- `s` 只含小写英文字母

### 题解

#### 思路总结

利用**哈希表记录每个字符第一次出现的位置**，在遍历字符串时计算当前字符与其第一次出现位置之间的距离。

对于两个相同字符分别位于下标 `start` 和 `i`，它们之间的子字符串长度为：

```
i - start - 1
```

为了让同一个字符形成的子字符串尽可能长，只需要始终保存该字符**第一次出现的位置**，后续每次再次遇到该字符时，都用当前位置与第一次出现位置计算距离。

当前代码通过：

```
int start = map.getOrDefault(s.charAt(i), i);
```

处理字符首次出现的情况；如果字符没有出现过，就让 `start = i`，此时得到的长度为 `-1`，不会影响初始答案。

随后：

```
map.put(s.charAt(i), start);
```

继续保存第一次出现的位置，而不会被后续位置覆盖。

整体只需要遍历字符串一次，时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **初始化字符位置映射：** 使用 `map` 保存每个字符第一次出现的下标，并设置 `ans = -1` 表示暂时不存在两个相同字符。
2. **从左向右遍历字符串：** 对每个位置 `i` 获取当前字符 `s.charAt(i)`。
3. **获取第一次出现位置：** 如果当前字符已经出现，则从 `map` 获取第一次出现的下标；如果尚未出现，则使用当前位置 `i`。
4. **计算中间字符串长度：** 根据 `i - start - 1` 计算当前字符与第一次出现位置之间的字符数量。
5. **更新最大长度：** 使用当前长度更新 `ans`，保存已经找到的最大值。
6. **保存第一次出现位置：** 将当前字符对应的位置保存为 `start`，保证后续始终使用第一次出现的位置。
7. **返回最终答案：** 遍历完成后返回 `ans`，如果没有任何字符重复出现则保持为 `-1`。

```java
class Solution {
    public int maxLengthBetweenEqualCharacters(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int ans = -1;
        for(int i = 0; i < s.length(); i++){
            int start = map.getOrDefault(s.charAt(i), i);
            int val = i - start - 1;
            ans = Math.max(ans, val);
            map.put(s.charAt(i), start);
        }
        return ans;
    }
}
```

## [1614. 括号的最大嵌套深度](https://leetcode.cn/problems/maximum-nesting-depth-of-the-parentheses/)

### 题目

给定 **有效括号字符串** `s`，返回 `s` 的 **嵌套深度**。嵌套深度是嵌套括号的 **最大** 数量。

 

**示例 1：**

**输入：**s = "(1+(2*3)+((**8**)/4))+1"

**输出：**3

**解释：**数字 8 在嵌套的 3 层括号中。

**示例 2：**

**输入：**s = "(1)+((2))+(((**3**)))"

**输出：**3

**解释：**数字 3 在嵌套的 3 层括号中。

**示例 3：**

**输入：**s = "()(())((()()))"

**输出：**3

 

**提示：**

- `1 <= s.length <= 100`
- `s` 由数字 `0-9` 和字符 `'+'`、`'-'`、`'*'`、`'/'`、`'('`、`')'` 组成
- 题目数据保证括号字符串 `s` 是 **有效的括号字符串**

### 题解

#### 思路总结

利用**计数器模拟括号嵌套深度**。

使用 `count` 表示当前尚未闭合的左括号数量，也就是当前位置的括号嵌套深度：

- 遇到 `'('` 时，进入新的一层，执行 `count++`。
- 遇到 `')'` 时，退出当前层，执行 `count--`。
- 每次遇到 `'('` 后，使用当前 `count` 更新最大深度 `ans`。

由于题目保证 `s` 是有效括号字符串，因此遍历过程中括号能够正确匹配，最终 `count` 会回到 `0`。

该方法不需要真正使用栈，只需要维护当前深度和最大深度两个变量。

------

#### 解题步骤

1. **初始化当前深度：** 设置 `count = 0`，表示当前没有未闭合的左括号。
2. **初始化最大深度：** 设置 `ans = 0`，用于保存遍历过程中出现的最大嵌套层数。
3. **遍历字符串字符：** 从左向右依次检查字符串中的每一个字符。
4. **处理左括号：** 如果当前字符是 `'('`，执行 `count++`，表示进入新的一层括号。
5. **更新最大深度：** 每次进入新的一层后，使用 `Math.max(ans, count)` 更新最大嵌套深度。
6. **处理右括号：** 如果当前字符是 `')'`，执行 `count--`，表示当前括号层结束。
7. **忽略普通字符：** 数字和运算符不会影响括号嵌套层数，因此无需处理。
8. **返回最终结果：** 遍历完成后返回 `ans`。

```java
class Solution {
    public int maxDepth(String s) {
        int count = 0;
        int ans = 0;
        for(char c : s.toCharArray()){
            if(c == '('){
                count++;
                ans = Math.max(ans, count);
            }else if(c == ')'){
                count--;
            }
        }
        return ans;
    }
}
```

## [1573. 分割字符串的方案数](https://leetcode.cn/problems/number-of-ways-to-split-a-string/)

### 题目

给你一个二进制串 `s` （一个只包含 0 和 1 的字符串），我们可以将 `s` 分割成 3 个 **非空** 字符串 s1, s2, s3 （s1 + s2 + s3 = s）。

请你返回分割 `s` 的方案数，满足 s1，s2 和 s3 中字符 '1' 的数目相同。

由于答案可能很大，请将它对 10^9 + 7 取余后返回。

 

**示例 1：**

```
输入：s = "10101"
输出：4
解释：总共有 4 种方法将 s 分割成含有 '1' 数目相同的三个子字符串。
"1|010|1"
"1|01|01"
"10|10|1"
"10|1|01"
```

**示例 2：**

```
输入：s = "1001"
输出：0
```

**示例 3：**

```
输入：s = "0000"
输出：3
解释：总共有 3 种分割 s 的方法。
"0|0|00"
"0|00|0"
"00|0|0"
```

**示例 4：**

```
输入：s = "100100010100110"
输出：12
```

 

**提示：**

- `s[i] == '0'` 或者 `s[i] == '1'`
- `3 <= s.length <= 10^5`

### 题解

#### 思路总结

利用**统计 `'1'` 的总数 + 计算两个分割位置的可选数量**解决问题。

设字符串中 `'1'` 的总数为 `total`：

- 如果 `total % 3 != 0`，无法让三个子串包含相同数量的 `'1'`，答案为 `0`。
- 如果 `total == 0`，三个子串都天然包含 `0` 个 `'1'`，只需要从 `n - 1` 个间隙中选择两个分割点，方案数为 `C(n - 1, 2)`。
- 如果 `total > 0`，每一段都必须包含 `k = total / 3` 个 `'1'`。

此时第一个分割点必须位于**第 `k` 个 `'1'` 和第 `k + 1` 个 `'1'` 之间**，第二个分割点必须位于**第 `2k` 个 `'1'` 和第 `2k + 1` 个 `'1'` 之间**。

若这些 `'1'` 的位置分别为 `p1、p2、p3、p4`，则：

```
第一个分割点方案数 = p2 - p1
第二个分割点方案数 = p4 - p3
```

两个分割点相互独立，因此最终答案为：

```
(p2 - p1) × (p4 - p3)
```

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **统计 1 的总数：** 遍历字符串得到字符 `'1'` 的数量 `total`。
2. **判断是否能够平均分配：** 如果 `total % 3 != 0`，三个子串不可能拥有相同数量的 `'1'`，直接返回 `0`。
3. **处理全 0 情况：** 如果 `total == 0`，从字符串的 `n - 1` 个间隙中任选两个作为分割点，方案数为 `(n - 1) * (n - 2) / 2`。
4. **计算每段目标数量：** 设置 `k = total / 3`，表示每个子串应该包含 `k` 个 `'1'`。
5. **寻找第一处分割边界：** 记录第 `k` 个 `'1'` 的位置 `p1` 和第 `k + 1` 个 `'1'` 的位置 `p2`。
6. **寻找第二处分割边界：** 记录第 `2k` 个 `'1'` 的位置 `p3` 和第 `2k + 1` 个 `'1'` 的位置 `p4`。
7. **计算第一刀方案数：** 第一个分割点可以放在 `p1` 到 `p2` 之间，共有 `p2 - p1` 种选择。
8. **计算第二刀方案数：** 第二个分割点可以放在 `p3` 到 `p4` 之间，共有 `p4 - p3` 种选择。
9. **计算最终答案：** 将两部分方案数相乘，并对 `10^9 + 7` 取模后返回。

```java
class Solution {
    public int numWays(String s) {
        int n = s.length();
        int total = 0;
        int mod = 1000000007;
        for(int i = 0; i < n; i++){
            if(s.charAt(i) == '1'){
                total++;
            }
        }
        if(total % 3 != 0){
            return 0;
        }
        if(total == 0){
            long ans = (long) (n - 1) * (n - 2) / 2 % mod;
            return (int) ans;
        }
        int k = total / 3;

        int p1 = 0, p2 = 0, p3 = 0, p4 = 0;
        int count = 0;

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') {
                count++;

                if (count == k) {
                    p1 = i;
                } else if (count == k + 1) {
                    p2 = i;
                }
                if (count == 2 * k) {
                    p3 = i;
                } else if (count == 2 * k + 1) {
                    p4 = i;
                }
            }
        }

        long first = p2 - p1;
        long second = p4 - p3;

        return (int) (first * second % mod);
    }
}
```

## [1461. 检查一个字符串是否包含所有长度为 K 的二进制子串](https://leetcode.cn/problems/check-if-a-string-contains-all-binary-codes-of-size-k/)

### 题目

给你一个二进制字符串 `s` 和一个整数 `k` 。如果所有长度为 `k` 的二进制字符串都是 `s` 的子串，请返回 `true` ，否则请返回 `false` 。

 

**示例 1：**

```
输入：s = "00110110", k = 2
输出：true
解释：长度为 2 的二进制串包括 "00"，"01"，"10" 和 "11"。它们分别是 s 中下标为 0，1，3，2 开始的长度为 2 的子串。
```

**示例 2：**

```
输入：s = "0110", k = 1
输出：true
解释：长度为 1 的二进制串包括 "0" 和 "1"，显然它们都是 s 的子串。
```

**示例 3：**

```
输入：s = "0110", k = 2
输出：false
解释：长度为 2 的二进制串 "00" 没有出现在 s 中。
```

 

**提示：**

- `1 <= s.length <= 5 * 105`
- `s[i]` 不是`'0'` 就是 `'1'`
- `1 <= k <= 20`

### 题解

#### 思路总结

利用**滑动窗口 + HashSet 去重**判断长度为 `k` 的所有二进制字符串是否都在 `s` 中出现。

长度为 `k` 的二进制字符串一共有：

```
2^k
```

种。

当前实现枚举 `s` 中所有长度为 `k` 的连续子串，通过 `HashSet` 保存不同的子串。遍历完成后，如果集合中的不同子串数量恰好等于 `2^k`，说明所有长度为 `k` 的二进制字符串都已经出现。

------

#### 解题步骤

1. **初始化去重集合：** 创建 `HashSet<String>`，用于保存字符串 `s` 中出现过的所有长度为 `k` 的不同子串。
2. **枚举长度为 k 的窗口：** 从下标 `0` 遍历到 `s.length() - k`，保证每次都能截取完整的长度为 `k` 的子串。
3. **截取当前二进制子串：** 使用 `s.substring(i, i + k)` 获取当前位置开始的长度为 `k` 的字符串。
4. **保存不同子串：** 将当前子串加入 `HashSet`，重复出现的字符串会自动被去重。

6. **判断是否全部出现：** 如果集合大小等于 `1 << k`，说明所有可能的长度为 `k` 的二进制字符串都存在于 `s` 中。
7. **返回判断结果：** 根据集合大小与理论数量是否相等返回最终布尔值。

```java
class Solution {
    public boolean hasAllCodes(String s, int k) {
        Set<String> set = new HashSet<>();
        for(int i = 0; i < s.length() - k + 1; i++){
            set.add(s.substring(i, i + k));
        }
        return set.size() == (1 << k);
    }
}
```

## [1332. 删除回文子序列](https://leetcode.cn/problems/remove-palindromic-subsequences/)

### 题目

给你一个字符串 `s`，它仅由字母 `'a'` 和 `'b'` 组成。每一次删除操作都可以从 `s` 中删除一个回文 **子序列**。

返回删除给定字符串中所有字符（字符串为空）的最小删除次数。

「子序列」定义：如果一个字符串可以通过删除原字符串某些字符而不改变原字符顺序得到，那么这个字符串就是原字符串的一个子序列。

「回文」定义：如果一个字符串向后和向前读是一致的，那么这个字符串就是一个回文。

 

**示例 1：**

```
输入：s = "ababa"
输出：1
解释：字符串本身就是回文序列，只需要删除一次。
```

**示例 2：**

```
输入：s = "abb"
输出：2
解释："abb" -> "bb" -> "". 
先删除回文子序列 "a"，然后再删除 "bb"。
```

**示例 3：**

```
输入：s = "baabb"
输出：2
解释："baabb" -> "b" -> "". 
先删除回文子序列 "baab"，然后再删除 "b"。
```

 

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅包含字母 `'a'` 和 `'b'`

### 题解

#### 思路总结

利用**回文判断 + 二字符性质**解决问题。

这道题的关键不在于模拟删除，而在于利用字符串只包含 `'a'` 和 `'b'` 这一特殊条件。

存在两种情况：

- 如果整个字符串 `s` 本身就是回文，那么可以直接把整个字符串作为一个回文子序列删除，答案为 `1`。
- 如果 `s` 不是回文，那么一定可以在 `2` 次以内删除完：第一次删除所有 `'a'`，第二次删除所有 `'b'`。由相同字符组成的字符串一定是回文，因此这两个子序列都合法。

又因为字符串本身不是回文，所以不可能只删除一次，答案必然为 `2`。

因此问题最终转化为：**判断整个字符串是否为回文。**

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **初始化左右指针：** 设置 `l = 0`、`r = s.length() - 1`，分别指向字符串两端。
2. **比较对称字符：** 当 `l < r` 时，比较 `s.charAt(l)` 和 `s.charAt(r)` 是否相同。
3. **发现非回文结构：** 如果某一对对称字符不同，说明整个字符串不是回文，不可能一次删除完成。
4. **利用字符种类性质：** 字符串只包含 `'a'` 和 `'b'`，可以分别删除所有 `'a'` 和所有 `'b'`，因此最多需要两次，直接返回 `2`。
5. **继续向中间检查：** 如果当前两个字符相同，则执行 `l++`、`r--` 继续判断下一对字符。
6. **确认整个字符串为回文：** 如果所有对称位置都相同，说明整个字符串本身就是回文子序列。
7. **返回最少删除次数：** 整个字符串可以一次删除，因此返回 `1`。

```java
class Solution {
    public int removePalindromeSub(String s) {
        int l = 0;
        int r = s.length() - 1;
        while(l < r){
            if(s.charAt(l) != s.charAt(r)){
                return 2;
            }
            l++;
            r--;
        }
        return 1;
    }
}
```
