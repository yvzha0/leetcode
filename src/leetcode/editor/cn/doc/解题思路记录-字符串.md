## [1758. 生成交替二进制字符串的最少操作数](https://leetcode.cn/problems/minimum-changes-to-make-alternating-binary-string/)

### 题目

给你一个仅由字符 `'0'` 和 `'1'` 组成的字符串 `s` 。一步操作中，你可以将任一 `'0'` 变成 `'1'` ，或者将 `'1'` 变成 `'0'` 。

**交替字符串** 定义为：如果字符串中不存在相邻两个字符相等的情况，那么该字符串就是交替字符串。例如，字符串 `"010"` 是交替字符串，而字符串 `"0100"` 不是。

返回使 `s` 变成 **交替字符串** 所需的 **最少** 操作数。

 

**示例 1：**

```
输入：s = "0100"
输出：1
解释：如果将最后一个字符变为 '1' ，s 就变成 "0101" ，即符合交替字符串定义。
```

**示例 2：**

```
输入：s = "10"
输出：0
解释：s 已经是交替字符串。
```

**示例 3：**

```
输入：s = "1111"
输出：2
解释：需要 2 步操作得到 "0101" 或 "1010" 。
```

 

**提示：**

- `1 <= s.length <= 104`
- `s[i]` 是 `'0'` 或 `'1'`

### 题解

1. **明确目标形态** 长度固定的交替字符串只有两种可能：
   - 形态一：`"010101..."`（索引为偶数是 `'0'`，奇数是 `'1'`）
   - 形态二：`"101010..."`（与形态一完全相反）
2. **统计形态一的修改步数** 遍历字符串 `s`，利用 `i % 2` 模拟形态一的交替规律。若当前字符 `s.charAt(i) - '0'` 不等于 `i % 2`，则说明该位置需要修改，计数器 `ans` 加 1。
3. **利用互补原理计算形态二** 由于形态一和形态二完全相反，修改成形态二所需的步数不需要重新遍历，它直接等于总长度减去形态一的步数，即 `s.length() - ans`。
4. **返回最小值** 比较两种形态所需的步数，返回较小值：`Math.min(ans, s.length() - ans)`。

```java
class Solution {
    public int minOperations(String s) {
        int ans = 0;
        int n = s.length();
        for(int i = 0;i < n;i++){
            // 变成010101...形式
            if(s.charAt(i) - '0' != i % 2){
                ans++;
            }
        }
        ans = Integer.min(ans, s.length() - ans);
        return ans;
    }
}
```

## [1736. 替换隐藏数字得到的最晚时间](https://leetcode.cn/problems/latest-time-by-replacing-hidden-digits/)

### 题目

给你一个字符串 `time` ，格式为 ` hh:mm`（小时：分钟），其中某几位数字被隐藏（用 `?` 表示）。

有效的时间为 `00:00` 到 `23:59` 之间的所有时间，包括 `00:00` 和 `23:59` 。

替换 `time` 中隐藏的数字，返回你可以得到的最晚有效时间。

 

**示例 1：**

```
输入：time = "2?:?0"
输出："23:50"
解释：以数字 '2' 开头的最晚一小时是 23 ，以 '0' 结尾的最晚一分钟是 50 。
```

**示例 2：**

```
输入：time = "0?:3?"
输出："09:39"
```

**示例 3：**

```
输入：time = "1?:22"
输出："19:22"
```

 

**提示：**

- `time` 的格式为 `hh:mm`
- 题目数据保证你可以由输入的字符串生成有效的时间

### 题解

#### 思路总结

利用**贪心算法（Greedy Algorithm）**从高位到低位依次替换字符串中的 `?`。由于目标是得到最晚时间，应优先让小时十位、小时个位、分钟十位和分钟个位尽可能大，同时保证最终时间仍处于 `00:00` 到 `23:59` 的有效范围内。

算法核心逻辑在于：

1. **优先处理小时部分**，因为小时对时间大小的影响高于分钟。
2. **根据相邻位确定最大合法数字**，保证小时不超过 `23`。
3. **分钟部分直接取最大合法值**，分钟十位最大为 `5`，分钟个位最大为 `9`。
4. **按照从高位到低位的顺序填充**，每一步都选择当前能取到的最大合法数字。

整体过程只需依次检查固定的四个数字位置，实现 **O(1)** 时间复杂度和 **O(1)** 空间复杂度。

------

#### 解题步骤

1. **转换字符串结构**：将字符串 `time` 转换为字符数组 `chars`，便于直接修改各个数字位置。
2. **处理小时十位**：若 `chars[0]` 为 `?`，则根据小时个位 `chars[1]` 判断可填入的最大数字；当小时个位未知时直接组成最大小时 `23`，当小时个位大于等于 `4` 时只能填 `1`，否则填 `2`。
3. **处理小时个位**：若 `chars[1]` 为 `?`，当小时十位小于 `2` 时可填最大数字 `9`，否则小时十位为 `2`，只能填最大数字 `3`。
4. **处理分钟十位**：若 `chars[3]` 为 `?`，填入分钟十位允许的最大数字 `5`。
5. **处理分钟个位**：若 `chars[4]` 为 `?`，填入分钟个位允许的最大数字 `9`。
6. **构造最终结果**：将修改后的字符数组重新转换为字符串并返回，得到能够生成的最晚有效时间。

```java
class Solution {
    public String maximumTime(String time) {
        char[] chars = time.toCharArray();
        if(chars[0] == '?'){
            if(chars[1] == '?'){
                chars[0] = '2';
                chars[1] = '3';
            }else if(chars[1] >= '4'){
                chars[0] = '1';
            }else {
                chars[0] = '2';
            }
        }

        if(chars[1] == '?'){
            if(chars[0] < '2'){
                chars[1] = '9';
            }else {
                chars[1] = '3';
            }
        }

        if(chars[3] == '?'){
            chars[3] = '5';
        }

        if(chars[4] == '?'){
            chars[4] = '9';
        }

        return new String(chars);
    }
}
```

## [1704. 判断字符串的两半是否相似](https://leetcode.cn/problems/determine-if-string-halves-are-alike/)

### 题目

给你一个偶数长度的字符串 `s` 。将其拆分成长度相同的两半，前一半为 `a` ，后一半为 `b` 。

两个字符串 **相似** 的前提是它们都含有相同数目的元音（`'a'`，`'e'`，`'i'`，`'o'`，`'u'`，`'A'`，`'E'`，`'I'`，`'O'`，`'U'`）。注意，`s` 可能同时含有大写和小写字母。

如果 `a` 和 `b` 相似，返回 `true` ；否则，返回 `false` 。

 

**示例 1：**

```
输入：s = "book"
输出：true
解释：a = "bo" 且 b = "ok" 。a 中有 1 个元音，b 也有 1 个元音。所以，a 和 b 相似。
```

**示例 2：**

```
输入：s = "textbook"
输出：false
解释：a = "text" 且 b = "book" 。a 中有 1 个元音，b 中有 2 个元音。因此，a 和 b 不相似。
注意，元音 o 在 b 中出现两次，记为 2 个。
```

 

**提示：**

- `2 <= s.length <= 1000`
- `s.length` 是偶数
- `s` 由 **大写和小写** 字母组成

### 题解

#### 思路总结

利用**双指针 + 计数（Two Pointers + Counting）**判断字符串两半是否相似。分别从字符串的前半部分和后半部分同时遍历，统计两部分元音字母数量的差值，最终若差值为 `0`，则说明两部分包含相同数量的元音字母。

算法核心逻辑在于：

1. **确定字符串中点**，将字符串划分为长度相同的两部分。
2. **同时遍历前后两部分**，分别判断当前字符是否为元音字母。
3. **维护元音数量差值**，前半部分遇到元音则加一，后半部分遇到元音则减一。
4. **根据最终差值判断结果**，若差值为 `0`，则两部分元音数量相同。

整体过程仅遍历字符串一次，实现 **O(n)** 时间复杂度和 **O(1)** 空间复杂度。

------

#### 解题步骤

1. **初始化变量**：定义元音字符集合 `ss`，计算字符串中点 `n`，并初始化计数器 `count`。
2. **同时遍历两部分字符串**：从前半部分起始位置和后半部分末尾位置同时遍历，每次分别获取两个字符。
3. **统计元音数量差值**：若前半部分当前字符为元音，则将 `count` 加一；若后半部分当前字符为元音，则将 `count` 减一。
4. **判断最终结果**：遍历结束后，若 `count` 等于 `0`，说明两部分元音数量相同，返回 `true`；否则返回 `false`。

```java
class Solution {
    public boolean halvesAreAlike(String s) {
        String ss = "aeiouAEIOU";
        int n = s.length() / 2;
        int count = 0;
        for(int i = 0; i < n; i++){
            char c1 = s.charAt(i);
            char c2 = s.charAt(n * 2 - 1 - i);
            if(ss.indexOf(c1) != -1){
                count++;
            }
            if(ss.indexOf(c2) != -1){
                count--;
            }
        }
        return count == 0;
    }
}
```

## [1694. 重新格式化电话号码](https://leetcode.cn/problems/reformat-phone-number/)

### 题目

给你一个字符串形式的电话号码 `number` 。`number` 由数字、空格 `' '`、和破折号 `'-'` 组成。

请你按下述方式重新格式化电话号码。

- 首先，**删除** 所有的空格和破折号。

- 其次，将数组从左到右

   

  每 3 个一组

   

  分块，

  直到 

  剩下 4 个或更少数字。剩下的数字将按下述规定再分块：

  - 2 个数字：单个含 2 个数字的块。
  - 3 个数字：单个含 3 个数字的块。
  - 4 个数字：两个分别含 2 个数字的块。

最后用破折号将这些块连接起来。注意，重新格式化过程中 **不应该** 生成仅含 1 个数字的块，并且 **最多** 生成两个含 2 个数字的块。

返回格式化后的电话号码。

 

**示例 1：**

```
输入：number = "1-23-45 6"
输出："123-456"
解释：数字是 "123456"
步骤 1：共有超过 4 个数字，所以先取 3 个数字分为一组。第 1 个块是 "123" 。
步骤 2：剩下 3 个数字，将它们放入单个含 3 个数字的块。第 2 个块是 "456" 。
连接这些块后得到 "123-456" 。
```

**示例 2：**

```
输入：number = "123 4-567"
输出："123-45-67"
解释：数字是 "1234567".
步骤 1：共有超过 4 个数字，所以先取 3 个数字分为一组。第 1 个块是 "123" 。
步骤 2：剩下 4 个数字，所以将它们分成两个含 2 个数字的块。这 2 块分别是 "45" 和 "67" 。
连接这些块后得到 "123-45-67" 。
```

**示例 3：**

```
输入：number = "123 4-5678"
输出："123-456-78"
解释：数字是 "12345678" 。
步骤 1：第 1 个块 "123" 。
步骤 2：第 2 个块 "456" 。
步骤 3：剩下 2 个数字，将它们放入单个含 2 个数字的块。第 3 个块是 "78" 。
连接这些块后得到 "123-456-78" 。
```

**示例 4：**

```
输入：number = "12"
输出："12"
```

**示例 5：**

```
输入：number = "--17-5 229 35-39475 "
输出："175-229-353-94-75"
```

 

**提示：**

- `2 <= number.length <= 100`
- `number` 由数字和字符 `'-'` 及 `' '` 组成。
- `number` 中至少含 **2** 个数字。

### 题解

#### 思路总结

利用**字符串处理 + 贪心分组**实现电话号码重新格式化。首先删除原字符串中的空格和破折号，得到只包含数字的新字符串，然后按照题目要求从左到右优先每三个数字划分为一组，同时特殊处理剩余 `2`、`3`、`4` 个数字的情况，避免产生长度为 `1` 的分组。

算法核心逻辑在于：

1. **预处理字符串**，去除所有非数字字符，获得纯数字字符串。
2. **从左到右遍历数字字符串**，优先每三个数字划分为一组。
3. **处理剩余数字情况：**
   - 剩余 `2` 或 `3` 个数字时，直接作为最后一组。
   - 剩余 `4` 个数字时，拆分为两个长度为 `2` 的分组。
4. **使用分隔符连接各个分组**，得到最终格式化后的电话号码。

整体过程只需遍历数字字符串一次，实现 **O(n)** 时间复杂度和 **O(n)** 空间复杂度。

------

#### 解题步骤

1. **清理电话号码格式**：删除字符串中的空格和破折号，只保留数字字符，得到待处理的电话号码。
2. **初始化遍历过程**：根据数字字符串长度 `n`，从起始位置开始，每次处理最多三个数字。
3. **划分三位分组**：当剩余数字数量大于 `4` 时，将当前三个数字作为一个分组，并添加连接符。
4. **处理剩余数字**：当剩余数字数量为 `2` 或 `3` 时，将剩余数字作为最后一个分组；当剩余数字数量为 `4` 时，将其拆分为两个长度为 `2` 的分组。
5. **返回格式化结果**：将所有分组连接成字符串，得到重新格式化后的电话号码。

```java
class Solution {
    public String reformatNumber(String number) {
        number = number.replace(" ", "").replace("-", "");
        int n = number.length();
        StringBuilder sb = new StringBuilder();
        for(int i = 0; i < n; i += 3){
            if(n - i == 2 || n - i == 3){
                sb.append(number, i, n);
            }else if(n - i == 4){
                sb.append(number, i, i + 2).append("-").append(number, i + 2, n);
                break;
            }else {
                sb.append(number, i, i + 3).append("-");
            }
        }
        return sb.toString();
    }
}
```

## [1684. 统计一致字符串的数目](https://leetcode.cn/problems/count-the-number-of-consistent-strings/)

### 题目

给你一个由不同字符组成的字符串 `allowed` 和一个字符串数组 `words` 。如果一个字符串的每一个字符都在 `allowed` 中，就称这个字符串是 **一致字符串** 。

请你返回 `words` 数组中 **一致字符串** 的数目。

 

**示例 1：**

```
输入：allowed = "ab", words = ["ad","bd","aaab","baa","badab"]
输出：2
解释：字符串 "aaab" 和 "baa" 都是一致字符串，因为它们只包含字符 'a' 和 'b' 。
```

**示例 2：**

```
输入：allowed = "abc", words = ["a","b","c","ab","ac","bc","abc"]
输出：7
解释：所有字符串都是一致的。
```

**示例 3：**

```
输入：allowed = "cad", words = ["cc","acd","b","ba","bac","bad","ac","d"]
输出：4
解释：字符串 "cc"，"acd"，"ac" 和 "d" 是一致字符串。
```

 

**提示：**

- `1 <= words.length <= 104`
- `1 <= allowed.length <= 26`
- `1 <= words[i].length <= 10`
- `allowed` 中的字符 **互不相同** 。
- `words[i]` 和 `allowed` 只包含小写英文字母。

### 题解

#### 思路总结

利用**哈希集合（HashSet）**实现一致字符串统计。由于 `allowed` 中的字符互不重复，可以将其中所有字符存入集合，通过集合的快速查找能力判断 `words` 中每个字符串的字符是否都存在于 `allowed` 中。

算法核心逻辑在于：

1. **建立字符集合**，存储 `allowed` 中允许出现的所有字符。
2. **遍历字符串数组**，逐个检查每个字符串中的字符。
3. **判断字符串是否一致**，若存在任意字符不属于允许集合，则该字符串不是一致字符串。
4. **统计满足条件的字符串数量**，最终返回一致字符串的个数。

整体过程利用哈希集合实现字符快速判断，遍历所有字符串一次，实现 **O(n)** 时间复杂度和 **O(1)** 空间复杂度（字符集大小固定）。

------

#### 解题步骤

1. **初始化字符集合**：遍历字符串 `allowed`，将其中所有字符加入集合 `set`，用于快速判断字符是否合法。
2. **遍历字符串数组**：依次访问 `words` 中的每个字符串，并假设当前字符串是一致字符串。
3. **检查字符串字符**：遍历当前字符串中的每个字符，判断该字符是否存在于集合 `set` 中；若不存在，则说明该字符串不是一致字符串。
4. **统计结果数量**：若当前字符串中的所有字符均存在于 `allowed` 中，则增加一致字符串计数；否则跳过该字符串。
5. **返回统计结果**：遍历结束后，返回所有一致字符串的数量。

```java
class Solution {
    public int countConsistentStrings(String allowed, String[] words) {
        Set<Character> set = new HashSet<>();
        for(char c : allowed.toCharArray()){
            set.add(c);
        }
        int ans = 0;
        for(String word : words){
            ans++;
            for(char c : word.toCharArray()){
                if(!set.contains(c)){
                    ans--;
                    break;
                }
            }
        }
        return ans;
    }
}
```

## [1678. 设计 Goal 解析器](https://leetcode.cn/problems/goal-parser-interpretation/)

### 题目

请你设计一个可以解释字符串 `command` 的 **Goal 解析器** 。`command` 由 `"G"`、`"()"` 和/或 `"(al)"` 按某种顺序组成。Goal 解析器会将 `"G"` 解释为字符串 `"G"`、`"()"` 解释为字符串 `"o"` ，`"(al)"` 解释为字符串 `"al"` 。然后，按原顺序将经解释得到的字符串连接成一个字符串。

给你字符串 `command` ，返回 **Goal 解析器** 对 `command` 的解释结果。

 

**示例 1：**

```
输入：command = "G()(al)"
输出："Goal"
解释：Goal 解析器解释命令的步骤如下所示：
G -> G
() -> o
(al) -> al
最后连接得到的结果是 "Goal"
```

**示例 2：**

```
输入：command = "G()()()()(al)"
输出："Gooooal"
```

**示例 3：**

```
输入：command = "(al)G(al)()()G"
输出："alGalooG"
```

 

**提示：**

- `1 <= command.length <= 100`
- `command` 由 `"G"`、`"()"` 和/或 `"(al)"` 按某种顺序组成

### 题解

#### 思路总结

利用**字符串遍历 + 模式匹配**实现 Goal 解析器。由于 `command` 只包含三种固定形式：`G`、`()` 和 `(al)`，因此可以通过遍历字符串，根据当前字符判断对应的命令类型，并将其转换为目标字符串。

算法核心逻辑在于：

1. **逐字符扫描字符串**，判断当前位置对应的命令类型。
2. **根据不同模式进行转换：**
   - 遇到 `G`，直接解析为 `G`。
   - 遇到 `()`，解析为 `o`。
   - 遇到 `(al)`，解析为 `al`。
3. **跳过已经解析的字符**，避免重复处理同一个命令。
4. **拼接所有解析结果**，得到最终字符串。

整体过程只需遍历字符串一次，实现 **O(n)** 时间复杂度和 **O(n)** 空间复杂度。

------

#### 解题步骤

1. **初始化结果字符串**：创建 `StringBuilder` 用于保存 Goal 解析器转换后的结果。
2. **遍历命令字符串**：从左到右依次访问 `command` 中的每个字符，根据当前位置字符判断命令类型。
3. **解析单字符命令**：若当前字符为 `G`，直接将 `G` 加入结果字符串。
4. **解析括号命令**：若当前字符为 `(`，根据下一个字符判断是 `()` 还是 `(al)`；若下一个字符为 `)`，则解析为 `o`，否则解析为 `al`。
5. **调整遍历位置**：解析括号命令后跳过已经处理的字符，避免重复解析。
6. **返回解析结果**：遍历结束后，将拼接完成的字符串作为最终答案返回。

```java
class Solution {
    public String interpret(String command) {
        StringBuilder sb = new StringBuilder();
        int n = command.length();
        for(int i = 0; i < n; i++){
            if(command.charAt(i) == 'G'){
                sb.append('G');
            }else {
                if(command.charAt(i + 1) == ')'){
                    sb.append('o');
                    i++;
                }else {
                    sb.append("al");
                    i += 3;
                }
            }
        }
        return sb.toString();
    }
}
```

## [1668. 最大重复子字符串](https://leetcode.cn/problems/maximum-repeating-substring/)

### 题目

给你一个字符串 `sequence` ，如果字符串 `word` 连续重复 `k` 次形成的字符串是 `sequence` 的一个子字符串，那么单词 `word` 的 **重复值为 `k`** 。单词 `word` 的 **最大重复值** 是单词 `word` 在 `sequence` 中最大的重复值。如果 `word` 不是 `sequence` 的子串，那么重复值 `k` 为 `0` 。

给你一个字符串 `sequence` 和 `word` ，请你返回 **最大重复值 `k`** 。

 

**示例 1：**

```
输入：sequence = "ababc", word = "ab"
输出：2
解释："abab" 是 "ababc" 的子字符串。
```

**示例 2：**

```
输入：sequence = "ababc", word = "ba"
输出：1
解释："ba" 是 "ababc" 的子字符串，但 "baba" 不是 "ababc" 的子字符串。
```

**示例 3：**

```
输入：sequence = "ababc", word = "ac"
输出：0
解释："ac" 不是 "ababc" 的子字符串。
```

 

**提示：**

- `1 <= sequence.length <= 100`
- `1 <= word.length <= 100`
- `sequence` 和 `word` 都只包含小写英文字母。

### 题解一

#### 思路总结

利用**枚举重复次数 + 字符串匹配**解决最大重复子字符串问题。

字符串 `word` 最多只能重复：

```
sequence.length() / word.length()
```

次，因为重复后的字符串长度不能超过 `sequence`。

当前实现从这个理论最大值开始向下枚举 `k`，每次构造 `word` 连续重复 `k` 次得到的字符串，然后判断它是否为 `sequence` 的子串。由于按照 `k` 从大到小搜索，因此第一次匹配成功时，对应的 `k` 就是最大重复值。

------

#### 解题步骤

1. **计算最大重复次数：** 使用 `sequence.length() / word.length()` 得到 `word` 理论上最多能够重复的次数 `k`。
2. **从最大次数向下枚举：** 从当前 `k` 开始逐渐减小重复次数，优先检查更大的重复值。
3. **构造重复字符串：** 使用 `word.repeat(k)` 得到 `word` 连续重复 `k` 次后的字符串。
4. **判断是否为子串：** 使用 `sequence.contains()` 判断构造出的重复字符串是否出现在 `sequence` 中。
5. **找到后立即返回：** 由于 `k` 按照从大到小枚举，因此第一次匹配成功的 `k` 就是最大重复值。
6. **处理不存在情况：** 如果所有正整数重复次数都无法匹配，则最终返回 `0`。

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int k = sequence.length() / word.length();
        for(; k >= 0; k--){
            if(sequence.contains(word.repeat(k))){
                return k;
            }
        }
        return 0;
    }
}
```

## 题解二

#### 思路总结

利用**动态规划**统计 `word` 在 `sequence` 中连续重复出现的最大次数。

定义：

`dp[i]` 表示以 `sequence[i]` 作为最后一个字符时，连续出现了多少个 `word`。

对于当前位置 `i`，对应单词的起始位置为：

```
start = i - m + 1
```

如果区间 `[start, start + m)` 与 `word` 相同，那么当前至少出现了一个 `word`。由于连续重复的前一个 `word` 必须恰好结束在 `start - 1`，也就是 `i - m`，因此状态转移为：

```
dp[i] = dp[i - m] + 1
```

如果当前位置是第一个完整的 `word`，前面不存在对应状态，则 `dp[i] = 1`。

遍历过程中维护最大的 `dp[i]`，即可得到最大重复值。

------

#### 解题步骤

1. **获取字符串长度：** 使用 `m` 表示 `word` 的长度，使用 `n` 表示 `sequence` 的长度。
2. **初始化动态规划数组：** 创建 `dp`，其中 `dp[i]` 表示以位置 `i` 结尾时连续出现的 `word` 数量。
3. **枚举单词结束位置：** 从 `i = m - 1` 开始遍历，因为此前的位置无法组成一个完整的 `word`。
4. **计算当前起始位置：** 使用 `start = i - m + 1` 得到当前长度为 `m` 的子串起点。
5. **判断是否匹配单词：** 如果当前长度为 `m` 的子串与 `word` 相同，则当前位置能够形成一个完整的 `word`。
6. **连接前一个重复单词：** 如果前面还存在长度为 `m` 的区域，则通过 `dp[start - 1] + 1` 得到当前连续重复次数。
7. **处理第一次匹配：** 如果当前匹配从下标 `0` 开始，则当前连续重复次数为 `1`。
8. **更新最大重复次数：** 使用当前 `dp[i]` 更新全局最大值 `ans`。
9. **返回最终结果：** 遍历完成后返回 `ans`。

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int m = word.length();
        int n = sequence.length();
        int[] dp = new int[n];
        int ans = 0;
        for(int i = m - 1; i < n; i++){
            int start = i - m + 1;
            if(word.equals(sequence.substring(start, start + m))){
                if(i > m - 1){
                    dp[i] = dp[start - 1] + 1;
                }else {
                    dp[i] = 1;
                }
                ans = Math.max(ans, dp[i]);
            }
        }
        return ans;
    }
}
```

## [1653. 使字符串平衡的最少删除次数](https://leetcode.cn/problems/minimum-deletions-to-make-string-balanced/)

### 题目

给你一个字符串 `s` ，它仅包含字符 `'a'` 和 `'b'` 。

你可以删除 `s` 中任意数目的字符，使得 `s` **平衡** 。当不存在下标对 `(i,j)` 满足 `i < j` ，且 `s[i] = 'b'` 的同时 `s[j]= 'a'` ，此时认为 `s` 是 **平衡** 的。

请你返回使 `s` **平衡** 的 **最少** 删除次数。

 

**示例 1：**

```
输入：s = "aababbab"
输出：2
解释：你可以选择以下任意一种方案：
下标从 0 开始，删除第 2 和第 6 个字符（"aababbab" -> "aaabbb"），
下标从 0 开始，删除第 3 和第 6 个字符（"aababbab" -> "aabbbb"）。
```

**示例 2：**

```
输入：s = "bbaaaaabb"
输出：2
解释：唯一的最优解是删除最前面两个字符。
```

 

**提示：**

- `1 <= s.length <= 105`
- `s[i]` 要么是 `'a'` 要么是 `'b'` 。

### 题解一

#### 思路总结

利用**枚举分割点 + 前后缀计数**解决最少删除次数问题。

平衡字符串的最终形式一定满足：

```
aaaa...bbbb
```

也就是说，可以在字符串中选择一个分割位置，使得：

- 分割点左侧只能保留 `'a'`，因此左侧所有 `'b'` 都必须删除。
- 分割点右侧只能保留 `'b'`，因此右侧所有 `'a'` 都必须删除。

因此，对于任意一个分割位置，需要删除的字符数量就是：

```
左侧 b 的数量 + 右侧 a 的数量
```

当前实现使用：

- `leftb` 维护分割点左侧 `'b'` 的数量。
- `righta` 维护分割点右侧 `'a'` 的数量。

随着分割点从左向右移动，不断计算 `leftb + righta` 的最小值，即可得到答案。

整体时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **统计所有字符 a：** 第一次遍历字符串，统计全部 `'a'` 的数量并保存到 `righta`，表示分割点位于字符串最左侧时右边需要删除的 `'a'` 数量。
2. **初始化删除次数：** 使用 `righta` 作为初始答案，表示删除全部 `'a'`，最终只保留 `'b'` 的情况。
3. **从左向右移动分割点：** 第二次遍历字符串，每处理一个字符，就相当于将该字符从分割点右侧移动到左侧。
4. **更新左侧 b 数量：** 如果当前字符是 `'b'`，说明左侧多了一个需要删除的 `'b'`，执行 `leftb++`。
5. **更新右侧 a 数量：** 如果当前字符是 `'a'`，说明该字符已经从右侧移到左侧，因此执行 `righta--`。
6. **计算当前删除次数：** 当前分割位置需要删除的字符数量为 `leftb + righta`。
7. **维护最小删除次数：** 每次移动分割点后使用 `leftb + righta` 更新 `ans`。
8. **返回最终结果：** 所有分割位置检查完成后，返回最小删除次数 `ans`。

```java
class Solution {
    public int minimumDeletions(String s) {
        int righta = 0;
        int leftb = 0;
        int ans = 100000;
        for(char c : s.toCharArray()){
            if(c == 'a'){
                righta++;
            }
        }
        ans = Math.min(ans, righta);
        for(char c : s.toCharArray()){
            if(c == 'b'){
                leftb++;
            }else {
                righta--;
            }
            ans = Math.min(ans, leftb + righta);
        }
        return ans;
    }
}
```

### 题解二

#### 思路总结

利用**动态规划 + 状态压缩**解决字符串平衡所需的最少删除次数。

遍历字符串时维护两个状态：

- `bCount`：当前已经遇到的 `'b'` 数量。
- `dp`：使当前已经遍历的前缀字符串达到平衡状态所需的最少删除次数。

当遇到 `'b'` 时，字符 `'b'` 可以合法地出现在平衡字符串的后半部分，因此不需要立即删除，只需要执行 `bCount++`。

当遇到 `'a'` 时，如果前面已经存在 `'b'`，就产生了 `"ba"` 的不平衡关系，此时有两种选择：

`删除当前 a`：删除次数为 `dp + 1`。

`保留当前 a`：需要删除前面所有 `'b'`，删除次数为 `bCount`。

因此状态转移为：

```
dp = Math.min(dp + 1, bCount)
```

最终 `dp` 就是使整个字符串平衡所需的最少删除次数。

------

#### 解题步骤

1. **初始化状态：** 设置 `bCount = 0` 记录已经遍历到的 `'b'` 数量，设置 `dp = 0` 表示当前前缀变平衡所需的最少删除次数。
2. **从左向右遍历字符串：** 依次处理字符串中的每一个字符。
3. **处理字符 b：** 如果当前字符是 `'b'`，不会立即破坏平衡结构，只需要执行 `bCount++`。
4. **处理字符 a：** 如果当前字符是 `'a'`，需要在删除当前 `'a'` 和删除前面所有 `'b'` 两种方案之间选择。
5. **计算删除当前 a 的代价：** 当前前缀原本最少需要删除 `dp` 个字符，再删除当前 `'a'`，总代价为 `dp + 1`。
6. **计算保留当前 a 的代价：** 如果保留当前 `'a'`，则前面所有 `'b'` 都不能存在，因此需要删除 `bCount` 个 `'b'`。
7. **更新最少删除次数：** 使用 `dp = Math.min(dp + 1, bCount)` 保存处理当前前缀后的最优结果。
8. **返回最终答案：** 遍历完整个字符串后返回 `dp`。

```java
class Solution {
    public int minimumDeletions(String s) {
        int bCount = 0;
        int dp = 0;
        for(char c : s.toCharArray()){
            if(c == 'b'){
                bCount++;
            }else {
                dp = Math.min(dp + 1, bCount);
            }
        }
        return dp;
    }
}
```

## [1624. 两个相同字符之间的最长子字符串](https://leetcode.cn/problems/largest-substring-between-two-equal-characters/)

### 题目

给你一个字符串 `s`，请你返回 **两个相同字符之间的最长子字符串的长度** *，*计算长度时不含这两个字符。如果不存在这样的子字符串，返回 `-1` 。

**子字符串** 是字符串中的一个连续字符序列。

 

**示例 1：**

```
输入：s = "aa"
输出：0
解释：最优的子字符串是两个 'a' 之间的空子字符串。
```

**示例 2：**

```
输入：s = "abca"
输出：2
解释：最优的子字符串是 "bc" 。
```

**示例 3：**

```
输入：s = "cbzxy"
输出：-1
解释：s 中不存在出现出现两次的字符，所以返回 -1 。
```

**示例 4：**

```
输入：s = "cabbac"
输出：4
解释：最优的子字符串是 "abba" ，其他的非最优解包括 "bb" 和 "" 。
```

 

**提示：**

- `1 <= s.length <= 300`
- `s` 只含小写英文字母

### 题解

#### 思路总结

利用**哈希表记录每个字符第一次出现的位置**，在遍历字符串时计算当前字符与其第一次出现位置之间的距离。

对于两个相同字符分别位于下标 `start` 和 `i`，它们之间的子字符串长度为：

```
i - start - 1
```

为了让同一个字符形成的子字符串尽可能长，只需要始终保存该字符**第一次出现的位置**，后续每次再次遇到该字符时，都用当前位置与第一次出现位置计算距离。

当前代码通过：

```
int start = map.getOrDefault(s.charAt(i), i);
```

处理字符首次出现的情况；如果字符没有出现过，就让 `start = i`，此时得到的长度为 `-1`，不会影响初始答案。

随后：

```
map.put(s.charAt(i), start);
```

继续保存第一次出现的位置，而不会被后续位置覆盖。

整体只需要遍历字符串一次，时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **初始化字符位置映射：** 使用 `map` 保存每个字符第一次出现的下标，并设置 `ans = -1` 表示暂时不存在两个相同字符。
2. **从左向右遍历字符串：** 对每个位置 `i` 获取当前字符 `s.charAt(i)`。
3. **获取第一次出现位置：** 如果当前字符已经出现，则从 `map` 获取第一次出现的下标；如果尚未出现，则使用当前位置 `i`。
4. **计算中间字符串长度：** 根据 `i - start - 1` 计算当前字符与第一次出现位置之间的字符数量。
5. **更新最大长度：** 使用当前长度更新 `ans`，保存已经找到的最大值。
6. **保存第一次出现位置：** 将当前字符对应的位置保存为 `start`，保证后续始终使用第一次出现的位置。
7. **返回最终答案：** 遍历完成后返回 `ans`，如果没有任何字符重复出现则保持为 `-1`。

```java
class Solution {
    public int maxLengthBetweenEqualCharacters(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int ans = -1;
        for(int i = 0; i < s.length(); i++){
            int start = map.getOrDefault(s.charAt(i), i);
            int val = i - start - 1;
            ans = Math.max(ans, val);
            map.put(s.charAt(i), start);
        }
        return ans;
    }
}
```

## [1614. 括号的最大嵌套深度](https://leetcode.cn/problems/maximum-nesting-depth-of-the-parentheses/)

### 题目

给定 **有效括号字符串** `s`，返回 `s` 的 **嵌套深度**。嵌套深度是嵌套括号的 **最大** 数量。

 

**示例 1：**

**输入：**s = "(1+(2*3)+((**8**)/4))+1"

**输出：**3

**解释：**数字 8 在嵌套的 3 层括号中。

**示例 2：**

**输入：**s = "(1)+((2))+(((**3**)))"

**输出：**3

**解释：**数字 3 在嵌套的 3 层括号中。

**示例 3：**

**输入：**s = "()(())((()()))"

**输出：**3

 

**提示：**

- `1 <= s.length <= 100`
- `s` 由数字 `0-9` 和字符 `'+'`、`'-'`、`'*'`、`'/'`、`'('`、`')'` 组成
- 题目数据保证括号字符串 `s` 是 **有效的括号字符串**

### 题解

#### 思路总结

利用**计数器模拟括号嵌套深度**。

使用 `count` 表示当前尚未闭合的左括号数量，也就是当前位置的括号嵌套深度：

- 遇到 `'('` 时，进入新的一层，执行 `count++`。
- 遇到 `')'` 时，退出当前层，执行 `count--`。
- 每次遇到 `'('` 后，使用当前 `count` 更新最大深度 `ans`。

由于题目保证 `s` 是有效括号字符串，因此遍历过程中括号能够正确匹配，最终 `count` 会回到 `0`。

该方法不需要真正使用栈，只需要维护当前深度和最大深度两个变量。

------

#### 解题步骤

1. **初始化当前深度：** 设置 `count = 0`，表示当前没有未闭合的左括号。
2. **初始化最大深度：** 设置 `ans = 0`，用于保存遍历过程中出现的最大嵌套层数。
3. **遍历字符串字符：** 从左向右依次检查字符串中的每一个字符。
4. **处理左括号：** 如果当前字符是 `'('`，执行 `count++`，表示进入新的一层括号。
5. **更新最大深度：** 每次进入新的一层后，使用 `Math.max(ans, count)` 更新最大嵌套深度。
6. **处理右括号：** 如果当前字符是 `')'`，执行 `count--`，表示当前括号层结束。
7. **忽略普通字符：** 数字和运算符不会影响括号嵌套层数，因此无需处理。
8. **返回最终结果：** 遍历完成后返回 `ans`。

```java
class Solution {
    public int maxDepth(String s) {
        int count = 0;
        int ans = 0;
        for(char c : s.toCharArray()){
            if(c == '('){
                count++;
                ans = Math.max(ans, count);
            }else if(c == ')'){
                count--;
            }
        }
        return ans;
    }
}
```

## [1573. 分割字符串的方案数](https://leetcode.cn/problems/number-of-ways-to-split-a-string/)

### 题目

给你一个二进制串 `s` （一个只包含 0 和 1 的字符串），我们可以将 `s` 分割成 3 个 **非空** 字符串 s1, s2, s3 （s1 + s2 + s3 = s）。

请你返回分割 `s` 的方案数，满足 s1，s2 和 s3 中字符 '1' 的数目相同。

由于答案可能很大，请将它对 10^9 + 7 取余后返回。

 

**示例 1：**

```
输入：s = "10101"
输出：4
解释：总共有 4 种方法将 s 分割成含有 '1' 数目相同的三个子字符串。
"1|010|1"
"1|01|01"
"10|10|1"
"10|1|01"
```

**示例 2：**

```
输入：s = "1001"
输出：0
```

**示例 3：**

```
输入：s = "0000"
输出：3
解释：总共有 3 种分割 s 的方法。
"0|0|00"
"0|00|0"
"00|0|0"
```

**示例 4：**

```
输入：s = "100100010100110"
输出：12
```

 

**提示：**

- `s[i] == '0'` 或者 `s[i] == '1'`
- `3 <= s.length <= 10^5`

### 题解

#### 思路总结

利用**统计 `'1'` 的总数 + 计算两个分割位置的可选数量**解决问题。

设字符串中 `'1'` 的总数为 `total`：

- 如果 `total % 3 != 0`，无法让三个子串包含相同数量的 `'1'`，答案为 `0`。
- 如果 `total == 0`，三个子串都天然包含 `0` 个 `'1'`，只需要从 `n - 1` 个间隙中选择两个分割点，方案数为 `C(n - 1, 2)`。
- 如果 `total > 0`，每一段都必须包含 `k = total / 3` 个 `'1'`。

此时第一个分割点必须位于**第 `k` 个 `'1'` 和第 `k + 1` 个 `'1'` 之间**，第二个分割点必须位于**第 `2k` 个 `'1'` 和第 `2k + 1` 个 `'1'` 之间**。

若这些 `'1'` 的位置分别为 `p1、p2、p3、p4`，则：

```
第一个分割点方案数 = p2 - p1
第二个分割点方案数 = p4 - p3
```

两个分割点相互独立，因此最终答案为：

```
(p2 - p1) × (p4 - p3)
```

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **统计 1 的总数：** 遍历字符串得到字符 `'1'` 的数量 `total`。
2. **判断是否能够平均分配：** 如果 `total % 3 != 0`，三个子串不可能拥有相同数量的 `'1'`，直接返回 `0`。
3. **处理全 0 情况：** 如果 `total == 0`，从字符串的 `n - 1` 个间隙中任选两个作为分割点，方案数为 `(n - 1) * (n - 2) / 2`。
4. **计算每段目标数量：** 设置 `k = total / 3`，表示每个子串应该包含 `k` 个 `'1'`。
5. **寻找第一处分割边界：** 记录第 `k` 个 `'1'` 的位置 `p1` 和第 `k + 1` 个 `'1'` 的位置 `p2`。
6. **寻找第二处分割边界：** 记录第 `2k` 个 `'1'` 的位置 `p3` 和第 `2k + 1` 个 `'1'` 的位置 `p4`。
7. **计算第一刀方案数：** 第一个分割点可以放在 `p1` 到 `p2` 之间，共有 `p2 - p1` 种选择。
8. **计算第二刀方案数：** 第二个分割点可以放在 `p3` 到 `p4` 之间，共有 `p4 - p3` 种选择。
9. **计算最终答案：** 将两部分方案数相乘，并对 `10^9 + 7` 取模后返回。

```java
class Solution {
    public int numWays(String s) {
        int n = s.length();
        int total = 0;
        int mod = 1000000007;
        for(int i = 0; i < n; i++){
            if(s.charAt(i) == '1'){
                total++;
            }
        }
        if(total % 3 != 0){
            return 0;
        }
        if(total == 0){
            long ans = (long) (n - 1) * (n - 2) / 2 % mod;
            return (int) ans;
        }
        int k = total / 3;

        int p1 = 0, p2 = 0, p3 = 0, p4 = 0;
        int count = 0;

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') {
                count++;

                if (count == k) {
                    p1 = i;
                } else if (count == k + 1) {
                    p2 = i;
                }
                if (count == 2 * k) {
                    p3 = i;
                } else if (count == 2 * k + 1) {
                    p4 = i;
                }
            }
        }

        long first = p2 - p1;
        long second = p4 - p3;

        return (int) (first * second % mod);
    }
}
```

```

```

种。

1. **初始化去重集合：** 创建 `HashSet<String>`，用于保存字符串 `s` 中出现过的所有长度为 `k` 的不同子串。

```java
class Solution {
    public boolean hasAllCodes(String s, int k) {

        for(int i = 0; i < s.length() - k + 1; i++){
            set.add(s.substring(i, i + k));
        }
        return set.size() == (1 << k);
    }
}
```

## [1332. 删除回文子序列](https://leetcode.cn/problems/remove-palindromic-subsequences/)

### 题目

给你一个字符串 `s`，它仅由字母 `'a'` 和 `'b'` 组成。每一次删除操作都可以从 `s` 中删除一个回文 **子序列**。

「子序列」定义：如果一个字符串可以通过删除原字符串某些字符而不改变原字符顺序得到，那么这个字符串就是原字符串的一个子序列。

「回文」定义：如果一个字符串向后和向前读是一致的，那么这个字符串就是一个回文。

 

**示例 1：**

```
输入：s = "ababa"
输出：1
解释：字符串本身就是回文序列，只需要删除一次。
```

**示例 2：**

```
输入：s = "abb"
输出：2
解释："abb" -> "bb" -> "". 
先删除回文子序列 "a"，然后再删除 "bb"。
```

**示例 3：**

```
输入：s = "baabb"
输出：2
解释："baabb" -> "b" -> "". 
先删除回文子序列 "baab"，然后再删除 "b"。
```

 

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅包含字母 `'a'` 和 `'b'`

### 题解

#### 思路总结

利用**回文判断 + 二字符性质**解决问题。

这道题的关键不在于模拟删除，而在于利用字符串只包含 `'a'` 和 `'b'` 这一特殊条件。

存在两种情况：

- 如果整个字符串 `s` 本身就是回文，那么可以直接把整个字符串作为一个回文子序列删除，答案为 `1`。
- 如果 `s` 不是回文，那么一定可以在 `2` 次以内删除完：第一次删除所有 `'a'`，第二次删除所有 `'b'`。由相同字符组成的字符串一定是回文，因此这两个子序列都合法。

又因为字符串本身不是回文，所以不可能只删除一次，答案必然为 `2`。

因此问题最终转化为：**判断整个字符串是否为回文。**

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **初始化左右指针：** 设置 `l = 0`、`r = s.length() - 1`，分别指向字符串两端。
2. **比较对称字符：** 当 `l < r` 时，比较 `s.charAt(l)` 和 `s.charAt(r)` 是否相同。
3. **发现非回文结构：** 如果某一对对称字符不同，说明整个字符串不是回文，不可能一次删除完成。
4. **利用字符种类性质：** 字符串只包含 `'a'` 和 `'b'`，可以分别删除所有 `'a'` 和所有 `'b'`，因此最多需要两次，直接返回 `2`。
5. **继续向中间检查：** 如果当前两个字符相同，则执行 `l++`、`r--` 继续判断下一对字符。
6. **确认整个字符串为回文：** 如果所有对称位置都相同，说明整个字符串本身就是回文子序列。
7. **返回最少删除次数：** 整个字符串可以一次删除，因此返回 `1`。

```java
class Solution {
    public int removePalindromeSub(String s) {
        int l = 0;
        int r = s.length() - 1;
        while(l < r){
            if(s.charAt(l) != s.charAt(r)){
                return 2;
            }
            l++;
            r--;
        }
        return 1;
    }
}
```

由于产品数组已经按照字典序排列，所有以 `pre` 为前缀的产品一定连续出现，因此从 `l` 开始向后检查，最多收集三个满足 `startsWith(pre)` 的产品即可。

如果遇到第一个不满足前缀条件的产品，就可以直接结束扫描，因为后面的产品也不会再属于当前前缀对应的连续区间。

整体思路正确，二分查找部分本质上就是寻找当前前缀的 **lower_bound**。

------

#### 解题步骤

1. **按照字典序排序：** 对 `products` 进行升序排序，使相同前缀的产品连续排列，并保证推荐结果天然满足字典序要求。
2. **依次构造搜索前缀：** 对 `searchWord` 的每个位置 `i`，取前 `i` 个字符组成当前检索前缀 `pre`。
3. **二分查找左边界：** 在排序后的产品数组中寻找第一个字典序大于等于 `pre` 的产品位置 `l`。
4. **从左边界开始匹配：** 从位置 `l` 向右检查产品是否满足 `startsWith(pre)`。
5. **收集最多三个产品：** 如果产品以前缀 `pre` 开头，则加入当前推荐列表，并在数量达到 `3` 时停止。
6. **提前结束连续区间：** 如果遇到第一个不以 `pre` 开头的产品，则说明当前前缀对应的连续区间已经结束，直接停止扫描。
7. **保存当前推荐结果：** 将当前前缀对应的推荐列表加入 `ans`。
8. **返回所有推荐列表：** 所有前缀处理完成后返回二维列表 `ans`。

```java
class Solution {
    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        List<List<String>> ans = new ArrayList<>();
        Arrays.sort(products);
        for(int i = 1; i <= searchWord.length(); i++){
            String pre = searchWord.substring(0, i);
            int l = 0;
            int r = products.length;
            while(l < r){
                int mid = l + (r - l) / 2;
                if(products[mid].compareTo(pre) >= 0){
                    r = mid;
                }else {
                    l = mid + 1;
                }
            }
            List<String> list = new ArrayList<>();
            for (int j = l; j < products.length && list.size() < 3; j++) {
                if (products[j].startsWith(pre)) {
                    list.add(products[j]);
                } else {
                    break;
                }
            }

            ans.add(list);
        }
        return ans;
    }
}
```

### 题解二

#### 思路总结

利用**Trie 前缀树 + 每个节点保存最多 3 个推荐结果**解决搜索推荐系统问题。

首先将 `products` 按照字典序排序，然后依次插入 Trie。每插入一个产品时，沿着产品字符对应的 Trie 路径向下移动，并在经过的每个节点中保存当前产品。

由于产品已经按照字典序插入，因此每个节点只需要保存最先插入的三个产品：

```
if (node.suggestions.size() < 3) {
    node.suggestions.add(word);
}
```

这样节点中的 `suggestions` 天然就是当前前缀下**字典序最小的三个产品**。

查询 `searchWord` 时，从 Trie 根节点按照字符逐层向下：

- 如果对应节点存在，直接取出该节点保存的 `suggestions`。
- 如果对应节点不存在，说明当前前缀没有任何产品匹配，并且之后更长的前缀也一定无法匹配，因此后续结果全部为空列表。

这种方案把推荐结果提前存储在 Trie 节点中，因此每个前缀查询都可以直接获得最多三个推荐产品。

------

#### 解题步骤

1. **定义 Trie 节点：** 每个节点使用 `children[26]` 保存 26 个小写字母对应的子节点，并使用 `suggestions` 保存当前前缀下字典序最小的三个产品。
2. **按照字典序排序产品：** 对 `products` 进行排序，保证后续插入 Trie 的产品顺序本身就是字典序。
3. **逐个插入产品：** 对每个产品从 Trie 根节点开始，按照字符依次创建或进入对应子节点。
4. **记录节点推荐结果：** 每经过一个 Trie 节点，如果其 `suggestions` 数量不足 `3`，就将当前产品加入其中。
5. **从根节点开始查询：** 遍历 `searchWord` 的每个字符，根据字符找到对应的 Trie 子节点。
6. **处理匹配成功情况：** 如果当前节点存在，将节点中的 `suggestions` 复制到当前前缀的答案中。
7. **处理匹配失败情况：** 如果当前节点不存在，则当前以及后续所有更长前缀都无法匹配产品，因此加入空列表。
8. **返回所有推荐结果：** 遍历完整个 `searchWord` 后返回二维列表 `ans`。

```java
class Solution {
    static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        List<String> suggestions = new ArrayList<>();
    }

    TrieNode root = new TrieNode();

    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        List<List<String>> ans = new ArrayList<>();
        Arrays.sort(products);
        for(String product : products){
            insert(product);
        }
        TrieNode node = root;
        for(char c : searchWord.toCharArray()){
            if(node == null){
                ans.add(new ArrayList<>());
                continue;
            }

            int index = c - 'a';
            node = node.children[index];
            if(node == null){
                ans.add(new ArrayList<>());
            }else {
                ans.add(new ArrayList<>(node.suggestions));
            }
        }
        return ans;
    }

    private void insert(String word){
        TrieNode node = root;

        for(char c : word.toCharArray()){
            int index = c - 'a';

            if(node.children[index] == null){
                node.children[index] = new TrieNode();
            }
            node = node.children[index];

            if(node.suggestions.size() < 3){
                node.suggestions.add(word);
            }
        }
    }
}
```

## [1249. 移除无效的括号](https://leetcode.cn/problems/minimum-remove-to-make-valid-parentheses/)

### 题目

给你一个由 `'('`、`')'` 和小写字母组成的字符串 `s`。

你需要从字符串中删除最少数目的 `'('` 或者 `')'` （可以删除任意位置的括号)，使得剩下的「括号字符串」有效。

请返回任意一个合法字符串。

有效「括号字符串」应当符合以下 **任意一条** 要求：

- 空字符串或只包含小写字母的字符串
- 可以被写作 `AB`（`A` 连接 `B`）的字符串，其中 `A` 和 `B` 都是有效「括号字符串」
- 可以被写作 `(A)` 的字符串，其中 `A` 是一个有效的「括号字符串」

 

**示例 1：**

```
输入：s = "lee(t(c)o)de)"
输出："lee(t(c)o)de"
解释："lee(t(co)de)" , "lee(t(c)ode)" 也是一个可行答案。
```

**示例 2：**

```
输入：s = "a)b(c)d"
输出："ab(c)d"
```

**示例 3：**

```
输入：s = "))(("
输出：""
解释：空字符串也是有效的
```

 

**提示：**

- `1 <= s.length <= 105`
- `s[i]` 可能是 `'('`、`')'` 或英文小写字母

### 题解

#### 思路总结

利用**栈 + 删除位置集合**找出所有必须删除的无效括号。

遍历字符串时：

- 遇到 `'('`，将其下标压入栈，等待后续右括号匹配。
- 遇到 `')'`：
  - 如果栈不为空，则与最近的 `'('` 匹配并弹栈。
  - 如果栈为空，说明当前 `')'` 没有对应的左括号，必须删除。
- 遍历结束后，栈中剩余的所有 `'('` 都没有对应右括号，也必须删除。

最后再次遍历字符串，跳过所有需要删除的位置，其余字符按照原顺序加入结果。

这种方法能够保证只删除无法匹配的括号，因此删除数量最少。整体时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **初始化辅助结构：** 使用 `stack` 保存尚未匹配的左括号下标，使用 `willdelete` 保存最终需要删除的位置。
2. **从左向右遍历字符串：** 依次检查每个字符，并根据括号类型处理匹配关系。
3. **记录左括号位置：** 遇到 `'('` 时，将当前位置下标压入栈中。
4. **处理右括号匹配：** 遇到 `')'` 时，如果栈不为空，则弹出一个左括号完成匹配。
5. **记录多余右括号：** 如果遇到 `')'` 时栈为空，说明没有左括号可以匹配，将当前位置加入 `willdelete`。
6. **处理多余左括号：** 第一次遍历结束后，将栈中所有尚未匹配的左括号位置加入 `willdelete`。
7. **重新构造字符串：** 再次遍历原字符串，只将不属于 `willdelete` 的字符加入 `StringBuilder`。
8. **返回合法结果：** 将 `StringBuilder` 转换成字符串并返回。

```java
class Solution {
    public String minRemoveToMakeValid(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        StringBuilder sb = new StringBuilder();
        Set<Integer> willdelete = new HashSet<>();
        for(int i = 0; i < s.length(); i++){
            if(s.charAt(i) == '('){
                stack.push(i);
            }else if(s.charAt(i) == ')'){
                if(stack.isEmpty()){
                    willdelete.add(i);
                }else {
                    stack.pop();
                }
            }
        }
        while(!stack.isEmpty()){
            willdelete.add(stack.pop());
        }
        for(int i = 0; i < s.length(); i++){
            if(!willdelete.contains(i)){
                sb.append(s.charAt(i));
            }
        }
        return sb.toString();
    }
}
```

## [1234. 替换子串得到平衡字符串](https://leetcode.cn/problems/replace-the-substring-for-balanced-string/)

### 题目

有一个只含有 `'Q', 'W', 'E', 'R'` 四种字符，且长度为 `n` 的字符串。

假如在该字符串中，这四个字符都恰好出现 `n/4` 次，那么它就是一个「平衡字符串」。

 

给你一个这样的字符串 `s`，请通过「替换一个子串」的方式，使原字符串 `s` 变成一个「平衡字符串」。

你可以用和「待替换子串」长度相同的 **任何** 其他字符串来完成替换。

请返回待替换子串的最小可能长度。

如果原字符串自身就是一个平衡字符串，则返回 `0`。

 

**示例 1：**

```
输入：s = "QWER"
输出：0
解释：s 已经是平衡的了。
```

**示例 2：**

```
输入：s = "QQWE"
输出：1
解释：我们需要把一个 'Q' 替换成 'R'，这样得到的 "RQWE" (或 "QRWE") 是平衡的。
```

**示例 3：**

```
输入：s = "QQQW"
输出：2
解释：我们可以把前面的 "QQ" 替换成 "ER"。 
```

**示例 4：**

```
输入：s = "QQQQ"
输出：3
解释：我们可以替换后 3 个 'Q'，使 s = "QWER"。
```

 

**提示：**

- `1 <= s.length <= 10^5`
- `s.length` 是 `4` 的倍数
- `s` 中只含有 `'Q'`, `'W'`, `'E'`, `'R'` 四种字符

### 题解

#### 思路总结

利用**滑动窗口 + 计数**寻找最短的待替换子串。

平衡字符串要求 `'Q'`、`'W'`、`'E'`、`'R'` 都恰好出现 `n / 4` 次，因此真正需要处理的是各字符**超过 `n / 4` 的部分**。

当前代码先统计每种字符的数量，再执行：

```
count[i] -= n / 4;
```

此时：

- `count[i] > 0`：该字符多出了 `count[i]` 个，待替换子串必须至少包含这么多个。
- `count[i] <= 0`：该字符没有多余，不需要强制包含。

随后使用滑动窗口 `[l, r]`。当字符进入窗口时，从对应的 `count` 中减一，相当于用当前窗口去“覆盖”多余字符。

当四个 `count` 都满足：

```
count[i] <= 0
```

说明当前窗口已经包含了所有必须被替换掉的多余字符，因此窗口外的字符数量已经能够满足平衡要求，窗口内部可以任意替换成缺少的字符。此时不断收缩左边界，就能找到最短合法窗口。

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **统计字符数量：** 分别计算 `'Q'`、`'W'`、`'E'`、`'R'` 在整个字符串中的出现次数。
2. **计算多余字符数量：** 每种字符的实际数量减去目标数量 `n / 4`，得到对应字符超出的数量。
3. **判断是否已经平衡：** 如果四种字符都不存在多余数量，则原字符串已经平衡，直接返回 `0`。
4. **初始化滑动窗口：** 设置左边界 `l = 0`，并使用 `ans` 保存最短合法窗口长度。
5. **扩展右边界：** 每次将 `s[r]` 加入待替换窗口，并将该字符对应的剩余多余数量减一。
6. **判断窗口是否合法：** 当四种字符对应的剩余多余数量全部小于等于 `0` 时，说明当前窗口已经覆盖所有必须删除的多余字符。
7. **更新最短窗口：** 使用当前窗口长度 `r - l + 1` 更新 `ans`。
8. **收缩左边界：** 将 `s[l]` 移出窗口，并恢复该字符对应的计数，然后执行 `l++`。
9. **持续寻找最短窗口：** 只要窗口仍然覆盖所有多余字符，就继续收缩左边界。
10. **返回最小长度：** 遍历结束后，`ans` 即为最短待替换子串长度。

```java
class Solution {
    public int balancedString(String s) {
        int[] count = new int[4];
        char[] chars = new char[] {'Q', 'W', 'E', 'R'};
        int n = s.length();

        for(char c : s.toCharArray()){
            for(int i = 0; i < 4; i++){
                if(c == chars[i]){
                    count[i]++;
                    break;
                }
            }
        }

        for(int i = 0; i < 4; i++){
            count[i] -= n / 4;
        }

        // 本身已经平衡
        if(count[0] <= 0 && count[1] <= 0 &&
                count[2] <= 0 && count[3] <= 0){
            return 0;
        }

        int l = 0;
        int ans = n + 1;

        for(int r = 0; r < n; r++){

            // s[r] 加入窗口
            for(int i = 0; i < 4; i++){
                if(s.charAt(r) == chars[i]){
                    count[i]--;
                    break;
                }
            }

            // 当前窗口已经覆盖所有多余字符
            while(count[0] <= 0 && count[1] <= 0 &&
                    count[2] <= 0 && count[3] <= 0){

                ans = Math.min(ans, r - l + 1);

                // s[l] 移出窗口
                for(int i = 0; i < 4; i++){
                    if(s.charAt(l) == chars[i]){
                        count[i]++;
                        break;
                    }
                }

                l++;
            }
        }

        return ans;
    }
}
```

## [1221. 分割平衡字符串](https://leetcode.cn/problems/split-a-string-in-balanced-strings/)

### 题目

**平衡字符串** 中，`'L'` 和 `'R'` 字符的数量是相同的。

给你一个平衡字符串 `s`，请你将它分割成尽可能多的子字符串，并满足：

- 每个子字符串都是平衡字符串。

返回可以通过分割得到的平衡字符串的 **最大数量** **。**

 

**示例 1：**

```
输入：s = "RLRRLLRLRL"
输出：4
解释：s 可以分割为 "RL"、"RRLL"、"RL"、"RL" ，每个子字符串中都包含相同数量的 'L' 和 'R' 。
```

**示例 2：**

```
输入：s = "RLRRRLLRLL"
输出：2
解释：s 可以分割为 "RL"、"RRRLLRLL"，每个子字符串中都包含相同数量的 'L' 和 'R' 。
注意，s 无法分割为 "RL"、"RR"、"RL"、"LR"、"LL" 因为第 2 个和第 5 个子字符串不是平衡字符串。
```

**示例 3：**

```
输入：s = "LLLLRRRR"
输出：1
解释：s 只能保持原样 "LLLLRRRR" 。
```

 

**提示：**

- `2 <= s.length <= 1000`
- `s[i] = 'L' 或 'R'`
- `s` 是一个 **平衡** 字符串

 

### 题解

#### 思路总结

利用**贪心 + 差值计数**解决平衡字符串分割问题。

可以将：

- `'L'` 记为 `+1`
- `'R'` 记为 `-1`

遍历字符串时维护当前子串的差值 `balance`。当：

```
balance == 0
```

说明当前这一段中 `'L'` 和 `'R'` 数量相同，已经形成一个平衡子串。

为了让分割出来的平衡子串数量尽可能多，只要当前前缀第一次达到平衡，就立即进行一次分割。因为越早切分，越不会影响后续继续形成新的平衡子串。

当前代码使用 `c1` 和 `c2` 分别统计 `'L'`、`'R'` 数量，逻辑完全正确。本质上等价于维护一个差值变量。

------

#### 解题步骤

1. **初始化计数变量：** 使用 `c1` 统计当前子串中 `'L'` 的数量，使用 `c2` 统计 `'R'` 的数量。
2. **从左向右遍历字符串：** 依次检查每一个字符。
3. **统计当前字符：** 如果当前字符是 `'L'`，则执行 `c1++`，否则执行 `c2++`。
4. **判断当前子串是否平衡：** 如果 `c1 == c2`，说明从上一个分割点到当前位置形成了一个平衡子串。
5. **增加分割数量：** 找到一个平衡子串后执行 `ans++`。
6. **重新开始统计：** 将 `c1` 和 `c2` 重置为 `0`，从下一个位置开始寻找新的平衡子串。
7. **返回最大数量：** 遍历结束后返回 `ans`。

```java
class Solution {
    public int balancedStringSplit(String s) {
        int c1 = 0;
        int c2 = 0;
        int ans = 0;
        for(char c : s.toCharArray()){
            if(c == 'L'){
                c1++;
            }else {
                c2++;
            }
            if(c1 == c2){
                ans++;
                c1 = 0;
                c2 = 0;
            }
        }
        return ans;
    }
}
```

### 题解

- `'l'`：2 个
- `'o'`：2 个
- `'n'`：1 个

因此每种字符分别能够支持的 `"balloon"` 数量为：

```
count['b']
count['a']
count['l'] / 2
count['o'] / 2
count['n']
```

最终能够组成的单词数量由其中最少的一项决定，所以依次使用 `Math.min()` 取最小值即可。

相比逐个模拟扣除字符，这种方法直接计算结果，更加简洁高效。

------

#### 解题步骤

1. **初始化字符计数数组：** 创建长度为 `26` 的 `count` 数组，用于记录每个小写字母的出现次数。
2. **统计所有字符：** 遍历 `text`，通过 `text.charAt(i) - 'a'` 将字符映射到对应下标并增加计数。
3. **初始化答案：** 使用 `'b'` 的出现次数初始化 `ans`，因为每个 `"balloon"` 需要一个 `'b'`。
4. **计算字符 a 的限制：** 使用 `count['a' - 'a']` 与当前 `ans` 取最小值。
5. **计算字符 l 的限制：** 每个 `"balloon"` 需要两个 `'l'`，因此使用 `count['l' - 'a'] / 2` 更新 `ans`。
6. **计算字符 o 的限制：** 每个 `"balloon"` 需要两个 `'o'`，因此使用 `count['o' - 'a'] / 2` 更新 `ans`。
7. **计算字符 n 的限制：** 使用 `count['n' - 'a']` 与当前 `ans` 取最小值。
8. **返回最终结果：** 最小值就是能够组成 `"balloon"` 的最大数量。

```java
class Solution {
    public int maxNumberOfBalloons(String text) {
        int[] count = new int[26];
        int n = text.length();
        for(int i = 0; i < n; i++){
            count[text.charAt(i) - 'a']++;
        }
        int ans = count['b' - 'a'];
        ans = Math.min(ans, count['a' - 'a']);
        ans = Math.min(ans, count['l' - 'a'] / 2);
        ans = Math.min(ans, count['o' - 'a'] / 2);
        ans = Math.min(ans, count['n' - 'a']);
        return ans;
    }
}
```

## [1170. 比较字符串最小字母出现频次](https://leetcode.cn/problems/compare-strings-by-frequency-of-the-smallest-character/)

### 题目

定义一个函数 `f(s)`，统计 `s` 中**（按字典序比较）最小字母的出现频次** ，其中 `s` 是一个非空字符串。

例如，若 `s = "dcce"`，那么 `f(s) = 2`，因为字典序最小字母是 `"c"`，它出现了 2 次。

现在，给你两个字符串数组待查表 `queries` 和词汇表 `words` 。对于每次查询 `queries[i]` ，需统计 `words` 中满足 `f(queries[i])` < `f(W)` 的 **词的数目** ，`W` 表示词汇表 `words` 中的每个词。

请你返回一个整数数组 `answer` 作为答案，其中每个 `answer[i]` 是第 `i` 次查询的结果。

 

**示例 1：**

```
输入：queries = ["cbd"], words = ["zaaaz"]
输出：[1]
解释：查询 f("cbd") = 1，而 f("zaaaz") = 3 所以 f("cbd") < f("zaaaz")。
```

**示例 2：**

```
输入：queries = ["bbb","cc"], words = ["a","aa","aaa","aaaa"]
输出：[1,2]
解释：第一个查询 f("bbb") < f("aaaa")，第二个查询 f("aaa") 和 f("aaaa") 都 > f("cc")。
```

 

**提示：**

- `1 <= queries.length <= 2000`
- `1 <= words.length <= 2000`
- `1 <= queries[i].length, words[i].length <= 10`
- `queries[i][j]`、`words[i][j]` 都由小写英文字母组成

### 题解

#### 思路总结

利用**频次函数 + 计数桶 + 后缀和**解决问题。先计算每个 `word` 的 `f(word)`，由于字符串长度最多为 `10`，所以 `f(word)` 的范围只有 `1 ~ 10`，可以直接使用数组统计不同频次对应的单词数量。

随后对计数数组计算后缀和，使 `count[x]` 表示满足 `f(word) >= x` 的单词数量。对于查询字符串，设 `x = f(query)`，题目要求统计 `f(query) < f(word)`，等价于统计 `f(word) >= x + 1`，因此答案直接取 `count[x + 1]`。

整体时间复杂度为 **O(Q + W)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **初始化频次桶：** 创建 `count` 数组，其中 `count[i]` 用于统计 `f(word) = i` 的单词数量。
2. **统计 words 的频次值：** 遍历 `words`，计算每个字符串的 `f(word)`，并将对应位置的计数加一。
3. **计算后缀和：** 从较大的频次向较小的频次累加，使 `count[i]` 表示 `f(word) >= i` 的单词数量。
4. **遍历所有查询：** 对每个 `queries[i]` 计算其最小字符出现次数 `f(queries[i])`。
5. **查询严格更大频次：** 如果查询频次为 `x`，则满足条件的单词必须满足 `f(word) >= x + 1`，因此答案为 `count[x + 1]`。
6. **保存查询结果：** 将每次查询得到的数量写入 `ans[i]`。
7. **返回最终答案：** 所有查询处理完成后返回 `ans`。

```java
class Solution {
    public int[] numSmallerByFrequency(String[] queries, String[] words) {
        int length = queries.length;
        int[] count = new int[12];
        for (String word : words) {
            count[f(word)]++;
        }
        for(int i = 9; i > 0; i--){
            count[i] += count[i+1];
        }
        int[] ans = new int[length];
        for(int i = 0; i < length; i++){
            ans[i] = count[f(queries[i]) + 1];
        }
        return ans;
    }

    private int f(String s){
        int[] count = new int[26];
        for(char c : s.toCharArray()){
            count[c - 'a']++;
        }
        for(int i : count){
            if (i != 0){
                return i;
            }
        }
        return 0;
    }
}
```

## [1003. 检查替换后的词是否有效](https://leetcode.cn/problems/check-if-word-is-valid-after-substitutions/)

### 题目

给你一个字符串 `s` ，请你判断它是否 **有效** 。

字符串 `s` **有效** 需要满足：假设开始有一个空字符串 `t = ""` ，你可以执行 **任意次** 下述操作将 `t` **转换为** `s` ：

- 将字符串 `"abc"` 插入到 `t` 中的任意位置。形式上，`t` 变为 `tleft + "abc" + tright`，其中 `t == tleft + tright` 。注意，`tleft` 和 `tright` 可能为 **空** 。

如果字符串 `s` 有效，则返回 `true`；否则，返回 `false`。

 

**示例 1：**

```
输入：s = "aabcbc"
输出：true
解释：
"" -> "abc" -> "aabcbc"
因此，"aabcbc" 有效。
```

**示例 2：**

```
输入：s = "abcabcababcc"
输出：true
解释：
"" -> "abc" -> "abcabc" -> "abcabcabc" -> "abcabcababcc"
因此，"abcabcababcc" 有效。
```

**示例 3：**

```
输入：s = "abccba"
输出：false
解释：执行操作无法得到 "abccba" 。
```

 

**提示：**

- `1 <= s.length <= 2 * 104`
- `s` 由字母 `'a'`、`'b'` 和 `'c'` 组成

### 题解

#### 思路总结

利用**数组模拟栈 + 局部消除 `"abc"`**。先判断字符串长度是否为 `3` 的倍数，因为每次合法操作都会增加 3 个字符，不满足时一定无效。随后从左向右遍历字符串，`'a'`、`'b'` 暂时压入栈中；遇到 `'c'` 时，检查栈顶两个字符是否依次为 `'a'`、`'b'`，如果满足，就与当前 `'c'` 一起组成 `"abc"` 并消除。

这种方法相当于不断执行构造过程的逆操作 `"abc" -> ""`。如果所有字符最终都能够被消除，栈的大小会变成 `0`，字符串有效。整体时间复杂度为 **O(n)**，空间复杂度为 **O(n)**。

不过当前代码存在一个正确性问题：遇到 `'c'` 时，如果栈顶不是 `"ab"`，当前代码既没有返回 `false`，也没有保存这个 `'c'`，相当于直接把非法的 `'c'` 丢掉了，可能产生错误结果。

------

#### 解题步骤

1. **判断字符串长度：** 如果字符串长度不能被 `3` 整除，则不可能通过不断插入 `"abc"` 得到，直接返回 `false`。
2. **初始化模拟栈：** 创建字符数组 `stack`，使用 `size` 表示当前栈中有效字符数量。
3. **处理字符 a：** 遇到 `'a'` 时直接压入栈中，等待后面的 `'b'` 和 `'c'` 与其组成 `"abc"`。
4. **处理字符 b：** 遇到 `'b'` 时同样压入栈中，后续由 `'c'` 判断栈顶是否形成 `"ab"`。
5. **处理字符 c：** 遇到 `'c'` 时检查栈中是否至少有两个字符，并判断栈顶两个字符是否依次为 `'a'`、`'b'`。
6. **消除合法 abc：** 如果栈顶为 `"ab"`，则将 `size` 减少 `2`，表示栈顶的 `'a'`、`'b'` 与当前 `'c'` 一起被消除。
7. **发现非法结构：** 如果当前字符为 `'c'` 但栈顶不能形成 `"ab"`，则当前字符串无法完全消除，直接返回 `false`。
8. **判断最终状态：** 遍历结束后，如果 `size == 0`，说明所有字符都被完整消除，返回 `true`。

```java
class Solution {
    public boolean isValid(String s) {
        if (s.length() % 3 != 0) {
            return false;
        }

        char[] stack = new char[s.length()];
        int size = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if(c == 'c'){
                if(size < 2){
                    return false;
                }else {
                    if(stack[size - 1] == 'b' && stack[size - 2] == 'a'){
                        size -= 2;
                    }
                }
            }else if(c == 'b'){
                if(size < 1){
                    return false;
                }else {
                    stack[size] = 'b';
                    size++;
                }
            }else {
                stack[size] = 'a';
                size++;
            }
        }
        return size == 0;
    }
}
```

## [966. 元音拼写检查器](https://leetcode.cn/problems/vowel-spellchecker/)

### 题目

在给定单词列表 `wordlist` 的情况下，我们希望实现一个拼写检查器，将查询单词转换为正确的单词。

对于给定的查询单词 `query`，拼写检查器将会处理两类拼写错误：

- 大小写：如果查询匹配单词列表中的某个单词（**不区分大小写**），则返回的正确单词与单词列表中的大小写相同。
  - 例如：`wordlist = ["yellow"]`, `query = "YellOw"`: `correct = "yellow"`
  - 例如：`wordlist = ["Yellow"]`, `query = "yellow"`: `correct = "Yellow"`
  - 例如：`wordlist = ["yellow"]`, `query = "yellow"`: `correct = "yellow"`
- 元音错误：如果在将查询单词中的元音`('a', 'e', 'i', 'o', 'u')`分别替换为任何元音后，能与单词列表中的单词匹配（**不区分大小写**），则返回的正确单词与单词列表中的匹配项大小写相同。
  - 例如：`wordlist = ["YellOw"]`, `query = "yollow"`: `correct = "YellOw"`
  - 例如：`wordlist = ["YellOw"]`, `query = "yeellow"`: `correct = ""` （无匹配项）
  - 例如：`wordlist = ["YellOw"]`, `query = "yllw"`: `correct = ""` （无匹配项）

此外，拼写检查器还按照以下优先级规则操作：

- 当查询完全匹配单词列表中的某个单词（**区分大小写**）时，应返回相同的单词。
- 当查询匹配到大小写问题的单词时，您应该返回单词列表中的第一个这样的匹配项。
- 当查询匹配到元音错误的单词时，您应该返回单词列表中的第一个这样的匹配项。
- 如果该查询在单词列表中没有匹配项，则应返回空字符串。

给出一些查询 `queries`，返回一个单词列表 `answer`，其中 `answer[i]` 是由查询 `query = queries[i]` 得到的正确单词。

 

**示例 1：**

```
输入：wordlist = ["KiTe","kite","hare","Hare"], queries = ["kite","Kite","KiTe","Hare","HARE","Hear","hear","keti","keet","keto"]
输出：["kite","KiTe","KiTe","Hare","hare","","","KiTe","","KiTe"]
```

**示例 2:**

```
输入：wordlist = ["yellow"], queries = ["YellOw"]
输出：["yellow"]
```

 

**提示：**

- `1 <= wordlist.length, queries.length <= 5000`
- `1 <= wordlist[i].length, queries[i].length <= 7`
- `wordlist[i]` 和 `queries[i]` 只包含英文字母

### 题解

#### 思路总结

利用**三层哈希结构 + 规范化字符串**按照题目要求的优先级处理匹配。预处理 `wordlist` 时，分别建立完全匹配集合 `exact`、忽略大小写映射 `lowerMap` 和忽略元音差异映射 `vowelMap`。

其中 `lowerMap` 和 `vowelMap` 使用 `putIfAbsent()`，因此同一种规范化形式存在多个候选单词时，只会保存 `wordlist` 中最先出现的那个，恰好满足题目要求。查询时按照 **完全匹配 → 大小写匹配 → 元音匹配 → 无匹配** 的顺序处理，不需要再遍历候选列表，整体效率很高。

------

#### 解题步骤

1. **建立完全匹配集合：** 将 `wordlist` 中每个原始单词加入 `exact`，用于判断区分大小写的完全匹配。
2. **生成小写形式：** 将每个单词转换为小写字符串 `lower`，作为忽略大小写匹配的键。
3. **生成元音掩码：** 将 `lower` 中的元音统一替换成 `'*'`，得到 `mask`。
4. **保存首个大小写匹配：** 使用 `lowerMap.putIfAbsent(lower, word)` 保留同一小写形式下最先出现的原始单词。
5. **保存首个元音匹配：** 使用 `vowelMap.putIfAbsent(mask, word)` 保留同一元音模式下最先出现的原始单词。
6. **优先检查完全匹配：** 如果 `exact` 中存在原查询字符串，直接返回查询本身。
7. **检查大小写匹配：** 将查询转换为小写形式，如果 `lowerMap` 中存在对应键，则返回第一个匹配单词。
8. **检查元音错误匹配：** 将查询转换为元音掩码，如果 `vowelMap` 中存在对应键，则返回对应单词。
9. **处理无匹配情况：** 如果三种规则均未匹配，则返回空字符串。

```java
class Solution {
    public String[] spellchecker(String[] wordlist, String[] queries) {
        Set<String> exact = new HashSet<>();
        Map<String, String> lowerMap = new HashMap<>();
        Map<String, String> vowelMap = new HashMap<>();

        for (String word : wordlist) {
            exact.add(word);

            String lower = word.toLowerCase();
            String mask = mask(lower);

            lowerMap.putIfAbsent(lower, word);
            vowelMap.putIfAbsent(mask, word);
        }

        String[] ans = new String[queries.length];

        for (int i = 0; i < queries.length; i++) {
            String query = queries[i];

            if (exact.contains(query)) {
                ans[i] = query;
                continue;
            }

            String lower = query.toLowerCase();

            if (lowerMap.containsKey(lower)) {
                ans[i] = lowerMap.get(lower);
                continue;
            }

            String mask = mask(lower);
            ans[i] = vowelMap.getOrDefault(mask, "");
        }

        return ans;
    }

    private String mask(String s) {
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (isVowel(c)) {
                sb.append('*');
            } else {
                sb.append(c);
            }
        }

        return sb.toString();
    }

    private boolean isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i'
                || c == 'o' || c == 'u';
    }
}
```

## [925. 长按键入](https://leetcode.cn/problems/long-pressed-name/)

### 题目

你的朋友正在使用键盘输入他的名字 `name`。偶尔，在键入字符 `c` 时，按键可能会被*长按*，而字符可能被输入 1 次或多次。

你将会检查键盘输入的字符 `typed`。如果它对应的可能是你的朋友的名字（其中一些字符可能被长按），那么就返回 `True`。

 

**示例 1：**

```
输入：name = "alex", typed = "aaleex"
输出：true
解释：'alex' 中的 'a' 和 'e' 被长按。
```

**示例 2：**

```
输入：name = "saeed", typed = "ssaaedd"
输出：false
解释：'e' 一定需要被键入两次，但在 typed 的输出中不是这样。
```

 

**提示：**

- `1 <= name.length, typed.length <= 1000`
- `name` 和 `typed` 的字符都是小写字母

### 题解

#### 思路总结

利用**双指针**判断 `typed` 是否可以由 `name` 中某些字符长按得到。指针 `i` 指向 `typed` 当前待匹配位置，依次遍历 `name` 中的字符 `c`：如果 `typed[i] == c`，说明正常匹配；如果不同，则当前 `typed[i]` 只有在与前一个字符相同的情况下才能解释为“长按产生的重复字符”，此时不断跳过这些重复字符，直到找到 `c`。

当 `name` 全部匹配完成后，`typed` 可能还存在剩余字符，这些字符只能是最后一个字符长按产生的重复字符，因此继续跳过。最终只有 `i == typed.length()` 时才说明整个 `typed` 都可以被合理解释。

当前实现思路正确，整个过程中 `typed` 的指针只向右移动，因此时间复杂度为 **O(m + n)**。

------

#### 解题步骤

1. **初始化 typed 指针：** 设置 `i = 0`，表示当前等待与 `name` 字符匹配的 `typed` 位置。
2. **依次处理 name 字符：** 按照顺序遍历 `name` 中的每一个字符 `c`。
3. **跳过长按字符：** 当 `typed[i] != c` 时，如果 `typed[i] == typed[i - 1]`，说明当前位置可以视为前一个字符长按产生的重复字符，执行 `i++`。
4. **判断非法字符：** 如果当前字符既无法匹配 `c`，又不是前一个字符的重复，则无法由长按产生，直接返回 `false`。
5. **完成当前字符匹配：** 找到与 `c` 相同的 `typed[i]` 后执行 `i++`，继续匹配 `name` 的下一个字符。
6. **处理尾部长按字符：** `name` 匹配结束后，如果 `typed` 还有剩余字符，则它们必须全部与前一个字符相同。
7. **判断是否完全消费：** 如果最终 `i == typed.length()`，说明整个输入都可以匹配，返回 `true`，否则返回 `false`。

```java
class Solution {
    public boolean isLongPressedName(String name, String typed) {
        int i = 0;
        int n = typed.length();
        for(char c : name.toCharArray()){
            while(i < n && c != typed.charAt(i)){
                if(i == 0){
                    return false;
                }
                if(typed.charAt(i) == typed.charAt(i - 1)){
                    i++;
                }else {
                    return false;
                }
            }
            i++;
        }
        while(i < n && typed.charAt(i) == typed.charAt(i - 1)){
            i++;
        }
        return i == n;
    }
}
```

## [916. 单词子集](https://leetcode.cn/problems/word-subsets/)

### 题目

给你两个字符串数组 `words1` 和 `words2`。

现在，如果 `b` 中的每个字母都出现在 `a` 中，**包括重复出现的字母**，那么称字符串 `b` 是字符串 `a` 的 **子集** 。

- 例如，`"wrr"` 是 `"warrior"` 的子集，但不是 `"world"` 的子集。

如果对 `words2` 中的每一个单词 `b`，`b` 都是 `a` 的子集，那么我们称 `words1` 中的单词 `a` 是 **通用单词** 。

以数组形式返回 `words1` 中所有的 **通用** 单词。你可以按 **任意顺序** 返回答案。

 



**示例 1：**

**输入：**words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["e","o"]

**输出：**["facebook","google","leetcode"]

**示例 2：**

**输入：**words1 = ["amazon","apple","facebook","google","leetcode"], words2 = ["lc","eo"]

**输出：**["leetcode"]

**示例 3：**

**输入：**words1 = ["acaac","cccbb","aacbb","caacc","bcbbb"], words2 = ["c","cc","b"]

**输出：**["cccbb"]

 

**提示：**

- `1 <= words1.length, words2.length <= 104`
- `1 <= words1[i].length, words2[i].length <= 10`
- `words1[i]` 和 `words2[i]` 仅由小写英文字母组成
- `words1` 中的所有字符串 **互不相同**

### 题解

#### 思路总结

利用**字符频次统计 + 最大需求合并**解决通用单词问题。对于 `words2` 中的每个单词，分别统计 26 个字母的出现次数，然后对每个字母取所有单词需求中的最大值，得到统一的需求数组 `need`。

例如 `words2 = ["eoo", "eo"]` 时，并不是需要 `3` 个 `'o'`，而是最多只需要 `2` 个 `'o'`，因为一个单词只要同时满足两个子集条件即可。因此 `need[c]` 应该表示 `words2` 中所有单词对字符 `c` 的**最大需求量**。之后遍历 `words1`，统计每个单词的字符频次，只要所有字符数量都满足 `temp[i] >= need[i]`，该单词就是通用单词。

整体只需要对两个字符串数组各遍历一次，字符种类固定为 26。

------

#### 解题步骤

1. **初始化需求数组：** 创建长度为 `26` 的 `need`，用于保存成为通用单词时每个字母至少需要出现多少次。
2. **统计 words2 单词频次：** 对 `words2` 中每个字符串建立临时频次数组 `temp`。
3. **合并字符最大需求：** 对每个字母执行 `need[i] = Math.max(need[i], temp[i])`，保存所有 `words2` 单词中的最大需求。
4. **遍历 words1：** 对每个候选单词重新统计 26 个字母的出现次数。
5. **检查是否满足需求：** 如果存在某个字符满足 `temp[i] < need[i]`，说明当前单词不是通用单词。
6. **保存合法单词：** 如果 26 个字符全部满足需求，则将当前单词加入结果集合。
7. **返回最终结果：** 返回所有满足条件的通用单词。

```java
class Solution {
    public List<String> wordSubsets(String[] words1, String[] words2) {
        List<String> ans = new ArrayList<>();
        int[] need = new int[26];
        for (String s : words2) {
            int[] temp = new int[26];
            for (char c : s.toCharArray()) {
                temp[c - 'a']++;
            }
            for (int i = 0; i < 26; i++) {
                if (temp[i] != 0) {
                    need[i] = Math.max(need[i], temp[i]);
                }
            }
        }
        for(String s : words1){
            int[] temp = new int[26];
            for (char c : s.toCharArray()) {
                temp[c - 'a']++;
            }
            int i = 0;
            for (; i < 26; i++) {
                if (temp[i] < need[i]) {
                    break;
                }
            }
            if(i == 26){
                ans.add(s);
            }
        }
        return ans;
    }
}
```

## [890. 查找和替换模式](https://leetcode.cn/problems/find-and-replace-pattern/)

### 题目

你有一个单词列表 `words` 和一个模式 `pattern`，你想知道 `words` 中的哪些单词与模式匹配。

如果存在字母的排列 `p` ，使得将模式中的每个字母 `x` 替换为 `p(x)` 之后，我们就得到了所需的单词，那么单词与模式是匹配的。

*（回想一下，字母的排列是从字母到字母的双射：每个字母映射到另一个字母，没有两个字母映射到同一个字母。）*

返回 `words` 中与给定模式匹配的单词列表。

你可以按任何顺序返回答案。

 

**示例：**

```
输入：words = ["abc","deq","mee","aqq","dkd","ccc"], pattern = "abb"
输出：["mee","aqq"]
解释：
"mee" 与模式匹配，因为存在排列 {a -> m, b -> e, ...}。
"ccc" 与模式不匹配，因为 {a -> c, b -> c, ...} 不是排列。
因为 a 和 b 映射到同一个字母。
```

 

**提示：**

- `1 <= pattern.length <= 20`
- `1 <= words.length <= 50`
- `words[i].length == pattern.length`
- `pattern` 和 `words[i]` 只包含小写英文字母。

### 题解

#### 思路总结

利用**字符串标准化（Canonical Form）**判断单词与 `pattern` 是否具有相同的字符映射结构。标准化时，按照字符第一次出现的顺序依次映射成 `'a'`、`'b'`、`'c'`……，例如 `"mee"` 会转换为 `"abb"`，`"aqq"` 也会转换为 `"abb"`，而 `"ccc"` 会转换为 `"aaa"`。

先计算 `pattern` 的标准形态 `pNorm`，再依次计算每个 `word` 的标准形态。如果二者完全相同，说明两个字符串中“相同位置是否属于同一字符”的关系完全一致，也就存在一一对应的双射映射，可以加入答案。

------

#### 解题步骤

1. **标准化模式串：** 调用 `normalize(pattern)`，得到 `pattern` 对应的标准字符结构 `pNorm`。
2. **遍历所有单词：** 依次处理 `words` 中的每一个 `word`。
3. **建立字符映射：** 在 `normalize()` 中使用 `map` 保存原字符对应的标准字符。
4. **分配标准编号：** 某个字符第一次出现时，按照 `'a'`、`'b'`、`'c'` 的顺序分配新的标准字符。
5. **复用已有映射：** 如果字符已经出现，则直接使用之前分配的标准字符，保证相同字符始终具有相同表示。
6. **比较标准形态：** 如果 `normalize(word)` 与 `pNorm` 相同，说明当前单词与模式具有完全相同的字符对应关系。
7. **保存匹配单词：** 将所有标准形态相同的单词加入 `ans`。
8. **返回最终结果：** 遍历结束后返回所有匹配 `pattern` 的单词。

```java
class Solution {
    public List<String> findAndReplacePattern(String[] words, String pattern) {
        List<String> ans = new ArrayList<>();
        String pNorm = normalize(pattern); // 获取 pattern 的标准形态

        for (String word : words) {
            // 如果单词的标准形态和 pattern 一样，就匹配
            if (normalize(word).equals(pNorm)) {
                ans.add(word);
            }
        }
        return ans;
    }

    // 辅助方法：将字符串转换为标准形态 (如 "mee" -> "abb")
    private String normalize(String s) {
        char[] map = new char[26];
        char id = 'a'; // 用 a, b, c... 来标记第几个出现的不同字符
        StringBuilder sb = new StringBuilder();

        for (char c : s.toCharArray()) {
            if (map[c - 'a'] == 0) {
                map[c - 'a'] = id++; // 第一次出现，分配一个新的字母
            }
            sb.append(map[c - 'a']); // 追加映射后的字母
        }
        return sb.toString();
    }
}
```

## [856. 括号的分数](https://leetcode.cn/problems/score-of-parentheses/)

### 题目

给定一个平衡括号字符串 `S`，按下述规则计算该字符串的分数：

- `()` 得 1 分。
- `AB` 得 `A + B` 分，其中 A 和 B 是平衡括号字符串。
- `(A)` 得 `2 * A` 分，其中 A 是平衡括号字符串。

 

**示例 1：**

```
输入： "()"
输出： 1
```

**示例 2：**

```
输入： "(())"
输出： 2
```

**示例 3：**

```
输入： "()()"
输出： 2
```

**示例 4：**

```
输入： "(()(()))"
输出： 6
```

 

**提示：**

1. `S` 是平衡括号字符串，且只含有 `(` 和 `)` 。
2. `2 <= S.length <= 50`

### 题解

#### 思路总结

利用**递归分解平衡括号字符串**，直接按照题目给出的三条定义计算分数。首先处理最基本的 `"()"`，直接返回 `1`；否则通过 `balance` 统计左右括号差值，如果在字符串结束之前出现 `balance == 0`，说明字符串可以拆成两个独立的平衡括号串 `AB`，根据规则计算 `score(A) + score(B)`。

如果遍历过程中只有最后一个位置才使 `balance` 回到 `0`，说明整个字符串的结构一定是 `(A)`，去掉最外层括号后递归计算内部字符串，再乘以 `2`。

------

#### 解题步骤

1. **处理最基本情况：** 如果当前字符串为 `"()"`，根据规则直接返回 `1`。
2. **初始化括号平衡值：** 使用 `balance` 记录当前前缀中左括号数量减去右括号数量。
3. **从左向右扫描字符串：** 遇到 `'('` 执行 `balance++`，遇到 `')'` 执行 `balance--`。
4. **寻找顶层分割位置：** 当 `balance == 0` 时，说明当前位置之前构成一个完整的平衡括号字符串。
5. **处理 AB 结构：** 如果当前位置不是字符串末尾，则将字符串拆成 `A` 和 `B`，递归计算 `score(A) + score(B)`。
6. **处理 (A) 结构：** 如果整个扫描过程中没有提前出现顶层分割，说明当前字符串被一对最外层括号完整包围。
7. **递归计算内部得分：** 去掉最外层括号得到内部字符串 `A`，返回 `2 * score(A)`。
8. **得到最终分数：** 递归不断按照三条定义分解，最终计算出整个平衡括号字符串的分数。

```java
class Solution {
    public int scoreOfParentheses(String s) {
        if(s.equals("()")){
            return 1;
        }
        int balance = 0;
        for(int i = 0; i < s.length(); i++){
            if(s.charAt(i) == '('){
                balance++;
            }else {
                balance--;
            }
            if(balance == 0){
                if(i != s.length() - 1){
                    String A = s.substring(0, i + 1);
                    String B = s.substring(i + 1);
                    return scoreOfParentheses(A) + scoreOfParentheses(B);
                }
            }
        }
        String in = s.substring(1, s.length() - 1);
        return 2 * scoreOfParentheses(in);
    }
}
```

## [842. 将数组拆分成斐波那契序列](https://leetcode.cn/problems/split-array-into-fibonacci-sequence/)

### 题目

给定一个数字字符串 `num`，比如 `"123456579"`，我们可以将它分成「斐波那契式」的序列 `[123, 456, 579]`。

形式上，**斐波那契式** 序列是一个非负整数列表 `f`，且满足：

- `0 <= f[i] < 231` ，（也就是说，每个整数都符合 **32 位** 有符号整数类型）
- `f.length >= 3`
- 对于所有的`0 <= i < f.length - 2`，都有 `f[i] + f[i + 1] = f[i + 2]`

另外，请注意，将字符串拆分成小块时，每个块的数字一定不要以零开头，除非这个块是数字 `0` 本身。

返回从 `num` 拆分出来的任意一组斐波那契式的序列块，如果不能拆分则返回 `[]`。

 

**示例 1：**

```
输入：num = "1101111"
输出：[11,0,11,11]
解释：输出 [110,1,111] 也可以。
```

**示例 2：**

```
输入: num = "112358130"
输出: []
解释: 无法拆分。
```

**示例 3：**

```
输入："0123"
输出：[]
解释：每个块的数字不能以零开头，因此 "01"，"2"，"3" 不是有效答案。
```

 

**提示：**

- `1 <= num.length <= 200`
- `num` 中只含有数字

### 题解

#### 思路总结

利用**枚举前两个数字 + 贪心验证后续序列**解决问题。斐波那契式序列只要前两个数字 `x`、`y` 确定，后面的数字就全部唯一确定，因此不需要对后续每个位置继续枚举，只需要不断计算 `next = x + y`，然后判断 `num` 从当前位置开始是否恰好以 `next` 的十进制形式开头。

枚举前两个数字时需要同时处理两个限制：数字不能超过 `Integer.MAX_VALUE`，并且除数字 `0` 本身之外不能出现前导零。如果后续所有计算得到的数字都能够依次匹配，并且最终恰好消费完整个字符串，就得到一组合法斐波那契序列。

------

#### 解题步骤

1. **枚举第一个数字结尾：** 使用 `i` 将字符串前缀 `num[0, i)` 作为第一个数字，并保证后面至少还能留下两个数字的位置。
2. **处理第一个数字前导零：** 如果字符串以 `'0'` 开头，那么第一个数字只能是单独的 `0`，长度超过 `1` 时直接结束枚举。
3. **校验第一个数字范围：** 第一个数字必须不超过 `Integer.MAX_VALUE`，超过后由于继续增加位数只会更大，可以结束当前循环。
4. **枚举第二个数字结尾：** 使用 `j` 将 `num[i, j)` 作为第二个数字，并保证字符串后面仍然存在内容。
5. **处理第二个数字前导零：** 如果 `num[i] == '0'`，那么第二个数字同样只能取单独的 `0`。
6. **初始化斐波那契序列：** 将前两个数字加入结果集合，并从位置 `j` 开始验证后续字符串。
7. **计算下一个数字：** 使用 `next = a + b` 得到唯一应该出现的下一个数字，并判断是否超过 32 位整数范围。
8. **匹配后续字符串：** 将 `next` 转换成字符串，判断 `num` 从当前位置是否以该字符串开头。
9. **更新斐波那契状态：** 匹配成功后加入 `next`，移动字符串位置，并令 `a = b`、`b = next`。
10. **判断是否完整匹配：** 如果最终位置恰好到达字符串末尾，则返回当前序列；所有前两个数字组合都失败时返回空列表。

```java
class Solution {
    public List<Integer> splitIntoFibonacci(String num) {
        int n = num.length();
        for(int i = 1; i <= n - 2; i++){
            if (num.charAt(0) == '0' && i > 1) {
                break;
            }
            long x = Long.parseLong(num.substring(0, i));
            if(x > Integer.MAX_VALUE){
                break;
            }
            for(int j = i + 1; j <= n - 1; j++){
                if(num.charAt(i) == '0' && j > i + 1){
                    break;
                }
                long y = Long.parseLong(num.substring(i, j));
                if(y > Integer.MAX_VALUE){
                    break;
                }
                int index = j;
                List<Integer> ans = new ArrayList<>();
                ans.add((int) x);
                ans.add((int) y);
                long a = x;
                long b = y;
                while(index < n){
                    long next = a + b;
                    if(next > Integer.MAX_VALUE){
                        break;
                    }
                    String pre = String.valueOf(next);
                    if(!num.startsWith(pre, index)){
                        break;
                    }
                    ans.add(Integer.valueOf(pre));
                    index += pre.length();
                    a = b;
                    b = next;
                }
                if(index == n){
                    return ans;
                }
            }
        }
        return new ArrayList<>();
    }
}
```

## [819. 最常见的单词](https://leetcode.cn/problems/most-common-word/)

### 题目

给你一个字符串 `paragraph` 和一个表示禁用词的字符串数组 `banned` ，返回出现频率最高的非禁用词。题目数据 **保证** 至少存在一个非禁用词，且答案 **唯一** 。

`paragraph` 中的单词 **不区分大小写** ，答案应以 **小写** 形式返回。

**注意** 单词不包含标点符号。

 

**示例 1：**

```
输入：paragraph = "Bob hit a ball, the hit BALL flew far after it was hit.", banned = ["hit"]
输出："ball"
解释：
"hit" 出现了 3 次，但它是禁用词。
"ball" 出现了两次（没有其他单词出现这么多次），因此它是段落中出现频率最高的非禁用词。
请注意，段落中的单词不区分大小写，
标点符号会被忽略（即使它们紧挨着单词，如 "ball,"），
并且尽管 "hit" 出现的次数更多，但它不能作为答案，因为它是禁用词。
```

**示例 2：**

```
输入：paragraph = "a.", banned = []
输出："a"
```

 

**提示：**

- `1 <= paragraph.length <= 1000`
- `paragraph` 由英文字母、空格 `' '`、和以下符号组成：`"!?',;."`
- `0 <= banned.length <= 100`
- `1 <= banned[i].length <= 10`
- `banned[i]` 仅由小写英文字母组成

### 题解

#### 思路总结

当前实现采用**一次扫描 + 哈希计数**。先把 `banned` 放入 `HashSet`，随后逐字符扫描 `paragraph`：遇到字母就统一转成小写并加入当前单词，遇到空格或标点符号时就结算已经构造完成的单词。

结算时只统计非禁用词，并在更新词频的同时维护最高频率 `max` 和答案 `ans`。

------

#### 解题步骤

1. **建立禁用词集合：** 将 `banned` 中的所有单词加入 `HashSet`，用于快速判断当前单词是否被禁用。
2. **初始化词频表：** 使用 `HashMap` 保存每个非禁用词已经出现的次数。
3. **初始化单词缓冲区：** 使用 `StringBuilder word` 保存当前正在读取的单词。
4. **扫描整个段落：** 从下标 `0` 遍历到 `paragraph.length()`，额外的一次循环用于处理最后一个单词。
5. **收集字母字符：** 当前字符是字母时，将其转换为小写后加入 `word`。
6. **结算完整单词：** 遇到空格、标点或字符串末尾时，如果 `word` 非空，则说明已经得到一个完整单词。
7. **过滤禁用词：** 如果当前单词不在 `bannedSet` 中，就更新其出现次数。
8. **同步维护最大频率：** 如果当前单词的新频率超过 `max`，立即更新 `max` 和 `ans`。
9. **清空单词缓冲区：** 使用 `word.setLength(0)` 清空内容，为下一个单词做准备。
10. **返回最终答案：** 扫描结束后返回出现次数最多的非禁用词。

```java
class Solution {
    public String mostCommonWord(String paragraph, String[] banned) {
        Set<String> bannedSet = new HashSet<>(Arrays.asList(banned));
        Map<String, Integer> count = new HashMap<>();

        StringBuilder word = new StringBuilder();
        String ans = "";
        int max = 0;

        for (int i = 0; i <= paragraph.length(); i++) {
            if (i < paragraph.length() && Character.isLetter(paragraph.charAt(i))) {
                word.append(Character.toLowerCase(paragraph.charAt(i)));
            } else if (!word.isEmpty()) {
                String s = word.toString();

                if (!bannedSet.contains(s)) {
                    int freq = count.getOrDefault(s, 0) + 1;
                    count.put(s, freq);

                    if (freq > max) {
                        max = freq;
                        ans = s;
                    }
                }

                word.setLength(0);
            }
        }

        return ans;
    }
}
```

## [816. 模糊坐标](https://leetcode.cn/problems/ambiguous-coordinates/)

### 题目

我们有一些二维坐标，如 `"(1, 3)"` 或 `"(2, 0.5)"`，然后我们移除所有逗号，小数点和空格，得到一个字符串`S`。返回所有可能的原始字符串到一个列表中。

原始的坐标表示法不会存在多余的零，所以不会出现类似于"00", "0.0", "0.00", "1.0", "001", "00.01"或一些其他更小的数来表示坐标。此外，一个小数点前至少存在一个数，所以也不会出现“.1”形式的数字。

最后返回的列表可以是任意顺序的。而且注意返回的两个数字中间（逗号之后）都有一个空格。

 

```
示例 1:
输入: "(123)"
输出: ["(1, 23)", "(12, 3)", "(1.2, 3)", "(1, 2.3)"]
示例 2:
输入: "(00011)"
输出:  ["(0.001, 1)", "(0, 0.011)"]
解释: 
0.0, 00, 0001 或 00.01 是不被允许的。
示例 3:
输入: "(0123)"
输出: ["(0, 123)", "(0, 12.3)", "(0, 1.23)", "(0.1, 23)", "(0.1, 2.3)", "(0.12, 3)"]
示例 4:
输入: "(100)"
输出: [(10, 0)]
解释: 
1.0 是不被允许的。
```

 

**提示:**

- `4 <= S.length <= 12`.
- `S[0]` = "(", `S[S.length - 1]` = ")", 且字符串 `S` 中的其他元素都是数字。

### 题解

#### 思路总结

当前实现采用**枚举坐标分割位置 + 枚举小数点位置**。首先去掉最外层括号的影响，在数字串中枚举一个分割点，将原字符串拆成横坐标 `pre` 和纵坐标 `end`；然后分别调用 `addPoint()`，生成这两个数字串所有合法的整数或小数形式，最后对两边的合法结果做笛卡尔积组合成坐标。

`addPoint()` 的核心是判断数字表示是否合法：整数不能有前导零；小数的整数部分同样不能有前导零，而小数部分不能以 `0` 结尾，否则会产生 `"1.0"`、`"0.010"` 这种多余的零。

------

#### 解题步骤

1. **枚举坐标分割点：** 在原数字串内部枚举位置 `i`，将数字部分拆成左侧横坐标和右侧纵坐标。
2. **生成横坐标形式：** 调用 `addPoint(pre)`，得到左侧数字串所有合法的整数和小数表示。
3. **生成纵坐标形式：** 调用 `addPoint(end)`，得到右侧数字串所有合法表示。
4. **处理单个数字：** 如果数字串长度为 `1`，它本身一定是合法整数，直接加入结果。
5. **判断整数形式：** 如果数字串长度大于 `1`，只有首字符不是 `'0'` 时才能直接作为整数。
6. **枚举小数点位置：** 在数字串内部枚举小数点，将其拆成整数部分 `pre` 和小数部分 `end`。
7. **校验小数合法性：** 整数部分不能存在前导零，小数部分最后一个字符不能是 `'0'`。
8. **组合坐标结果：** 对横坐标和纵坐标的所有合法形式两两组合，生成 `"(x, y)"`。
9. **返回所有坐标：** 所有分割位置处理结束后返回结果列表。

```java
class Solution {
    public List<String> ambiguousCoordinates(String s) {
        int n = s.length();
        List<String> ans = new ArrayList<>();
        for(int i = 2; i <= n - 2; i++){
            String pre = s.substring(1, i);
            String end = s.substring(i, n - 1);
            List<String> pres = addPoint(pre);
            List<String> ends = addPoint(end);
            for(String s1 : pres){
                for(String s2 : ends){
                    ans.add('(' + s1 + ", " + s2 + ')');
                }
            }
        }
        return ans;
    }

    private List<String> addPoint(String s){
        List<String> res = new ArrayList<>();
        int n = s.length();
        if(n == 1){
            res.add(s);
            return res;
        }
        if(judge(s, 0)){
            res.add(s);
        }
        for(int i = 1; i <= n - 1; i++){
            String pre = s.substring(0, i);
            String end = s.substring(i);
            if(judge(pre, 0) && judge(end, 1)){
                res.add(pre + '.' + end);
            }
        }
        return res;
    }

    private boolean judge(String s, int flag){
        if(flag == 0){
            if(s.length() == 1){
                return true;
            }
            return s.charAt(0) != '0';
        }
        return s.charAt(s.length() - 1) != '0';
    }
}
```

## [767. 重构字符串](https://leetcode.cn/problems/reorganize-string/)

### 题目

给定一个字符串 `s` ，检查是否能重新排布其中的字母，使得两相邻的字符不同。

返回 *`s` 的任意可能的重新排列。若不可行，返回空字符串 `""`* 。

 

**示例 1:**

```
输入: s = "aab"
输出: "aba"
```

**示例 2:**

```
输入: s = "aaab"
输出: ""
```

 

**提示:**

- `1 <= s.length <= 500`
- `s` 只包含小写字母

### 题解

#### 思路总结

当前实现采用**计数 + 奇偶下标填充**。先统计 26 个字母的出现次数，并找到出现次数最多的字符。由于相同字符之间至少需要插入一个其他字符，因此最大频次不能超过 `(n + 1) / 2`；一旦超过，就不可能完成重排，直接返回空字符串。

在可行的情况下，先把出现次数最多的字符放到 `0、2、4...` 这些偶数位置，从而尽可能把它们分隔开。然后再依次填充其他字符：继续填剩余偶数位置，偶数位置用完后转到 `1、3、5...` 的奇数位置。这样可以保证最终不存在两个相邻的相同字符。

------

#### 解题步骤

1. **统计字符频次：** 使用长度为 `26` 的 `count` 数组统计每个小写字母出现的次数。
2. **寻找最高频字符：** 遍历 `count`，找到出现次数最多的字符下标 `maxIndex`。
3. **判断是否能够重排：** 如果最高频字符出现次数大于 `(n + 1) / 2`，则无法让相同字符全部隔开，返回空字符串。
4. **创建结果数组：** 使用长度为 `n` 的字符数组 `ans` 保存最终排列结果。
5. **优先填充最高频字符：** 从下标 `0` 开始，每次增加 `2`，将最高频字符依次放入偶数位置。
6. **填充其他字符：** 遍历剩余字符，继续按照间隔为 `2` 的方式依次填入结果数组。
7. **切换到奇数位置：** 当偶数位置已经填满时，将 `index` 设置为 `1`，继续填充 `1、3、5...`。
8. **构造最终字符串：** 所有字符填充完成后，将字符数组转换成字符串并返回。

```java
class Solution {
    public String reorganizeString(String s) {
        int[] count = new int[26];
        int n = s.length();
        for(char c : s.toCharArray()){
            count[c - 'a']++;
        }

        int maxIndex = 0;
        for (int i = 1; i < 26; i++) {
            if (count[i] > count[maxIndex]) {
                maxIndex = i;
            }
        }

        if (count[maxIndex] > (n + 1) / 2) {
            return "";
        }

        char[] ans = new char[n];
        int index = 0;

        while (count[maxIndex] > 0) {
            ans[index] = (char) (maxIndex + 'a');
            index += 2;
            count[maxIndex]--;
        }

        for (int i = 0; i < 26; i++) {
            while (count[i] > 0) {
                if (index >= n) {
                    index = 1;
                }

                ans[index] = (char) (i + 'a');
                index += 2;
                count[i]--;
            }
        }

        return new String(ans);
    }
}
```

## [696. 计数二进制子串](https://leetcode.cn/problems/count-binary-substrings/)

### 题目

给定一个字符串 `s`，统计并返回具有相同数量 `0` 和 `1` 的非空（连续）子字符串的数量，并且这些子字符串中的所有 `0` 和所有 `1` 都是成组连续的。

重复出现（不同位置）的子串也要统计它们出现的次数。

 

**示例 1：**

```
输入：s = "00110011"
输出：6
解释：6 个子串满足具有相同数量的连续 1 和 0 ："0011"、"01"、"1100"、"10"、"0011" 和 "01" 。
注意，一些重复出现的子串（不同位置）要统计它们出现的次数。
另外，"00110011" 不是有效的子串，因为所有的 0（还有 1 ）没有组合在一起。
```

**示例 2：**

```
输入：s = "10101"
输出：4
解释：有 4 个子串："10"、"01"、"10"、"01" ，具有相同数量的连续 1 和 0 。
```

 

**提示：**

- `1 <= s.length <= 105`
- `s[i]` 为 `'0'` 或 `'1'`

### 题解

#### 思路总结

当前实现采用**连续分组计数 + 相邻分组取最小值**。先把字符串按照连续相同字符划分成若干组，并记录每组长度。例如：

```
"00110011" -> [2, 2, 2, 2]
```

一个合法子字符串只能跨越**相邻的两个字符组**，并且其中 `0` 和 `1` 的数量必须相同。假设相邻两组长度分别为 `a` 和 `b`，那么能够组成的合法子字符串数量就是 `min(a, b)`。因此最终答案就是所有相邻分组长度最小值之和。

------

#### 解题步骤

1. **初始化当前分组长度：** 设置 `count = 1`，表示第一个字符所在连续分组当前长度为 1。
2. **扫描字符串：** 从第二个字符开始，与前一个字符进行比较。
3. **扩展当前分组：** 如果当前字符与前一个字符相同，则执行 `count++`。
4. **结束当前分组：** 如果当前字符发生变化，将当前分组长度加入 `list`，然后重置 `count = 1`。
5. **保存最后一个分组：** 字符串遍历结束后，将最后一个连续分组长度加入 `list`。
6. **遍历相邻分组：** 对 `list` 中每两个相邻的分组长度进行处理。
7. **计算合法子串数量：** 相邻分组能够形成的合法子字符串数量为两组长度的较小值。
8. **累加最终结果：** 将所有 `Math.min(list[i - 1], list[i])` 累加后返回。

```java
class Solution {
    public int countBinarySubstrings(String s) {
        int ans = 0;
        int n = s.length();
        List<Integer> list = new ArrayList<>();
        int count = 1;
        for(int i = 1; i < n; i++){
            if(s.charAt(i) != s.charAt(i - 1)){
                list.add(count);
                count = 1;
            }else {
                count++;
            }
        }
        list.add(count);
        for(int i = 1; i < list.size(); i++){
            ans += Math.min(list.get(i), list.get(i - 1));
        }
        return ans;
    }
}
```

## [647. 回文子串](https://leetcode.cn/problems/palindromic-substrings/)

### 题目

给你一个字符串 `s` ，请你统计并返回这个字符串中 **回文子串** 的数目。

**回文字符串** 是正着读和倒过来读一样的字符串。

**子字符串** 是字符串中的由连续字符组成的一个序列。

 

**示例 1：**

```
输入：s = "abc"
输出：3
解释：三个回文子串: "a", "b", "c"
```

**示例 2：**

```
输入：s = "aaa"
输出：6
解释：6个回文子串: "a", "a", "a", "aa", "aa", "aaa"
```

 

**提示：**

- `1 <= s.length <= 1000`
- `s` 由小写英文字母组成

### 题解一

#### 思路总结

当前实现采用**区间动态规划**。定义 `dp[i][j]` 表示子串 `s[i...j]` 是否为回文串。一个子串能够成为回文串，需要满足首尾字符相同，并且中间部分同样是回文串，因此状态转移为：

```
dp[i][j] = s[i] == s[j] && (j - i <= 1 || dp[i + 1][j - 1])
```

其中 `j - i <= 1` 用于处理长度为 `1` 和 `2` 的子串。由于 `dp[i][j]` 依赖左下方的 `dp[i + 1][j - 1]`，所以 `i` 必须从右向左遍历，而 `j` 从 `i` 向右遍历。每发现一个回文区间，就将答案加一。

------

#### 解题步骤

1. **定义 DP 状态：** 使用 `dp[i][j]` 表示子串 `s[i...j]` 是否为回文子串。
2. **逆序枚举左端点：** `i` 从 `n - 1` 向 `0` 遍历，保证计算当前状态时 `dp[i + 1][j - 1]` 已经得到结果。
3. **正序枚举右端点：** 对每个 `i`，令 `j` 从 `i` 向右遍历所有可能的子串。
4. **判断首尾字符：** 只有 `s[i] == s[j]` 时，当前子串才可能是回文串。
5. **处理短子串：** 当 `j - i <= 1` 时，长度为 `1` 或 `2`，只要首尾字符相同即可判定为回文。
6. **检查内部区间：** 对长度大于 `2` 的子串，需要进一步满足 `dp[i + 1][j - 1] == true`。
7. **记录回文状态：** 满足条件时令 `dp[i][j] = true`。
8. **统计回文数量：** 每产生一个新的回文区间就执行 `ans++`，最后返回答案。

```java
class Solution {
    public int countSubstrings(String s) {
        int n = s.length();

        boolean[][] dp = new boolean[n][n];

        int ans = 0;
        for(int i = n - 1; i >= 0; i--){
            for(int j = i; j < n; j++){
                if(s.charAt(i) == s.charAt(j) && (j - i <= 1 || dp[i + 1][j - 1])){
                    dp[i][j] = true;
                    ans++;
                }
            }
        }
        return ans;
    }
}
```

### 题解二

#### 思路总结

当前实现采用**中心扩展法**统计回文子串。每一个回文串都可以确定一个中心，因此只需要枚举所有可能的中心，然后不断向左右两侧扩展，只要左右字符相同，就说明当前区间形成了一个新的回文子串。

回文串分为两种：奇数长度回文以某个字符为中心，对应 `expand(s, i, i)`；偶数长度回文以两个字符之间的位置为中心，对应 `expand(s, i, i + 1)`。每个回文子串都有唯一的中心，因此不会重复统计。当前实现时间复杂度为 **O(n²)**，辅助空间为 **O(1)**。

------

#### 解题步骤

1. **枚举回文中心：** 从左到右遍历字符串中的每个位置 `i`。
2. **统计奇数长度回文：** 调用 `expand(s, i, i)`，以当前字符本身作为中心向两侧扩展。
3. **统计偶数长度回文：** 调用 `expand(s, i, i + 1)`，以当前字符和下一个字符之间作为中心扩展。
4. **检查左右边界：** 在 `expand()` 中保证 `l >= 0` 且 `r < n`，避免数组越界。
5. **检查字符是否相同：** 如果 `s[l] == s[r]`，说明区间 `[l, r]` 是一个回文子串。
6. **累计当前回文：** 每成功扩展一层执行 `count++`。
7. **继续向外扩展：** 执行 `l--`、`r++`，尝试得到更长的回文子串。
8. **汇总所有中心：** 将每次 `expand()` 返回的数量累加到 `ans`，最终返回总数。

```java
class Solution {
    public int countSubstrings(String s) {
        int n = s.length();
        int ans = 0;
        for(int i = 0; i < n; i++){
            ans += expand(s, i, i);
            ans += expand(s, i, i + 1);
        }
        return ans;
    }

    private int expand(String s, int l, int r){
        int count = 0;
        int n = s.length();
        while(l >= 0 && r < n && s.charAt(l) == s.charAt(r)){
            count++;
            l--;
            r++;
        }
        return count;
    }
}
```

## [632. 最小区间](https://leetcode.cn/problems/smallest-range-covering-elements-from-k-lists/)

### 题目

你有 `k` 个 **非递减排列** 的整数列表。找到一个 **最小** 区间，使得 `k` 个列表中的每个列表至少有一个数包含在其中。

我们定义如果 `b-a < d-c` 或者在 `b-a == d-c` 时 `a < c`，则区间 `[a,b]` 比 `[c,d]` 小。

 

**示例 1：**

```
输入：nums = [[4,10,15,24,26], [0,9,12,20], [5,18,22,30]]
输出：[20,24]
解释： 
列表 1：[4, 10, 15, 24, 26]，24 在区间 [20,24] 中。
列表 2：[0, 9, 12, 20]，20 在区间 [20,24] 中。
列表 3：[5, 18, 22, 30]，22 在区间 [20,24] 中。
```

**示例 2：**

```
输入：nums = [[1,2,3],[1,2,3],[1,2,3]]
输出：[1,1]
```

 

**提示：**

- `nums.length == k`
- `1 <= k <= 3500`
- `1 <= nums[i].length <= 50`
- `-105 <= nums[i][j] <= 105`
- `nums[i]` 按非递减顺序排列

### 题解

#### 思路总结

当前实现采用**最小堆 + 维护当前最大值**。堆中始终保存每个列表当前选中的一个元素，因此只要堆中有 `k` 个元素，堆顶最小值 `min` 和维护的最大值 `max` 就构成一个至少覆盖每个列表一个元素的合法区间 `[min, max]`。

要想让当前区间进一步缩小，只能尝试增大左端点，因此每次弹出堆顶，也就是当前最小元素，并将它所属列表的下一个元素加入堆中，同时更新 `max`。如果某个列表已经没有下一个元素，就无法再维持“每个列表至少选一个元素”的条件，可以直接结束。

------

#### 解题步骤

1. **初始化最小堆：** 将每个列表的第一个元素加入堆中，同时记录元素值、所属列表下标和列表内部下标。
2. **维护当前最大值：** 初始化过程中不断更新 `max`，使其表示当前堆中元素的最大值。
3. **初始化答案区间：** 当前堆已经包含每个列表的一个元素，因此 `[堆顶值, max]` 是第一个合法区间。
4. **取出当前最小值：** 每次从最小堆弹出 `minNode`，其值 `min` 就是当前合法区间的左端点。
5. **更新最优答案：** 比较 `[min, max]` 与当前答案的长度，长度更小时更新；长度相同时选择左端点更小的区间。
6. **推进最小值所在列表：** 只有替换当前最小元素，才有可能增大左端点并得到更小的区间。
7. **判断是否能够继续：** 如果该列表已经没有下一个元素，则无法再构造覆盖全部 `k` 个列表的候选区间，直接结束循环。
8. **加入下一个元素：** 将该列表中的下一个元素加入最小堆，并使用它更新当前最大值 `max`。
9. **重复搜索：** 不断执行弹出最小值和推进对应列表的过程，直到某个列表耗尽。
10. **返回最优区间：** 循环结束后返回记录的最小区间。

```java
class Solution {
    class Node{
        int val;
        int numsIndex;
        int index;

        Node(int val, int numsIndex, int index){
            this.val = val;
            this.index = index;
            this.numsIndex = numsIndex;
        }
    }
    public int[] smallestRange(List<List<Integer>> nums) {
        PriorityQueue<Node> minHeap = new PriorityQueue<>(Comparator.comparingInt(a -> a.val));
        int max = Integer.MIN_VALUE;
        for(int i = 0; i < nums.size(); i++){
            List<Integer> num = nums.get(i);
            int val = num.get(0);
            minHeap.offer(new Node(val, i, 0));
            max = Math.max(max, val);
        }
        int[] ans = new int[] {minHeap.peek().val, max};

        while(true){
            Node minNode = minHeap.poll();
            int min = minNode.val;
            if(max - min < ans[1] - ans[0] || (max - min == ans[1] - ans[0] && min < ans[0])){
                ans[0] = min;
                ans[1] = max;
            }

            int listIndex = minNode.numsIndex;

            int nextIndex = minNode.index + 1;

            if (nextIndex == nums.get(listIndex).size()) {
                break;
            }
            int nextValue = nums.get(listIndex).get(nextIndex);

            minHeap.offer(new Node(nextValue, listIndex, nextIndex));

            // 更新最大值
            max = Math.max(max, nextValue);
        }
        return ans;
    }
}
```

## [583. 两个字符串的删除操作](https://leetcode.cn/problems/delete-operation-for-two-strings/)

### 题目

给定两个单词 `word1` 和 `word2` ，返回使得 `word1` 和 `word2` **相同**所需的**最小步数**。

**每步** 可以删除任意一个字符串中的一个字符。

 

**示例 1：**

```
输入: word1 = "sea", word2 = "eat"
输出: 2
解释: 第一步将 "sea" 变为 "ea" ，第二步将 "eat "变为 "ea"
```

**示例  2:**

```
输入：word1 = "leetcode", word2 = "etco"
输出：4
```

 

**提示：**

- `1 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 只包含小写英文字母

### 题解一

#### 思路总结

当前实现将问题转化为**最长公共子序列（LCS）**。最终要让 `word1` 和 `word2` 通过删除字符变成同一个字符串，那么保留下来的部分必须同时是两个字符串的公共子序列。为了让删除次数最少，就应该尽可能多地保留字符，因此保留下来的字符串应当是两者的**最长公共子序列**。

设最长公共子序列长度为 `L`，那么 `word1` 需要删除 `m - L` 个字符，`word2` 需要删除 `n - L` 个字符，所以最少删除次数为：

```
(m - L) + (n - L) = m + n - 2L
```

------

#### 解题步骤

1. **定义 DP 状态：** `dp[i][j]` 表示 `word1` 前 `i` 个字符和 `word2` 前 `j` 个字符的最长公共子序列长度。
2. **初始化边界状态：** 当任意一个字符串长度为 `0` 时，最长公共子序列长度为 `0`，因此第一行和第一列默认都是 `0`。
3. **比较当前字符：** 判断 `word1.charAt(i - 1)` 和 `word2.charAt(j - 1)` 是否相同。
4. **处理字符相同：** 如果两个字符相同，则可以将该字符加入公共子序列，得到 `dp[i][j] = dp[i - 1][j - 1] + 1`。
5. **处理字符不同：** 如果两个字符不同，则至少舍弃其中一个字符，取 `dp[i - 1][j]` 和 `dp[i][j - 1]` 的较大值。
6. **得到最长公共子序列：** 遍历完成后，`dp[m][n]` 就是两个字符串的 LCS 长度。
7. **计算 word1 删除次数：** 需要删除 `m - dp[m][n]` 个字符。
8. **计算 word2 删除次数：** 需要删除 `n - dp[m][n]` 个字符。
9. **返回最少删除次数：** 返回两个字符串删除次数之和。

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        for(int i = 1; i <= m; i++){
            for(int j = 1; j <= n; j++){
                if(word1.charAt(i - 1) == word2.charAt(j - 1)){
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        int max = dp[m][n];
        return m - max + n - max;
    }
}
```

### 题解二

#### 思路总结

当前实现采用**直接动态规划求最少删除次数**。定义 `dp[i][j]` 表示让 `word1` 的前 `i` 个字符和 `word2` 的前 `j` 个字符变得相同，最少需要删除多少个字符。

如果当前两个字符相同，那么这两个字符都可以保留，问题直接转化为前面的子问题 `dp[i - 1][j - 1]`；如果不同，则必须删除其中至少一个字符，可以删除 `word1` 当前字符得到 `dp[i - 1][j] + 1`，或者删除 `word2` 当前字符得到 `dp[i][j - 1] + 1`，取两者较小值。

------

#### 解题步骤

1. **定义 DP 状态：** `dp[i][j]` 表示 `word1` 前 `i` 个字符和 `word2` 前 `j` 个字符变成相同字符串所需的最少删除次数。
2. **初始化第一列：** 当 `word2` 为空时，只能删除 `word1` 的全部 `i` 个字符，因此 `dp[i][0] = i`。
3. **初始化第一行：** 当 `word1` 为空时，只能删除 `word2` 的全部 `j` 个字符，因此 `dp[0][j] = j`。
4. **比较当前字符：** 判断 `word1[i - 1]` 与 `word2[j - 1]` 是否相同。
5. **处理字符相同：** 两个字符可以同时保留，因此 `dp[i][j] = dp[i - 1][j - 1]`。
6. **处理字符不同：** 删除 `word1` 当前字符或删除 `word2` 当前字符，取 `dp[i - 1][j]` 和 `dp[i][j - 1]` 的较小值后加 `1`。
7. **完成所有状态计算：** 按照从上到下、从左到右的顺序填充整个 DP 表。
8. **返回最终答案：** `dp[m][n]` 即两个完整字符串变成相同所需的最少删除次数。

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[][] dp = new int[m + 1][n + 1];
        for(int i = 0; i <= m; i++){
            dp[i][0] = i;
        }
        for(int j = 0; j <= n; j++){
            dp[0][j] = j;
        }
        for(int i = 1; i <= m; i++){
            for(int j = 1; j <= n; j++){
                if(word1.charAt(i - 1) == word2.charAt(j - 1)){
                    dp[i][j] = dp[i - 1][j - 1];
                }else {
                    dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + 1;
                }
            }
        }
        return dp[m][n];
    }
}
```

## [541. 反转字符串 II](https://leetcode.cn/problems/reverse-string-ii/)

### 题目

给定一个字符串 `s` 和一个整数 `k`，从字符串开头算起，每计数至 `2k` 个字符，就反转这 `2k` 字符中的前 `k` 个字符，再重新计数。

- 如果剩余字符少于 `k` 个，则将剩余字符全部反转。
- 如果剩余字符小于 `2k` 但大于或等于 `k` 个，则反转前 `k` 个字符，其余字符保持原样。

 

**示例 1：**

```
输入：s = "abcdefg", k = 2
输出："bacdfeg"
```

**示例 2：**

```
输入：s = "abcd", k = 2
输出："bacd"
```

 

**提示：**

- `1 <= s.length <= 104`
- `s` 仅由小写英文组成
- `1 <= k <= 104`

### 题解

#### 思路总结

当前实现采用**字符数组 + 分组原地反转**。将字符串转成 `char[]` 后，以 `2k` 为步长枚举每一组，只反转当前组中的前 `k` 个字符，其余字符保持原样。

反转区间的右端点使用 `Math.min(i + k - 1, n - 1)`，因此能够自然覆盖所有情况：剩余字符不少于 `2k` 时反转前 `k` 个；剩余字符在 `[k, 2k)` 时仍反转前 `k` 个；剩余字符不足 `k` 时直接反转全部剩余字符。整个实现不需要额外判断尾部情况，逻辑简洁且正确。

------

#### 解题步骤

1. **转换字符数组：** 将字符串 `s` 转换成 `char[]`，方便直接交换字符。
2. **按 2k 分组遍历：** 使用 `i += 2 * k`，每次定位一个需要处理的字符块。
3. **确定反转左端点：** 当前分组的起点 `i` 就是需要反转部分的左边界。
4. **确定反转右端点：** 使用 `Math.min(i + k - 1, n - 1)`，保证尾部不足 `k` 个字符时不会越界。
5. **双指针交换字符：** 使用 `left` 和 `right` 从两端向中间移动，不断交换字符。
6. **保留后半部分不变：** 当前 `2k` 分组中剩余字符无需处理，直接进入下一组。
7. **继续处理后续分组：** 起点增加 `2k`，重复上述过程。
8. **构造最终字符串：** 使用修改后的字符数组创建并返回结果字符串。

```java
class Solution {
    public String reverseStr(String s, int k) {
        char[] chars = s.toCharArray();
        int n = chars.length;

        for (int i = 0; i < n; i += 2 * k) {
            int left = i;
            int right = Math.min(i + k - 1, n - 1);

            while (left < right) {
                char temp = chars[left];
                chars[left] = chars[right];
                chars[right] = temp;

                left++;
                right--;
            }
        }

        return new String(chars);
    }
}
```

```
解释：(1 - i) * (1 - i) = 1 + i2 - 2 * i = -2i ，你需要将它转换为 0+-2i 的形式。 
```

 

**提示：**

- `num1` 和 `num2` 都是有效的复数表示。

### 题解

#### 思路总结

当前实现采用**字符串解析 + 复数乘法公式**。先将两个复数分别解析成实部 `a1、a2` 和虚部 `b1、b2`，然后根据复数乘法公式计算结果：

```
(a1 + b1i)(a2 + b2i) = (a1a2 - b1b2) + (a1b2 + a2b1)i
```

题目的格式固定为 `"实部+虚部i"`，即使虚部是负数，也会写成 `"1+-1i"`，因此使用 `"+"` 作为分隔位置是可行的。

------

#### 解题步骤

1. **拆分第一个复数：** 按照 `'+'` 将 `num1` 分成实部和带有 `'i'` 的虚部。
2. **解析第一个实部：** 使用 `Integer.parseInt()` 将第一部分转换成整数 `a1`。
3. **解析第一个虚部：** 去掉第二部分末尾的 `'i'`，再转换成整数 `b1`。
4. **拆分第二个复数：** 使用相同方式得到第二个复数的实部 `a2` 和虚部 `b2`。
5. **计算结果实部：** 根据公式计算 `a3 = a1 * a2 - b1 * b2`。
6. **计算结果虚部：** 根据公式计算 `b3 = a1 * b2 + a2 * b1`。
7. **拼接结果字符串：** 按照 `"实部+虚部i"` 的固定格式生成最终结果。
8. **返回乘积：** 返回构造完成的复数字符串。

```java
class Solution {
    public String complexNumberMultiply(String num1, String num2) {
        String[] s1 = num1.split("\\+");
        int a1 = Integer.parseInt(s1[0]);
        int b1 = Integer.parseInt(s1[1].replace("i", ""));
        String[] s2 = num2.split("\\+");
        int a2 = Integer.parseInt(s2[0]);
        int b2 = Integer.parseInt(s2[1].replace("i", ""));
        int a3 = a1 * a2 - b1 * b2;
        int b3 = a1 * b2 + a2 * b1;
        return String.valueOf(a3) + '+' + String.valueOf(b3) + 'i';
    }
}
```

### 题目

给定一个字符串 `s` ，找到 *它的第一个不重复的字符，并返回它的索引* 。如果不存在，则返回 `-1` 。

 

**示例 1：**

```
输入: s = "leetcode"
输出: 0
```

**示例 2:**

```
输入: s = "loveleetcode"
输出: 2
```

**示例 3:**

```
输入: s = "aabb"
输出: -1
```

 

**提示:**

- `1 <= s.length <= 105`
- `s` 只包含小写字母

### 题解

#### 思路总结

当前实现采用**字符频次统计 + 查找最早唯一字符位置**。首先使用长度为 `26` 的数组统计每个小写字母出现的次数，然后遍历 26 个字母，对于只出现一次的字符，通过 `indexOf()` 找到它在字符串中的位置，并维护其中最小的下标。

------

#### 解题步骤

1. **初始化频次数组：** 创建长度为 `26` 的 `count`，分别记录 `'a' ~ 'z'` 的出现次数。
2. **统计字符频率：** 遍历字符串，将当前字符对应的 `count` 加一。
3. **遍历所有字母：** 检查 26 个字母中哪些字符的出现次数恰好为 `1`。
4. **查找唯一字符位置：** 对每个只出现一次的字符调用 `indexOf()` 获取其在字符串中的下标。
5. **维护最小下标：** 在所有只出现一次的字符位置中记录最小值。
6. **返回最终结果：** 如果存在唯一字符则返回最小下标，否则返回 `-1`。

```java
class Solution {
    public int firstUniqChar(String s) {
        int[] count = new int[26];
        for(char c : s.toCharArray()){
            count[c - 'a']++;
        }
        int ans = -1;
        for(int i = 0; i < 26; i++){
            if(count[i] == 1){
                int index = s.indexOf(i + 'a');
                if(ans == -1){
                    ans = index;
                }else {
                    ans = Math.min(ans, index);
                }
            }
        }
        return ans;
    }
}
```

### 题目

给定一个字符串 s 表示一个整数嵌套列表，实现一个解析它的语法分析器并返回解析的结果 `NestedInteger` 。

**示例 1：**

```
输入：s = "324",

解释：你应该返回一个 NestedInteger 对象，其中只包含整数值 324。
```

**示例 2：**

```
输入：s = "[123,[456,[789]]]",
输出：[123,[456,[789]]]
解释：返回一个 NestedInteger 对象包含一个有两个元素的嵌套列表：
1. 一个 integer 包含值 123
2. 一个包含两个元素的嵌套列表：
    i.  一个 integer 包含值 456
    ii. 一个包含一个元素的嵌套列表

```

 

**提示：**

- `1 <= s.length <= 5 * 104`
- `s` 由数字、方括号 `"[]"`、负号 `'-'` 、逗号 `','`组成
- 用例保证 `s` 是可解析的 `NestedInteger`
- 输入中的所有值的范围是 `[-106, 106]`

### 题解一

#### 思路总结

当前实现采用**递归下降解析 + 全局下标 `index`**。解析过程中，根据当前位置字符判断当前元素属于哪种类型：如果遇到 `'['`，说明当前元素是一个嵌套列表，创建空的 `NestedInteger` 并递归解析其中的每个元素；如果当前位置不是 `'['`，则解析一个可能带负号的整数。

------

#### 解题步骤

1. **检查当前字符类型：** 如果 `s[index] == '['`，则解析嵌套列表，否则解析整数。
2. **进入列表结构：** 遇到 `'['` 后先执行 `index++` 跳过左括号，并创建一个空的 `NestedInteger`。
3. **递归解析列表元素：** 只要当前位置还不是 `']'`，就递归调用解析函数得到当前元素，并加入列表。
4. **跳过元素分隔符：** 一个元素解析完成后，如果当前位置是 `','`，执行 `index++` 继续解析下一个元素。
5. **结束当前列表：** 遇到 `']'` 时执行 `index++` 跳过右括号，并返回当前列表。
6. **处理整数符号：** 如果当前位置是 `'-'`，记录负号并向后移动一位。
7. **解析整数数值：** 连续读取数字字符，通过 `num = num * 10 + digit` 构造整数。
8. **构造整数节点：** 将符号与数值相乘，并通过 `new NestedInteger(value)` 返回当前整数节点。
9. **递归返回上层：** 每个子列表或整数解析完成后都会将 `index` 停留在下一个待处理字符位置。

```java
class Solution {
    int index = 0;
    public NestedInteger deserialize(String s) {
        if(s.charAt(index) == '['){
            index++;
            NestedInteger ni = new NestedInteger();
            while(s.charAt(index) != ']'){
                ni.add(deserialize(s));
                if(s.charAt(index) == ','){
                    index++;
                }
            }
            index++;
            return ni;
        }else {
            int sign = 1;
            if(s.charAt(index) == '-'){
                index++;
                sign = -1;
            }
            int num = 0;
            while(index < s.length() && s.charAt(index) >= '0' && s.charAt(index) <= '9'){
                num = num * 10 + s.charAt(index) - '0';
                index++;
            }
            return new NestedInteger(sign * num);
        }
    }
}
```

### 题解二

#### 思路总结

当前实现采用**显式栈模拟递归解析**。如果输入本身就是单个整数，直接使用 `Integer.parseInt()` 构造 `NestedInteger`；如果输入以 `'['` 开头，则使用 `Deque<NestedInteger>` 保存当前尚未解析完成的各层列表。

遇到 `'['` 时创建新列表入栈；遇到数字时解析完整整数并加入栈顶列表；遇到 `']'` 时说明当前列表解析完成，将其出栈并加入上一层列表。如果出栈后栈为空，说明当前列表就是整个输入的根节点，可以直接返回。

------

#### 解题步骤

1. **处理纯整数情况：** 如果字符串第一个字符不是 `'['`，说明整个输入就是一个整数，直接解析并返回。
2. **初始化显式栈：** 使用 `Deque<NestedInteger>` 保存当前正在解析的各层嵌套列表。
3. **处理左括号：** 遇到 `'['` 时创建一个新的空 `NestedInteger` 列表并压入栈中。
4. **处理右括号：** 遇到 `']'` 时弹出当前已经完成的列表。
5. **连接父子列表：** 如果弹出后栈仍非空，则将当前列表加入上一层列表中。
6. **识别根节点：** 如果弹出后栈为空，说明整个嵌套结构已经解析完成，直接返回当前列表。
7. **跳过逗号：** 遇到 `','` 时只作为元素分隔符处理，不需要额外操作。
8. **解析整数符号：** 如果当前字符是 `'-'`，记录负号并移动到数字部分。
9. **连续读取数字：** 不断执行 `num = num * 10 + digit`，直到遇到非数字字符。
10. **加入当前列表：** 将解析完成的整数构造成 `NestedInteger` 并加入栈顶列表。

```java
class Solution {
    public NestedInteger deserialize(String s) {
        if(s.charAt(0) != '['){
            return new NestedInteger(Integer.parseInt(s));
        }
        Deque<NestedInteger> stack = new ArrayDeque<>();
        for(int i = 0; i < s.length(); i++){
            char c = s.charAt(i);
            if(c == '['){
                stack.push(new NestedInteger());
            }else if(c == ']'){
                NestedInteger cur = stack.pop();
                if(!stack.isEmpty()){
                    stack.peek().add(cur);
                }else {
                    return cur;
                }
            }else if(c == ','){
                continue;
            }else {
                int sign = 1;
                if(c == '-'){
                    sign = -1;
                    i++;
                }
                int num = 0;
                while(i < s.length() && s.charAt(i) >= '0' && s.charAt(i) <= '9'){
                    num = num * 10 + s.charAt(i) - '0';
                    i++;
                }
                i--;

                stack.peek().add(new NestedInteger(sign * num));
            }
        }
        return null;
    }
}
```

## [345. 反转字符串中的元音字母](https://leetcode.cn/problems/reverse-vowels-of-a-string/)

### 题目

给你一个字符串 `s` ，仅反转字符串中的所有元音字母，并返回结果字符串。

元音字母包括 `'a'`、`'e'`、`'i'`、`'o'`、`'u'`，且可能以大小写两种形式出现不止一次。

 

**示例 1：**

**输入：**s = "IceCreAm"

**输出：**"AceCreIm"

**解释：**

`s` 中的元音是 `['I', 'e', 'e', 'A']`。反转这些元音，`s` 变为 `"AceCreIm"`.

**示例 2：**

**输入：**s = "leetcode"

**输出：**"leotcede"

 

**提示：**

- `1 <= s.length <= 3 * 105`
- `s` 由 **可打印的 ASCII** 字符组成

### 题解

#### 思路总结

当前实现采用**双指针**反转字符串中的元音字符。先将字符串转换为字符数组，然后让 `l` 从左向右寻找元音、`r` 从右向左寻找元音；当两边都找到元音后交换它们，再继续向中间移动。

非元音字符始终不会被移动，因此最终只会改变所有元音字符之间的相对顺序。整个过程中左右指针都只向一个方向移动，每个字符最多检查常数次，所以时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **定义所有元音字符：** 使用字符串 `"aeiouAEIOU"` 保存大小写共 10 个元音字母。
2. **转换字符数组：** 将 `s` 转成 `char[]`，方便直接交换字符串中的字符。
3. **初始化双指针：** `l` 指向字符串开头，`r` 指向字符串末尾。
4. **左侧寻找元音：** 如果 `chars[l]` 不是元音，就不断执行 `l++`。
5. **右侧寻找元音：** 如果 `chars[r]` 不是元音，就不断执行 `r--`。
6. **交换两侧元音：** 当 `l < r` 时交换 `chars[l]` 和 `chars[r]`。
7. **继续向中间搜索：** 交换完成后执行 `l++` 和 `r--`，寻找下一对元音。
8. **构造最终字符串：** 双指针相遇后，将字符数组转换成字符串并返回。

```java
class Solution {
    public String reverseVowels(String s) {
        String a = "aeiouAEIOU";
        char[] chars = s.toCharArray();
        int n = s.length();
        int l = 0;
        int r = n - 1;
        while(l < r){
            while(l < r && a.indexOf(chars[l]) == -1){
                l++;
            }
            while (l < r && a.indexOf(chars[r]) == -1){
                r--;
            }
            if(l < r){
                char temp = chars[l];
                chars[l] = chars[r];
                chars[r] = temp;
                l++;
                r--;
            }
        }
        return new String(chars);
    }
}
```

### 题解

#### 思路总结

当前实现采用**双指针原地交换**。一个指针 `i` 从数组左端开始，一个指针 `j` 从数组右端开始，每次交换 `s[i]` 和 `s[j]`，然后两个指针同时向中间移动，直到相遇。

```java
class Solution {

        int i = 0;
        int j = s.length - 1;
        while(i < j){
            char temp = s[i];
            s[i] = s[j];
            s[j] = temp;
            i++;
            j--;
        }
    }
}
```

## [227. 基本计算器 II](https://leetcode.cn/problems/basic-calculator-ii/)

### 题目

给你一个字符串表达式 `s` ，请你实现一个基本计算器来计算并返回它的值。

整数除法仅保留整数部分。

你可以假设给定的表达式总是有效的。所有中间结果将在 `[-231, 231 - 1]` 的范围内。

**注意：**不允许使用任何将字符串作为数学表达式计算的内置函数，比如 `eval()` 。

 

**示例 1：**

```
输入：s = "3+2*2"
输出：7
```

**示例 2：**

```
输入：s = " 3/2 "
输出：1
```

**示例 3：**

```
输入：s = " 3+5 / 2 "
输出：5
```

 

**提示：**

- `1 <= s.length <= 3 * 105`
- `s` 由整数和算符 `('+', '-', '*', '/')` 组成，中间由一些空格隔开
- `s` 表示一个有效表达式
- 表达式中的所有整数都是非负整数，且在范围 `[0, 231 - 1]` 内
- 题目数据 **保证** 答案是一个 **32-bit 整数**

### 题解

#### 思路总结

当前实现采用**栈保存每一项的最终贡献值**，相比上一版把数字和运算符一起放入栈中，这一版结构明显更清晰。先去掉空格并解析第一个数字；之后每次读取一个运算符和其后的数字，根据运算符决定如何处理。

对于 `+` 和 `-`，直接将正数或负数压入栈；对于 `*` 和 `/`，由于优先级更高，立即弹出栈顶数字与当前数字计算，再将结果压回栈中。这样所有乘除在扫描过程中已经处理完毕，最后栈中只剩下若干带符号的“项”，全部相加就是最终答案。该实现正确，也是这道题非常经典的栈解法。

------

#### 解题步骤

1. **去除所有空格：** 使用 `replace(" ", "")` 得到只包含数字和四则运算符的表达式。
2. **解析第一个数字：** 从字符串开头连续读取数字并构造整数 `num`。
3. **保存第一项：** 将第一个数字压入栈中，作为表达式当前的第一项。
4. **读取运算符：** 每轮循环先取得当前位置的 `+、-、*、/`，然后移动下标。
5. **解析当前数字：** 连续读取运算符之后的所有数字，得到完整整数 `num`。
6. **处理乘除运算：** 如果运算符为 `*` 或 `/`，立即取出栈顶项与 `num` 计算并将结果压回栈。
7. **处理加减运算：** 如果运算符为 `+`，压入 `num`；如果为 `-`，直接压入 `-num`。
8. **累加所有项：** 表达式扫描结束后，将栈中所有整数相加。
9. **返回最终结果：** 栈中所有项的和就是表达式的计算结果。

```java
class Solution {
    public int calculate(String s) {
        s = s.replace(" ", "");
        int index = 0;
        Deque<Integer> stack = new ArrayDeque<>();
        int num = 0;
        int n = s.length();
        while(index < n && s.charAt(index) >= '0' && s.charAt(index) <= '9'){
            num = num * 10 + s.charAt(index) - '0';
            index++;
        }
        stack.push(num);
        num = 0;
        while(index < n){
            char c = s.charAt(index);
            index++;
            while(index < n && s.charAt(index) >= '0' && s.charAt(index) <= '9'){
                num = num * 10 + s.charAt(index) - '0';
                index++;
            }
            if(c == '*'){
                stack.push(stack.pop() * num);
            }else if(c == '/'){
                stack.push(stack.pop() / num);
            }else if(c == '+'){
                stack.push(num);
            }else {
                stack.push(-num);
            }
            num = 0;
        }
        int ans = 0;
        while(!stack.isEmpty()){
            ans += stack.pop();
        }
        return ans;
    }
}
```

### 题目

**单词** 是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的 **单词** 分隔开。

返回 **单词** 顺序颠倒且 **单词** 之间用单个空格连接的结果字符串。

**注意：**输入字符串 `s`中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

 

**示例 1：**

```
输入：s = "the sky is blue"
输出："blue is sky the"
```

**示例 2：**

```
输入：s = "  hello world  "
输出："world hello"
解释：反转后的字符串中不能存在前导空格和尾随空格。
```

**示例 3：**

```
输入：s = "a good   example"
输出："example good a"
解释：如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。
```

 

**提示：**

- `1 <= s.length <= 104`
- `s` 包含英文大小写字母、数字和空格 `' '`
- `s` 中 **至少存在一个** 单词



 

**进阶：**如果字符串在你使用的编程语言中是一种可变数据类型，请尝试使用 `O(1)` 额外空间复杂度的 **原地** 解法。

### 题解

#### 思路总结

当前实现采用**从右向左扫描字符串**，直接按照最终需要的顺序提取单词。先跳过当前位置连续的空格，然后记录当前单词的右边界 `end`，继续向左找到单词起点，最后把完整单词追加到 `StringBuilder` 中。

这种方式同时完成了三件事：**反转单词顺序、删除首尾多余空格、将单词之间的多个空格压缩成一个空格**。由于每个字符最多被扫描一次，不需要额外保存所有单词，因此时间复杂度为 **O(n)**，不考虑返回结果时辅助空间为 **O(1)**。

------

#### 解题步骤

1. **从字符串末尾开始：** 使用 `n` 指向字符串最后一个字符。
2. **跳过连续空格：** 当当前位置为空格时不断执行 `n--`，自然忽略尾随空格和单词间多余空格。
3. **判断是否结束：** 如果 `n < 0`，说明所有单词都已经处理完成。
4. **记录单词右边界：** 将当前非空格位置保存到 `end`。
5. **寻找单词左边界：** 不断向左移动 `n`，直到遇到空格或越过字符串开头。
6. **添加单词分隔符：** 如果结果中已经存在单词，则先追加一个空格。
7. **追加完整单词：** 将原字符串 `[n + 1, end + 1)` 对应的单词直接追加到结果中。
8. **返回最终结果：** 所有单词处理完成后返回 `StringBuilder` 构造的字符串。

```java
class Solution {
    public String reverseWords(String s) {
        int n = s.length() - 1;
        StringBuilder sb = new StringBuilder();
        while(n >= 0){
            while(n >= 0 && s.charAt(n) == ' '){
                n--;
            }
            if (n < 0) {
                break;
            }
            int end = n;
            while(n >= 0 && s.charAt(n) != ' '){
                n--;
            }
            if(!sb.isEmpty()){
                sb.append(' ');
            }
            sb.append(s, n + 1, end + 1);
        }
        return sb.toString();
    }
}
```
