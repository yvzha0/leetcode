## [1758. 生成交替二进制字符串的最少操作数](https://leetcode.cn/problems/minimum-changes-to-make-alternating-binary-string/)

### 题目

给你一个仅由字符 `'0'` 和 `'1'` 组成的字符串 `s` 。一步操作中，你可以将任一 `'0'` 变成 `'1'` ，或者将 `'1'` 变成 `'0'` 。

**交替字符串** 定义为：如果字符串中不存在相邻两个字符相等的情况，那么该字符串就是交替字符串。例如，字符串 `"010"` 是交替字符串，而字符串 `"0100"` 不是。

返回使 `s` 变成 **交替字符串** 所需的 **最少** 操作数。

 

**示例 1：**

```
输入：s = "0100"
输出：1
解释：如果将最后一个字符变为 '1' ，s 就变成 "0101" ，即符合交替字符串定义。
```

**示例 2：**

```
输入：s = "10"
输出：0
解释：s 已经是交替字符串。
```

**示例 3：**

```
输入：s = "1111"
输出：2
解释：需要 2 步操作得到 "0101" 或 "1010" 。
```

 

**提示：**

- `1 <= s.length <= 104`
- `s[i]` 是 `'0'` 或 `'1'`

### 题解

1. **明确目标形态** 长度固定的交替字符串只有两种可能：
   - 形态一：`"010101..."`（索引为偶数是 `'0'`，奇数是 `'1'`）
   - 形态二：`"101010..."`（与形态一完全相反）
2. **统计形态一的修改步数** 遍历字符串 `s`，利用 `i % 2` 模拟形态一的交替规律。若当前字符 `s.charAt(i) - '0'` 不等于 `i % 2`，则说明该位置需要修改，计数器 `ans` 加 1。
3. **利用互补原理计算形态二** 由于形态一和形态二完全相反，修改成形态二所需的步数不需要重新遍历，它直接等于总长度减去形态一的步数，即 `s.length() - ans`。
4. **返回最小值** 比较两种形态所需的步数，返回较小值：`Math.min(ans, s.length() - ans)`。

```java
class Solution {
    public int minOperations(String s) {
        int ans = 0;
        int n = s.length();
        for(int i = 0;i < n;i++){
            // 变成010101...形式
            if(s.charAt(i) - '0' != i % 2){
                ans++;
            }
        }
        ans = Integer.min(ans, s.length() - ans);
        return ans;
    }
}
```

## [1736. 替换隐藏数字得到的最晚时间](https://leetcode.cn/problems/latest-time-by-replacing-hidden-digits/)

### 题目

给你一个字符串 `time` ，格式为 ` hh:mm`（小时：分钟），其中某几位数字被隐藏（用 `?` 表示）。

有效的时间为 `00:00` 到 `23:59` 之间的所有时间，包括 `00:00` 和 `23:59` 。

替换 `time` 中隐藏的数字，返回你可以得到的最晚有效时间。

 

**示例 1：**

```
输入：time = "2?:?0"
输出："23:50"
解释：以数字 '2' 开头的最晚一小时是 23 ，以 '0' 结尾的最晚一分钟是 50 。
```

**示例 2：**

```
输入：time = "0?:3?"
输出："09:39"
```

**示例 3：**

```
输入：time = "1?:22"
输出："19:22"
```

 

**提示：**

- `time` 的格式为 `hh:mm`
- 题目数据保证你可以由输入的字符串生成有效的时间

### 题解

#### 思路总结

利用**贪心算法（Greedy Algorithm）**从高位到低位依次替换字符串中的 `?`。由于目标是得到最晚时间，应优先让小时十位、小时个位、分钟十位和分钟个位尽可能大，同时保证最终时间仍处于 `00:00` 到 `23:59` 的有效范围内。

算法核心逻辑在于：

1. **优先处理小时部分**，因为小时对时间大小的影响高于分钟。
2. **根据相邻位确定最大合法数字**，保证小时不超过 `23`。
3. **分钟部分直接取最大合法值**，分钟十位最大为 `5`，分钟个位最大为 `9`。
4. **按照从高位到低位的顺序填充**，每一步都选择当前能取到的最大合法数字。

整体过程只需依次检查固定的四个数字位置，实现 **O(1)** 时间复杂度和 **O(1)** 空间复杂度。

------

#### 解题步骤

1. **转换字符串结构**：将字符串 `time` 转换为字符数组 `chars`，便于直接修改各个数字位置。
2. **处理小时十位**：若 `chars[0]` 为 `?`，则根据小时个位 `chars[1]` 判断可填入的最大数字；当小时个位未知时直接组成最大小时 `23`，当小时个位大于等于 `4` 时只能填 `1`，否则填 `2`。
3. **处理小时个位**：若 `chars[1]` 为 `?`，当小时十位小于 `2` 时可填最大数字 `9`，否则小时十位为 `2`，只能填最大数字 `3`。
4. **处理分钟十位**：若 `chars[3]` 为 `?`，填入分钟十位允许的最大数字 `5`。
5. **处理分钟个位**：若 `chars[4]` 为 `?`，填入分钟个位允许的最大数字 `9`。
6. **构造最终结果**：将修改后的字符数组重新转换为字符串并返回，得到能够生成的最晚有效时间。

```java
class Solution {
    public String maximumTime(String time) {
        char[] chars = time.toCharArray();
        if(chars[0] == '?'){
            if(chars[1] == '?'){
                chars[0] = '2';
                chars[1] = '3';
            }else if(chars[1] >= '4'){
                chars[0] = '1';
            }else {
                chars[0] = '2';
            }
        }

        if(chars[1] == '?'){
            if(chars[0] < '2'){
                chars[1] = '9';
            }else {
                chars[1] = '3';
            }
        }

        if(chars[3] == '?'){
            chars[3] = '5';
        }

        if(chars[4] == '?'){
            chars[4] = '9';
        }

        return new String(chars);
    }
}
```

## [1704. 判断字符串的两半是否相似](https://leetcode.cn/problems/determine-if-string-halves-are-alike/)

### 题目

给你一个偶数长度的字符串 `s` 。将其拆分成长度相同的两半，前一半为 `a` ，后一半为 `b` 。

两个字符串 **相似** 的前提是它们都含有相同数目的元音（`'a'`，`'e'`，`'i'`，`'o'`，`'u'`，`'A'`，`'E'`，`'I'`，`'O'`，`'U'`）。注意，`s` 可能同时含有大写和小写字母。

如果 `a` 和 `b` 相似，返回 `true` ；否则，返回 `false` 。

 

**示例 1：**

```
输入：s = "book"
输出：true
解释：a = "bo" 且 b = "ok" 。a 中有 1 个元音，b 也有 1 个元音。所以，a 和 b 相似。
```

**示例 2：**

```
输入：s = "textbook"
输出：false
解释：a = "text" 且 b = "book" 。a 中有 1 个元音，b 中有 2 个元音。因此，a 和 b 不相似。
注意，元音 o 在 b 中出现两次，记为 2 个。
```

 

**提示：**

- `2 <= s.length <= 1000`
- `s.length` 是偶数
- `s` 由 **大写和小写** 字母组成

### 题解

#### 思路总结

利用**双指针 + 计数（Two Pointers + Counting）**判断字符串两半是否相似。分别从字符串的前半部分和后半部分同时遍历，统计两部分元音字母数量的差值，最终若差值为 `0`，则说明两部分包含相同数量的元音字母。

算法核心逻辑在于：

1. **确定字符串中点**，将字符串划分为长度相同的两部分。
2. **同时遍历前后两部分**，分别判断当前字符是否为元音字母。
3. **维护元音数量差值**，前半部分遇到元音则加一，后半部分遇到元音则减一。
4. **根据最终差值判断结果**，若差值为 `0`，则两部分元音数量相同。

整体过程仅遍历字符串一次，实现 **O(n)** 时间复杂度和 **O(1)** 空间复杂度。

------

#### 解题步骤

1. **初始化变量**：定义元音字符集合 `ss`，计算字符串中点 `n`，并初始化计数器 `count`。
2. **同时遍历两部分字符串**：从前半部分起始位置和后半部分末尾位置同时遍历，每次分别获取两个字符。
3. **统计元音数量差值**：若前半部分当前字符为元音，则将 `count` 加一；若后半部分当前字符为元音，则将 `count` 减一。
4. **判断最终结果**：遍历结束后，若 `count` 等于 `0`，说明两部分元音数量相同，返回 `true`；否则返回 `false`。

```java
class Solution {
    public boolean halvesAreAlike(String s) {
        String ss = "aeiouAEIOU";
        int n = s.length() / 2;
        int count = 0;
        for(int i = 0; i < n; i++){
            char c1 = s.charAt(i);
            char c2 = s.charAt(n * 2 - 1 - i);
            if(ss.indexOf(c1) != -1){
                count++;
            }
            if(ss.indexOf(c2) != -1){
                count--;
            }
        }
        return count == 0;
    }
}
```

## [1694. 重新格式化电话号码](https://leetcode.cn/problems/reformat-phone-number/)

### 题目

给你一个字符串形式的电话号码 `number` 。`number` 由数字、空格 `' '`、和破折号 `'-'` 组成。

请你按下述方式重新格式化电话号码。

- 首先，**删除** 所有的空格和破折号。

- 其次，将数组从左到右

   

  每 3 个一组

   

  分块，

  直到 

  剩下 4 个或更少数字。剩下的数字将按下述规定再分块：

  - 2 个数字：单个含 2 个数字的块。
  - 3 个数字：单个含 3 个数字的块。
  - 4 个数字：两个分别含 2 个数字的块。

最后用破折号将这些块连接起来。注意，重新格式化过程中 **不应该** 生成仅含 1 个数字的块，并且 **最多** 生成两个含 2 个数字的块。

返回格式化后的电话号码。

 

**示例 1：**

```
输入：number = "1-23-45 6"
输出："123-456"
解释：数字是 "123456"
步骤 1：共有超过 4 个数字，所以先取 3 个数字分为一组。第 1 个块是 "123" 。
步骤 2：剩下 3 个数字，将它们放入单个含 3 个数字的块。第 2 个块是 "456" 。
连接这些块后得到 "123-456" 。
```

**示例 2：**

```
输入：number = "123 4-567"
输出："123-45-67"
解释：数字是 "1234567".
步骤 1：共有超过 4 个数字，所以先取 3 个数字分为一组。第 1 个块是 "123" 。
步骤 2：剩下 4 个数字，所以将它们分成两个含 2 个数字的块。这 2 块分别是 "45" 和 "67" 。
连接这些块后得到 "123-45-67" 。
```

**示例 3：**

```
输入：number = "123 4-5678"
输出："123-456-78"
解释：数字是 "12345678" 。
步骤 1：第 1 个块 "123" 。
步骤 2：第 2 个块 "456" 。
步骤 3：剩下 2 个数字，将它们放入单个含 2 个数字的块。第 3 个块是 "78" 。
连接这些块后得到 "123-456-78" 。
```

**示例 4：**

```
输入：number = "12"
输出："12"
```

**示例 5：**

```
输入：number = "--17-5 229 35-39475 "
输出："175-229-353-94-75"
```

 

**提示：**

- `2 <= number.length <= 100`
- `number` 由数字和字符 `'-'` 及 `' '` 组成。
- `number` 中至少含 **2** 个数字。

### 题解

#### 思路总结

利用**字符串处理 + 贪心分组**实现电话号码重新格式化。首先删除原字符串中的空格和破折号，得到只包含数字的新字符串，然后按照题目要求从左到右优先每三个数字划分为一组，同时特殊处理剩余 `2`、`3`、`4` 个数字的情况，避免产生长度为 `1` 的分组。

算法核心逻辑在于：

1. **预处理字符串**，去除所有非数字字符，获得纯数字字符串。
2. **从左到右遍历数字字符串**，优先每三个数字划分为一组。
3. **处理剩余数字情况：**
   - 剩余 `2` 或 `3` 个数字时，直接作为最后一组。
   - 剩余 `4` 个数字时，拆分为两个长度为 `2` 的分组。
4. **使用分隔符连接各个分组**，得到最终格式化后的电话号码。

整体过程只需遍历数字字符串一次，实现 **O(n)** 时间复杂度和 **O(n)** 空间复杂度。

------

#### 解题步骤

1. **清理电话号码格式**：删除字符串中的空格和破折号，只保留数字字符，得到待处理的电话号码。
2. **初始化遍历过程**：根据数字字符串长度 `n`，从起始位置开始，每次处理最多三个数字。
3. **划分三位分组**：当剩余数字数量大于 `4` 时，将当前三个数字作为一个分组，并添加连接符。
4. **处理剩余数字**：当剩余数字数量为 `2` 或 `3` 时，将剩余数字作为最后一个分组；当剩余数字数量为 `4` 时，将其拆分为两个长度为 `2` 的分组。
5. **返回格式化结果**：将所有分组连接成字符串，得到重新格式化后的电话号码。

```java
class Solution {
    public String reformatNumber(String number) {
        number = number.replace(" ", "").replace("-", "");
        int n = number.length();
        StringBuilder sb = new StringBuilder();
        for(int i = 0; i < n; i += 3){
            if(n - i == 2 || n - i == 3){
                sb.append(number, i, n);
            }else if(n - i == 4){
                sb.append(number, i, i + 2).append("-").append(number, i + 2, n);
                break;
            }else {
                sb.append(number, i, i + 3).append("-");
            }
        }
        return sb.toString();
    }
}
```

## [1684. 统计一致字符串的数目](https://leetcode.cn/problems/count-the-number-of-consistent-strings/)

### 题目

给你一个由不同字符组成的字符串 `allowed` 和一个字符串数组 `words` 。如果一个字符串的每一个字符都在 `allowed` 中，就称这个字符串是 **一致字符串** 。

请你返回 `words` 数组中 **一致字符串** 的数目。

 

**示例 1：**

```
输入：allowed = "ab", words = ["ad","bd","aaab","baa","badab"]
输出：2
解释：字符串 "aaab" 和 "baa" 都是一致字符串，因为它们只包含字符 'a' 和 'b' 。
```

**示例 2：**

```
输入：allowed = "abc", words = ["a","b","c","ab","ac","bc","abc"]
输出：7
解释：所有字符串都是一致的。
```

**示例 3：**

```
输入：allowed = "cad", words = ["cc","acd","b","ba","bac","bad","ac","d"]
输出：4
解释：字符串 "cc"，"acd"，"ac" 和 "d" 是一致字符串。
```

 

**提示：**

- `1 <= words.length <= 104`
- `1 <= allowed.length <= 26`
- `1 <= words[i].length <= 10`
- `allowed` 中的字符 **互不相同** 。
- `words[i]` 和 `allowed` 只包含小写英文字母。

### 题解

#### 思路总结

利用**哈希集合（HashSet）**实现一致字符串统计。由于 `allowed` 中的字符互不重复，可以将其中所有字符存入集合，通过集合的快速查找能力判断 `words` 中每个字符串的字符是否都存在于 `allowed` 中。

算法核心逻辑在于：

1. **建立字符集合**，存储 `allowed` 中允许出现的所有字符。
2. **遍历字符串数组**，逐个检查每个字符串中的字符。
3. **判断字符串是否一致**，若存在任意字符不属于允许集合，则该字符串不是一致字符串。
4. **统计满足条件的字符串数量**，最终返回一致字符串的个数。

整体过程利用哈希集合实现字符快速判断，遍历所有字符串一次，实现 **O(n)** 时间复杂度和 **O(1)** 空间复杂度（字符集大小固定）。

------

#### 解题步骤

1. **初始化字符集合**：遍历字符串 `allowed`，将其中所有字符加入集合 `set`，用于快速判断字符是否合法。
2. **遍历字符串数组**：依次访问 `words` 中的每个字符串，并假设当前字符串是一致字符串。
3. **检查字符串字符**：遍历当前字符串中的每个字符，判断该字符是否存在于集合 `set` 中；若不存在，则说明该字符串不是一致字符串。
4. **统计结果数量**：若当前字符串中的所有字符均存在于 `allowed` 中，则增加一致字符串计数；否则跳过该字符串。
5. **返回统计结果**：遍历结束后，返回所有一致字符串的数量。

```java
class Solution {
    public int countConsistentStrings(String allowed, String[] words) {
        Set<Character> set = new HashSet<>();
        for(char c : allowed.toCharArray()){
            set.add(c);
        }
        int ans = 0;
        for(String word : words){
            ans++;
            for(char c : word.toCharArray()){
                if(!set.contains(c)){
                    ans--;
                    break;
                }
            }
        }
        return ans;
    }
}
```

## [1678. 设计 Goal 解析器](https://leetcode.cn/problems/goal-parser-interpretation/)

### 题目

请你设计一个可以解释字符串 `command` 的 **Goal 解析器** 。`command` 由 `"G"`、`"()"` 和/或 `"(al)"` 按某种顺序组成。Goal 解析器会将 `"G"` 解释为字符串 `"G"`、`"()"` 解释为字符串 `"o"` ，`"(al)"` 解释为字符串 `"al"` 。然后，按原顺序将经解释得到的字符串连接成一个字符串。

给你字符串 `command` ，返回 **Goal 解析器** 对 `command` 的解释结果。

 

**示例 1：**

```
输入：command = "G()(al)"
输出："Goal"
解释：Goal 解析器解释命令的步骤如下所示：
G -> G
() -> o
(al) -> al
最后连接得到的结果是 "Goal"
```

**示例 2：**

```
输入：command = "G()()()()(al)"
输出："Gooooal"
```

**示例 3：**

```
输入：command = "(al)G(al)()()G"
输出："alGalooG"
```

 

**提示：**

- `1 <= command.length <= 100`
- `command` 由 `"G"`、`"()"` 和/或 `"(al)"` 按某种顺序组成

### 题解

#### 思路总结

利用**字符串遍历 + 模式匹配**实现 Goal 解析器。由于 `command` 只包含三种固定形式：`G`、`()` 和 `(al)`，因此可以通过遍历字符串，根据当前字符判断对应的命令类型，并将其转换为目标字符串。

算法核心逻辑在于：

1. **逐字符扫描字符串**，判断当前位置对应的命令类型。
2. **根据不同模式进行转换：**
   - 遇到 `G`，直接解析为 `G`。
   - 遇到 `()`，解析为 `o`。
   - 遇到 `(al)`，解析为 `al`。
3. **跳过已经解析的字符**，避免重复处理同一个命令。
4. **拼接所有解析结果**，得到最终字符串。

整体过程只需遍历字符串一次，实现 **O(n)** 时间复杂度和 **O(n)** 空间复杂度。

------

#### 解题步骤

1. **初始化结果字符串**：创建 `StringBuilder` 用于保存 Goal 解析器转换后的结果。
2. **遍历命令字符串**：从左到右依次访问 `command` 中的每个字符，根据当前位置字符判断命令类型。
3. **解析单字符命令**：若当前字符为 `G`，直接将 `G` 加入结果字符串。
4. **解析括号命令**：若当前字符为 `(`，根据下一个字符判断是 `()` 还是 `(al)`；若下一个字符为 `)`，则解析为 `o`，否则解析为 `al`。
5. **调整遍历位置**：解析括号命令后跳过已经处理的字符，避免重复解析。
6. **返回解析结果**：遍历结束后，将拼接完成的字符串作为最终答案返回。

```java
class Solution {
    public String interpret(String command) {
        StringBuilder sb = new StringBuilder();
        int n = command.length();
        for(int i = 0; i < n; i++){
            if(command.charAt(i) == 'G'){
                sb.append('G');
            }else {
                if(command.charAt(i + 1) == ')'){
                    sb.append('o');
                    i++;
                }else {
                    sb.append("al");
                    i += 3;
                }
            }
        }
        return sb.toString();
    }
}
```

## [1668. 最大重复子字符串](https://leetcode.cn/problems/maximum-repeating-substring/)

### 题目

给你一个字符串 `sequence` ，如果字符串 `word` 连续重复 `k` 次形成的字符串是 `sequence` 的一个子字符串，那么单词 `word` 的 **重复值为 `k`** 。单词 `word` 的 **最大重复值** 是单词 `word` 在 `sequence` 中最大的重复值。如果 `word` 不是 `sequence` 的子串，那么重复值 `k` 为 `0` 。

给你一个字符串 `sequence` 和 `word` ，请你返回 **最大重复值 `k`** 。

 

**示例 1：**

```
输入：sequence = "ababc", word = "ab"
输出：2
解释："abab" 是 "ababc" 的子字符串。
```

**示例 2：**

```
输入：sequence = "ababc", word = "ba"
输出：1
解释："ba" 是 "ababc" 的子字符串，但 "baba" 不是 "ababc" 的子字符串。
```

**示例 3：**

```
输入：sequence = "ababc", word = "ac"
输出：0
解释："ac" 不是 "ababc" 的子字符串。
```

 

**提示：**

- `1 <= sequence.length <= 100`
- `1 <= word.length <= 100`
- `sequence` 和 `word` 都只包含小写英文字母。

### 题解一

#### 思路总结

利用**枚举重复次数 + 字符串匹配**解决最大重复子字符串问题。

字符串 `word` 最多只能重复：

```
sequence.length() / word.length()
```

次，因为重复后的字符串长度不能超过 `sequence`。

当前实现从这个理论最大值开始向下枚举 `k`，每次构造 `word` 连续重复 `k` 次得到的字符串，然后判断它是否为 `sequence` 的子串。由于按照 `k` 从大到小搜索，因此第一次匹配成功时，对应的 `k` 就是最大重复值。

------

#### 解题步骤

1. **计算最大重复次数：** 使用 `sequence.length() / word.length()` 得到 `word` 理论上最多能够重复的次数 `k`。
2. **从最大次数向下枚举：** 从当前 `k` 开始逐渐减小重复次数，优先检查更大的重复值。
3. **构造重复字符串：** 使用 `word.repeat(k)` 得到 `word` 连续重复 `k` 次后的字符串。
4. **判断是否为子串：** 使用 `sequence.contains()` 判断构造出的重复字符串是否出现在 `sequence` 中。
5. **找到后立即返回：** 由于 `k` 按照从大到小枚举，因此第一次匹配成功的 `k` 就是最大重复值。
6. **处理不存在情况：** 如果所有正整数重复次数都无法匹配，则最终返回 `0`。

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int k = sequence.length() / word.length();
        for(; k >= 0; k--){
            if(sequence.contains(word.repeat(k))){
                return k;
            }
        }
        return 0;
    }
}
```

## 题解二

#### 思路总结

利用**动态规划**统计 `word` 在 `sequence` 中连续重复出现的最大次数。

定义：

`dp[i]` 表示以 `sequence[i]` 作为最后一个字符时，连续出现了多少个 `word`。

对于当前位置 `i`，对应单词的起始位置为：

```
start = i - m + 1
```

如果区间 `[start, start + m)` 与 `word` 相同，那么当前至少出现了一个 `word`。由于连续重复的前一个 `word` 必须恰好结束在 `start - 1`，也就是 `i - m`，因此状态转移为：

```
dp[i] = dp[i - m] + 1
```

如果当前位置是第一个完整的 `word`，前面不存在对应状态，则 `dp[i] = 1`。

遍历过程中维护最大的 `dp[i]`，即可得到最大重复值。

------

#### 解题步骤

1. **获取字符串长度：** 使用 `m` 表示 `word` 的长度，使用 `n` 表示 `sequence` 的长度。
2. **初始化动态规划数组：** 创建 `dp`，其中 `dp[i]` 表示以位置 `i` 结尾时连续出现的 `word` 数量。
3. **枚举单词结束位置：** 从 `i = m - 1` 开始遍历，因为此前的位置无法组成一个完整的 `word`。
4. **计算当前起始位置：** 使用 `start = i - m + 1` 得到当前长度为 `m` 的子串起点。
5. **判断是否匹配单词：** 如果当前长度为 `m` 的子串与 `word` 相同，则当前位置能够形成一个完整的 `word`。
6. **连接前一个重复单词：** 如果前面还存在长度为 `m` 的区域，则通过 `dp[start - 1] + 1` 得到当前连续重复次数。
7. **处理第一次匹配：** 如果当前匹配从下标 `0` 开始，则当前连续重复次数为 `1`。
8. **更新最大重复次数：** 使用当前 `dp[i]` 更新全局最大值 `ans`。
9. **返回最终结果：** 遍历完成后返回 `ans`。

```java
class Solution {
    public int maxRepeating(String sequence, String word) {
        int m = word.length();
        int n = sequence.length();
        int[] dp = new int[n];
        int ans = 0;
        for(int i = m - 1; i < n; i++){
            int start = i - m + 1;
            if(word.equals(sequence.substring(start, start + m))){
                if(i > m - 1){
                    dp[i] = dp[start - 1] + 1;
                }else {
                    dp[i] = 1;
                }
                ans = Math.max(ans, dp[i]);
            }
        }
        return ans;
    }
}
```

## [1653. 使字符串平衡的最少删除次数](https://leetcode.cn/problems/minimum-deletions-to-make-string-balanced/)

### 题目

给你一个字符串 `s` ，它仅包含字符 `'a'` 和 `'b'` 。

你可以删除 `s` 中任意数目的字符，使得 `s` **平衡** 。当不存在下标对 `(i,j)` 满足 `i < j` ，且 `s[i] = 'b'` 的同时 `s[j]= 'a'` ，此时认为 `s` 是 **平衡** 的。

请你返回使 `s` **平衡** 的 **最少** 删除次数。

 

**示例 1：**

```
输入：s = "aababbab"
输出：2
解释：你可以选择以下任意一种方案：
下标从 0 开始，删除第 2 和第 6 个字符（"aababbab" -> "aaabbb"），
下标从 0 开始，删除第 3 和第 6 个字符（"aababbab" -> "aabbbb"）。
```

**示例 2：**

```
输入：s = "bbaaaaabb"
输出：2
解释：唯一的最优解是删除最前面两个字符。
```

 

**提示：**

- `1 <= s.length <= 105`
- `s[i]` 要么是 `'a'` 要么是 `'b'` 。

### 题解一

#### 思路总结

利用**枚举分割点 + 前后缀计数**解决最少删除次数问题。

平衡字符串的最终形式一定满足：

```
aaaa...bbbb
```

也就是说，可以在字符串中选择一个分割位置，使得：

- 分割点左侧只能保留 `'a'`，因此左侧所有 `'b'` 都必须删除。
- 分割点右侧只能保留 `'b'`，因此右侧所有 `'a'` 都必须删除。

因此，对于任意一个分割位置，需要删除的字符数量就是：

```
左侧 b 的数量 + 右侧 a 的数量
```

当前实现使用：

- `leftb` 维护分割点左侧 `'b'` 的数量。
- `righta` 维护分割点右侧 `'a'` 的数量。

随着分割点从左向右移动，不断计算 `leftb + righta` 的最小值，即可得到答案。

整体时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **统计所有字符 a：** 第一次遍历字符串，统计全部 `'a'` 的数量并保存到 `righta`，表示分割点位于字符串最左侧时右边需要删除的 `'a'` 数量。
2. **初始化删除次数：** 使用 `righta` 作为初始答案，表示删除全部 `'a'`，最终只保留 `'b'` 的情况。
3. **从左向右移动分割点：** 第二次遍历字符串，每处理一个字符，就相当于将该字符从分割点右侧移动到左侧。
4. **更新左侧 b 数量：** 如果当前字符是 `'b'`，说明左侧多了一个需要删除的 `'b'`，执行 `leftb++`。
5. **更新右侧 a 数量：** 如果当前字符是 `'a'`，说明该字符已经从右侧移到左侧，因此执行 `righta--`。
6. **计算当前删除次数：** 当前分割位置需要删除的字符数量为 `leftb + righta`。
7. **维护最小删除次数：** 每次移动分割点后使用 `leftb + righta` 更新 `ans`。
8. **返回最终结果：** 所有分割位置检查完成后，返回最小删除次数 `ans`。

```java
class Solution {
    public int minimumDeletions(String s) {
        int righta = 0;
        int leftb = 0;
        int ans = 100000;
        for(char c : s.toCharArray()){
            if(c == 'a'){
                righta++;
            }
        }
        ans = Math.min(ans, righta);
        for(char c : s.toCharArray()){
            if(c == 'b'){
                leftb++;
            }else {
                righta--;
            }
            ans = Math.min(ans, leftb + righta);
        }
        return ans;
    }
}
```

### 题解二

#### 思路总结

利用**动态规划 + 状态压缩**解决字符串平衡所需的最少删除次数。

遍历字符串时维护两个状态：

- `bCount`：当前已经遇到的 `'b'` 数量。
- `dp`：使当前已经遍历的前缀字符串达到平衡状态所需的最少删除次数。

当遇到 `'b'` 时，字符 `'b'` 可以合法地出现在平衡字符串的后半部分，因此不需要立即删除，只需要执行 `bCount++`。

当遇到 `'a'` 时，如果前面已经存在 `'b'`，就产生了 `"ba"` 的不平衡关系，此时有两种选择：

`删除当前 a`：删除次数为 `dp + 1`。

`保留当前 a`：需要删除前面所有 `'b'`，删除次数为 `bCount`。

因此状态转移为：

```
dp = Math.min(dp + 1, bCount)
```

最终 `dp` 就是使整个字符串平衡所需的最少删除次数。

------

#### 解题步骤

1. **初始化状态：** 设置 `bCount = 0` 记录已经遍历到的 `'b'` 数量，设置 `dp = 0` 表示当前前缀变平衡所需的最少删除次数。
2. **从左向右遍历字符串：** 依次处理字符串中的每一个字符。
3. **处理字符 b：** 如果当前字符是 `'b'`，不会立即破坏平衡结构，只需要执行 `bCount++`。
4. **处理字符 a：** 如果当前字符是 `'a'`，需要在删除当前 `'a'` 和删除前面所有 `'b'` 两种方案之间选择。
5. **计算删除当前 a 的代价：** 当前前缀原本最少需要删除 `dp` 个字符，再删除当前 `'a'`，总代价为 `dp + 1`。
6. **计算保留当前 a 的代价：** 如果保留当前 `'a'`，则前面所有 `'b'` 都不能存在，因此需要删除 `bCount` 个 `'b'`。
7. **更新最少删除次数：** 使用 `dp = Math.min(dp + 1, bCount)` 保存处理当前前缀后的最优结果。
8. **返回最终答案：** 遍历完整个字符串后返回 `dp`。

```java
class Solution {
    public int minimumDeletions(String s) {
        int bCount = 0;
        int dp = 0;
        for(char c : s.toCharArray()){
            if(c == 'b'){
                bCount++;
            }else {
                dp = Math.min(dp + 1, bCount);
            }
        }
        return dp;
    }
}
```

## [1624. 两个相同字符之间的最长子字符串](https://leetcode.cn/problems/largest-substring-between-two-equal-characters/)

### 题目

给你一个字符串 `s`，请你返回 **两个相同字符之间的最长子字符串的长度** *，*计算长度时不含这两个字符。如果不存在这样的子字符串，返回 `-1` 。

**子字符串** 是字符串中的一个连续字符序列。

 

**示例 1：**

```
输入：s = "aa"
输出：0
解释：最优的子字符串是两个 'a' 之间的空子字符串。
```

**示例 2：**

```
输入：s = "abca"
输出：2
解释：最优的子字符串是 "bc" 。
```

**示例 3：**

```
输入：s = "cbzxy"
输出：-1
解释：s 中不存在出现出现两次的字符，所以返回 -1 。
```

**示例 4：**

```
输入：s = "cabbac"
输出：4
解释：最优的子字符串是 "abba" ，其他的非最优解包括 "bb" 和 "" 。
```

 

**提示：**

- `1 <= s.length <= 300`
- `s` 只含小写英文字母

### 题解

#### 思路总结

利用**哈希表记录每个字符第一次出现的位置**，在遍历字符串时计算当前字符与其第一次出现位置之间的距离。

对于两个相同字符分别位于下标 `start` 和 `i`，它们之间的子字符串长度为：

```
i - start - 1
```

为了让同一个字符形成的子字符串尽可能长，只需要始终保存该字符**第一次出现的位置**，后续每次再次遇到该字符时，都用当前位置与第一次出现位置计算距离。

当前代码通过：

```
int start = map.getOrDefault(s.charAt(i), i);
```

处理字符首次出现的情况；如果字符没有出现过，就让 `start = i`，此时得到的长度为 `-1`，不会影响初始答案。

随后：

```
map.put(s.charAt(i), start);
```

继续保存第一次出现的位置，而不会被后续位置覆盖。

整体只需要遍历字符串一次，时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **初始化字符位置映射：** 使用 `map` 保存每个字符第一次出现的下标，并设置 `ans = -1` 表示暂时不存在两个相同字符。
2. **从左向右遍历字符串：** 对每个位置 `i` 获取当前字符 `s.charAt(i)`。
3. **获取第一次出现位置：** 如果当前字符已经出现，则从 `map` 获取第一次出现的下标；如果尚未出现，则使用当前位置 `i`。
4. **计算中间字符串长度：** 根据 `i - start - 1` 计算当前字符与第一次出现位置之间的字符数量。
5. **更新最大长度：** 使用当前长度更新 `ans`，保存已经找到的最大值。
6. **保存第一次出现位置：** 将当前字符对应的位置保存为 `start`，保证后续始终使用第一次出现的位置。
7. **返回最终答案：** 遍历完成后返回 `ans`，如果没有任何字符重复出现则保持为 `-1`。

```java
class Solution {
    public int maxLengthBetweenEqualCharacters(String s) {
        Map<Character, Integer> map = new HashMap<>();
        int ans = -1;
        for(int i = 0; i < s.length(); i++){
            int start = map.getOrDefault(s.charAt(i), i);
            int val = i - start - 1;
            ans = Math.max(ans, val);
            map.put(s.charAt(i), start);
        }
        return ans;
    }
}
```

## [1614. 括号的最大嵌套深度](https://leetcode.cn/problems/maximum-nesting-depth-of-the-parentheses/)

### 题目

给定 **有效括号字符串** `s`，返回 `s` 的 **嵌套深度**。嵌套深度是嵌套括号的 **最大** 数量。

 

**示例 1：**

**输入：**s = "(1+(2*3)+((**8**)/4))+1"

**输出：**3

**解释：**数字 8 在嵌套的 3 层括号中。

**示例 2：**

**输入：**s = "(1)+((2))+(((**3**)))"

**输出：**3

**解释：**数字 3 在嵌套的 3 层括号中。

**示例 3：**

**输入：**s = "()(())((()()))"

**输出：**3

 

**提示：**

- `1 <= s.length <= 100`
- `s` 由数字 `0-9` 和字符 `'+'`、`'-'`、`'*'`、`'/'`、`'('`、`')'` 组成
- 题目数据保证括号字符串 `s` 是 **有效的括号字符串**

### 题解

#### 思路总结

利用**计数器模拟括号嵌套深度**。

使用 `count` 表示当前尚未闭合的左括号数量，也就是当前位置的括号嵌套深度：

- 遇到 `'('` 时，进入新的一层，执行 `count++`。
- 遇到 `')'` 时，退出当前层，执行 `count--`。
- 每次遇到 `'('` 后，使用当前 `count` 更新最大深度 `ans`。

由于题目保证 `s` 是有效括号字符串，因此遍历过程中括号能够正确匹配，最终 `count` 会回到 `0`。

该方法不需要真正使用栈，只需要维护当前深度和最大深度两个变量。

------

#### 解题步骤

1. **初始化当前深度：** 设置 `count = 0`，表示当前没有未闭合的左括号。
2. **初始化最大深度：** 设置 `ans = 0`，用于保存遍历过程中出现的最大嵌套层数。
3. **遍历字符串字符：** 从左向右依次检查字符串中的每一个字符。
4. **处理左括号：** 如果当前字符是 `'('`，执行 `count++`，表示进入新的一层括号。
5. **更新最大深度：** 每次进入新的一层后，使用 `Math.max(ans, count)` 更新最大嵌套深度。
6. **处理右括号：** 如果当前字符是 `')'`，执行 `count--`，表示当前括号层结束。
7. **忽略普通字符：** 数字和运算符不会影响括号嵌套层数，因此无需处理。
8. **返回最终结果：** 遍历完成后返回 `ans`。

```java
class Solution {
    public int maxDepth(String s) {
        int count = 0;
        int ans = 0;
        for(char c : s.toCharArray()){
            if(c == '('){
                count++;
                ans = Math.max(ans, count);
            }else if(c == ')'){
                count--;
            }
        }
        return ans;
    }
}
```

## [1573. 分割字符串的方案数](https://leetcode.cn/problems/number-of-ways-to-split-a-string/)

### 题目

给你一个二进制串 `s` （一个只包含 0 和 1 的字符串），我们可以将 `s` 分割成 3 个 **非空** 字符串 s1, s2, s3 （s1 + s2 + s3 = s）。

请你返回分割 `s` 的方案数，满足 s1，s2 和 s3 中字符 '1' 的数目相同。

由于答案可能很大，请将它对 10^9 + 7 取余后返回。

 

**示例 1：**

```
输入：s = "10101"
输出：4
解释：总共有 4 种方法将 s 分割成含有 '1' 数目相同的三个子字符串。
"1|010|1"
"1|01|01"
"10|10|1"
"10|1|01"
```

**示例 2：**

```
输入：s = "1001"
输出：0
```

**示例 3：**

```
输入：s = "0000"
输出：3
解释：总共有 3 种分割 s 的方法。
"0|0|00"
"0|00|0"
"00|0|0"
```

**示例 4：**

```
输入：s = "100100010100110"
输出：12
```

 

**提示：**

- `s[i] == '0'` 或者 `s[i] == '1'`
- `3 <= s.length <= 10^5`

### 题解

#### 思路总结

利用**统计 `'1'` 的总数 + 计算两个分割位置的可选数量**解决问题。

设字符串中 `'1'` 的总数为 `total`：

- 如果 `total % 3 != 0`，无法让三个子串包含相同数量的 `'1'`，答案为 `0`。
- 如果 `total == 0`，三个子串都天然包含 `0` 个 `'1'`，只需要从 `n - 1` 个间隙中选择两个分割点，方案数为 `C(n - 1, 2)`。
- 如果 `total > 0`，每一段都必须包含 `k = total / 3` 个 `'1'`。

此时第一个分割点必须位于**第 `k` 个 `'1'` 和第 `k + 1` 个 `'1'` 之间**，第二个分割点必须位于**第 `2k` 个 `'1'` 和第 `2k + 1` 个 `'1'` 之间**。

若这些 `'1'` 的位置分别为 `p1、p2、p3、p4`，则：

```
第一个分割点方案数 = p2 - p1
第二个分割点方案数 = p4 - p3
```

两个分割点相互独立，因此最终答案为：

```
(p2 - p1) × (p4 - p3)
```

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **统计 1 的总数：** 遍历字符串得到字符 `'1'` 的数量 `total`。
2. **判断是否能够平均分配：** 如果 `total % 3 != 0`，三个子串不可能拥有相同数量的 `'1'`，直接返回 `0`。
3. **处理全 0 情况：** 如果 `total == 0`，从字符串的 `n - 1` 个间隙中任选两个作为分割点，方案数为 `(n - 1) * (n - 2) / 2`。
4. **计算每段目标数量：** 设置 `k = total / 3`，表示每个子串应该包含 `k` 个 `'1'`。
5. **寻找第一处分割边界：** 记录第 `k` 个 `'1'` 的位置 `p1` 和第 `k + 1` 个 `'1'` 的位置 `p2`。
6. **寻找第二处分割边界：** 记录第 `2k` 个 `'1'` 的位置 `p3` 和第 `2k + 1` 个 `'1'` 的位置 `p4`。
7. **计算第一刀方案数：** 第一个分割点可以放在 `p1` 到 `p2` 之间，共有 `p2 - p1` 种选择。
8. **计算第二刀方案数：** 第二个分割点可以放在 `p3` 到 `p4` 之间，共有 `p4 - p3` 种选择。
9. **计算最终答案：** 将两部分方案数相乘，并对 `10^9 + 7` 取模后返回。

```java
class Solution {
    public int numWays(String s) {
        int n = s.length();
        int total = 0;
        int mod = 1000000007;
        for(int i = 0; i < n; i++){
            if(s.charAt(i) == '1'){
                total++;
            }
        }
        if(total % 3 != 0){
            return 0;
        }
        if(total == 0){
            long ans = (long) (n - 1) * (n - 2) / 2 % mod;
            return (int) ans;
        }
        int k = total / 3;

        int p1 = 0, p2 = 0, p3 = 0, p4 = 0;
        int count = 0;

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '1') {
                count++;

                if (count == k) {
                    p1 = i;
                } else if (count == k + 1) {
                    p2 = i;
                }
                if (count == 2 * k) {
                    p3 = i;
                } else if (count == 2 * k + 1) {
                    p4 = i;
                }
            }
        }

        long first = p2 - p1;
        long second = p4 - p3;

        return (int) (first * second % mod);
    }
}
```

```

```

种。

1. **初始化去重集合：** 创建 `HashSet<String>`，用于保存字符串 `s` 中出现过的所有长度为 `k` 的不同子串。

class Solution {
    public boolean hasAllCodes(String s, int k) {

        for(int i = 0; i < s.length() - k + 1; i++){
            set.add(s.substring(i, i + k));
        }
        return set.size() == (1 << k);
    }
}

## [1332. 删除回文子序列](https://leetcode.cn/problems/remove-palindromic-subsequences/)

### 题目

给你一个字符串 `s`，它仅由字母 `'a'` 和 `'b'` 组成。每一次删除操作都可以从 `s` 中删除一个回文 **子序列**。

「子序列」定义：如果一个字符串可以通过删除原字符串某些字符而不改变原字符顺序得到，那么这个字符串就是原字符串的一个子序列。

「回文」定义：如果一个字符串向后和向前读是一致的，那么这个字符串就是一个回文。

 

**示例 1：**

```
输入：s = "ababa"
输出：1
解释：字符串本身就是回文序列，只需要删除一次。
```

**示例 2：**

```
输入：s = "abb"
输出：2
解释："abb" -> "bb" -> "". 
先删除回文子序列 "a"，然后再删除 "bb"。
```

**示例 3：**

```
输入：s = "baabb"
输出：2
解释："baabb" -> "b" -> "". 
先删除回文子序列 "baab"，然后再删除 "b"。
```

 

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅包含字母 `'a'` 和 `'b'`

### 题解

#### 思路总结

利用**回文判断 + 二字符性质**解决问题。

这道题的关键不在于模拟删除，而在于利用字符串只包含 `'a'` 和 `'b'` 这一特殊条件。

存在两种情况：

- 如果整个字符串 `s` 本身就是回文，那么可以直接把整个字符串作为一个回文子序列删除，答案为 `1`。
- 如果 `s` 不是回文，那么一定可以在 `2` 次以内删除完：第一次删除所有 `'a'`，第二次删除所有 `'b'`。由相同字符组成的字符串一定是回文，因此这两个子序列都合法。

又因为字符串本身不是回文，所以不可能只删除一次，答案必然为 `2`。

因此问题最终转化为：**判断整个字符串是否为回文。**

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **初始化左右指针：** 设置 `l = 0`、`r = s.length() - 1`，分别指向字符串两端。
2. **比较对称字符：** 当 `l < r` 时，比较 `s.charAt(l)` 和 `s.charAt(r)` 是否相同。
3. **发现非回文结构：** 如果某一对对称字符不同，说明整个字符串不是回文，不可能一次删除完成。
4. **利用字符种类性质：** 字符串只包含 `'a'` 和 `'b'`，可以分别删除所有 `'a'` 和所有 `'b'`，因此最多需要两次，直接返回 `2`。
5. **继续向中间检查：** 如果当前两个字符相同，则执行 `l++`、`r--` 继续判断下一对字符。
6. **确认整个字符串为回文：** 如果所有对称位置都相同，说明整个字符串本身就是回文子序列。
7. **返回最少删除次数：** 整个字符串可以一次删除，因此返回 `1`。

```java
class Solution {
    public int removePalindromeSub(String s) {
        int l = 0;
        int r = s.length() - 1;
        while(l < r){
            if(s.charAt(l) != s.charAt(r)){
                return 2;
            }
            l++;
            r--;
        }
        return 1;
    }
}
```

由于产品数组已经按照字典序排列，所有以 `pre` 为前缀的产品一定连续出现，因此从 `l` 开始向后检查，最多收集三个满足 `startsWith(pre)` 的产品即可。

如果遇到第一个不满足前缀条件的产品，就可以直接结束扫描，因为后面的产品也不会再属于当前前缀对应的连续区间。

整体思路正确，二分查找部分本质上就是寻找当前前缀的 **lower_bound**。

------

#### 解题步骤

1. **按照字典序排序：** 对 `products` 进行升序排序，使相同前缀的产品连续排列，并保证推荐结果天然满足字典序要求。
2. **依次构造搜索前缀：** 对 `searchWord` 的每个位置 `i`，取前 `i` 个字符组成当前检索前缀 `pre`。
3. **二分查找左边界：** 在排序后的产品数组中寻找第一个字典序大于等于 `pre` 的产品位置 `l`。
4. **从左边界开始匹配：** 从位置 `l` 向右检查产品是否满足 `startsWith(pre)`。
5. **收集最多三个产品：** 如果产品以前缀 `pre` 开头，则加入当前推荐列表，并在数量达到 `3` 时停止。
6. **提前结束连续区间：** 如果遇到第一个不以 `pre` 开头的产品，则说明当前前缀对应的连续区间已经结束，直接停止扫描。
7. **保存当前推荐结果：** 将当前前缀对应的推荐列表加入 `ans`。
8. **返回所有推荐列表：** 所有前缀处理完成后返回二维列表 `ans`。

```java
class Solution {
    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        List<List<String>> ans = new ArrayList<>();
        Arrays.sort(products);
        for(int i = 1; i <= searchWord.length(); i++){
            String pre = searchWord.substring(0, i);
            int l = 0;
            int r = products.length;
            while(l < r){
                int mid = l + (r - l) / 2;
                if(products[mid].compareTo(pre) >= 0){
                    r = mid;
                }else {
                    l = mid + 1;
                }
            }
            List<String> list = new ArrayList<>();
            for (int j = l; j < products.length && list.size() < 3; j++) {
                if (products[j].startsWith(pre)) {
                    list.add(products[j]);
                } else {
                    break;
                }
            }

            ans.add(list);
        }
        return ans;
    }
}
```

### 题解二

#### 思路总结

利用**Trie 前缀树 + 每个节点保存最多 3 个推荐结果**解决搜索推荐系统问题。

首先将 `products` 按照字典序排序，然后依次插入 Trie。每插入一个产品时，沿着产品字符对应的 Trie 路径向下移动，并在经过的每个节点中保存当前产品。

由于产品已经按照字典序插入，因此每个节点只需要保存最先插入的三个产品：

```
if (node.suggestions.size() < 3) {
    node.suggestions.add(word);
}
```

这样节点中的 `suggestions` 天然就是当前前缀下**字典序最小的三个产品**。

查询 `searchWord` 时，从 Trie 根节点按照字符逐层向下：

- 如果对应节点存在，直接取出该节点保存的 `suggestions`。
- 如果对应节点不存在，说明当前前缀没有任何产品匹配，并且之后更长的前缀也一定无法匹配，因此后续结果全部为空列表。

这种方案把推荐结果提前存储在 Trie 节点中，因此每个前缀查询都可以直接获得最多三个推荐产品。

------

#### 解题步骤

1. **定义 Trie 节点：** 每个节点使用 `children[26]` 保存 26 个小写字母对应的子节点，并使用 `suggestions` 保存当前前缀下字典序最小的三个产品。
2. **按照字典序排序产品：** 对 `products` 进行排序，保证后续插入 Trie 的产品顺序本身就是字典序。
3. **逐个插入产品：** 对每个产品从 Trie 根节点开始，按照字符依次创建或进入对应子节点。
4. **记录节点推荐结果：** 每经过一个 Trie 节点，如果其 `suggestions` 数量不足 `3`，就将当前产品加入其中。
5. **从根节点开始查询：** 遍历 `searchWord` 的每个字符，根据字符找到对应的 Trie 子节点。
6. **处理匹配成功情况：** 如果当前节点存在，将节点中的 `suggestions` 复制到当前前缀的答案中。
7. **处理匹配失败情况：** 如果当前节点不存在，则当前以及后续所有更长前缀都无法匹配产品，因此加入空列表。
8. **返回所有推荐结果：** 遍历完整个 `searchWord` 后返回二维列表 `ans`。

```java
class Solution {
    static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        List<String> suggestions = new ArrayList<>();
    }

    TrieNode root = new TrieNode();

    public List<List<String>> suggestedProducts(String[] products, String searchWord) {
        List<List<String>> ans = new ArrayList<>();
        Arrays.sort(products);
        for(String product : products){
            insert(product);
        }
        TrieNode node = root;
        for(char c : searchWord.toCharArray()){
            if(node == null){
                ans.add(new ArrayList<>());
                continue;
            }

            int index = c - 'a';
            node = node.children[index];
            if(node == null){
                ans.add(new ArrayList<>());
            }else {
                ans.add(new ArrayList<>(node.suggestions));
            }
        }
        return ans;
    }

    private void insert(String word){
        TrieNode node = root;

        for(char c : word.toCharArray()){
            int index = c - 'a';

            if(node.children[index] == null){
                node.children[index] = new TrieNode();
            }
            node = node.children[index];

            if(node.suggestions.size() < 3){
                node.suggestions.add(word);
            }
        }
    }
}
```

## [1249. 移除无效的括号](https://leetcode.cn/problems/minimum-remove-to-make-valid-parentheses/)

### 题目

给你一个由 `'('`、`')'` 和小写字母组成的字符串 `s`。

你需要从字符串中删除最少数目的 `'('` 或者 `')'` （可以删除任意位置的括号)，使得剩下的「括号字符串」有效。

请返回任意一个合法字符串。

有效「括号字符串」应当符合以下 **任意一条** 要求：

- 空字符串或只包含小写字母的字符串
- 可以被写作 `AB`（`A` 连接 `B`）的字符串，其中 `A` 和 `B` 都是有效「括号字符串」
- 可以被写作 `(A)` 的字符串，其中 `A` 是一个有效的「括号字符串」

 

**示例 1：**

```
输入：s = "lee(t(c)o)de)"
输出："lee(t(c)o)de"
解释："lee(t(co)de)" , "lee(t(c)ode)" 也是一个可行答案。
```

**示例 2：**

```
输入：s = "a)b(c)d"
输出："ab(c)d"
```

**示例 3：**

```
输入：s = "))(("
输出：""
解释：空字符串也是有效的
```

 

**提示：**

- `1 <= s.length <= 105`
- `s[i]` 可能是 `'('`、`')'` 或英文小写字母

### 题解

#### 思路总结

利用**栈 + 删除位置集合**找出所有必须删除的无效括号。

遍历字符串时：

- 遇到 `'('`，将其下标压入栈，等待后续右括号匹配。
- 遇到 `')'`：
  - 如果栈不为空，则与最近的 `'('` 匹配并弹栈。
  - 如果栈为空，说明当前 `')'` 没有对应的左括号，必须删除。
- 遍历结束后，栈中剩余的所有 `'('` 都没有对应右括号，也必须删除。

最后再次遍历字符串，跳过所有需要删除的位置，其余字符按照原顺序加入结果。

这种方法能够保证只删除无法匹配的括号，因此删除数量最少。整体时间复杂度为 **O(n)**。

------

#### 解题步骤

1. **初始化辅助结构：** 使用 `stack` 保存尚未匹配的左括号下标，使用 `willdelete` 保存最终需要删除的位置。
2. **从左向右遍历字符串：** 依次检查每个字符，并根据括号类型处理匹配关系。
3. **记录左括号位置：** 遇到 `'('` 时，将当前位置下标压入栈中。
4. **处理右括号匹配：** 遇到 `')'` 时，如果栈不为空，则弹出一个左括号完成匹配。
5. **记录多余右括号：** 如果遇到 `')'` 时栈为空，说明没有左括号可以匹配，将当前位置加入 `willdelete`。
6. **处理多余左括号：** 第一次遍历结束后，将栈中所有尚未匹配的左括号位置加入 `willdelete`。
7. **重新构造字符串：** 再次遍历原字符串，只将不属于 `willdelete` 的字符加入 `StringBuilder`。
8. **返回合法结果：** 将 `StringBuilder` 转换成字符串并返回。

```java
class Solution {
    public String minRemoveToMakeValid(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        StringBuilder sb = new StringBuilder();
        Set<Integer> willdelete = new HashSet<>();
        for(int i = 0; i < s.length(); i++){
            if(s.charAt(i) == '('){
                stack.push(i);
            }else if(s.charAt(i) == ')'){
                if(stack.isEmpty()){
                    willdelete.add(i);
                }else {
                    stack.pop();
                }
            }
        }
        while(!stack.isEmpty()){
            willdelete.add(stack.pop());
        }
        for(int i = 0; i < s.length(); i++){
            if(!willdelete.contains(i)){
                sb.append(s.charAt(i));
            }
        }
        return sb.toString();
    }
}
```

## [1234. 替换子串得到平衡字符串](https://leetcode.cn/problems/replace-the-substring-for-balanced-string/)

### 题目

有一个只含有 `'Q', 'W', 'E', 'R'` 四种字符，且长度为 `n` 的字符串。

假如在该字符串中，这四个字符都恰好出现 `n/4` 次，那么它就是一个「平衡字符串」。

 

给你一个这样的字符串 `s`，请通过「替换一个子串」的方式，使原字符串 `s` 变成一个「平衡字符串」。

你可以用和「待替换子串」长度相同的 **任何** 其他字符串来完成替换。

请返回待替换子串的最小可能长度。

如果原字符串自身就是一个平衡字符串，则返回 `0`。

 

**示例 1：**

```
输入：s = "QWER"
输出：0
解释：s 已经是平衡的了。
```

**示例 2：**

```
输入：s = "QQWE"
输出：1
解释：我们需要把一个 'Q' 替换成 'R'，这样得到的 "RQWE" (或 "QRWE") 是平衡的。
```

**示例 3：**

```
输入：s = "QQQW"
输出：2
解释：我们可以把前面的 "QQ" 替换成 "ER"。 
```

**示例 4：**

```
输入：s = "QQQQ"
输出：3
解释：我们可以替换后 3 个 'Q'，使 s = "QWER"。
```

 

**提示：**

- `1 <= s.length <= 10^5`
- `s.length` 是 `4` 的倍数
- `s` 中只含有 `'Q'`, `'W'`, `'E'`, `'R'` 四种字符

### 题解

#### 思路总结

利用**滑动窗口 + 计数**寻找最短的待替换子串。

平衡字符串要求 `'Q'`、`'W'`、`'E'`、`'R'` 都恰好出现 `n / 4` 次，因此真正需要处理的是各字符**超过 `n / 4` 的部分**。

当前代码先统计每种字符的数量，再执行：

```
count[i] -= n / 4;
```

此时：

- `count[i] > 0`：该字符多出了 `count[i]` 个，待替换子串必须至少包含这么多个。
- `count[i] <= 0`：该字符没有多余，不需要强制包含。

随后使用滑动窗口 `[l, r]`。当字符进入窗口时，从对应的 `count` 中减一，相当于用当前窗口去“覆盖”多余字符。

当四个 `count` 都满足：

```
count[i] <= 0
```

说明当前窗口已经包含了所有必须被替换掉的多余字符，因此窗口外的字符数量已经能够满足平衡要求，窗口内部可以任意替换成缺少的字符。此时不断收缩左边界，就能找到最短合法窗口。

整体时间复杂度为 **O(n)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **统计字符数量：** 分别计算 `'Q'`、`'W'`、`'E'`、`'R'` 在整个字符串中的出现次数。
2. **计算多余字符数量：** 每种字符的实际数量减去目标数量 `n / 4`，得到对应字符超出的数量。
3. **判断是否已经平衡：** 如果四种字符都不存在多余数量，则原字符串已经平衡，直接返回 `0`。
4. **初始化滑动窗口：** 设置左边界 `l = 0`，并使用 `ans` 保存最短合法窗口长度。
5. **扩展右边界：** 每次将 `s[r]` 加入待替换窗口，并将该字符对应的剩余多余数量减一。
6. **判断窗口是否合法：** 当四种字符对应的剩余多余数量全部小于等于 `0` 时，说明当前窗口已经覆盖所有必须删除的多余字符。
7. **更新最短窗口：** 使用当前窗口长度 `r - l + 1` 更新 `ans`。
8. **收缩左边界：** 将 `s[l]` 移出窗口，并恢复该字符对应的计数，然后执行 `l++`。
9. **持续寻找最短窗口：** 只要窗口仍然覆盖所有多余字符，就继续收缩左边界。
10. **返回最小长度：** 遍历结束后，`ans` 即为最短待替换子串长度。

```java
class Solution {
    public int balancedString(String s) {
        int[] count = new int[4];
        char[] chars = new char[] {'Q', 'W', 'E', 'R'};
        int n = s.length();

        for(char c : s.toCharArray()){
            for(int i = 0; i < 4; i++){
                if(c == chars[i]){
                    count[i]++;
                    break;
                }
            }
        }

        for(int i = 0; i < 4; i++){
            count[i] -= n / 4;
        }

        // 本身已经平衡
        if(count[0] <= 0 && count[1] <= 0 &&
                count[2] <= 0 && count[3] <= 0){
            return 0;
        }

        int l = 0;
        int ans = n + 1;

        for(int r = 0; r < n; r++){

            // s[r] 加入窗口
            for(int i = 0; i < 4; i++){
                if(s.charAt(r) == chars[i]){
                    count[i]--;
                    break;
                }
            }

            // 当前窗口已经覆盖所有多余字符
            while(count[0] <= 0 && count[1] <= 0 &&
                    count[2] <= 0 && count[3] <= 0){

                ans = Math.min(ans, r - l + 1);

                // s[l] 移出窗口
                for(int i = 0; i < 4; i++){
                    if(s.charAt(l) == chars[i]){
                        count[i]++;
                        break;
                    }
                }

                l++;
            }
        }

        return ans;
    }
}
```

## [1221. 分割平衡字符串](https://leetcode.cn/problems/split-a-string-in-balanced-strings/)

### 题目

**平衡字符串** 中，`'L'` 和 `'R'` 字符的数量是相同的。

给你一个平衡字符串 `s`，请你将它分割成尽可能多的子字符串，并满足：

- 每个子字符串都是平衡字符串。

返回可以通过分割得到的平衡字符串的 **最大数量** **。**

 

**示例 1：**

```
输入：s = "RLRRLLRLRL"
输出：4
解释：s 可以分割为 "RL"、"RRLL"、"RL"、"RL" ，每个子字符串中都包含相同数量的 'L' 和 'R' 。
```

**示例 2：**

```
输入：s = "RLRRRLLRLL"
输出：2
解释：s 可以分割为 "RL"、"RRRLLRLL"，每个子字符串中都包含相同数量的 'L' 和 'R' 。
注意，s 无法分割为 "RL"、"RR"、"RL"、"LR"、"LL" 因为第 2 个和第 5 个子字符串不是平衡字符串。
```

**示例 3：**

```
输入：s = "LLLLRRRR"
输出：1
解释：s 只能保持原样 "LLLLRRRR" 。
```

 

**提示：**

- `2 <= s.length <= 1000`
- `s[i] = 'L' 或 'R'`
- `s` 是一个 **平衡** 字符串

 

### 题解

#### 思路总结

利用**贪心 + 差值计数**解决平衡字符串分割问题。

可以将：

- `'L'` 记为 `+1`
- `'R'` 记为 `-1`

遍历字符串时维护当前子串的差值 `balance`。当：

```
balance == 0
```

说明当前这一段中 `'L'` 和 `'R'` 数量相同，已经形成一个平衡子串。

为了让分割出来的平衡子串数量尽可能多，只要当前前缀第一次达到平衡，就立即进行一次分割。因为越早切分，越不会影响后续继续形成新的平衡子串。

当前代码使用 `c1` 和 `c2` 分别统计 `'L'`、`'R'` 数量，逻辑完全正确。本质上等价于维护一个差值变量。

------

#### 解题步骤

1. **初始化计数变量：** 使用 `c1` 统计当前子串中 `'L'` 的数量，使用 `c2` 统计 `'R'` 的数量。
2. **从左向右遍历字符串：** 依次检查每一个字符。
3. **统计当前字符：** 如果当前字符是 `'L'`，则执行 `c1++`，否则执行 `c2++`。
4. **判断当前子串是否平衡：** 如果 `c1 == c2`，说明从上一个分割点到当前位置形成了一个平衡子串。
5. **增加分割数量：** 找到一个平衡子串后执行 `ans++`。
6. **重新开始统计：** 将 `c1` 和 `c2` 重置为 `0`，从下一个位置开始寻找新的平衡子串。
7. **返回最大数量：** 遍历结束后返回 `ans`。

```java
class Solution {
    public int balancedStringSplit(String s) {
        int c1 = 0;
        int c2 = 0;
        int ans = 0;
        for(char c : s.toCharArray()){
            if(c == 'L'){
                c1++;
            }else {
                c2++;
            }
            if(c1 == c2){
                ans++;
                c1 = 0;
                c2 = 0;
            }
        }
        return ans;
    }
}
```

### 题解

- `'l'`：2 个
- `'o'`：2 个
- `'n'`：1 个

因此每种字符分别能够支持的 `"balloon"` 数量为：

```
count['b']
count['a']
count['l'] / 2
count['o'] / 2
count['n']
```

最终能够组成的单词数量由其中最少的一项决定，所以依次使用 `Math.min()` 取最小值即可。

相比逐个模拟扣除字符，这种方法直接计算结果，更加简洁高效。

------

#### 解题步骤

1. **初始化字符计数数组：** 创建长度为 `26` 的 `count` 数组，用于记录每个小写字母的出现次数。
2. **统计所有字符：** 遍历 `text`，通过 `text.charAt(i) - 'a'` 将字符映射到对应下标并增加计数。
3. **初始化答案：** 使用 `'b'` 的出现次数初始化 `ans`，因为每个 `"balloon"` 需要一个 `'b'`。
4. **计算字符 a 的限制：** 使用 `count['a' - 'a']` 与当前 `ans` 取最小值。
5. **计算字符 l 的限制：** 每个 `"balloon"` 需要两个 `'l'`，因此使用 `count['l' - 'a'] / 2` 更新 `ans`。
6. **计算字符 o 的限制：** 每个 `"balloon"` 需要两个 `'o'`，因此使用 `count['o' - 'a'] / 2` 更新 `ans`。
7. **计算字符 n 的限制：** 使用 `count['n' - 'a']` 与当前 `ans` 取最小值。
8. **返回最终结果：** 最小值就是能够组成 `"balloon"` 的最大数量。

```java
class Solution {
    public int maxNumberOfBalloons(String text) {
        int[] count = new int[26];
        int n = text.length();
        for(int i = 0; i < n; i++){
            count[text.charAt(i) - 'a']++;
        }
        int ans = count['b' - 'a'];
        ans = Math.min(ans, count['a' - 'a']);
        ans = Math.min(ans, count['l' - 'a'] / 2);
        ans = Math.min(ans, count['o' - 'a'] / 2);
        ans = Math.min(ans, count['n' - 'a']);
        return ans;
    }
}
```

## [1170. 比较字符串最小字母出现频次](https://leetcode.cn/problems/compare-strings-by-frequency-of-the-smallest-character/)

### 题目

定义一个函数 `f(s)`，统计 `s` 中**（按字典序比较）最小字母的出现频次** ，其中 `s` 是一个非空字符串。

例如，若 `s = "dcce"`，那么 `f(s) = 2`，因为字典序最小字母是 `"c"`，它出现了 2 次。

现在，给你两个字符串数组待查表 `queries` 和词汇表 `words` 。对于每次查询 `queries[i]` ，需统计 `words` 中满足 `f(queries[i])` < `f(W)` 的 **词的数目** ，`W` 表示词汇表 `words` 中的每个词。

请你返回一个整数数组 `answer` 作为答案，其中每个 `answer[i]` 是第 `i` 次查询的结果。

 

**示例 1：**

```
输入：queries = ["cbd"], words = ["zaaaz"]
输出：[1]
解释：查询 f("cbd") = 1，而 f("zaaaz") = 3 所以 f("cbd") < f("zaaaz")。
```

**示例 2：**

```
输入：queries = ["bbb","cc"], words = ["a","aa","aaa","aaaa"]
输出：[1,2]
解释：第一个查询 f("bbb") < f("aaaa")，第二个查询 f("aaa") 和 f("aaaa") 都 > f("cc")。
```

 

**提示：**

- `1 <= queries.length <= 2000`
- `1 <= words.length <= 2000`
- `1 <= queries[i].length, words[i].length <= 10`
- `queries[i][j]`、`words[i][j]` 都由小写英文字母组成

### 题解

#### 思路总结

利用**频次函数 + 计数桶 + 后缀和**解决问题。先计算每个 `word` 的 `f(word)`，由于字符串长度最多为 `10`，所以 `f(word)` 的范围只有 `1 ~ 10`，可以直接使用数组统计不同频次对应的单词数量。

随后对计数数组计算后缀和，使 `count[x]` 表示满足 `f(word) >= x` 的单词数量。对于查询字符串，设 `x = f(query)`，题目要求统计 `f(query) < f(word)`，等价于统计 `f(word) >= x + 1`，因此答案直接取 `count[x + 1]`。

整体时间复杂度为 **O(Q + W)**，额外空间复杂度为 **O(1)**。

------

#### 解题步骤

1. **初始化频次桶：** 创建 `count` 数组，其中 `count[i]` 用于统计 `f(word) = i` 的单词数量。
2. **统计 words 的频次值：** 遍历 `words`，计算每个字符串的 `f(word)`，并将对应位置的计数加一。
3. **计算后缀和：** 从较大的频次向较小的频次累加，使 `count[i]` 表示 `f(word) >= i` 的单词数量。
4. **遍历所有查询：** 对每个 `queries[i]` 计算其最小字符出现次数 `f(queries[i])`。
5. **查询严格更大频次：** 如果查询频次为 `x`，则满足条件的单词必须满足 `f(word) >= x + 1`，因此答案为 `count[x + 1]`。
6. **保存查询结果：** 将每次查询得到的数量写入 `ans[i]`。
7. **返回最终答案：** 所有查询处理完成后返回 `ans`。

```java
class Solution {
    public int[] numSmallerByFrequency(String[] queries, String[] words) {
        int length = queries.length;
        int[] count = new int[12];
        for (String word : words) {
            count[f(word)]++;
        }
        for(int i = 9; i > 0; i--){
            count[i] += count[i+1];
        }
        int[] ans = new int[length];
        for(int i = 0; i < length; i++){
            ans[i] = count[f(queries[i]) + 1];
        }
        return ans;
    }

    private int f(String s){
        int[] count = new int[26];
        for(char c : s.toCharArray()){
            count[c - 'a']++;
        }
        for(int i : count){
            if (i != 0){
                return i;
            }
        }
        return 0;
    }
}
```

## [1003. 检查替换后的词是否有效](https://leetcode.cn/problems/check-if-word-is-valid-after-substitutions/)

### 题目

给你一个字符串 `s` ，请你判断它是否 **有效** 。

字符串 `s` **有效** 需要满足：假设开始有一个空字符串 `t = ""` ，你可以执行 **任意次** 下述操作将 `t` **转换为** `s` ：

- 将字符串 `"abc"` 插入到 `t` 中的任意位置。形式上，`t` 变为 `tleft + "abc" + tright`，其中 `t == tleft + tright` 。注意，`tleft` 和 `tright` 可能为 **空** 。

如果字符串 `s` 有效，则返回 `true`；否则，返回 `false`。

 

**示例 1：**

```
输入：s = "aabcbc"
输出：true
解释：
"" -> "abc" -> "aabcbc"
因此，"aabcbc" 有效。
```

**示例 2：**

```
输入：s = "abcabcababcc"
输出：true
解释：
"" -> "abc" -> "abcabc" -> "abcabcabc" -> "abcabcababcc"
因此，"abcabcababcc" 有效。
```

**示例 3：**

```
输入：s = "abccba"
输出：false
解释：执行操作无法得到 "abccba" 。
```

 

**提示：**

- `1 <= s.length <= 2 * 104`
- `s` 由字母 `'a'`、`'b'` 和 `'c'` 组成

### 题解

#### 思路总结

利用**数组模拟栈 + 局部消除 `"abc"`**。先判断字符串长度是否为 `3` 的倍数，因为每次合法操作都会增加 3 个字符，不满足时一定无效。随后从左向右遍历字符串，`'a'`、`'b'` 暂时压入栈中；遇到 `'c'` 时，检查栈顶两个字符是否依次为 `'a'`、`'b'`，如果满足，就与当前 `'c'` 一起组成 `"abc"` 并消除。

这种方法相当于不断执行构造过程的逆操作 `"abc" -> ""`。如果所有字符最终都能够被消除，栈的大小会变成 `0`，字符串有效。整体时间复杂度为 **O(n)**，空间复杂度为 **O(n)**。

不过当前代码存在一个正确性问题：遇到 `'c'` 时，如果栈顶不是 `"ab"`，当前代码既没有返回 `false`，也没有保存这个 `'c'`，相当于直接把非法的 `'c'` 丢掉了，可能产生错误结果。

------

#### 解题步骤

1. **判断字符串长度：** 如果字符串长度不能被 `3` 整除，则不可能通过不断插入 `"abc"` 得到，直接返回 `false`。
2. **初始化模拟栈：** 创建字符数组 `stack`，使用 `size` 表示当前栈中有效字符数量。
3. **处理字符 a：** 遇到 `'a'` 时直接压入栈中，等待后面的 `'b'` 和 `'c'` 与其组成 `"abc"`。
4. **处理字符 b：** 遇到 `'b'` 时同样压入栈中，后续由 `'c'` 判断栈顶是否形成 `"ab"`。
5. **处理字符 c：** 遇到 `'c'` 时检查栈中是否至少有两个字符，并判断栈顶两个字符是否依次为 `'a'`、`'b'`。
6. **消除合法 abc：** 如果栈顶为 `"ab"`，则将 `size` 减少 `2`，表示栈顶的 `'a'`、`'b'` 与当前 `'c'` 一起被消除。
7. **发现非法结构：** 如果当前字符为 `'c'` 但栈顶不能形成 `"ab"`，则当前字符串无法完全消除，直接返回 `false`。
8. **判断最终状态：** 遍历结束后，如果 `size == 0`，说明所有字符都被完整消除，返回 `true`。

```java
class Solution {
    public boolean isValid(String s) {
        if (s.length() % 3 != 0) {
            return false;
        }

        char[] stack = new char[s.length()];
        int size = 0;

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if(c == 'c'){
                if(size < 2){
                    return false;
                }else {
                    if(stack[size - 1] == 'b' && stack[size - 2] == 'a'){
                        size -= 2;
                    }
                }
            }else if(c == 'b'){
                if(size < 1){
                    return false;
                }else {
                    stack[size] = 'b';
                    size++;
                }
            }else {
                stack[size] = 'a';
                size++;
            }
        }
        return size == 0;
    }
}
```

## [966. 元音拼写检查器](https://leetcode.cn/problems/vowel-spellchecker/)

### 题目

在给定单词列表 `wordlist` 的情况下，我们希望实现一个拼写检查器，将查询单词转换为正确的单词。

对于给定的查询单词 `query`，拼写检查器将会处理两类拼写错误：

- 大小写：如果查询匹配单词列表中的某个单词（**不区分大小写**），则返回的正确单词与单词列表中的大小写相同。
  - 例如：`wordlist = ["yellow"]`, `query = "YellOw"`: `correct = "yellow"`
  - 例如：`wordlist = ["Yellow"]`, `query = "yellow"`: `correct = "Yellow"`
  - 例如：`wordlist = ["yellow"]`, `query = "yellow"`: `correct = "yellow"`
- 元音错误：如果在将查询单词中的元音`('a', 'e', 'i', 'o', 'u')`分别替换为任何元音后，能与单词列表中的单词匹配（**不区分大小写**），则返回的正确单词与单词列表中的匹配项大小写相同。
  - 例如：`wordlist = ["YellOw"]`, `query = "yollow"`: `correct = "YellOw"`
  - 例如：`wordlist = ["YellOw"]`, `query = "yeellow"`: `correct = ""` （无匹配项）
  - 例如：`wordlist = ["YellOw"]`, `query = "yllw"`: `correct = ""` （无匹配项）

此外，拼写检查器还按照以下优先级规则操作：

- 当查询完全匹配单词列表中的某个单词（**区分大小写**）时，应返回相同的单词。
- 当查询匹配到大小写问题的单词时，您应该返回单词列表中的第一个这样的匹配项。
- 当查询匹配到元音错误的单词时，您应该返回单词列表中的第一个这样的匹配项。
- 如果该查询在单词列表中没有匹配项，则应返回空字符串。

给出一些查询 `queries`，返回一个单词列表 `answer`，其中 `answer[i]` 是由查询 `query = queries[i]` 得到的正确单词。

 

**示例 1：**

```
输入：wordlist = ["KiTe","kite","hare","Hare"], queries = ["kite","Kite","KiTe","Hare","HARE","Hear","hear","keti","keet","keto"]
输出：["kite","KiTe","KiTe","Hare","hare","","","KiTe","","KiTe"]
```

**示例 2:**

```
输入：wordlist = ["yellow"], queries = ["YellOw"]
输出：["yellow"]
```

 

**提示：**

- `1 <= wordlist.length, queries.length <= 5000`
- `1 <= wordlist[i].length, queries[i].length <= 7`
- `wordlist[i]` 和 `queries[i]` 只包含英文字母

### 题解

#### 思路总结

利用**三层哈希结构 + 规范化字符串**按照题目要求的优先级处理匹配。预处理 `wordlist` 时，分别建立完全匹配集合 `exact`、忽略大小写映射 `lowerMap` 和忽略元音差异映射 `vowelMap`。

其中 `lowerMap` 和 `vowelMap` 使用 `putIfAbsent()`，因此同一种规范化形式存在多个候选单词时，只会保存 `wordlist` 中最先出现的那个，恰好满足题目要求。查询时按照 **完全匹配 → 大小写匹配 → 元音匹配 → 无匹配** 的顺序处理，不需要再遍历候选列表，整体效率很高。

------

#### 解题步骤

1. **建立完全匹配集合：** 将 `wordlist` 中每个原始单词加入 `exact`，用于判断区分大小写的完全匹配。
2. **生成小写形式：** 将每个单词转换为小写字符串 `lower`，作为忽略大小写匹配的键。
3. **生成元音掩码：** 将 `lower` 中的元音统一替换成 `'*'`，得到 `mask`。
4. **保存首个大小写匹配：** 使用 `lowerMap.putIfAbsent(lower, word)` 保留同一小写形式下最先出现的原始单词。
5. **保存首个元音匹配：** 使用 `vowelMap.putIfAbsent(mask, word)` 保留同一元音模式下最先出现的原始单词。
6. **优先检查完全匹配：** 如果 `exact` 中存在原查询字符串，直接返回查询本身。
7. **检查大小写匹配：** 将查询转换为小写形式，如果 `lowerMap` 中存在对应键，则返回第一个匹配单词。
8. **检查元音错误匹配：** 将查询转换为元音掩码，如果 `vowelMap` 中存在对应键，则返回对应单词。
9. **处理无匹配情况：** 如果三种规则均未匹配，则返回空字符串。

```java
class Solution {
    public String[] spellchecker(String[] wordlist, String[] queries) {
        Set<String> exact = new HashSet<>();
        Map<String, String> lowerMap = new HashMap<>();
        Map<String, String> vowelMap = new HashMap<>();

        for (String word : wordlist) {
            exact.add(word);

            String lower = word.toLowerCase();
            String mask = mask(lower);

            lowerMap.putIfAbsent(lower, word);
            vowelMap.putIfAbsent(mask, word);
        }

        String[] ans = new String[queries.length];

        for (int i = 0; i < queries.length; i++) {
            String query = queries[i];

            if (exact.contains(query)) {
                ans[i] = query;
                continue;
            }

            String lower = query.toLowerCase();

            if (lowerMap.containsKey(lower)) {
                ans[i] = lowerMap.get(lower);
                continue;
            }

            String mask = mask(lower);
            ans[i] = vowelMap.getOrDefault(mask, "");
        }

        return ans;
    }

    private String mask(String s) {
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);

            if (isVowel(c)) {
                sb.append('*');
            } else {
                sb.append(c);
            }
        }

        return sb.toString();
    }

    private boolean isVowel(char c) {
        return c == 'a' || c == 'e' || c == 'i'
                || c == 'o' || c == 'u';
    }
}
```
